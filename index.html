Containerization is a Swift package for running Linux containers on macOS

作者: gok | 评分: 264 | 评论数: 26 | 发布时间: 2025-06-09 20:53
文章摘要

Apple的Containerization是一个Swift包，用于在macOS上运行Linux容器。它利用Virtualization.framework，支持管理OCI镜像、与远程注册表交互、创建ext4文件系统、管理轻量级虚拟机和容器化进程等功能。该项目通过优化Linux内核和最小根文件系统实现快速启动，并支持使用Rosetta 2在Apple Silicon上执行x86_64进程。主要要求包括使用Apple Silicon和较新的macOS及Xcode版本。对于预编译内核，需包含VIRTIO驱动。用户可参考Kata Containers项目获取优化的内核镜像。构建包前需安装Swiftly、Swift和Static Linux SDK。
