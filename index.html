文章摘要

Zoekt 是一个基于 trigram 的快速代码搜索引擎，支持子字符串和正则表达式匹配，具有丰富的查询语言和布尔运算符。它能够搜索单个代码库或跨多个仓库，并利用代码相关信号（如符号匹配）进行结果排序。Zoekt 提供两种主要使用方式：通过命令行工具进行本地索引和搜索，或通过 indexserver 和 webserver 服务实现大规模代码托管和搜索。安装后，用户可以索引本地 Git 仓库或目录，并通过命令行或 Web UI 进行搜索。此外，Zoekt 还支持 GitHub 组织的自动索引，并提供 JSON API 和 gRPC API 用于高级搜索功能。
