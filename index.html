A new book recovers the origins of Effective Altruism

作者: Thevet | 评分: 18 | 评论数: 2 | 发布时间: 2025-11-17 17:37
文章摘要

本文主要讲述了有效利他主义（Effective Altruism，简称EA）的起源与发展。该运动由牛津大学哲学家彼得·辛格（Peter Singer）的思想实验启发，核心观点是：如果人们有能力以微小代价防止重大苦难发生，就有道德义务采取行动。2009年，牛津哲学家托比·奥德（Toby Ord）和威尔·麦卡斯基尔（Will MacAskill）创立了“尽力施与”（Giving What We Can）等组织，推动人们将收入的10%捐赠给高效慈善机构，并优化职业选择以最大化社会影响。 然而，EA在发展过程中出现极端案例（如过度捐赠导致自身贫困）和争议事件（如加密货币富豪山姆·班克曼-弗里德的欺诈案），甚至衍生出技术法西斯主义、生育主义等分支，偏离了最初改善全球贫困的初衷。哲学家戴维·埃德蒙兹（David Edmonds）指出，EA从一开始就兼具学术性与行动性，但其规模化过程中不可避免地面临理想与现实的分歧。 （199字）

这篇文章探讨了美国经济中两种有趣现象：杰文斯悖论（Jevons Paradox）和鲍莫尔效应（Baumol Effect）。前者指生产效率提升反而导致需求激增（如计算机芯片价格暴跌却带来用量万亿倍增长），后者指低效率行业的服务价格因劳动力市场竞争被迫上涨（如空调维修费比空调本身更贵）。作者认为，当前AI投资热潮将同时强化这两种效应：AI能大幅提升效率的领域会出现价格暴跌和需求暴增，而难以被AI替代的领域（如人工服务）价格将飙升。这种现象甚至可能出现在同一职业内部——自动化部分效率倍增，而必须由人工完成的部分反而成为高薪核心。

WebTransport is almost here to allow UDP-like exchange in the browser

作者: BinaryIgor | 评分: 32 | 评论数: 3 | 发布时间: 2025-11-05 08:38
文章摘要

WebTransport API 是基于HTTP/3的新型通信协议，旨在替代WebSockets。它支持双向、多路复用、无序和可靠的流传输，以及类似UDP的不可靠数据报传输。相比TCP，HTTP/3通过QUIC协议解决了队头阻塞、网络切换和性能问题。该API只能在HTTPS环境下使用，通过`WebTransport()`构造函数建立连接，提供`datagrams`属性处理不可靠传输，以及`readable`和`writable`流进行可靠通信。适用于需要高性能、低延迟的应用场景，如游戏和实时通信。

评论摘要
主要讨论点：[WebTransport技术的优缺点及其与WebSocket的关系] 不同观点： • [支持WebTransport但担忧其定位] - mort96认为WebTransport很酷，但反对将其视为WebSocket的替代品 - 指出WebSocket在需要可靠双向通信时仍是首选方案 - 批评WebTransport强制HTTPS限制阻碍了本地应用场景 • [关注实现成熟度] - rustyconover质疑缺乏服务端实现 - 暗示技术落地面临实际困难 • [质疑设计决策] - ktpsns批评没有扩展现有WebSocket API - 指出HTTP/3专属设计导致需要额外抽象层来实现向后兼容 - 认为这种设计增加了开发复杂度 补充讨论： - 争议焦点集中在： 1) WebTransport是否应该/能够取代WebSocket 2) HTTPS强制要求的合理性 3) 专属HTTP/3设计的代价 - 讨论反映出新技术推广需要平衡：功能创新 vs 向后兼容，安全性 vs 灵活性
