More honey bees dying, even as antibiotic use halves

作者: pseudolus | 评分: 60 | 评论数: 11 | 发布时间: 2025-07-29 19:37
文章摘要

尽管加拿大限制了养蜂业中抗生素的使用，蜜蜂的死亡率仍在上升。一项由圭尔夫大学研究人员主导的研究发现，随着抗生素使用减半，蜜蜂的越冬死亡率反而从不到20%上升到超过40%。研究表明，抗生素的减少可能导致蜜蜂对致病微生物的抵御能力下降，因为它们的微生物群受到破坏。此外，二氧化氮（NO2）污染也被发现是蜜蜂死亡率上升的一个意外因素，因为它干扰了蜜蜂的觅食能力。研究人员呼吁采用“同一健康”方法，综合考虑人类、动物和环境健康，寻找替代抗生素的解决方案，如益生菌。目前，加拿大正在开展一个全国性项目，研究蜜蜂的微生物群以应对这一问题。

评论摘要
主要讨论点：蜜蜂、抗生素使用及其对生态的影响 不同观点： • JumpCrisscross认为，蜜蜂并非北美原生物种，它们在与本土授粉者（如大黄蜂）的竞争中占据优势，导致生物多样性下降。此外，工业化农业更倾向于使用蜜蜂授粉，这进一步影响本土物种的生存。[1][2][3][4] • smithkl42对一句话表示困惑，认为抗生素在研究中的作用不应被误解为负面影响，尽管抗生素有复杂的长期影响，但在研究中其正面作用是显而易见的。 • mushroomba指出，现代养蜂实践类似于工厂化农业，并提到Tim Rowe的养蜂方法利用进化来改善蜜蜂活力，但由于自身对蜂蜇过敏，无法亲自实践，并对商业养蜂的可持续性表示担忧。[1] • horacemorace对夏季风挡玻璃上不再有虫渍的现象表示担忧，暗示这一变化可能带来巨大的生态影响。 • alionski呼吁业界和政府应同等重视野生蜜蜂的减少问题，并指出“拯救蜜蜂”应针对野蜂，而非作为“牲畜”的蜜蜂。 • imzadi认为，如果养蜂人通过抗生素保持蜜蜂健康，停止使用抗生素可能导致蜜蜂健康状况下降，因为抗生素可能已经杀死了有益菌。 • endo_bunker指出，抗生素使用与蜂群死亡的关联可能是因为抗生素主要用于不健康的蜂群。 • animitronix和more_corn认为，问题主要在于农药而非抗生素。 补充讨论： • 争议的焦点之一是蜜蜂（尤其是蜜蜂与本土授粉者）在生态系统中的角色及其对生物多样性的影响。 • 另一个讨论点是抗生素在蜜蜂养殖中的使用及其潜在影响，包括抗生素对蜜蜂健康的长远影响和抗生素是否被过度使用或不当使用。 • 农药对蜜蜂及其他授粉者的影响也是讨论的重点之一，部分评论者认为这是比抗生素更严重的问题。

Playing with Open Source LLMs

作者: zer0tonin | 评分: 36 | 评论数: 4 | 发布时间: 2025-07-29 18:36
文章摘要

文章摘要

**PR Quiz** 是一个 GitHub Action，利用 AI 根据 pull request 生成测验，帮助开发者检验对代码的理解。它要求用户拥有 OpenAI API Key 和 ngrok 认证 token，并在 GitHub 仓库中设置为 secrets。当 pull request 通过审核后，系统会触发测验生成，并在临时 web 服务器上通过 ngrok 提供访问。测验有时间限制和尝试次数限制，还可以排除特定文件。该工具确保代码不会发送给第三方，仅与 OpenAI 模型交互，也可修改为支持自托管模型。
