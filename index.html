评论摘要

文章介绍了 `datasette-apps`：在 Datasette 中以受限 `iframe` 运行自包含的 HTML/JavaScript 应用，可安全访问只读 SQL，配合存储查询也能写入。核心创新是结合 `sandbox`、CSP、`postMessage`/`MessageChannel`，在保护敏感数据的同时开放受控能力。作者认为这把轻量前端与持久化数据库结合，能显著扩展 Datasette 的应用场景。

评论摘要
主要讨论点：关于 datasette 及其生态系统中 SQLite 驱动的 Web 应用开发方向 不同观点： • **传统框架倡导者（euroderf）**：主张应该有简化框架让 SQLite 数据库轻松嵌入 HTML 页面，通过 WASM 实现全客户端方案，强调 SQLite 的轻量和稳定性 • **现有工具实践者（anitil, joren-）**：分享了实际使用经验，anitil 用 datasette 的 JSON 端点方案，joren- 开发了 Pihka 项目实现数据与展示一体化的定制应用 • **安全担忧者（jacobgold）**：肯定浏览器的安全特性进步，但对 HTML 解析和属性过滤仍存警惕，建议使用 Fable 等工具增强测试覆盖 • **AI 工程质疑者（sumitkumar）**：发现项目有 119 个仓库，质疑这是否为"AI 代码垃圾"，认为可能是为 AI Agent 设计而非人类维护 • **自组装应用倡导者（hankbond）**：提出"自组装软件"概念，开发 uix 项目专注人机交互式 HTML 应用，认为这代表"个人计算"新时代 补充讨论： xgulfie 批评术语"datasette"被过度使用。多位开发者不约而同探索 SQLite + HTML 的融合方案，显示这一技术方向正成为共识。
