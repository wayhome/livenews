展开评论摘要

CLIFT: Conformal Self-Verification for Web Agent Training and Test-Time Scaling

Yifan Zhang, Yutong Dai, Viraj Prabhu, Zhiyuan Hu, Ran Xu, Zeyuan Chen · cs.CL · 提交日期: 2026-10-05
展开中文摘要

开源 Web 智能体如今已经足够强大，能够执行真实的浏览器任务，但使用强化学习训练它们仍然依赖较弱的监督信号：二元任务成功信号过于稀疏，不利于信用分配；而前沿语言模型评判器的调用成本过高，无法在每一步都调用，并且不能假设其在部署时可用。我们提出 CLIFT，这是一种围绕保序自验证（conformal self-verification）构建的训练与测试时扩展方法。 在训练期间，智能体针对自身执行轨迹回答自然语言验证问题；组合式保序认证器（Compositional Conformal Certifier）仅保留其 URL 条件证据与训练时评判器一致的问题信号，通过感知极性的提升度（polarity-aware lift）分配带符号的信任权重，并将所得验证器得分融合到逐步奖励中，同时确保该过程不会减去评判器基线。在测试时，相同的认证问题库被冻结，并作为结构化证据用于保序轨迹选择（Conformal Trajectory Selection，CTS）：智能体采样一条贪心执行轨迹以及一条或多条具有多样性的重试轨迹，自验证器对每条 URL 轨迹进行总结，然后通过一种保守的多数投票规则决定是否放弃当前的候选轨迹，而无需调用任何外部评判器。 这一单一机制支持三种设置。在 WebArena Infinity 上，CLIFT 在开源 Web 智能体中取得了当前最优性能。在 VisualWebArena 上，使用开源模型训练的问题库能够在测试时迁移到 GPT-5.5，并在标准评测框架下达到当前最优性能。在 Online Mind2Web 上，在未针对该基准训练智能体的情况下，对认证问题库进行翻译即可在零样本评估中提升一个真实在线 Web 智能体的性能。 总体而言，这些结果表明，保序自验证能够将代价高昂的评判器反馈转化为可复用的训练信号，以及一种无需评判器的测试时扩展信号。
