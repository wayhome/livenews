Transformer neural net learns to run Conway's Game of Life just from examples

作者: montebicyclelo | 评分: 28 | 评论数: 4 | 发布时间: 2025-05-17 09:31
文章摘要

本文介绍了一种简化的Transformer神经网络——SingleAttentionNet，能够通过训练学会完美计算康威的“生命游戏”。该模型利用其注意力机制模拟3x3卷积，以计算每个细胞的邻域，从而决定细胞的生死状态。实验表明，该模型并非基于统计预测，而是真正计算生命游戏的演化规则。通过随机生成生命网格提供训练数据，模型在GPU上训练数分钟即可收敛，最大成功训练网格尺寸为16x16。当使用手动计算的邻域注意力矩阵或3x3平均池化层时，模型学习速度更快并能泛化到任意网格尺寸。实验还发现，仅训练初期迭代不足以使模型完全掌握游戏规则，需结合第一和第二次迭代训练。

JavaScript's New Superpower: Explicit Resource Management

作者: olalonde | 评分: 121 | 评论数: 20 | 发布时间: 2025-05-17 05:23
文章摘要

《显式资源管理》提案介绍了一种管理资源生命周期的确定性方法，包括文件句柄、网络连接等。该提案引入以下内容： 1. `using`和`await using`声明，用于在资源超出作用域时自动调用其`dispose`方法。 2. `[Symbol.dispose]()`和`[Symbol.asyncDispose]()`符号，分别用于同步和异步资源的清理操作。 3. `DisposableStack`和`AsyncDisposableStack`对象，用于聚合可清理资源。 4. `SuppressedError`类型，用于处理资源清理时出现的错误，避免掩盖其他错误。 这些新增功能使开发者能更精细地控制资源管理，提高代码的健壮性和可维护性。例如，处理`ReadableStreamDefaultReader`时，常需确保调用`reader.releaseLock()`以解锁流。通过`using`声明，可以自动调用`releaseLock()`，避免手动处理。未来，这些符号可能直接集成到Web API中，进一步简化开发。

本文描述了Oracle VirtualBox中的一个高危漏洞，该漏洞存在于VGA设备的`vmsvga3dSurfaceMipBufferSize`函数中。攻击者可以利用整数溢出漏洞，操纵内存分配，实现从虚拟机逃逸并在主机上执行任意代码。漏洞利用过程涉及通过操纵`VMSVGAGBO`和`VMSVGAMOB`结构体，实现对内存的线性读写，并最终通过破坏函数指针控制程序执行流，绕过地址空间布局随机化（ASLR）并执行shellcode。目前，7.1.6版本受此漏洞影响，且尚未发布补丁。

本文讨论了如何利用AI（特别是Google的Gemini模型）将自然语言转换为SQL查询（即文本到SQL技术），以提高开发人员和分析人员的工作效率，并让非技术用户也能直接与数据库交互。文中介绍了Google Cloud中的多种文本到SQL应用，如BigQuery Studio、SQL Editor、SQL Generation工具以及AlloyDB AI等。 尽管像Gemini 2.5这样的先进大型语言模型（LLM）能够处理复杂的SQL查询，但面对真实世界的数据库和用户问题时，仍面临挑战，包括： 1. **提供业务特定上下文**：模型需要了解数据库的模式和业务语义，但为每个数据库进行专门训练既昂贵又不实际。 2. **理解用户意图**：自然语言存在歧义，模型可能会生成不准确的查询，尤其是在处理模糊问题时。 为了应对这些挑战，需要进一步研究如何有效构建上下文、检索表格以及评估文本到SQL的质量。

文章摘要

Popcorn 是一个允许在浏览器中运行 Elixir 代码的库，通过客户端 AtomVM 运行时执行编译后的 Elixir 代码。它提供了 Elixir 与 JavaScript 互操作的 API，处理序列化、通信以及保持浏览器响应。 ### 主要功能： 1. **执行环境**：通过 WebAssembly（WASM）在浏览器中运行 Elixir。 2. **API**：提供 JS 和 Elixir 之间的消息传递机制。 3. **示例**：包括 Elixir REPL、文档交互示例和生命游戏模拟。 ### 使用步骤： 1. **添加依赖**：在 `mix.exs` 中添加 `{:popcorn, "~> 0.1"}`。 2. **构建运行时**：运行 `mix popcorn.build_runtime` 生成 WASM 和 JS 库。 3. **HTML 配置**：在 HTML 文件中引入生成的 JS 文件。 4. **Elixir 入口**：定义一个永不退出的 `start/0` 函数，并通过 `Popcorn.Wasm.send_elixir_ready` 通知 JS。 ### API 详解： - **JS API**：`Popcorn.init()` 初始化，`call()` 和 `cast()` 用于发送消息到 Elixir。 - **Elixir API**：`Popcorn.Wasm.send_elixir_ready()` 通知 JS 初始化完成。 ### 注意事项： 该库仍在开发中，API 不稳定，部分功能未实现。详细限制见文档。 通过 Popcorn，开发者可以在浏览器中运行 Elixir 代码并与 JS 交互。
