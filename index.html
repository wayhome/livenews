文章摘要

**uv** 是一个用 Rust 编写的高速 Python 包和项目管理工具，能够替代 pip、pipx、poetry、pyenv 等多个工具。它具有以下特点： 1. **速度快**：比 pip 快 10-100 倍。 2. **项目管理**：支持锁文件、工作区等功能，类似于 rye 或 poetry。 3. **依赖管理**：支持内联依赖元数据，可管理单文件脚本的依赖。 4. **Python 版本管理**：安装和管理多个 Python 版本。 5. **工具执行和安装**：类似 pipx，可运行和安装 Python 包提供的命令行工具。 6. **跨平台**：支持 macOS、Linux 和 Windows。 7. **高效磁盘空间使用**：通过全局缓存进行依赖去重。 安装可通过 curl 或 pip 进行，文档可在 [docs.astral.sh/uv](https://docs.astral.sh/uv) 查看。
