文章摘要

kage 是一个网站离线克隆工具，可将网站完整保存到本地供离线浏览，并自动移除所有 JavaScript 代码。它使用真实的 Chrome 浏览器渲染页面，等待页面完全加载后保存 DOM 快照，然后删除脚本并下载 CSS、图片、字体到本地。核心功能包括：clone（克隆网站）、serve（本地预览）、pack（打包成单个 ZIM 文件或可执行文件）、open（打开打包文件）。支持自动遵守 robots.txt、从 sitemap.xml 抓取、断点续传等特性。适用于保存需要长期访问的网页内容，避免因 JS 失效或网站下线而无法查看。

评论摘要
主要讨论点：关于 kage（网站离线归档工具）的功能、使用场景和技术实现的讨论 不同观点： • **支持者观点**：认为该工具对离线访问很有用，特别是在飞机上、网络覆盖差的地点、或需要保存公司 wiki 文档时。多位用户表示会尝试使用 • **质疑静态服务器的必要性**：有用户指出既然结果是静态的，为什么需要服务器进程？建议直接用浏览器打开文件，这样在没有安装 kage 的机器上也能使用 • **替代方案推荐者**：部分用户推荐其他工具更优，如 SingleFile（打包成单个 HTML 文件，方便传输）、httrack、RSS 订阅等。有人提到"丑陋的 HTML 存档"比"完美归档"更实用 • **技术安全关切**：有开发者注意到项目使用了 `--no-sandbox` 启动 Chrome，从安全角度质疑这个设计选择 补充讨论： 用户还关注一些实际问题：如何避免对目标网站造成过大负载、能否只抓取网站子集、是否支持复杂网站（如 Apple Docs）。有人建议结合 mitmproxy 提高归档保真度，也有人询问与类似工具 gwtar 的对比。另有技术讨论涉及 demo GIF 的生成方式。

Chaosnet (1981)

文章摘要

Chaosnet是1975年由MIT人工智能实验室开发的局域网系统，用于连接地理位置相近的计算机群。其名称来源于缺乏中央控制元素的设计理念。最初为Lisp Machine系统开发，后扩展到MIT及其他研究机构的多种设备。 系统设计目标是简洁性和高性能。通过高速传输介质和简单协议实现快速响应和高吞吐量，而非复杂算法。硬件采用类似Xerox PARC以太网的载波侦听多路访问结构，使用同轴电缆作为物理介质。软件定义了基于数据包的高层协议。 Chaosnet专注于局域网应用，不处理长距离传输、低速链路等复杂场景，适用于文件系统访问、打印机等共享资源的连接。

评论摘要
主要讨论点：Chaosnet网络协议的历史和技术特性 不同观点： • **技术细节探讨**：peter_d_sherman详细引用了Chaosnet的物理传输介质规格，认为这是构建"基于第一原理"的最简单局域网实验系统，强调其作为早期以太网类系统的价值 • **协议关联疑问**：ale42提出技术问题，询问Chaosnet是否与IP数据包中协议号0x10的CHAOS协议相同，寻求协议层面的澄清 • **硬件兼容性**：karlgkk以兴奋的语气指出可以在Chaosnet上使用Space Cadet键盘，关注历史硬件的兼容性 • **命名辨析**：inigyou提醒不要将Chaosnet与Chaos VPN混淆，后者是Chaos Computer Club用于连接网络的dn42前身，强调两者是完全不同的系统 补充讨论：评论区整体呈现出对早期网络技术的考古兴趣，dang的置顶评论列出了该主题在HN上的多次讨论历史（2013-2023年间7次），显示这是一个持续引起社区关注的话题。讨论氛围偏向技术怀旧和知识分享，没有明显争议。
