A hackable AI assistant using a single SQLite table and a handful of cron jobs

文章摘要

本文介绍了一个名为Stevens的简易AI助理，它通过单个SQLite表和几个cron任务实现，托管在Val.town平台上。Stevens每天早上通过Telegram发送日程、天气、邮件和提醒等信息，用户还可以随时通过Telegram与其互动。Stevens的架构非常简单，核心是一个记录信息的“笔记本”，即SQLite表，数据来自Google Calendar、天气API、USPS邮件扫描和Telegram消息等。该系统易于扩展，通过cron任务定期更新信息，并使用Claude API生成每日简报。这种简单的记忆系统和广泛的信息来源结合，使Stevens成为一个实用且有趣的个人助理工具。

Show HN: Zero-codegen, no-compile TypeScript type inference from Protobufs

作者: 18nleung | 评分: 44 | 评论数: 8 | 发布时间: 2025-04-14 15:41
文章摘要

`protobuf-ts-types` 是一个用于从 Protobuf `message` 自动推断 TypeScript 类型的工具，无需代码生成和编译。它通过利用 TypeScript 的模板字面量类型实现类型推断，支持从 Protobuf 定义的 `message` 结构中提取类型信息。用户可以在 TypeScript 中直接使用这些推断出的类型，并获得类型检查的支持。该工具目前处于概念验证阶段，存在一些限制，例如不支持 `service`、`rpc`、`oneof`、`map` 以及 `import` 等特性。使用时需要通过 npm 安装，并将 Protobuf 定义作为字符串传递给工具进行类型推断。

评论摘要
主要讨论点：TypeScript 中 tagged template literals 的类型推断及其在 protobuf 模式定义中的应用 不同观点： • **支持类型推断和语法增强**：[spankalee] 认为，如果 TypeScript 能够为 tagged template literals 添加类型推断功能，将极大提升开发体验。例如，可以在 `proto` 模板中自动推断出类型，并实现内置的模式验证，同时改善语法高亮显示。这种功能特别适用于像 lit-html 这样的库，能够实现类型安全的模板，而无需外部工具。 • **对 TypeScript 复杂性的反思**：[mubou] 对目前通过类型系统实现复杂功能的趋势表示惊讶和质疑。他认为，将 TypeScript 类型系统用作图灵完备的元语言是一种“曲线救国”的方式，而不是直接使用一种静态类型的语言替代 JavaScript。这种做法虽然强大，但可能导致不必要的复杂性。 • **对实际应用的质疑**：[recursive] 指出，当前方案要求将 `.proto` 文件的声明内联在源码中，而 TypeScript 不支持导入非 JavaScript 内容，这意味着需要额外的构建工具或手动同步 `.proto` 文件，从而削弱了该方案的实用性。相比之下，传统的代码生成方式可能更加直接。 • **对性能和工具的担忧**：[jillyboel] 认为该方案可能存在性能问题，并倾向于坚持使用代码生成工具。而 [tim1994] 也表达了类似观点，认为除非是作为一种玩具项目，否则在多语言数据交换场景中，直接使用 protobuf 工具链更为合理。 补充讨论： • **未来改进的可能性**：[porridgeraisin] 提到，一旦相关 TypeScript 问题解决，该方案将能够从文件中解析模板，从而提升其实用性。 争议焦点： • 该功能是否真正提升了开发效率，还是增加了不必要的复杂性。 • 在实际应用中，内联模板的方式是否优于传统的代码生成工具。 • 性能和工具链的依赖问题是否会限制该方案的应用场景。

作者: gnabgib | 评分: 15 | 评论数: 1 | 发布时间: 2025-04-14 17:35
文章摘要

AudioX是一种基于Diffusion Transformer的统一模型，用于实现从任意模态到音频及音乐的生成。与以往只能处理单一模态的模型不同，AudioX能够高质量地生成音频和音乐，并支持文本、视频、图像等多种输入模态的灵活处理。其核心创新在于多模态掩码训练策略，通过跨模态的掩码输入促使模型学习，从而形成 robust 的跨模态表示。为解决数据稀缺问题，研究团队还创建了两个大型数据集：vggsound-caps和V2M-caps。实验表明，AudioX在多种音频和音乐生成任务中表现出色，超越了现有的专门模型，并在统一架构下展现出处理多种输入模态的卓越能力。

评论摘要
主要讨论点：视频到音频技术的优缺点及未来潜力 不同观点： • Fauntleroy认为视频到音频的转换技术在某些例子中表现出色，尤其是在非生命物体的场景中（如网球例子），显示了其在声音 timing 和声学环境上的精确性。这表明该技术在处理简单或可预测的声音环境时具有优势。 • 然而，Fauntleroy也指出该技术在处理复杂、人类有明确预期的声音场景时存在不足，特别是涉及真人乐队演奏的视频。例如，人们对于五支长号应发出何种声音有非常具体的预期，而技术目前可能还无法完全满足这些预期。 补充讨论： • Fauntleroy对该技术未来的发展表示期待，认为随着更多研究的推进，这项技术有可能得到进一步改善。 • 争议的焦点可能在于该技术当前的局限性与未来潜力之间的差距。一些人可能认为目前的成果已经非常 impressive，而另一些人可能更关注其在复杂场景中的不足。

Scientists: Protein IL-17 fights infection, acts on the brain, inducing anxiety

作者: wglb | 评分: 52 | 评论数: 6 | 发布时间: 2025-04-14 15:54
文章摘要

科学家发现免疫蛋白IL-17不仅能抵抗感染，还对大脑产生影响，引发焦虑或促进社交行为。麻省理工学院和哈佛医学院的研究显示，IL-17作用于大脑的两个区域：杏仁核和体感皮层，产生不同效果。在杏仁核中，IL-17引发焦虑；而在体感皮层，它促进社交行为。这些研究表明免疫系统和神经系统紧密相连。研究还发现，IL-17通过其受体IL-17RA和IL-17RB影响大脑功能，可能最初是作为神经调节剂进化而来，后来被免疫系统用于促发炎症。这项研究揭示了免疫分子如何影响情绪和行为，提供了对身心状态联系的新理解。

评论摘要
