评论摘要
**主要讨论点：** 弗吉尼亚州禁止销售地理位置数据的新法律，以及对数据隐私保护的更广泛讨论 **不同观点：** • **支持派（占多数）：** 认为这是正确方向，但力度不够。有人指出需要刑事起诉而非仅罚款；有人引用Planned Parenthood被追踪案例说明此法必要性；广告从业者也认可应禁止此类数据交易 • **谨慎乐观派：** 希望法律真正针对数据经纪人等恶意行为者，而不是像加州法律那样模糊定义导致无实际约束力。强调应区分"第一方合理使用"（如Google Maps优化服务）和"向第三方出售" • **质疑法律范围：** 有人提出为何只禁"销售"不禁"共享"；另有人关注跨州管辖权问题（特别是Delaware注册公司在弗吉尼亚外销售数据） **补充讨论：** 法律已于2025年7月1日生效，弗吉尼亚是继马里兰和俄勒冈后第三个州。法律特指"精确地理位置数据"（设备报告的数据），不包括IP地址等粗略定位。有评论者困惑数据收集的实际渠道，因为很多用户并未授权后台定位权限。

crustc: entirety of `rustc`, translated to C

作者: Philpax | 评分: 292 | 评论数: 24 | 发布时间: 2026-07-02 22:57
文章摘要

crustc 是一个将 Rust 编译器（rustc 1.98.0-nightly）转换成 4600 万行 C 代码的项目，可用 GCC 和 make 构建出功能完整的 Rust 编译器。这是作者新开发的 Rust 到 C 编译器工具链 cilly 的演示。 cilly 的核心创新是能自适应不同的 C 编译器，通过生成"检测程序"来查询编译器支持的特性、类型布局、字符编码等，尽量只依赖 ANSI C 标准。主要目标是支持缺乏 LLVM/GCC 但有 C 编译器的老旧或冷门硬件平台。 cilly 还具有网络透明性，可通过 TCP 与远程 C 编译器通信，解决交叉编译问题。它能生成 makefile，让用户用标准 C 工具链构建 Rust 代码，并保持与原生 rustc 的 ABI 兼容性。

评论摘要
**主要讨论点：** Rust到C编译器（crustc）项目的价值和应用场景 **不同观点：** • **支持派（多数）**：赞赏作者14次尝试的坚持，认为转译到C比LLVM IR更可行，让GCC处理优化是聪明的方案。前C++编译器开发者明确表示支持 • **质疑派**：认为直接为LLVM/GCC添加老硬件支持比构建语言转译器更合理，质疑项目目标的技术路线选择 • **实用主义者**：关注具体应用场景 - Plan 9系统支持、PPC Mac OS X移植可能性、性能表现对比、以及在bootstrappable项目中大幅简化Rust编译器引导过程的潜力 **补充讨论：** • 有人提出用Diverse Double-Compiling方法验证官方编译器是否存在后门的安全性测试思路 • 多人发现LLVM曾有C后端但已废弃，现在可能重新出现 • 出现多条幽默评论，调侃"用C重写Rust"反转了"用Rust重写一切"的梗，以及"Rust终于内存安全到可以变成C"的讽刺

Safari MCP 服务器是苹果在 Safari Technology Preview 247 中推出的 Web 开发工具。它通过 Model Context Protocol 协议将 AI 代理连接到 Safari 浏览器窗口，让代理能够直接访问 DOM、网络请求、截图和控制台输出等信息。 这个工具旨在简化传统的调试流程，减少开发者在浏览器、编辑器和 AI 工具之间的反复切换。代理可以自主完成更多调试工作，包括检查代码渲染效果、测试 Safari 兼容性、分析性能、检查可访问性问题以及验证用户状态等。 Safari MCP 服务器提供了丰富的工具集，涵盖标签页管理、JavaScript 执行、网络监控、页面交互、截图等功能，帮助开发者构建更高效的开发工作流。

评论摘要
主要讨论点：浏览器自动化测试工具选择及跨浏览器兼容性测试 不同观点： • **MCP服务器支持者**：认为Chrome和Firefox的官方MCP服务器比传统web drivers更快更强大，适合进行跨浏览器兼容性测试（Chrome、Firefox、Safari） • **Playwright-CLI倡导者**：建议使用Playwright-CLI替代MCP服务器，声称运行速度更快 • **Safari生态批评者**：质疑Apple对web开发者的支持力度，指出缺乏Apple设备就难以测试Safari，批评Apple不提供虚拟机等基础测试工具，认为这对开发者不友好 • **AI工具讨论者**：观察到2026年开发圈的文化转变——不使用AI代理会被视为落后，对这种现象表示感慨 补充讨论： - 技术实现细节：有开发者指出Safari的Safaridriver与Bidi/CDP协议存在功能差异，这是某些工具未支持Safari的原因 - 特殊功能需求：有人关注Private Relay在绕过爬虫限制方面的应用价值 - 移动端测试：有人询问移动模拟器Safari的支持情况 - 工具形态：讨论CLI与MCP作为分发方式的差异
