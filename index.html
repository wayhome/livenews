WASM Agents: AI agents running in the browser

作者: selvan | 评分: 114 | 评论数: 12 | 发布时间: 2025-07-04 05:19
文章摘要

本文介绍了一个名为 **Wasm agents blueprint** 的实验性项目，旨在通过将代理编写为 HTML 文件，使其能够在浏览器中直接运行，而无需额外安装工具或框架。该项目利用 **WebAssembly** 和 **Pyodide** 技术，将 Python 代码在浏览器中运行，实现了一种轻量、跨平台的 AI 代理。项目中的每个代理都是独立的 HTML 文件，包含用户界面和运行代码，使用 **openai-agents-python** 库与 LLM（如 GPT-4）进行交互，也可以接入自托管模型（如通过 Ollama 或 HuggingFace 提供的模型）。项目提供了多个示例，包括简单对话代理、多代理系统和带有工具的代理等，展示了 Wasm 代理的潜力。用户可以通过 GitHub 获取代码并按照说明运行这些代理。

Major reversal in ocean circulation detected in the Southern Ocean

文章摘要

科学家通过卫星数据发现南大洋的海洋环流自2016年起发生逆转，这一现象可能加剧气候变化的影响。南半球深海环流（SMOC）的逆转导致深层温暖且富含二氧化碳的海水上涌，加速南极海冰融化，并可能使大气中的二氧化碳浓度倍增。这一发现由ICM-CSIC开发的卫星数据处理算法实现，以前由于技术限制无法有效监测该区域。该研究强调了南大洋在全球气候系统中的关键作用，其环流变化可能对全球气候产生连锁反应， urging 进一步研究和监测。

Introducing tmux-rs

文章摘要

作者Collin Richards介绍了将tmux从C语言移植到Rust的项目。历时六个月，他达到了一个重要里程碑：代码库现在100%由Rust编写（使用了unsafe）。原始C代码约67,000行，Rust版本则为约81,000行。作者最初使用了C2Rust工具进行自动转换，但生成代码难以维护且比原C代码大三倍。最终，作者放弃了自动转换，选择手动翻译每个文件。尽管如此，C2Rust工具仍帮助作者验证了项目的可行性。作者还详细描述了构建过程，并分享了一些有趣的bug和开发经验，如使用Vim和AI工具辅助开发。最终，项目取得了成功，展示了将复杂C项目移植到Rust的可行性。

How AI on Microcontrollers Actually Works: Operators and Kernels

作者: hasheddan | 评分: 4 | 评论数: 0 | 发布时间: 2025-06-30 12:53
文章摘要

文章讨论了在微控制器上运行边缘AI（edge AI）推理的实际能力以及新硬件进展的影响。边缘AI通常涉及在计算、内存或网络带宽受限的硬件上执行推理。文章重点介绍了TensorFlow Lite for Microcontrollers（现已更名为LiteRT for Microcontrollers），这是一个用于微控制器的优化推理 runtime。它使用 `.tflite` 文件格式，通过 FlatBuffers 编码数据，包含模型权重和计算图。 文章还解释了运算符（operators）和内核（kernels）的概念，运算符定义了推理操作，而内核则是这些运算符的软件实现，具体性能取决于硬件支持。例如，加法运算符（TFL::AddOp）的实现会根据输出类型（如 `kTfLiteInt8` 或 `kTfLiteInt16`）选择不同的计算方法。文章通过代码示例展示了 `AddEval()` 函数如何处理不同数据类型的加法操作，强调了硬件对性能的影响。
