Show HN: Goboscript, text-based programming language, compiles to Scratch

作者: aspizu | 评分: 76 | 评论数: 9 | 发布时间: 2025-05-19 05:51
文章摘要

goboscript 是一种基于文本的编程语言，能够编译为 Scratch 项目（.sb3 文件），允许在文本编辑器中编写 Scratch 代码，并支持版本控制和代码复用。它具有简洁易读的语法，支持宏系统和额外功能（如局部变量），并可集成外部工具和工作流。goboscript 还提供优化和问题检测功能。开发者可以通过克隆项目并在本地运行，使用特定脚本进行编译、验证、提取和修补 Scratch 项目。该项目在 FOSS HACK 25 hackathon 中获得一等奖及50,000卢比奖励，使用 Rust 编写，并欢迎社区贡献。

评论摘要
主要讨论点：Scratch编程教学及其向文本编程过渡的挑战与可能性 不同观点： • AlexanderDhoore认为，Scratch非常适合用来教孩子编程，但孩子们在掌握Scratch后，往往希望学习“真正的编程”，却面临语言障碍、计算机基础知识缺乏以及文本编程的困难。他提出是否可以在Scratch生态中逐步引入更多概念，并提到GoboScript作为一个过渡工具，但同时希望最终能引导孩子学习Python或JavaScript等实际编程语言。 • japanuspus赞同该项目，但指出缺乏简单的安装说明可能会阻碍像他儿子那样的从Scratch过渡过来的孩子使用。他建议增加非开发者安装指南，并提供了一个使用Rust工具链的建议，认为这样可以提高可访问性。 • nis251413提出可以创建一个编译到GoboScript的可视化编程语言，暗示这样可能进一步帮助孩子过渡到文本编程。 • arnavsurve和arjvik对项目表示赞赏，主要从情感和怀旧角度表达了对项目的喜爱，未提出具体的技术性建议。 • ferriswil对项目表示赞赏，并提出未来可以开发一个非Scratch运行时和类似Scratch的前端，以便向更低年龄段的孩子教授更复杂的编程概念如引导加载程序（bootstrapping）。 • sriram_malhar对GoboScript的功能表示赞赏，特别是它包含了一些Scratch缺乏的特性，如函数返回值、局部变量和结构体等。 • web3aj则持不同观点，认为GoboScript违背了Scratch的初衷，暗示这个工具可能偏离了Scratch作为入门编程工具的核心理念。 补充讨论： • 项目的主要争议点在于GoboScript是否真正符合Scratch的教学目的，web3aj认为它偏离了Scratch的初衷，而其他评论者则更多关注如何通过此类工具帮助孩子更平滑地过渡到“真正的编程”。 • 安装和使用便捷性也被提出作为重要讨论点，japanuspus特别指出详细的安装说明将大大提高项目的可访问性。 • 另一个讨论点是关于如何逐步引入计算机科学中的更多概念，如文件系统和网络，AlexanderDhoore和ferriswil都提到了这一点。 总体而言，评论集中于如何帮助Scratch学习者平滑过渡到文本编程，以及如何改进工具的易用性和功能性。

InventWood is about to mass-produce wood that's stronger than steel

作者: LorenDB | 评分: 78 | 评论数: 19 | 发布时间: 2025-05-18 12:22
文章摘要

美国马里兰大学的材料科学家胡良兵在2018年开发出一种将普通木材转变为比钢铁更坚固的材料的技术。经过多年改进，该技术已成熟并授权给初创公司InventWood进行商业化生产。该公司计划于今年夏季开始生产首批"超级木材"（Superwood），初期将专注于建筑外墙材料，未来目标是替代建筑中的钢筋和混凝土，以减少碳排放。这种材料强度比钢高50%，且重量更轻，还具有防火、防腐和防虫特性。通过压缩，木材颜色更深，外观类似热带硬木。InventWood已筹集1500万美元用于建设其首家工厂。

评论摘要
主要讨论点：一种新型强化木材的研发及其潜在应用和争议 不同观点： • Chilinot和The_SamminAter引用了研究和视频，描述了强化木材的制作过程（煮沸和压缩），并提到研究主要将其与普通木材比较，而非不同类型的钢材。 • sverhagen表达了对这种新型木材在环保和回收方面的担忧，担心其可能像一些从可回收变成难回收的材料（如带塑料衬里的纸杯）一样，对环境产生负面影响。 • mschild质疑这种木材比哪种钢更强（如HSLA、碳钢或钢筋），并对在建筑中使用这种木材持开放态度。 • a1371指出其本地林业协会已声称木材按单位重量计算比钢更强，并提到木制高楼正在增加。然而，对仅将这种木材用于建筑外立面而非结构表示担忧，认为这可能只是为了新颖性而非实用性。 • Gravityloss和TomWhitwell提到这种技术与其他技术类似（如Lignilock木钉和Modvion木制风力涡轮机），并建议追踪这些技术的后续发展。 • mmooss关注这种材料的实际缺点，质疑其在扭转、压缩和弯曲强度方面的表现，并提出为何不应用于飞机或汽车等领域。 • 55555提到这种技术多年前就已存在，质疑其为何未被广泛应用。 • webprofusion关心这种木材的加工难度，尤其是对木工工具的挑战。 • relyks则关注这种木材在生产成本和长期维护方面的经济性。 补充讨论： • 讨论中争议的焦点在于这种强化木材的实际强度（与不同钢材的比较）、环保性（是否易于回收）、应用范围（结构还是外立面）以及经济性（生产和维护成本）。 • 一些评论者对这种新材料持谨慎乐观态度，认为需要更多实际数据支持。 • 部分评论者提到类似技术，建议观察其长期效果和技术成熟度。

`This Printer company served you malware for months, called them false positives

作者: bundie | 评分: 62 | 评论数: 7 | 发布时间: 2025-05-17 05:44
文章摘要

Procolored inkjet printers, particularly UV models, were found to be distributing malicious software via their companion software. Tech reviewer Cameron Coward first noticed the issue when his antivirus flagged malware on a USB drive included with a $6,000 Procolored UV printer. The malware included a USB-spreading worm and a Floxif file infector. Despite Procolored initially dismissing it as a false positive, cybersecurity firm G Data confirmed the presence of malware in both the USB drive and official software downloads. The threats included the XRedRAT backdoor and the SnipVex cryptocurrency stealer, which had already amassed around 9.3 BTC (~$100,000) before activity ceased. Procolored removed the software from its website for scanning and re-released clean versions. Affected customers are advised to check for antivirus exclusions and consider full system reformats to remove any malware.

评论摘要
主要讨论点：围绕打印机厂商和硬件厂商在信息安全方面的失误，以及其对加密钱包安全的影响的讨论。 不同观点： • CanvasCritic 认为，打印机厂商将软件视为副业，缺乏基本的信息安全卫生措施。这种现象使得硬件配置存在安全隐患，尤其是在小型企业环境中，通过USB传播的蠕虫病毒依然非常有效。SnipVex只是这种不安全环境下的一个例子，它为窃取加密钱包的攻击者提供了机会。 • Shakna 则指出，虽然没有证据支持Reddit上一些用户关于木马是故意植入的猜测，但软件编译和分发过程中缺乏或失败的反病毒扫描是更合理的解释。对Procolored公司能否通过“改进流程”来防止此类事件再次发生表示怀疑。 • Elmt35 和 Razakel 提供了具体信息和意见，指出问题涉及的打印机公司是Procolored，并对其在Mega.co.nz上托管驱动程序的做法表示不信任。 • M95D 表示对HP打印机出现类似问题的预期，暗示对知名打印机厂商在安全问题上的普遍担忧。 • Rvnx 认为，问题的核心在于比特币钱包的设计缺陷，理想情况下应在进行大额转账时要求二次确认，以防止类似攻击再次发生。 补充讨论： • HPsquared 提出了对打印机行业普遍存在的可疑做法的质疑，隐含了对行业惯例的批评。 争议焦点： • 关于SnipVex事件是由于厂商疏忽还是故意植入的争议。 • 对Procolored公司能否通过改进流程来解决安全问题的怀疑。 • 比特币钱包设计是否应加入更多防护措施以防止类似攻击。

Show HN: Sshsync – CLI tool to run shell commands across multiple remote servers

作者: blackmamoth | 评分: 17 | 评论数: 10 | 发布时间: 2025-05-18 19:10
文章摘要

**sshsync** 是一个快速、极简的CLI工具，通过SSH在多个远程服务器上运行shell命令。它支持并发执行命令，适用于系统管理员和开发者。主要功能包括：针对所有服务器或特定组执行命令、基于组的配置、SSH超时设置、文件推送/拉取、操作历史记录与日志、以及干运行模式预览操作。它依赖 **asyncssh** 进行SSH连接，若使用密码保护的SSH密钥，需运行 **ssh-agent** 并通过 **ssh-add** 添加密钥。安装需Python 3.10+，可通过 **pip install sshsync** 安装。命令示例包括在所有服务器上检查磁盘空间、重启特定组服务器服务、文件传输等操作。
