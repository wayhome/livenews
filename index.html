Intel sells 51% stake in Altera to private equity firm on a $8.75B valuation

作者: voxadam | 评分: 168 | 评论数: 23 | 发布时间: 2025-04-14 21:59
文章摘要

2025年4月14日，英特尔宣布将Altera业务的51%出售给科技投资公司Silver Lake，交易对Altera估值为87.5亿美元。这使Altera成为最大的纯FPGA半导体解决方案公司，并获得运营独立性。英特尔将保留Altera的49%股份。Raghib Hussain将接替Sandra Rivera，于2025年5月5日担任Altera的首席执行官。Hussain曾在Marvell和Cavium担任高管，并参与创立VPNet。此次交易旨在增强Altera的技术领导地位，并投资于AI驱动市场如边缘计算和机器人。交易预计在2025年下半年完成，届时Altera的财务结果将不再并入英特尔的合并财务报表。2024财年，Altera收入为15.4亿美元，GAAP营业亏损6.15亿美元。

The Cost of Being Crawled: LLM Bots and Vercel Image API Pricing

作者: navs | 评分: 43 | 评论数: 11 | 发布时间: 2025-04-14 23:33
文章摘要

本文讲述了一个由LLM（大型语言模型）机器人引发的高额费用事件，差点让一个小型创业公司损失7000美元。事件背景是作者的播客技术创业公司Metacast，其网页应用托管在Vercel上，并使用Next.js的图片优化API。由于未正确配置防火墙和图片优化设置，导致大量来自Amazonbot、Claudebot和Meta等LLM机器人的请求，短时间内产生了巨额图片优化费用。 发现问题后，团队立即采取措施：首先通过防火墙规则阻止相关机器人，然后禁用图片优化功能，并更新`robots.txt`以防止未来类似事件。最终，通过设置敏感的支出限制和加强防御措施，团队避免了经济损失。文章最后提到Vercel也调整了图片优化定价，以防止类似情况发生。

评论摘要
主要讨论点：Vercel Image API 的费用和效率问题，以及如何应对AI爬虫和SEO爬虫带来的带宽消耗。 不同观点： • jhgg和bhouston认为Vercel Image API的费用过于昂贵且效率低下，尤其是与之前工作中更便宜的解决方案相比。 • leerob（Vercel员工）回应称，尽管Vercel的支出限制有效，但需要改进用户界面和增加机器人防护功能，同时提到即将推出的图像优化定价会有所帮助。 • GodelNumbering分享了自己的经历，指出大量SEO和AI爬虫对新站点的爬取行为，并决定在robots.txt中屏蔽这些爬虫。 • ashishb提出可以通过直接在移动设备上获取RSS feeds，而不需要服务器，来避免被恶意爬虫攻击。 • nullorempty建议使用Imagemagick等更便宜的方案，并表达对AI爬虫的担忧。 • dylan604怀疑讨论内容是Vercel的广告，反映了对营销内容泛滥的不满。 • andrethegiant建议不要完全屏蔽爬虫，而是提供纯markdown内容，以减少带宽消耗，同时让LLMs了解网站信息。 • ramesh31提到被Vercel锁定的成本问题。 • sergiotapia抱怨Vercel的费用高昂，并推荐了BunnyCDN，认为其更具性价比。 • cachedthing0认为66.5k的请求量不大，属于脚本小子的攻击范围，暗示安全配置可能存在问题。 补充讨论： • 争议焦点在于Vercel Image API的费用是否合理，以及其效率是否能满足用户需求。 • 对于AI和SEO爬虫的应对策略存在分歧，一些人选择完全屏蔽，另一些人建议提供简化内容以节省带宽。 • 对BunnyCDN等替代方案的推荐，反映了用户对性价比更高的服务的需求。 • 对讨论内容是否为广告的怀疑，显示出对营销内容的不信任感。 • 安全配置和应对爬虫攻击的措施也是讨论的一个重要方面。

A hackable AI assistant using a single SQLite table and a handful of cron jobs

文章摘要

What Is Entropy?

作者: jfantl | 评分: 127 | 评论数: 16 | 发布时间: 2025-04-14 18:32
文章摘要

这篇文章旨在帮助读者理解熵（entropy）的概念，从信息论的角度入手，逐步扩展到物理系统和时间的关系。熵本质上量化的是不确定性。在信息论中，熵表示传递某个随机事件结果所需的最少比特数。例如，掷公平硬币的结果需要1比特，而八面骰子的结果需要3比特。 熵的定义不仅适用于等概率事件，对于加权概率事件，比如一个偏向性的骰子，熵可以通过期望比特数来计算。这种情况下，熵反映了平均所需的信息量。文章还提到，熵的概念与物理学中的熵密切相关，它解释了为什么时间向前和向后流逝时，宇宙的表现不同。通过理解信息论中的熵，可以更好地理解物理系统的熵以及其与时间箭头的关系。

评论摘要
主要讨论点：熵（entropy）的定义、主观性及其应用 不同观点： • **TexanFeller** 引用了Sean Carroll、Leonard Susskind和Stephen Wolfram等人对熵的不同哲学和科学解释，强调了熵的定义存在基于不同哲学基础的竞争性解释，且有些定义似乎是依赖于观察者的。 • **hatthew** 质疑了"高熵宏观态"和"有序"之间的区别，认为宏观态和有序性都是主观的。通过密码的例子说明，对于同样的系统配置，不同观察者可能会有不同的主观判断，从而影响对熵的理解。 • **nihakue** 认为熵是量化一个事物“实际可能是”多少不同方式的结果，同时仍“看起来是”如何的工具，主要是由于观察者对系统真实性质的有限理解。 • **glial** 强调熵是量化不确定性的工具，而这种不确定性是观察者个人的属性，而不是系统或消息本身的属性。不同的人对同一消息的熵可能不同，因为不确定性取决于个人对系统的模型和先验观察。 • **IIAOPSW** 简单地将熵定义为缺少的信息 bits，并进一步解释为需要指定某个处于广泛状态类别中的确切细节的 bits 数量。 • **anon84873628** 对文章中的术语精确性提出质疑，认为在热力学中应使用"热能"而非"温度"来精确描述熵相关的概念。 • **vitus** 认为许多熵的解释没有回答为什么我们要关心"无序"或"不确定性"的问题，特别是在信息理论和统计力学中。他强调了熵在信息压缩和统计力学中的深层次应用和意义。 补充讨论： • **brummm** 和 **NitroPython** 对文章中澄清熵不等于无序表示赞赏，并表示理解上的提升。 • **karpathy** 提到熵的计算中隐含了对系统动态的假设，特别是关于混合性质的假设。 • **gozzoo** 对文章的呈现方式表示赞赏，并请求推荐类似博客。 • **bargava** 提供了一篇关于熵的学术文章作为进一步阅读的资源。 • **jwilber** 分享了一个关于熵的交互式视觉化资源。 • **DadBase** 和 **ponty_rick** 通过个人经历和教学例子进一步说明了熵的概念。 争议焦点： • 熵的定义是否主观，特别是宏观态和有序性的判断是否依赖于观察者。 • 熵在不同领域（如信息理论和统计力学）中的应用和意义是否得到充分解释。 • 热力学术语的精确性问题。

AudioX是一种基于Diffusion Transformer的统一模型，用于实现从任意模态到音频及音乐的生成。与以往只能处理单一模态的模型不同，AudioX能够高质量地生成音频和音乐，并支持文本、视频、图像等多种输入模态的灵活处理。其核心创新在于多模态掩码训练策略，通过跨模态的掩码输入促使模型学习，从而形成 robust 的跨模态表示。为解决数据稀缺问题，研究团队还创建了两个大型数据集：vggsound-caps和V2M-caps。实验表明，AudioX在多种音频和音乐生成任务中表现出色，超越了现有的专门模型，并在统一架构下展现出处理多种输入模态的卓越能力。
