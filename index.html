TIL: You can make HTTP requests without curl using Bash /dev/TCP

作者: mrshu | 评分: 196 | 评论数: 33 | 发布时间: 2026-06-16 16:40
文章摘要

这篇文章介绍了在没有 curl 或 wget 的精简 Docker 容器中，如何使用 bash 内置的 `/dev/tcp` 功能直接发送 HTTP 请求来测试服务连通性。 核心方法是通过 `exec 3<>/dev/tcp/host/port` 打开 TCP 套接字，然后手动构造 HTTP 请求并写入文件描述符。`/dev/tcp` 并非真实设备文件，而是 bash 内部处理的重定向机制。 需要注意：这不是真正的 HTTP 客户端，不支持 TLS、重定向、压缩等高级特性；必须添加 `Connection: close` 头避免连接挂起；这是 bash 特有功能，非 POSIX 标准；需要编译时启用 `--enable-net-redirections` 选项。 适用场景：在无法安装工具的精简容器中进行快速连通性测试，日常工作仍应使用 curl。

评论摘要
主要讨论点：Bash的/dev/tcp功能用于手动进行HTTP通信的实用性和局限性 不同观点： • **实用派**：多位开发者分享在受限环境中（Docker容器、安全限制的系统、极小存储空间的路由器）使用/dev/tcp成功解决问题的经验，认为这是curl/wget不可用时的有效替代方案 • **技术严谨派**（basilikum）：强调这不是"Bash会说HTTP"，只是Bash能打开TCP套接字，手动构造的HTTP请求不完整且易出错，建议用nc或完整的HTTP客户端，警告不应在生产环境中无人值守使用 • **历史溯源派**：指出这是KornShell 1997年的特性，并非Bash原创；也有人提到这是模仿Plan 9的/net目录设计 • **安全绕过场景**：部分用户提到在渗透测试、CTF竞赛中利用此功能绕过安全限制 补充讨论： • 有人感叹这种底层理解体现"没有魔法"的哲学，担心未来开发者过度依赖AI代理会失去对系统底层的理解 • 实际应用案例包括Docker健康检查、心跳服务、内部网络连接测试 • 技术细节讨论涉及HTTP/1.0 vs 1.1选择、example.com作为测试域名的适用性

科学家首次绘制出全球丛枝菌根真菌网络分布图。研究发现，土壤中的真菌菌丝网络总长度达110千万亿公里，相当于地球到太阳距离的7.5亿倍。这些真菌与超过70%的植物共生，为植物提供养分和水分，同时帮助储存碳、调节气候。研究显示草原生态系统中菌丝密度最高，但农田中的菌丝密度比野生生态系统低47.3%。耕作、化肥和杀菌剂等农业活动会破坏真菌网络。研究者呼吁保护这些地下网络，并鼓励农民与真菌合作，减少化肥使用，改善碳储存。

评论摘要
主要讨论点：关于真菌分布密度地图的准确性和解读 不同观点： • **[mkl] 类比观点**：通过距离类比（100×10^12 km ≈ 10.6光年，相当于16颗恒星范围）来理解数据的规模，认为这种巨大数值类似人体血管总长超过地球周长两倍的反直觉现象，暗示数据可能是合理的 • **[contingencies] 验证观点**：基于实地观察支持地图准确性。以悉尼560万人口的城市为例，仅自家院子就能识别出20多种真菌（包括发光、形态奇特的品种），证明即使在人口密集区域，真菌多样性和密度也极高 • **[waterTanuki] 质疑观点**：对地图数据表示怀疑，特别指出美国西南部干旱沙漠地区不可能有每立方厘米3米的真菌密度，认为地图存在明显错误 补充讨论：争议焦点在于如何解读"真菌密度"的计量单位和统计方法。waterTanuki可能误读了单位（3米/cm³在物理上不成立），而contingencies强调的是物种多样性而非单纯密度，两者讨论维度不同。mkl的类比试图说明微观生物总量的反直觉性。

作者Tim Ferriss分享了他五本畅销书的销售数据：2022年作为基准，2023年下降5%，2024年下降13%，2025年暴跌46%，2026年预计下降57%。相比2022年，2026年纸质书销量将下降约80%。这一剧烈下滑与ChatGPT等大语言模型的普及时间高度吻合（2022年11月发布）。 作者认为，他的书本质上是"查询表"和"决策树"——教人如何减肥、改善睡眠、自动化收入等。而现在，免费的AI聊天机器人能在15秒内提供个性化建议，已读过成千上万本书，可根据用户体重、时间表和个人情况定制方案。 整个自助类图书市场2026年第一季度同比下降26.3%，行业顶尖畅销书也普遍下跌40-60%。作者认为这预示着所有"指导性内容"都将面临AI替代的冲击。

评论摘要
主要讨论点：自助类非虚构书籍销量下降的原因分析 不同观点： • **AI替代论**：AI能提供个性化反馈和即时建议，比书籍更便捷有效，尤其替代了需要填写工作表的互动内容（havblue）；AI正在取代中间媒介如博客和生产力内容，而非书籍本身（submeta） • **行业自身问题**：自助行业是"自助黑手党"式的产品推销网络，缺乏实质内容（alexander）；多数自助书充斥趣闻轶事而非干货，核心信息可浓缩为一张卡片（innocentoldguy） • **媒介转移论**：读者转向有声书而非纸质书，有声书市场增长3倍，65%为非虚构类（SkyPuncher）；YouTube视频成为替代选择（neves） • **盗版影响**：Anna's Archive等盗版资源影响销量，部分优质在线资源因此下线（chris_money202, heisenbit） • **技术与习惯演进**：信息丰富度提升、可穿戴设备普及、消费者教育水平提高等长期趋势，AI只是最新特征而非根本原因（sublinear） 补充讨论：有评论质疑视频内容的效率，认为超文本在导航、搜索和链接方面更优（vova_hn2）；也有人担忧AI生成内容可能影响未来阅读习惯（delichon）
