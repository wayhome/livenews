Plain Vanilla Web

文章摘要

这篇文章介绍了不使用构建工具或框架，仅通过编辑器、浏览器和网页标准来制作网站和网页应用的主要技术。具体包括：使用Web Components作为基础构建块，取代React或Vue等框架的组件方法；充分利用现代CSS的功能，替代CSS Modules、PostCSS或SASS的便利；基于Web Components创建网页项目并部署到生产环境，不涉及构建工具、框架或服务器端逻辑；以及如何用原生技术构建单页应用，处理路由和状态管理。本文适合已掌握HTML、CSS和JavaScript的开发者，初学者建议先学习The Odin Project或MDN的教程。文章还指出，现代框架虽然功能强大但复杂，而原生开发方式则以简化和零维护为长期优势。接下来将介绍如何使用Web Components组合内容、样式和行为。

评论摘要

Continuous Thought Machines

作者: hardmaru | 评分: 205 | 评论数: 15 | 发布时间: 2025-05-12 02:21
文章摘要

本文介绍了一种新型神经网络架构——连续思维机（Continuous Thought Machine, CTM），旨在将时间作为人工智能的核心组件，模拟生物大脑中神经元活动的时间动态。与传统神经网络不同，CTM通过引入解耦的内部时间维度及神经元级模型（neuron-level models, NLMs），使每个神经元能根据历史信号动态激活，并利用神经同步作为潜在表征与外界互动。实验结果显示，这种方法在灵活性和适应性上更接近生物智能，有助于缩小当前AI与人类认知能力之间的差距。CTM的演示展示了其在迷宫求解等任务中的潜力。

评论摘要
主要讨论点：围绕连续时间神经网络和生物学上可信的神经网络模型的讨论，包括其与传统机器学习（ML）和大型语言模型（LLM）的比较，以及在工程实现和理论研究上的可行性。 不同观点： • iandanforth：认为该论文未充分 acknowledging 生物学上可信的脉冲神经网络研究，且对“思考”一词的使用容易引起混淆。他认为将“思考”用于描述单个单元过程过于激进，与ML和ANN文献不符。 • robwwilliams：对跨领域研究表示赞赏，强调时间在神经网络中的重要性，并通过具体的神经科学例子说明时间在不同情境下的变化。 • davedx：对近期多项技术进展表示兴奋，认为这些进展让人类更接近“奇点”，但自身并非领域专家。 • bob1029：指出模拟时间域在实际硬件上非常困难，并认为如果不以实时交互为设计目标，追求时间动态可能不值得。他还对STDP（Spike-Timing-Dependent Plasticity）的工程实现表示怀疑。 • swalsh：认为下一代模型应基于“一起发射一起连接”的神经元，并对脉冲神经网络表示乐观。 • erewhile：指出液态状态机（LSM）在2002年已被提出，并用于连续输入的处理，但并未在所有任务上超越传统神经网络。 • dcrimp：对LLM的进展持批评态度，认为当前模型缺乏连续思考和神经记忆，并主张探索更接近生物大脑的模型，如SNN和神经形态计算。 补充讨论： • AIorNot：询问该论文是否可以与LLM深度学习结合。 • coolcase：对ML图表的混合数学和架构表示欣赏。 • liamwire：对论文的展示方式和初步内容表示赞赏。 • rvz：对论文中连续思考机器（CTM）的内部递归和神经同步的应用表示兴奋，并希望看到更多透明化的AI系统。 争议焦点： • 对“思考”一词在神经网络模型中的定义和使用存在争议，尤其是iandanforth与其他评论者之间的不同看法。 • 对模拟时间域和STDP在实际硬件实现上的可行性存在不同意见，bob1029和davedx的观点形成对比。 • 对LLM和脉冲神经网络在实现人工智能上的优劣存在不同评价，dcrimp和主流LLM进展的观点形成对立。

Dart added support for cross-compilation

作者: Alifatisk | 评分: 41 | 评论数: 7 | 发布时间: 2025-05-08 13:15
文章摘要

`dart compile` 命令用于将 Dart 程序编译为目标平台的可执行文件或模块。通过子命令指定输出类型，包括： 1. **exe**：生成包含 Dart 运行时的独立可执行文件。 2. **aot-snapshot**：生成不含 Dart 运行时的 AOT 模块，需使用 `dartaotruntime` 运行。 3. **jit-snapshot**：生成 JIT 模块，包含中间代码和优化后的代码表示。 4. **kernel**：生成便携的中间代码模块。 5. **js**：生成可部署的 JavaScript 文件。 6. **wasm**（开发中）：生成 WebAssembly 二进制文件。 编译命令示例： ```sh dart compile exe bin/myapp.dart -o /tmp/myapp ./tmp/myapp ``` 支持跨平台编译，如为 Linux 系统编译： ```sh dart compile exe --target-os=linux --target-arch=x64 hello.dart ``` `dart compile` 取代了旧的 `dart2native`、`dart2aot` 和 `dart2js` 命令。开发时也可直接使用 `dart run` 命令运行程序。

Car companies are in a billion-dollar software war

作者: rntn | 评分: 92 | 评论数: 22 | 发布时间: 2025-05-11 17:51
文章摘要

文章讨论了汽车制造商在软件定义车辆（SDV）领域面临的挑战和竞争。传统车企正投入数十亿美元开发SDV，以提升车辆功能和可升级性，但进展艰难。特斯拉通过Model S率先实现SDV，采用空中下载（OTA）更新和集中式计算机控制，简化了系统并降低了成本。然而，这种快速更新和修复的方式也带来质量问题。其他车企如通用汽车在推出新平台时遭遇软件故障，影响了新车发布。文章指出，尽管SDV能提高灵活性和升级能力，但目前所有传统车企都未完全解决软件问题，只有部分企业可能完成转型。这场软件竞争至关重要，但也充满挑战。
