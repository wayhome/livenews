Show HN: Kage – Shadow any website to a single binary for offline viewing

文章摘要

kage 是一个网站离线克隆工具，可将网站完整保存到本地供离线浏览，并自动移除所有 JavaScript 代码。它使用真实的 Chrome 浏览器渲染页面，等待页面完全加载后保存 DOM 快照，然后删除脚本并下载 CSS、图片、字体到本地。核心功能包括：clone（克隆网站）、serve（本地预览）、pack（打包成单个 ZIM 文件或可执行文件）、open（打开打包文件）。支持自动遵守 robots.txt、从 sitemap.xml 抓取、断点续传等特性。适用于保存需要长期访问的网页内容，避免因 JS 失效或网站下线而无法查看。

作者: mrunix | 评分: 28 | 评论数: 2 | 发布时间: 2026-06-14 21:04
文章摘要

Zinnia是一个几乎完全用Rust编写的操作系统内核，尽可能避免使用unsafe代码。它实现了大量POSIX API和Linux/BSD扩展（如epoll、timerfd），支持通过Wayland和X11运行现代桌面环境。 驱动程序以模块形式实现，是启动时从initrd加载的Rust ELF动态库。内核通过Limine引导程序支持UEFI系统启动。 该项目始于2024年的学习目的，现已能在多数x86_64真机上运行。计划支持aarch64和riscv64架构，但目前不是优先级。

文章摘要

Chaosnet是1975年由MIT人工智能实验室开发的局域网系统，用于连接地理位置相近的计算机群。其名称来源于缺乏中央控制元素的设计理念。最初为Lisp Machine系统开发，后扩展到MIT及其他研究机构的多种设备。 系统设计目标是简洁性和高性能。通过高速传输介质和简单协议实现快速响应和高吞吐量，而非复杂算法。硬件采用类似Xerox PARC以太网的载波侦听多路访问结构，使用同轴电缆作为物理介质。软件定义了基于数据包的高层协议。 Chaosnet专注于局域网应用，不处理长距离传输、低速链路等复杂场景，适用于文件系统访问、打印机等共享资源的连接。

zeroserve 是一个高性能 HTTPS 服务器，现在支持 Caddy 兼容模式。它将 Caddyfile 配置 JIT 编译为 eBPF 和本地机器码，在 io_uring 事件循环中运行。性能测试显示：zeroserve 吞吐量达 38,948 req/s，是 Caddy 的 3 倍；延迟 p50 为 1.45ms，比 Caddy 低 70%；内存占用仅 30.9 MiB，远低于 Caddy 的 67.4 MiB。支持图灵完备的 eBPF 脚本，可从 Caddyfile 调用自定义代码，例如实现 AWS SigV4 认证的 S3 反向代理。

评论摘要
主要讨论点：关于 zeroserve（基于 io_uring 和 eBPF 的高性能 Web 服务器）的技术价值和安全性争议 不同观点： • **性能过剩质疑**：单机 35k qps 对大多数应用已足够，Caddy 性能已能满足需求，优化了非瓶颈指标，水平扩展更实用（bastawhiz） • **安全担忧**：io_uring 近期频繁爆出安全漏洞，JIT 编译增加攻击面，3400 行锁文件存疑；不应在生产环境暴露 io_uring 服务（ok123456, pbohun, BoingBoomTschak） • **功能缺失**：缺少 ACME 自动证书管理和插件系统，"Caddy 兼容"名不副实（codingjoe, tln） • **项目可持续性怀疑**：认为是"氛围驱动"的 Rust 项目，6 个月后会死掉，缺乏支持和实战记录，真正需要性能的用户不会采用（Thaxll） • **技术认可**：技术上令人印象深刻，有人想尝试；对 nginx 性能表现感到惊讶（nullstyle, augunrik, zsoltkacsandi） 补充讨论：有用户报告 su3.io 出现奇怪的证书选择弹窗，可能与项目相关；eBPF 图灵完备性的技术细节讨论。
