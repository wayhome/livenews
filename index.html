文章摘要

Lockdown Mode（锁定模式）是 OpenAI 产品中的一项可选高级安全设置，旨在通过限制访问网络和外部服务来降低提示注入攻击导致的数据泄露风险。它会禁用实时网页浏览、图像支持、深度研究、代理模式、文件下载等功能，仅允许访问缓存内容。该模式适用于处理敏感数据的用户和组织，目前正在向个人账户和自助式 ChatGPT Business 账户推出。它不能阻止提示注入本身，但可防止数据通过出站网络请求泄露。对于托管工作区，应用和连接器访问由管理员通过角色权限控制。

评论摘要
主要讨论点：ChatGPT 新推出的 Lockdown Mode（锁定模式）功能及其对提示词注入攻击的防护效果 不同观点： • **功能价值有限派**（zerobees）：认为提示词注入已是限制企业采用 AI 的主要因素，锁定模式只是降低了 AI 的实用性而非解决根本问题。AI 无法像人类员工那样可信和负责，限制工具使用最终会迫使用户放松限制 • **技术实现存疑派**（kijin）：指出 LLM 至今缺乏可靠的指令与数据分离机制（类似 SQL 注入防护），质疑锁定模式可能仅用系统提示实现，担心被绕过的可能性 • **企业需求派**（varenc）：认为企业会对此功能很感兴趣，类比 Apple 的同名安全功能 • **安全漏洞派**（simonw）：认为锁定模式的存在本身就证明 ChatGPT 默认设置无法有效防护数据泄露攻击 补充讨论： madanparas 发现重要漏洞：锁定模式不影响 Codex 的网络访问，企业使用 Codex 访问内部代码库时仍存在数据外泄风险。OpenAI CEO Sam Altman 在 X 平台发表了相关声明。

pg_durable: Microsoft open sources in-database durable execution

作者: coffeemug | 评分: 375 | 评论数: 18 | 发布时间: 2026-06-05 15:59
文章摘要

pg_durable 是微软开源的 PostgreSQL 扩展，在数据库内实现持久化执行（Durable Execution）。它让长时间运行的 SQL 函数具备容错能力，通过检查点机制在每步执行后保存状态，崩溃或重启后可从断点恢复，无需重新执行已完成的工作。 适用场景包括：向量嵌入管道、数据摄取、定时维护、并行聚合、外部 API 调用等。可替代 pg_cron + 状态表、外部编排器（Airflow/Temporal）、队列+工作者等传统方案，将工作流逻辑统一在 SQL 中管理，减少架构复杂度。 核心优势是消除部分失败后的手动恢复、避免长事务锁定、将重试和进度跟踪集中到 Postgres。不适合单条 SQL 语句、毫秒级同步请求，或需要复杂应用逻辑的场景。

评论摘要
主要讨论点：微软开源的 pg_durable 项目，在 Postgres 中实现持久化作业队列引发的技术路线争议 不同观点： • **支持派**：认为 2026 是 Postgres 队列之年，社区贡献了多个类似工具（DBOS、pgQue），为开发者提供了新选择。有人成功用 Postgres + PostgREST 构建了功能完善的作业队列 • **反对派**：将其比作存储过程的老路，批评无法单元测试、难以版本控制、业务逻辑隐藏在数据库中、缺乏可观测性、扩展压力全落在 Postgres 上、缺少 API 调用等 IO 能力。认为这是"内部平台效应"的又一例证 • **困惑派**：不理解为何要用数据库存储控制流而非代码，质疑与 Temporal、Apache Airflow 等成熟 DAG 调度器相比的优势。认为数据库已是最难扩展的基础设施，为何还要增加长时运行任务的负担 • **技术细节关注**：对 wait_for_schedule() 的幂等性、超时处理、错误处理等实现细节存疑 补充讨论：Azure Postgres 功能滞后问题、PGRX 赞助建议、与 GitHub Actions 的关系等边缘话题也被提及。整体争议焦点在于"数据库是否应承载业务逻辑和编排功能"这一架构哲学问题。

罗切斯特大学研究人员开发了一种新型太阳能海水淡化技术。该系统使用激光蚀刻的超吸光黑色金属面板，利用太阳能将海水转化为饮用水，无需化学添加剂。其自清洁表面能够分离并收集盐分，避免产生有害的浓盐水废弃物。系统还可从收集的盐分中提取锂等矿物质，用于电池生产。与传统反渗透和热蒸馏技术相比，该方法更节能环保，可同时解决全球缺水问题和矿物资源需求，已在太平洋、大西洋和印度洋水样中成功测试。

评论摘要
主要讨论点：关于太阳能海水淡化新技术的可行性、效率和影响 不同观点： • **技术效率质疑派**：认为传统反渗透(RO)已接近理论最优能效，该热能方法应与同面积太阳能板驱动传统设备对比效率。指出海水淡化存在基本能量需求下限(ajb) • **实用性怀疑派**：技术仍处于实验室玻璃容器阶段，关键防堵塞机制和盐分清除系统尚未验证，需证明可长年运行(Animats)。成本高昂且需要飞秒激光等专利技术，难以规模化推广(shevy-java) • **潜在价值派**：直接产出晶体盐比盐水更易处理且可能有商业价值，尤其是镁、锂等矿物提取可能抵消部分淡化成本。海水中镁含量可观，固体副产品提取效率更高(scythe, photochemsyn) • **生态担忧派**：海洋矿物提取一旦盈利可能导致过度开采，威胁生态系统，希望技术无法规模化(noripcord) • **应用场景派**：设备复杂且对温度敏感，更适合应急响应或游艇等小规模场景，而非大规模部署(photochemsyn) 补充讨论：有人提议低技术方案(如除湿机+太阳能板用于灌溉)，也有人对沙漠海岸蒸发通道结合红树林的构想表示兴趣。论文数据显示日产水10.33升/平方米，盐0.38公斤/平方米。
