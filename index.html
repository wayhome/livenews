Where Do the Bytes Go?

作者: ingve | 评分: 6 | 评论数: 0 | 发布时间: 2025-03-29 11:26
文章摘要

本文简要描述了在调用 `write` 系统调用时，数据在操作系统内核中的处理流程。主要步骤包括： 1. **系统调用入口**：`write` 调用通过 libc 进入内核，经过系统调用机制（如 `syscall` 函数）进入内核态处理。 2. **系统调用分派**：内核检查系统调用号，确认其有效性后，调用机器无关的系统调用处理函数 `mi_syscall`。 3. **参数处理**：在 `mi_syscall` 中，内核进行调试检查、跟踪点检查等操作，随后调用具体的系统调用函数 `sys_write`。 4. **参数重打包**：`sys_write` 将用户传入的参数重打包为 io 向量，然后调用 `dofilewritev` 进行进一步处理。 5. **文件操作**：`dofilewritev` 获取文件描述符对应的文件操作结构，并调用其 `fo_write` 方法，最终进入 `vn_write`。 6. **VOP 调用**：`vn_write` 根据文件状态设置标志位，并通过 `VOP_WRITE` 调用实际的写操作。 整个过程中，数据一直保存在用户态的 io 向量中，直到最终写入文件。

文章摘要

Plain 是一个基于 Python 的 web 框架，是 Django 的分支，旨在引入新想法并保留成熟的模式。它支持通过单个命令进行本地开发，并提供多种包以满足不同需求，如构建产品、身份验证、后台管理、开发工具和前端集成等。Plain 被设计用于创建新业务、内部工具或个人项目，其主要包包括： 1. **基础包**：如 URL、视图、模板、表单等核心功能。 2. **认证包**：包括用户认证、OAuth 支持、无密码登录等。 3. **管理包**：自定义管理后台、功能标志、客户支持等。 4. **开发包**：提供本地开发环境、测试、代码格式化等工具。 5. **前端包**：集成现代 CSS、JavaScript 工具，支持文件路由和资源自托管。 Plain 通过模块化设计，使主要功能可选并能独立演进。

You Need Subtyping

作者: speckx | 评分: 29 | 评论数: 8 | 发布时间: 2025-03-26 18:38
文章摘要

本文讨论了编程语言设计中子类型（subtyping）的概念及其重要性。子类型允许某种类型的值在需要另一种类型的地方使用，与类或继承无关。例如，在JavaScript或Python等语言中，函数可以接受包含特定属性的对象，即使该对象还有其他未使用的属性。虽然一些开发者认为低层次、注重性能的语言不需要子类型，但作者指出，即使是优化过的语言，仍需子类型来处理如空检查（null checking）等特性。例如，Kotlin中非空字符串（String）是可空字符串（String?）的子类型，这有助于编译时捕捉错误。子类型不仅适用于高层次语言，对于具备复杂类型系统的现代语言也至关重要。

评论摘要
主要讨论点：关于编程语言中的子类型化（subtyping）、空值处理、以及类型系统的技术和概念讨论 不同观点： • [masklinn] 认为，函数如果接受可以为 String 或 null 的值，那么传递一个保证为 String 且非空的值是合理的。但他质疑 "String 是 String 的子类型" 的说法，认为这不正确。同时，对于空值（nullability）不影响内存布局的观点，他表示反对，指出当涉及到可空的基本类型（如整数）时，内存布局确实会受到影响。 • [pansa2] 提出，现有的编程语言很少或几乎没有子类型化，但随即有人指出，现代编程语言（尤其是支持面向对象编程的语言）仍然广泛使用继承来支持子类型化，这与 pansa2 的观点形成对比。 • [a3w] 总结文章的观点，提出高层次编程语言中，子类型化是被隐含期待的，许多特性似乎基于子类型化的实现方式来工作，尽管这可能不是显式的。 • [psychoslave] 将讨论引向鸭子类型（duck typing），暗示文中的子类型化讨论可能与之类似，但并未展开具体分析。 • [stephantul] 对文中提到的 "boxed"（装箱）概念感到困惑，表明技术术语的使用可能不够清晰，需要进一步解释。 • [smackeyacky] 以情绪化的语气批评文章作者，认为其态度傲慢，并建议应虚心学习现有技术，而非标新立异。 • [SomeoneOnTheWeb] 反对文章的观点，指出 TypeScript 中的子类型化确实存在，但由于协变（covariance）导致了很多问题，这与其他讨论者对子类型化的支持态度形成对比。 补充讨论： • 争议的焦点之一是子类型化的定义和实际应用，特别是在现代编程语言中的表现形式。 • 另一个争议点是空值处理和内存布局的关系，不同观点基于对具体实现机制的理解差异。 • 技术术语的清晰度和使用也在讨论中被提及，表明读者对技术文章的准确性和可读性有要求。 • 情绪化的评论虽然未提供实质性观点，但反映了讨论中可能出现的紧张气氛和对技术讨论的态度分歧。

Chimpanzees act as 'engineers', choosing materials to make tools

作者: docmechanic | 评分: 8 | 评论数: 1 | 发布时间: 2025-03-25 14:39
文章摘要

研究发现，坦桑尼亚贡贝溪国家公园的黑猩猩在制作工具时展现出一定的工程学能力，它们故意选择具有特定机械和结构特性的植物来制作更具弹性的工具，用于钓取白蚁。研究团队使用便携式机械测试器比较了黑猩猩使用的植物材料和未使用的材料，发现未使用的植物材料要坚硬得多。黑猩猩选择的植物种类，如*Grewia spp.*，在远至5000公里外的黑猩猩群体中也用于制作工具，显示出这种基础的工程选择可能在黑猩猩的工具文化中根深蒂固。该研究揭示了黑猩猩对材料特性的直觉理解，并为研究人类工具使用能力的演化提供了重要启示。

评论摘要
