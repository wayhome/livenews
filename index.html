文章摘要

雷诺集团是无稀土电动机技术的先驱，采用电励磁同步电机(EESM)而非永磁同步电机。自2012年起大规模应用该技术，目前已发展至第二代(6A系列)，应用于Megane、Scenic、Alpine A290和雷诺5等车型。第三代E7A电机将于2027年推出，功率达200千瓦，体积缩小30%，效率约92%，并支持800伏快充。采用绕线转子设计可避免依赖中国稀土供应(中国控制全球90%以上稀土和永磁体生产)。所有电机均在Cléon工厂生产。

评论摘要

文章摘要

加州大学伯克利分校等机构的研究人员开发了一种新的CRISPR技术，能选择性摧毁携带特定癌症突变的细胞。该技术针对p53肿瘤抑制基因突变（存在于近半数癌症病例中，在卵巢癌、胰腺癌等难治癌症中占70-90%）。研究团队改造了CRISPR-Cas12a2系统，使其识别突变细胞产生的特异性RNA转录本，一旦检测到即启动"染色质粉碎"，切碎该细胞内所有遗传物质导致其死亡，而健康细胞不受影响。这为"不可成药"的癌症靶点提供了新的治疗途径，研究成果发表在《自然》杂志上。

评论摘要
主要讨论点：CRISPR技术在癌症治疗中的应用前景及其局限性 不同观点： • **技术乐观派**：认为癌症治疗正从广泛破坏（化疗/放疗）转向精确识别恶性细胞，CRISPR代表了这一方向的进步。有评论者对个人遗传疾病治疗抱有希望，也有人强调生物医学发展速度正在加快，从千年到十年再到未来可能的数年就能解决生物问题。 • **技术怀疑派**：指出CRISPR被过度炒作，FDA仅批准1种CRISPR疗法，而病毒载体疗法已有19种获批。认为病毒载体才是真正的未来，CRISPR只是更容易获得媒体关注。另有评论指出这项研究可能仍处于体外阶段，距离人体治疗还需数年甚至数十年。 • **技术细节讨论**：虽然用CRISPR检测肿瘤特异性突变并杀死细胞的想法并不新鲜，但本研究使用的Cas12a2比以往的Cas9更具破坏性。主要挑战在于递送效率和肿瘤可能产生的抗性（如细胞表面修饰阻止LNP摄取）。 补充讨论：有人质疑为何社会优先发展广告技术而非癌症治疗，反映出对资源配置的伦理关切。也有人表达对过去"癌症治愈"承诺的失望和谨慎态度。

Twenty One Zero-Days in FFmpeg

文章摘要

depthfirst的自动化安全代理在FFmpeg中发现了21个零日漏洞,成本仅1千美元(是Anthropic成本的10%)。FFmpeg是全球部署最广泛的软件之一,拥有150万行C代码。尽管经过Google Big Sleep团队和Anthropic的Mythos模型近期审计,depthfirst的代理系统仍通过深度代码分析、威胁建模和数据流追踪,发现了多个严重漏洞。其中8个已获CVE编号,包括堆缓冲区溢出、整数溢出、栈溢出等,部分漏洞潜伏长达15-20年。该系统不仅能发现理论漏洞,还能自动生成可复现的PoC输入验证漏洞真实性,并开发出RCE利用原语。

评论摘要
主要讨论点：FFmpeg 通过 LLM 发现的安全漏洞及其严重性评估 不同观点： • **严重威胁派**：认为漏洞影响面广，涉及媒体处理管道、监控系统、转码服务等多个场景，可能已被广泛利用（nemothekid） • **技术限制派**：指出虽然严重，但实际利用难度较高，需要突破 ASLR 等保护机制，难以实现任意代码执行（wavemode） • **历史必然派**：强调 FFmpeg 长期存在安全问题，fuzzing 测试持续发现内存损坏漏洞，处理不可信内容时必须沙箱化运行（zerobees, jacobgold） • **术语质疑派**：认为"zero-day"一词被滥用，这些漏洞并非真正的零日漏洞，存在夸大宣传嫌疑（da_chicken, lschueller） • **LLM 可信度质疑**：对 LLM 分析结果的准确性表示怀疑，认为 LLM 常给出听起来专业但实际错误的分析（fizzynut） • **语言安全派**：认为这类问题源于 C 语言本身，使用更安全的编程语言可避免此类漏洞（Philpax） 补充讨论：有人提出攻击者可能通过代码中嵌入提示注入来对抗 AI 安全审计工具（ttoinou）；部分评论关注漏洞时间线和是否已上报给 FFmpeg 团队。

主要讨论点：一款受《席德·梅尔的海盗》启发的游戏作品，引发了关于游戏机制改进和怀旧回忆的讨论 不同观点： • **需要增加真实航海机制**：多位评论者（dbingham, CrimsonCape, Daviey）认为应加入风向系统，船只朝风向航行应减速，增加逆风/顺风对速度的影响，并减少船只的灵活性以提升真实感和挑战性 • **当前平衡性问题**：dbingham指出小船太容易获胜，只需保持领先并偶尔回转射击即可；游戏平衡需要调整 • **功能扩展建议**：JMiao提议加入链弹（chain shot）；AnotherGoodName回忆旧版有撞船机制；Daviey希望加入拦截和剑战功能 • **相似游戏推荐**：评论者分享了多个相关游戏资源——tinywind.io（海盗主题）、navalstrike.app（海战多人游戏）、Taipan（1980年代贸易游戏）、Overboard（PS1游戏）等 补充讨论：评论者们普遍表达了对经典海盗游戏的怀旧情感，分享了在Apple 2、Amiga、8086等不同平台上的游戏记忆。部分开发者也受启发创作了自己的项目，显示出这类游戏的持续影响力。JMiao分享了孩子因玩《海盗》而对地理产生兴趣的教育价值。
