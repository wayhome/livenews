Erlang/OTP 29.0

作者: pyinstallwoes | 评分: 74 | 评论数: 2 | 发布时间: 2026-05-15 23:33
文章摘要

Erlang/OTP 29.0 是重大版本，新增 unsafe 标注、原生记录、范围整数守卫、多值推导式、文档示例测试等；强化安全默认配置（SSH/SFTP、量子安全密钥交换）；改进编译器/JIT并新增多项警告，同时调整代码路径和停止 Windows 32 位构建。

评论摘要
主要讨论点：Erlang/Elixir 相关新特性与改进的价值，尤其是安全默认设置、CLI 支持和 Native Records。 不同观点： • 支持者认为这是“一组不错的改进”：默认禁用 SSH daemon 和 SFTP 更安全；io_ansi 可能补强 Erlang 构建复杂 CLI 应用的能力，且 fwrite 跨节点一致性很有吸引力。 • 对 Native Records 持积极态度，认为它是重要进步，未来可能被 Elixir 更好利用；但也认为旧 records、tuple、map 的并存状态短期内不会彻底消失，Native Records 更像是显著增强而非全面替代。 • 另一位评论者没有表态支持或反对，而是追问“内部机制是什么”，说明讨论从“评价功能价值”转向“希望解释实现原理”。 补充讨论： • 争议焦点主要在 Native Records 会如何影响 Elixir 现有数据结构体系，以及 io_ansi 是否真能改善 Erlang 的 CLI 开发体验。

评论摘要
主要讨论点：围绕 Project Gutenberg 的历史价值、近期改版、使用体验、格式与生态支持展开讨论。 不同观点： • 赞赏与支持：多位评论者肯定 PG 的长期贡献，提到其始于1971年，早于互联网普及；有人感谢团队持续维护，也称新版移动端样式已改善、下载《白鲸》等书很方便。 • 改版体验分歧：有人认为新版桌面端更好、移动端问题已修复；但 Kindle 用户怀念旧版，认为旧站更轻量，能直接在设备内置浏览器下载。 • 格式偏好争议：有人不喜欢 PG 传统偏纯文本，偏好带排版的 PDF 或 archive.org 的扫描书，尤其是含插图和特殊排版的作品；也有人提到 ePub 可用但质量依赖制作和阅读器。 • 设备与生态缺口：评论者惊讶电子书阅读器厂商没有内置“Gutenberg 商店”，认为 Kindle 等平台不够友好，常需借助 Calibre，增加摩擦。 • 离线与扩展资源：有人推荐 Gutenberg ZIM，可离线下载约60GB英文全集；也补充加拿大 FadedPage、瑞典 Runeberg 等类似项目。 • 数据与质量疑问：有人注意到冷门书《Concrete Construction》下载量异常高，怀疑机器人流量；另有人询问插图书质量和插图 QA 是否改善。 补充讨论：PG 曾在德国被地理封锁；官方人员提到 Wikipedia 上关于 PG 的条目已陈旧，需要更新。

文章摘要

文章考察“新冰毒”（P2P法）是否因化学差异导致更严重精神问题。美国2009-2012年从麻黄碱法转向P2P法；早期P2P会混有较多低活性的l-甲基苯丙胺，但到2019年几乎全为d型。DEA数据显示现代街头冰毒纯度、效力更高，暂无充分证据证明其“化学不同”导致疯狂。

Naturally Occurring Quasicrystals

作者: lukeplato | 评分: 50 | 评论数: 5 | 发布时间: 2026-05-14 14:32
文章摘要

文章介绍天然准晶极其罕见，通常由小行星高速碰撞、雷击或核爆等极端事件形成。俄罗斯Khatyrka陨石发现三种准晶；内布拉斯加沙丘放电产生一种十二重准晶；另有三位一体核试验遗址准晶，并附相关研究文献。

评论摘要
主要讨论点：围绕准晶体及相关“特殊晶体/材料”的形成、发现过程和跨学科意义展开。 不同观点： • 推荐科普阅读：有人推荐 Paul Steinhardt 的《The Second Kind of Impossible》，认为其生动讲述了准晶体从理论、实验到在俄罗斯陨石区实地寻找的研究历程。 • 核爆副产物视角：有评论补充核爆产生的 trinitite 中发现了笼状结构材料 clathrate，可困住其他原子，作为极端条件下新材料形成的例子。 • 自然界类似结构：有人提到“天然”副晶态病毒，会使等足类动物变蓝并致死，说明非典型有序结构也存在于生物系统中。 • 数学关联观点：有评论指出曾有数学家和化学家讨论这类结构的图案可能与素数分布有关，强调其与数学规律的潜在联系。 • 概括性解释：有人总结准晶体是非周期结构，形成条件罕见，通常需要瞬时高温，可由陨石撞击或闪电击中沙地等事件产生；其化学表征也因缺乏重复单元而困难。 补充讨论：整体并无明显争吵，主要是围绕准晶体扩展到核爆、病毒、数论和材料科学等相关案例，焦点在“极端或特殊条件如何产生非传统有序结构”。
