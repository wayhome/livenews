A leap year check in three instructions

作者: gnabgib | 评分: 137 | 评论数: 12 | 发布时间: 2025-05-15 21:57
文章摘要

这篇文章介绍了一种通过位操作快速判断一个年份是否为闰年的方法。传统方法通过一系列的条件判断来确定闰年，而本文提出的优化方法可以在仅使用约3条CPU指令的情况下完成判断： ```cpp bool is_leap_year_fast(uint32_t y) { return ((y * 1073750999) & 3221352463) <= 126976; } ``` 文章首先回顾了典型的闰年判断实现，然后逐步优化，利用模运算的特性进行位操作优化，减少计算开销。接着，文章解释了如何使用乘法和位操作来替代模运算，详细介绍了魔术数字的来源和计算方法。最终的优化版本通过引入Z3求解器，找到合适的常数，使得判断过程无需分支预测，从而提高效率。 这种方法虽然不完全通用，但对于有限年份范围内的判断非常高效，适用于对速度要求较高的场景。

Initialization in C++ is bonkers (2017)

作者: todsacerdoti | 评分: 70 | 评论数: 16 | 发布时间: 2025-05-15 21:27
文章摘要

这篇文章讨论了C++中初始化行为的复杂性，特别是默认初始化、值初始化和零初始化之间的区别。文章通过一个代码示例展示了`foo`和`bar`两个结构体中成员变量`a`和`b`的不同初始化结果。关键在于构造函数是否是“用户提供的”：`foo`的构造函数在一开始就被声明为`default`，所以不是用户提供的，而`bar`的构造函数在定义时才使用`default`，所以被视为用户提供的。 由于初始化规则不同，`foo`的成员`a`会先进行零初始化再进行值初始化，最终`a.a`为0；而`bar`的成员`b`仅进行值初始化，其值未定义。文章强调了C++初始化的复杂性，并提醒开发者注意不同情况下初始化行为的变化，以避免未定义行为。

评论摘要
主要讨论点：C++默认初始化行为及其相关问题 不同观点： • **shadowdev1**：认为C++的默认初始化行为是语言的一大缺陷，导致了许多由未初始化引发的错误，尤其是新手容易踩坑。建议学习Python，将未初始化行为设置为显式选择，使用特定关键字来标记。认为旧代码如果依赖未初始化行为，本质上已经是错误的，不应继续支持。 • **waynecochran**：反对强制初始化，认为C++的设计哲学是让程序员拥有最终控制权，不应加入“训练轮”式的限制。程序员应有自由选择是否初始化变量，如果想使用未初始化内存也是他们的自由。 • **markhahn**：从历史和低级编程语言的角度解释C++的初始化行为，认为这些设计在历史背景下是有意义的。但对于从高级语言背景过来的开发者，可能不太适应。 • **jandrewrogers**：承认C++的初始化机制确实混乱，但认为现代C++在大多数情况下还是能满足需求，即便开发者不完全理解其初始化机制。 • **timewizard**：认为C++作为系统语言，其设计是为了让开发者有选择的自由，尤其是在性能优化方面，允许不初始化以节省不必要的开销。强调系统编程本质上充满细节和复杂性。 补充讨论： • **nlehuen**：提到有一本专门讨论C++初始化的书（278页），暗示C++初始化问题的复杂性。 • **nyarlathotep_**：提到一位作者及其著作《Building a Debugger》值得关注，显示出对C++调试等未充分探讨话题的兴趣。 • **gnabgib**：引用了Hacker News上的相关讨论，显示C++初始化问题在社区中引起过广泛讨论。 • **ts4z**：简单地将C++初始化问题概括为C++整体复杂性的一个特例。 • **jeffbee**：以讽刺口吻批评C++的复杂性和未初始化问题，认为C++应该默认初始化所有变量以避免不确定行为，同时调侃了那些希望优化性能的开发者。 • **beached_whale**：认为C++在大多数情况下表现符合预期，暗示默认初始化问题并没有那么严重。 争议焦点： • C++是否应该强制默认初始化所有变量，以避免未定义行为（UB），还是应该保留程序员的自由选择权，允许未初始化内存的使用以优化性能。

The Teal Programming Language

作者: generichuman | 评分: 4 | 评论数: 0 | 发布时间: 2025-05-16 00:40
文章摘要

Teal是一种静态类型的Lua方言，通过类型注释扩展Lua，支持数组、映射、记录、接口、联合类型和泛型。其目标类似于TypeScript之于JavaScript，但保持Lua的简约、可移植和嵌入式特性。Teal通过编译器`tl`将`.tl`源码编译为`.lua`文件。用户可以使用LuaRocks安装Teal，或使用预编译的二进制文件。对于大型项目，建议使用构建工具Cyan。Teal提供VSCode插件和语言服务器等集成工具，文档和社区资源丰富，项目在GitHub上开放开发，采用MIT许可。
