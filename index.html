Fui: C library for interacting with the framebuffer in a TTY context

作者: Bhulapi | 评分: 75 | 评论数: 10 | 发布时间: 2025-05-08 22:05
文章摘要

`fui` 是一个用于帧缓冲区（framebuffer）的 C 语言库，能够在 tty 环境下进行图形界面操作。它支持： 1. 向多个图层绘制像素，然后合成并渲染到帧缓冲区。 2. 基本的图形绘制功能，如线、矩形和圆。 3. 使用位图字体进行文本渲染。 4. 利用 `libevdev` 处理键盘和鼠标事件，并实现了一个通用事件系统。 5. 使用 ALSA 实现简单的音频播放功能。 安装步骤包括运行 `make` 和 `sudo make install`，库是静态链接的。由于需要 root 权限访问视频和输入设备，建议将用户添加到 `video` 和 `input` 用户组。示例代码和简单的游戏（如 `asteroids`）包含在项目中。该项目使用 MIT 许可证。
