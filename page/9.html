作者: yunusabd | 评分: 93 | 评论数: 14 | 发布时间: 2025-05-14 11:27
文章摘要

文章介绍了一种由华盛顿大学研发的自行车传感器ProxiCycle，旨在提升安全骑行路线的测绘。该设备安装在自行车左把手，利用红外光传感器监测附近车辆，通过蓝牙将数据传至手机应用，记录与汽车的近距离接触。传感器成本不到25美元，每次充电可使用12小时。初步测试显示，ProxiCycle能准确识别危险路段，比现有依赖事故报告或主观评价的测绘方法更客观。研究团队计划在更多城市进行大规模测试，以帮助新手骑行者选择安全路线，促进骑行安全。

作者: pavel_lishin | 评分: 56 | 评论数: 16 | 发布时间: 2025-05-14 17:04
文章摘要

研究人员发现了一段人类特有的基因片段（HARE5），当将其植入小鼠体内时，小鼠的大脑体积增加了约6.5%。这一基因片段能增强特定基因的表达，促进神经细胞的生成，从而扩大大脑外层。这项研究发表在《Nature》上，进一步揭示了人类大脑相比灵长类动物为何更大更复杂的部分原因。此前研究曾指出人类加速区域（HARs）可能与大脑发育有关，而HARE5正是其中之一，它在人类版本下能更有效地促进小鼠神经干细胞分裂和神经元生成。不过，目前尚不清楚大脑变大的小鼠是否在认知或记忆上有所提升。这项研究为理解人类大脑演化提供了新视角。

Popcorn: Run Elixir in WASM

作者: clessg | 评分: 138 | 评论数: 8 | 发布时间: 2025-05-15 17:14
文章摘要

Popcorn 是一个允许在浏览器中运行 Elixir 代码的库，通过客户端 AtomVM 运行时执行编译后的 Elixir 代码。它提供了 Elixir 与 JavaScript 互操作的 API，处理序列化、通信，并确保浏览器响应能力。本文介绍了三个使用 Popcorn 的示例：Elixir REPL、Elixir 文档交互片段和生命游戏模拟。 要使用 Popcorn，需将其作为依赖添加到 `mix.exs` 文件中，并运行 `mix deps.get`。接着，通过命令生成包含 Popcorn 库和 WASM 文件的目录，并在 HTML 中引入相关脚本。 Popcorn 通过消息传递实现 JS 和 Elixir 代码的交互。Elixir 端需要定义一个包含 `start/0` 函数的入口模块，并配置在 `config.ex` 文件中。完成 Elixir 初始化后，通过 `Wasm.send_elixir_ready/1` 通知 JS 端。 Popcorn API 提供了 `Popcorn.init(options)` 方法来初始化实例，并支持通过 `call` 和 `cast` 方法与 Elixir 进程通信。Elixir 端则使用 `Popcorn.Wasm` 模块处理与 JS 的通信。注意，该库仍在开发中，API 不稳定，部分功能未实现。

评论摘要
主要讨论点：Popcorn项目的发布及其相关技术问题和前景 不同观点： • Jump3r（Kuba，Popcorn项目成员）：对项目被发布在Hacker News上表示意外，并欢迎大家提问，显示出对项目开放讨论和进一步了解用户反馈的积极态度。 • pesnk：对Popcorn处理Elixir多 actors 创建时的表现提出质疑，并给出了一个具体代码示例（使用Task创建多个异步任务），指出该代码无法正常工作，暗示Popcorn在处理Elixir某些特性时可能存在不足。 • Lord_Zero：对WASM的发展速度感到失望，认为WASM本应促使像Python和Golang等传统后端语言在Web UI开发中得到更广泛应用，但目前进展缓慢。这里表达了对WASM技术前景的期望与现实之间的差距。 补充讨论： • codetrotter：提供了Popcorn项目的GitHub链接，解决了其他用户可能遇到的项目源码查找问题，表明对项目文档或发布信息中缺少链接的关注。 • Muromec：提到了AtomVM的编译大小（约1MB），似乎在对比不同技术栈的性能或体积，可能暗示对Popcorn项目体积或性能的关注。 • nelsonic：认为Popcorn项目很有前景，但目前还不够稳定，属于一个值得关注但需谨慎对待的项目，表明了对项目现状的认可但同时也指出了其不稳定性。 争议焦点： • Popcorn项目在处理Elixir多 actors 创建时的表现问题（pesnk提出的具体代码问题），这涉及到Popcorn项目在Elixir特定特性支持上的能力与限制。 其他值得注意的讨论点： • 对WASM技术发展速度的看法（Lord_Zero的观点），涉及到对新兴技术前景的期望与现实之间的差距。 • 对Popcorn项目稳定性的关注（nelsonic的观点），这是项目后续发展中需要解决的重要问题。 总结：评论主要围绕Popcorn项目的技术实现、当前不足及未来前景展开讨论，涉及到具体技术问题（如多 actors 创建）、项目资源链接的提供以及对新兴技术（WASM）发展现状的看法。同时，也有对项目稳定性的关注和对其他类似技术（如AtomVM）的提及。
