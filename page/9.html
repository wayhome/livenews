Malicious versions of Nx and some supporting plugins were published

文章摘要

Nx项目多个npm包（包括nx、@nx/devkit等）的21.5.0、20.9.0等特定版本被发现含有恶意代码，会扫描文件系统并窃取凭证上传至GitHub。漏洞源于一个存在Bash注入缺陷的GitHub工作流（可执行PR标题中的代码）和过度宽松的pull_request_target权限设置。攻击者利用这些漏洞获取了npm发布权限，上传了恶意版本。目前所有受影响版本已从npm下架。项目组建议用户检查是否安装了受影响版本，并立即升级到安全版本。

评论摘要
主要讨论点：[软件供应链安全、依赖管理、攻击防御措施] 不同观点： • **禁用安装脚本**：建议通过 `npm config set ignore-scripts true` 禁用 npm 安装脚本，以减少供应链攻击风险。认为当前大多数合法包无需安装脚本即可运行，对于需要脚本的包可单独处理。 • **减少依赖**：主张在添加新依赖前仔细考虑，尽可能自己编写简单功能。举例通过 LLM 生成一个简单的进度条代码，避免了引入复杂依赖。 • **安全机制缺失**：指出当前包管理器缺乏必要的安全机制，如代码签名、MFA、令牌管理等，认为这是行业整体失败，需要建立类似建筑规范的强制安全标准。 • **沙盒环境**：建议在虚拟机或容器中运行不信任的代码，特别是对于具有高风险的应用程序（如 NodeJS 应用、通过 shell 脚本安装的工具）。 • **包管理器改进**：提出包管理器应引入“最小年龄”设置，忽略新发布的包以减少风险。同时建议操作系统限制应用程序的默认文件系统访问权限。 补充讨论： • **新型攻击方式**：讨论了使用本地 LLM 通过提示词进行攻击的新形式，这种攻击绕过传统静态分析，难以防御。 • **实际案例**：提到 Grafana 的安全事件，以及 VS Code 插件通过运行 `npx` 命令被攻陷的案例，显示攻击的普遍性和易发性。 • **行业反应**：批评 Anthropic 在宣传其 AI 防犯罪能力的同时，其工具本身存在多个安全漏洞，显得 hypocritical。 • **潜在威胁**：担忧开源软件供应链攻击可能比已知的更普遍，特别是国家行为体可能利用广泛使用的依赖注入后门。 争议焦点： • **责任归属**：部分评论认为攻击成功是由于包管理器和开发者的安全措施不足，而另一些则强调攻击者的创新手段（如利用 LLM）使得传统防御无效。 • **解决方案的有效性**：禁用脚本和减少依赖是否足以应对日益复杂的攻击，还是需要更根本的系统性改革（如强制安全规范）。

佛罗里达州立大学的研究发现，自ChatGPT于2022年问世后，其过度使用的AI流行词汇（如"delve"、"intricate"等）开始显著影响人们的日常口语表达。研究人员分析了2210万条非脚本口语数据，发现约75%的AI常用词汇使用频率明显上升，部分甚至翻倍，而同义词则未见增长。这表明AI不仅被作为工具使用，更可能正在改变人类语言系统。该研究揭示了AI对人类语言行为的潜在渗透效应，并引发关于模型偏见可能影响人类行为的伦理思考。

评论摘要
主要讨论点：ChatGPT是否导致某些词汇（如“delve”“intricate”等）被过度使用，以及这种语言现象的影响和争议。 不同观点： • **质疑词汇被标记为“AI写作”的合理性** - [milancurcic]反对仅因使用“delve”等词就判定内容为AI生成，认为这是个人语言习惯的差异。 - [jameslk]认为“surpass”“garner”等词并非罕见，日常对话中也会使用，不应被归类为“AI词汇”。 • **对“buzzword”定义的争议** - [tasty_freeze]指出“delve”等词只是低频词，不符合“流行语”的定义（如“force multiplier”等商业术语）。 - [freehorse]提出“meticulous”可能源于翻译软件的偏好，而非ChatGPT的直接影响。 • **用户主动规避AI语言特征** - [willquack]列举刻意避免的AI常用词（如“strategically”）、标点（如em dash）和写作结构（如固定举例数量）。 - [lucaspauker]因AI影响减少使用em dash，[mrbonner]故意加入拼写错误以显示“人类身份”。 • **数据与现象真实性的讨论** - [MrManatee]呼吁查看原始数据以验证词汇使用率上升是否真由ChatGPT导致，提出其他可能解释（如话题变化或个别作者偏好）。 补充讨论： - **语言模仿与演化**： - [esafak]认为AI可能通过模仿改变人类语言习惯，[mikewarot]调侃自己的评论可能影响了AI训练数据。 - **文化因素**： - [freehorse]提到中文翻译中“meticulous”的高频使用可能反映语言或工具偏好。 - **新词接受度分歧**： - [mickelsen]接受ChatGPT引入的新表达（如“living with intention”），但排斥过度流行的词汇（如“vibing”）。 - **争议焦点**：词汇使用变化是AI强制输出的结果，还是自然语言演化的体现？用户对AI语言的抵触是否合理？
