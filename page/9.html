Stdio(3) change: FILE is now opaque

作者: gslin | 评分: 140 | 评论数: 11 | 发布时间: 2025-07-20 18:18
文章摘要

2025年7月17日，OpenBSD的-current分支中，stdio(3)的FILE类型结构体被设为不透明（opaque），相关库版本也已更新。具体改动包括将__sFILE定义移至libc/hidden/_stdio.h，并暂时保留某些符号以方便过渡，但这些符号将很快被删除。这一重大变更影响了许多系统组件，建议从源代码构建的用户使用快照升级以顺利过渡。

评论摘要
主要讨论点：FreeBSD 中 FILE 类型的非透明性及其相关更改 不同观点： • **loeg** 提到 FreeBSD 曾尝试将 FILE 类型变为不透明，但更改被回退，目前在主分支中仍为非透明。他提供了相关的代码提交链接以支持其观点。 • **JdeBP** 认为，当对 C 库进行此类更改时，首先应关注 stdin、stdout 和 stderr 的变化，因为这些标准流的历史实现方式可能会导致链接问题。他指出，改变这些标准流可能导致未重新编译的代码无法链接。 • **Cadwhisker** 质疑更改的原因，询问是否出于安全原因或为未来变化做准备，强调好的评论应说明“为什么”。 • **abnercoimbre** 表示自己一直将 FILE 视为不透明类型，但没想到有人会深入探究其内部结构，暗示对 FILE 内部的依赖可能是不好的实践。 • **severino** 引用了 Linux/GNU 中的代码，询问这种定义是否意味着类型是不透明的，提供了具体的代码示例。 • **cperciva** 补充，非不透明 FILE 允许与将 FILE 放入结构中的代码兼容，因为不透明 FILE 没有大小。 • **p0w3n3d** 质疑为何要依赖 FILE 的内部结构，认为这是一种不良实践。 • **xpressvideoz** 对提交信息和公告文章中未提及理由表示不满，认为这种做法令人不安。 • **notepad0x90** 赞赏 *bsd 的勇气，认为它们不惧变化，而 Linux 应从中学习，并指出 Windows 因不愿打破旧有体系而导致的问题。 • **somat** 通过对比 OpenBSD 和 Linux，指出 Linux 在更改 ABI 方面的困难和顾虑，并分析了 Linux 的特殊情况，如闭源软件的支持和项目规模的影响。 补充讨论： • **quotemstr** 提到 CHERI 可以在无需切换地址空间的情况下防止对内部数据结构的访问，为讨论提供了一种技术解决方案。 争议焦点： • 主要争议在于是否应将 FILE 类型设为不透明，以及依赖 FILE 内部结构是否为不良实践。部分参与者认为更改应有明确理由，并对当前做法表示担忧。

文章摘要

文章主要介绍了一种用于操作系统内核的高效并发数据更新机制——RCU（Read, Copy, Update）。RCU适用于数据读多写少的场景，如USB设备状态管理。其核心思想是在更新数据时，先读取当前数据，复制并修改生成新版本，然后通过原子操作更新指针。为解决旧数据删除时的使用中状态问题，读者通过`rcu_read_lock`和`rcu_read_unlock`标记读取过程，写者则等待之前的读者完成后才删除旧数据。为进一步优化，删除操作可以延迟执行，甚至交由专门的线程处理，类似于垃圾回收机制。RCU已被广泛应用，如Linux内核和Facebook的Folly库。

本文讨论了一种通过非激光手段体验新颜色的方法。人类眼睛有三种锥细胞，分别对不同波长的光敏感，但它们的感光范围重叠，导致我们无法单独激活某一种锥细胞。通常，进化使我们只能看到有限的颜色。然而，通过特定技术，如激光刺激或视觉错觉，可以实现单独激活锥细胞，从而看到全新颜色。 文章提到Fong等人（2025）通过激光选择性刺激M锥细胞，使实验对象看到了前所未见的蓝绿色。而通过一种光学错觉动画，普通人也可以体验类似效果：盯着缩小的小红圈，背景会产生强烈蓝绿色幻觉。这是因为红圈使L锥细胞饱和，从而减弱对M锥细胞的干扰。 此外，文章还探讨了颜色感知的基本原理和色彩空间的限制，指出标准RGB色彩空间无法完全呈现人眼可见的所有颜色。

主要讨论点：颜色的生物学基础、视觉感知现象、色彩幻觉及其相关现象 不同观点： • georgecmu 详细解释了人类色觉的进化背景，特别是不同类型视锥细胞的敏感波长和基因机制。他指出，旧世界猴和新世界猴的色觉演化路径不同，且由于基因位置，色盲在男性中更常见。他还提供了相关维基百科链接供进一步阅读。 • TheAceOfHearts 描述了自己观看某个动画时的主观体验，强调色彩幻觉带来的愉悦感，并建议其他人耐心观看以获得最佳体验。 • peterisza 提到水透明性的电磁波谱范围与生物进化之间的关系，指出人类对可见光的敏感性与这种范围密切相关。 • evanb 引用了多年前一个关于色觉的网站，并提到一种被称为“psychedelic aquamarine”的颜色，还分享了自己通过按压眼睑再现这种颜色的体验。 • perching_aix 表示无法重现评论中提到的色彩幻觉，反而看到了不同的颜色（橙色），并对背景色的实际颜色表示困惑。 • ziofill 分享了一个会议中的技术故障趣闻，由于RGB电缆故障导致幻灯片颜色偏青，修复后一位教授误认为颜色变紫。 • pixelpoet 提到链接页面作者的其他贡献，如Mandelbulb的分形研究，提供了额外的背景信息。 • anigbrowl 指出画家早已意识到颜色感知的细微差别，建议读者参考艺术书籍或亲自探索颜料之间的色调差异。 • pb060 提到高对比度排版可能导致的视觉残留问题，并以此提醒不应在排版中使用高对比度。 • olelele 联想到艺术家James Turell的作品，描述了一个特定装置艺术带来的色彩和光晕体验。 • osamagirl69 感叹某个复杂概念在短时间内被简化为一个简单的SVG动画，并以幽默语气表示对色彩幻觉体验的赞赏。 • macawfish 描述了自己在观看某些色彩动画后出现的世界褪色现象，仿佛置身于棕褐色调中。 • blincoln 分享了自己尝试不同颜色组合后的意外结果，原以为会看到增强的黄色，但却看到了鲜艳的紫色，对此感到困惑。 • alkyon 提到这种视觉现象与Op Art技术的相似性，并提供了一个相关艺术家的链接。 • a_t48 展望了未来脑机接口技术可能带来的用户界面过度使用问题，暗示这种色彩幻觉可能被过度应用。 补充讨论： 评论中涉及到多个层面的讨论，包括科学解释（如色觉进化和视觉残留）、主观体验（如观看色彩动画的个人感受）、技术趣闻（如RGB电缆故障）以及艺术联想（如Op Art和画家对颜色的理解）。不同评论者提供了丰富的背景信息和个人经验，展现了多角度的讨论。争议的焦点主要集中在个体对色彩幻觉体验的差异上，部分人如TheAceOfHearts和perching_aix对同一现象有不同的视觉感知。

What my mother didn’t talk about (2020)

作者: NaOH | 评分: 83 | 评论数: 8 | 发布时间: 2025-07-17 21:43
文章摘要

本文作者在母亲去世后，通过查阅她的电子邮件，试图寻找母亲隐瞒病情的证据。母亲患有晚期疾病28年，但很少提及具体病情，仅在特别严重时强调。作者曾以为母亲会一直挺过难关，但最终她去世了。母亲出生于战后波兰的贫困家庭，通过努力在美国取得了成功，但她从不自视为女权主义者。在母亲生病期间，作者逐渐意识到她病情的严重性，但内心却一直在否认。母亲去世后，作者反思自己是否因习惯了她长期患病而未能足够重视最后的时刻。文章表达了对母亲隐瞒病情的理解以及对她艰辛一生的缅怀。

评论摘要
主要讨论点：对文章内容及其相关经历的讨论 不同观点： • [comrade1234] 分享了个人经历，将其母亲因癌症去世的过程与文章中母亲去世的情况进行比较。他提到母亲在临终时因剧痛产生幻觉，意识不清，而在家 hospice 护理与之后父亲因ALS去世时受控的药物使用形成对比。这强调了不同疾病和护理方式对临终体验的影响。 • [weinzierl] 关注文章中的细节，指出文章未提及母亲所患的具体疾病，暗示读者可能对此有疑问或期待更详细的信息。 • [JKCalhoun] 对文章产生了情感共鸣，联想到自己母亲去世的经历，并对文章作者的其他作品有所了解，提供了文章存档链接以防原链接失效。 • [kazinator] 则对文章中的时间线提出质疑，试图通过推算文章中提到的事件年份来厘清 Karolina 母亲的生平时间表。他对 Karolina 的出生年份和她们一家离开波兰的时间提出了不同的假设和推理。 补充讨论： • 争议焦点集中在文章细节的缺失和时间线的不明确，[weinzierl] 和 [kazinator] 都指出了文章中未详细交代的部分，尤其是母亲的疾病名称和时间线，导致读者理解上的混乱。 • 个人经历的分享和文章内容的共鸣也是讨论的重要部分，[comrade1234] 和 [JKCalhoun] 都结合自身经历对文章进行了评价和反思。 • 对时间线的推理展示了读者对故事背景细节的关注和探究，[kazinator] 试图通过逻辑推理解开文章中未解的谜团。
