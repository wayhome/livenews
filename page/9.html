Stop using the elbow criterion for k-means

作者: Anon84 | 评分: 75 | 评论数: 11 | 发布时间: 2025-03-23 02:51
文章摘要

本文批评了在k-means聚类中广泛使用的肘部法则（elbow method），指出该方法缺乏理论支持，易导致错误结论。作者呼吁停止使用肘部法则，并推荐了几种已被文献证明更好的替代方法来确定聚类数量，如轮廓系数（silhouette coefficient）和差距统计量（gap statistic）。文章呼吁教育者在课堂上讨论肘部法则的缺陷，并教授更可靠的替代方法，同时建议研究人员和审稿人拒绝基于肘部法则得出的结论。

评论摘要
主要讨论点：K-means及其相关聚类方法的有效性和理论依据 不同观点： • **支持Elbow方法的观点**： - whatshisface认为Elbow方法有简单的理论基础，如果数据确实有k个明显分离的簇，分割不同簇的收益应明显大于分割同一簇的收益。 • **对论文标题的批评**： - joshdavham批评了一些研究论文的标题风格，认为它们像点击诱饵，特别是使用“Stop doing [conventional thing]!”这种标题令人厌烦。 • **替代方法的建议**： - djoldman提到像Calinski和Harabasz的方差比率标准(VRC)、贝叶斯信息准则(BIC)或Gap统计等替代方法通常更优。同时指出，聚类算法本质上是无监督的，因此没有绝对正确的答案，实际应用通常决定了最佳算法和参数。 • **支持其他方法的观点**： - tetris11偏好使用silhouette方法，因为其生成的结果看起来不错，但在K=1时失败。 • **Elbow方法的实际效果质疑**： - egberts1提到信用卡欺诈部门大量使用K-means中的Elbow方法。 - rgavuliak则认为Elbow方法在实践中效果不佳，自己多年经验中从未见过显著的分离图表。 • **对聚类任务的定义质疑**： - esafak认为聚类任务定义不清，如何构成一个簇，是否通过欧氏距离分离等标准不具有尺度不变性，并建议根据下游任务优化表示和聚类算法。 • **对K-means的批评和替代建议**： - bbstats直接建议停止使用K-means。 - pbronez指出K-means是高斯混合模型的一种特例，做了很多数据假设，理解模型背后的统计假设至关重要。 - Der_Einzige也建议停止使用K-means，推荐使用GPU实现的HDBScan，认为其在处理大数据集上更优越。 补充讨论： - jb1991认为对K-means的批评有些反应过激。 - 总体上，讨论中存在对K-means的批评与支持两种对立观点，同时也提到了多种替代方法和实际应用中的选择依据。

Landrun: Sandbox any Linux process using Landlock, no root or containers

作者: Zoup | 评分: 490 | 评论数: 27 | 发布时间: 2025-03-22 13:56
文章摘要

**landrun** 是一个轻量级、安全的 Linux 进程沙箱工具，利用内核中的 Landlock LSM 模块实现无特权进程的限制。相比 firejail，landrun 更轻量、易用，且直接集成在内核中。它支持细粒度的文件系统和网络访问控制，无需 root 权限或容器技术，也不需要配置 SELinux/AppArmor。 **主要特性**： - 内核级安全，使用 Landlock LSM - 轻量快速 - 精细目录访问控制（读、写、执行） - TCP 网络访问控制（绑定、连接） **安装与使用**： - 通过 `go install` 快速安装 - 使用不同选项控制文件和网络权限，如 `--ro`（只读）、`--rw`（读写）、`--bind-tcp`（绑定 TCP 端口）等 - 支持指定日志级别和环境变量 **要求**： - Linux 内核 5.13 及以上（基础功能），6.7 及以上（网络限制） - Go 1.18 及以上（从源码构建时） **示例**： - `landrun --rox /usr/ --ro /path/to/dir ls /path/to/dir`：以只读和执行权限运行命令 - `landrun --bind-tcp 8080 --connect-tcp 80 /usr/bin/my-server`：限制网络访问端口 8080 和 80
