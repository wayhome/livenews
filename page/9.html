Drag racers are ditching superchargers for scuba-style tanks and compressed air

作者: PaulHoule | 评分: 43 | 评论数: 18 | 发布时间: 2025-04-03 21:44
文章摘要

文章介绍了压缩空气增压技术（Compressed Air Supercharging，CAS）在直线加速赛车领域的新应用。传统上，赛车手使用涡轮增压和机械增压来提升动力，但一些车手开始尝试CAS，这种技术通过将压缩空气储存在碳纤维罐中并送入发动机，提供更冷、更密集的空气，从而提高动力输出。尽管初始阶段受到质疑，但像Dale Vaznaian等先锋车手证明了其有效性。Tina Pierce和Ryan Mitchell等赛车手也已采用这种技术，并取得显著成绩。CAS的优势在于其较低的工作压力和温度，对发动机更温和，且不受燃油辛烷值限制。尽管尚未普及，但CAS展示了巨大的潜力，可能成为未来赛车动力提升的重要手段。

Globstar: Open-source static analysis toolkit

作者: vortex_ape | 评分: 3 | 评论数: 0 | 发布时间: 2025-04-08 22:32
文章摘要

Globstar 是一个开源静态分析工具包，帮助开发者和安全工程师编写和运行代码检查器。它使用 tree-sitter 进行强大的 AST 分析，支持从简单的 YAML 接口到复杂的 Go 接口编写检查器。Globstar 具有以下特点： 1. **高速高效**：用 Go 编写，适合大型代码库，独立二进制文件无需担心依赖。 2. **原生支持 tree-sitter**：利用 S-expressions 编写检查器，或用 Go 实现更复杂的逻辑。 3. **CI 友好**：可在任何 CI/CD 管道中运行，无需额外安装依赖。 4. **完全开源**：MIT 许可，可自由用于商业项目。 安装方法： ```sh curl -sSL https://get.globstar.dev | sh ``` 编写检查器示例： ```yaml # .globstar/dangerous_eval.yml language: python name: dangerous_eval message: "Dangerous use of eval() detected." category: security severity: critical pattern: > (call function: (identifier) @func (#eq? @func "eval") arguments: (argument_list [(identifier) (binary_operator)])) ``` 在 CI 中运行： ```yaml jobs: analyze: runs-on: ubuntu-latest steps: - uses: actions/checkout@v3 - name: Install Globstar run: curl -sSL https://get.globstar.dev | sh - name: Run Globstar run: globstar check ```

文章摘要

《Elimination Game》是一个多玩家锦标赛，用于测试大型语言模型（LLMs）在社交推理、策略和欺骗方面的能力。玩家通过公开和私下的对话互动，结成联盟并投票淘汰对手，直到只剩两名玩家。被淘汰的玩家组成陪审团，决定最终胜者。该 benchmark 包含以下关键要素： 1. **公开与私下动态**：平衡公开讨论与秘密联盟。 2. **策略性投票**：每轮匿名投票淘汰一名玩家，平局时有附加规则。 3. **陪审团说服**：决赛选手需说服陪审团以赢得胜利。 比赛通过对话日志、投票模式和最终排名分析模型如何处理共享知识与隐藏意图，并提供多项指标如图表和视频回放，展示模型的表现和策略运用。

本文回顾了20世纪80年代通过电视广播下载软件的独特方式。当时，许多电视节目，如BBC的《The Computer Programme》和Channel 4的《Four Computer Buffs》，不仅教授编程和电子制作，还尝试通过电视信号传播软件。主要使用了两种技术：一种是通过**Teletext**（图文电视）传输数据，利用电视信号的空白间隙广播软件，BBC Micro电脑可接收这些数据；另一种方法使用**光电二极管**电路，通过检测电视屏幕上黑白方块的光变化来转换为计算机代码，但数据传输速率较低。后来，Billingsley兄弟发明了**Visicode**技术，通过快速光变化实现在每个半帧传输一个字节的数据，大大提高了传输效率。这些方法反映了早期技术爱好者在资源有限的情况下进行的创新尝试。

Work Simplification and the History of Government Efficiency and Management

作者: RetiredRichard | 评分: 14 | 评论数: 1 | 发布时间: 2025-04-09 00:17
文章摘要
