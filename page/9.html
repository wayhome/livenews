文章摘要

本文挑战了高性能计算(HPC)领域"硬件FP64是科学计算基础"的传统观念。作者提出,在NVIDIA B300等AI优化GPU上,虽然原生FP64性能大幅退化至~1.3 TFLOPS,但通过结合丰富的FP8张量算力与基于中国剩余定理的Ozaki Scheme II方法,可以在内存带宽限制下恢复完整FP64精度,使模拟FP64性能达到~500 TFLOPS,超越B200原生FP64性能一个数量级。研究通过张量-内存平衡(TME)模型证明,对于稀疏矩阵、模板计算等典型HPC核心算法,FP8配合Ozaki II技术即可满足生产级需求,硬件FP64不再是必需的"圣杯"。

How's Linear so fast? A technical breakdown

作者: howToTestFE | 评分: 474 | 评论数: 72 | 发布时间: 2026-06-07 19:01
文章摘要

Linear 的速度秘诀在于将数据库放在浏览器中（IndexedDB）。传统应用需要等待服务器响应（约300毫秒），而 Linear 的 UI 直接读取本地数据库，用户操作立即生效，数据异步同步到服务器。核心理念是隐藏所有网络请求，避免加载状态。修改一个 issue 只需两行代码：直接更新本地数据，后台保存。虽然大多数应用不需要自建同步引擎，但可以通过 Tanstack Query 或 SWR 的乐观更新实现类似效果。Linear 的技术栈很简单：React、TypeScript、MobX、Postgres，没有复杂框架，从第一天就围绕同步引擎构建。

评论摘要
主要讨论点：Linear 项目管理工具的性能表现及其本地优先（local-first）同步架构的优劣 不同观点： • **Linear 并不快派**：多位用户反馈 Linear 实际使用中搜索慢、UI 卡顿、CPU 占用高、数据加载无明显提示，与宣传的"快速"体验不符。有人认为早期 Trello 才是最佳体验。 • **技术架构质疑派**：认为 Linear 这类应用不需要复杂的本地优先架构。任务追踪工具写冲突少、易分片，传统 CRUD 架构通过优化后端（10ms RTT + 10ms 处理）也能达到 30ms 响应，而非文章声称的 300ms。本地副本反而可能增加不一致性。 • **eventual consistency 风险派**：指出最终一致性数据库难以实现，离线编辑、冲突解决、schema 漂移、外键约束等问题复杂。担心乐观更新（optimistic updates）成为趋势后，开发者忽视失败同步、冲突处理等"悲观路径"，导致新一轮竞态条件和用户挫败。 • **场景适用性派**：认可 Linear 的方案适合任务追踪场景，但不适合交易/订单类应用——服务端必须是单一真相源，否则会出现已付款但无库存的荒谬场景。 • **技术推广派**：分享类似技术方案（Zero/Replicache）和实现细节，推崇客户端渲染和预加载策略，认为登录后应用无需 SSR。 补充讨论：有人分享了 Linear 同步引擎的逆向工程解析。整体而言，争议焦点在于本地优先架构是否过度工程化，以及其复杂性是否值得。

Age verification tech could put children at greater risk, says think tank

作者: robtherobber | 评分: 180 | 评论数: 25 | 发布时间: 2026-06-08 07:40
文章摘要

英国信息政策研究基金会(FIPR)对政府强制年龄验证提案表示担忧。该提案旨在限制儿童访问社交媒体，但FIPR警告称，许多年龄验证方案可能加剧而非减轻伤害，使儿童面临敲诈和滥用风险。强制验证要求用户提供生物识别信息、信用卡或政府身份证明，存在隐私和安全风险，且对少数族裔等弱势群体识别效果差，可能导致数字排斥。FIPR建议采用"标签与屏蔽"方式，由家长在设备上设置内容过滤，类似电影分级系统，而非强制全面年龄验证。

评论摘要
主要讨论点：关于社交媒体年龄验证法规的争议，核心在于这是保护儿童还是政府监控的借口。 不同观点： • **家长责任论**：认为家长本身就有能力限制孩子使用社交媒体，无需政府立法。质疑为何90%支持禁令的家长不直接切断孩子的社交媒体访问，指责这是"懒惰家长"要求他人代为管教。 • **隐私与监控担忧**：认为年龄验证是政府大规模监控的伪装，会侵犯所有人的隐私权。担心统一身份识别系统的扩展应用，将追踪个人的所有在线活动。有评论称这是"人类历史上对个人自由最严重的威胁"。 • **实施无效论**：指出年龄验证容易被绕过，反而会把用户推向暗网等非法平台。认为家长控制软件已经存在，无需新法规。类比电影分级制度，家长经常让孩子观看超龄内容，预测年龄验证也会遭遇类似情况。 • **集体行动可能性**：提出家长可以集体行动限制孩子使用社交媒体，避免单个孩子被孤立的问题，但质疑这是否现实。 • **广告监管替代方案**：建议通过禁止向未成年人投放广告来解决问题，而非年龄验证。平台已有人口统计能力，可追究其法律责任。 补充讨论：有人质疑智库资金来源的透明度问题；也有观点认为科技公司借保护未成年人之名重新收集其数据。
