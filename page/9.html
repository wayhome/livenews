This is a comment}}`。 ### 示例 - **布尔节示例**: ```cpp std::string_view layout = R"({{first_name}} {{last_name}} {{#employed}}Status: Employed, Age: {{age}}{{/employed}})"; person p{"Carol", "Davis", 30, true, true}; auto result = glz::stencil(layout, p); // 结果: "Carol Davis Status: Employed, Age: 30" ``` - **容器迭代示例**: ```cpp struct TodoList { std::string title; std::vector items; bool has_items; }; std::string_view layout = R"({{title}}: {{#items}}{{text}} ({{priority}}) {{/items}})"; TodoList list{"My Tasks", {{"Buy milk", false, "normal", 1}, {"Call mom", true, "high", 2}}, true}; auto result = glz::stencil(layout, list); // 结果: "My Tasks: Buy milk (normal) Call mom (high) " ``` ### Mustache格式 `glz::mustache`与`glz::stencil`接口相同，但提供HTML转义： - 双括号 `{{key}}` 输出HTML转义内容。 - 三括号 `{{{key}}}` 输出原始HTML内容。 ### 错误处理 `stencil/mustache`函数返回`std::expected`，常见错误如引用不存在的字段。
