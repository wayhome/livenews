Why the $25,000 car is going extinct

作者: pseudolus | 评分: 26 | 评论数: 11 | 发布时间: 2025-06-29 15:59
文章摘要

文章主要讨论了为何价格在25,000美元以下的经济型汽车正在消失。以福特Maverick为例，尽管最初定价为19,995美元并受到欢迎，但由于需求旺盛，经销商加价销售，导致其成为“最不划算”的新车之一。自2019年以来，价格低于25,000美元的新车销售比例从23%下降至4.8%。经济型汽车的消失主要是因为汽车制造商更倾向于生产利润更高的高端车型，而这些低端车型的生产利润微薄。许多曾经经济实惠的车型，如雪佛兰Spark、福特Fiesta等，已经停产。随着供应减少，剩余的经济型汽车价格也被抬高，消费者面临更少选择和更高价格。

Exploring Trichromacy through Maxwell's Color Experiment (2023)

作者: niwrad | 评分: 22 | 评论数: 2 | 发布时间: 2025-06-28 21:55
文章摘要

本文探讨了詹姆斯·克拉克·麦克斯韦（James Clerk Maxwell）对三色视觉理论（trichromatic theory）的贡献。三色视觉理论解释了人类如何通过三种颜色感知大多数色彩，这一理论常归功于托马斯·杨（Thomas Young）和赫尔曼·冯·亥姆霍兹（Hermann von Helmholtz）。麦克斯韦通过一个复杂的实验装置，利用棱镜和狭缝，展示了如何通过三种特定波长的光（如红、绿、蓝）组合生成不同颜色。他调整狭缝的位置和宽度，控制光的强度和颜色，成功再现了各种色彩。这证明了人眼通过三种颜色可以感知到大多数自然色彩，奠定了现代色彩显示技术的基础。

c4wa – C compiler for Web Assembly

作者: 90s_dev | 评分: 86 | 评论数: 9 | 发布时间: 2025-06-24 15:52
文章摘要

**c4wa** 是一个将 C 语言的简化子集转译为 Web Assembly (WASM) 的编译器。其主要特点包括：生成精简高效的 WASM 输出，无额外嵌入库或不必要的开销，兼容任何 WASM 运行时，无需依赖 JavaScript 或 Node。它利用 WASM 的线性内存模型，支持动态内存分配，并能输出文本格式的 WAT，便于理解和手动编辑。c4wa 支持 C 语言的基本特性，如循环、条件、指针、动态内存分配等，且可使用外部 C 预处理器。其目的是在高级语言编写和底层 WASM 控制之间找到平衡，生成的 WAT 文件类似手写代码。该工具需要 Java 11 及以上版本，并可在任何安装 Java 的平台运行。生成的 WASM 文件独立于平台。
