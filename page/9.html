We won $92,337 bug bounty using a single kernel 0-day

作者: etenal | 评分: 8 | 评论数: 3 | 发布时间: 2026-07-08 01:37
文章摘要

GhostLock（CVE-2026-43499）是一个存在于所有Linux发行版长达15年的内核漏洞，影响版本从2.6.39到7.1。该漏洞允许无特权本地攻击者通过常规线程系统调用获得root权限和容器逃逸能力。 漏洞根源在于rtmutex（实时互斥锁）实现中的remove_waiter()函数。在Requeue-PI路径上，该函数错误地清除了当前线程（执行FUTEX_CMP_REQUEUE_PI的线程）的pi_blocked_on指针,而非实际等待者线程的指针。当发生死锁回滚时，真正的等待者线程保留了指向其已释放栈帧的悬空指针，攻击者可利用此获取内核栈内存访问权限，进而劫持函数表实现提权。 该漏洞仅需CONFIG_FUTEX_PI=y配置，无需特殊权限。Google通过kernelCTF项目奖励发现者$92,337。漏洞已在Linux 7.1中修复。

评论摘要
主要讨论点：Linux内核严重漏洞GhostLock的发现、利用和影响范围 不同观点： • **漏洞基本特征（djfergus）**：强调这是一个存在15年的本地内核use-after-free漏洞，从2011年Linux 2.6.39引入，直到2026年4月才修复，可实现97%成功率的权限提升和容器逃逸 • **实际利用价值（etenal）**：从安全研究团队角度，展示了该漏洞的商业价值（近$10k赏金）和实战能力——通过与Firefox IonMonkey 0-day结合，构建完整攻击链"IonStack"，实现从URL点击到远程控制Android 17设备的全链路攻击 补充讨论： 两条评论呈现互补关系而非对立。第一条侧重技术特征和历史影响（15年未修复），第二条则展示了漏洞的实战weaponization过程。争议焦点可能在于：如此严重的内核漏洞为何能存在15年未被发现？以及公开exploit代码是否合适。etenal团队已提供完整技术文档和GitHub代码，表明这是responsible disclosure后的公开。

Microsoft Can Track Users via a Windows Device ID

作者: ifh-hn | 评分: 281 | 评论数: 23 | 发布时间: 2026-07-07 08:54
文章摘要

微软通过"全局设备ID"(GDID)协助FBI逮捕了19岁黑客Peter Stokes,引发监控争议。 GDID是Windows系统中的持久设备标识符,可唯一识别每台设备或虚拟机。关键问题在于:微软能将GDID与第三方服务访问记录和时间戳关联,实际上可追踪Windows PC的在线活动。 在Stokes案中,微软记录显示其GDID在特定时间访问了ngrok等网站。虽然用户可通过重装系统重置GDID,但微软仍可能通过账户登录或IP地址将新旧ID关联。 网络安全专家认为这将Windows变成了"监控软件",并质疑苹果等其他科技公司是否有类似能力。目前GDID没有简单的退出选项,这引发了对用户隐私的担忧。

评论摘要
主要讨论点：微软Windows系统中的GDID（全局设备标识符）被用于追踪用户活动，并在刑事案件中向执法部门提供数据，引发隐私争议。 不同观点： • **技术边界争议**：核心问题不在于设备标识符的存在（多数操作系统都有），而在于访问权限边界——哪些组件可以访问它，以及本地标识符何时变成远程追踪工具。可能通过Windows Defender实时保护或MAPS系统进行流量分析并关联GDID。 • **隐私立场分歧**：强硬派认为这证明微软完全不关心用户隐私，即使其Cookie声明如此；部分用户已将家庭设备迁移至Linux、Apple等平台；质疑是否违反欧盟隐私法规。 • **技术实现质疑**：文章缺乏明确证据说明微软能看到Chrome/Firefox的访问页面；追踪可能通过Windows Update、时间服务器或Defender等系统服务实现，而非浏览器级别；ID格式（16位数字而非十六进制）引发疑问。 • **行业对比观点**：Android也有类似设备ID用于用户画像；美国科技公司做法趋近俄罗斯和中国；广告技术行业也是这种监控基础设施的一部分。 补充讨论：案件中通过IP地址定位设备，结合Windows Update请求锁定GDID，体现了隐私倡导者长期警告的监控能力；有人讽刺"黑客"竟然使用Windows系统。

Aleph团队开发了一种基于超声波的无声语音识别系统。他们将超声波探头置于下巴后方捕捉舌头运动视频，并将其转换为文字。 该系统在仅50小时数据集上训练（相比之下，唇读需要100万小时数据才能达到12.5%词错误率），就接近了现有方法的性能水平。更令人惊喜的是，模型能够泛化到新用户，无需个性化训练即可使用。 超声波技术的优势在于能直接清晰观察舌头，而舌头包含34种不同的音素类别，远超唇形的10-14种。这使得无声语音识别既准确又隐私，可实现比打字快4倍的"隐形"交流。 技术上，他们让受试者大声朗读合成短故事收集数据，使用ResNet-18处理视频，并借助Whisper解码器将舌头运动嵌入转换为文本。
