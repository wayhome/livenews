文章摘要

英国信息专员办公室（ICO）因儿童数据保护问题对Imgur母公司展开调查，并计划处以罚款。Imgur随后主动停止在英国的服务，但ICO强调退出市场不能免除企业责任。该平台拥有1.3亿用户，因涉嫌违反儿童数据保护规定面临处罚，具体金额未披露。ICO表示将继续推进调查，并要求企业在9月10日前提交陈述。Imgur于2009年创立，2021年被收购，主要提供图片托管和分享服务。

Browsh: A fully-modern text-based browser, rendering to TTY and browsers

作者: surprisetalk | 评分: 7 | 评论数: 0 | 发布时间: 2025-09-30 01:40
文章摘要

Browsh 是一个现代化的纯文本浏览器，支持在终端和浏览器中渲染网页内容。它基于无头 Firefox 浏览器，能在极低带宽（如 3kbps）下工作，适合通过 SSH 或 MoSH 连接使用。相比传统文本浏览器，Browsh 支持 JS 和 HTML5，并能将网页转换为纯文本显示。它还提供 Docker 镜像和二进制文件下载，支持开发者通过 Go 和 JavaScript 进行扩展。项目采用 LGPL-2.1 许可，特别适合低功耗设备或网络条件差的场景使用。
