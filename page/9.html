Blender: Beyond Mouse and Keyboard

作者: dagmx | 评分: 233 | 评论数: 20 | 发布时间: 2025-07-24 15:20
文章摘要

文章主要讨论了将Blender软件全面引入多点触控平板设备的计划，如Apple iPad Pro和Microsoft Surface等。目标是让Blender在保持完整功能的同时，适应这些设备的操作特性，提供更任务导向的用户界面，减少信息密度。初期将专注于基础对象操作和雕刻功能，后续加入Grease Pencil和分镜等更复杂的工具。 平板UX面临的挑战包括单窗口全屏工作流、较小的屏幕空间、无键盘鼠标操作、有限的处理能力和电池等。为解决这些问题，Blender将通过扩展输入方式、改进工作区和应用模板来优化用户体验。某些设计改进，如快速收藏编辑器和助手覆盖层，也将惠及桌面用户。开发团队计划先在iPad Pro上测试，之后扩展到Android和其他图形平板。 文章还展示了UI和交互的初步设计模型，强调在有限屏幕空间内提供高效工作环境。

"Multiplex" 是一个命令行工具和简单的 Python API，用于并行运行多个进程，并可以根据条件或一次性停止所有进程。它能够优雅地关闭子进程，并将它们的输出和错误信息复用到 stdout 和 stderr，方便使用常规命令行工具解析。适用于需要同时运行多个程序并组合其输出的场景，如同时启动 web 服务器、工作队列和数据库。 安装可通过 PyPI、pip 或直接下载进行。其命令语法支持命名进程、设置时间或进程延迟、以及定义进程行为（如静默输出或结束时终止其他进程）。通过简单的命令格式，可以实现进程的顺序执行、并行运行及复杂协调。 示例： ```bash multiplex "DB=mongod" "API+2=node server.js" "+API=npm test" ``` 这将并行启动 MongoDB、延迟 2 秒启动 Node.js 服务器，并在 Node.js 服务器启动后运行 npm test。
