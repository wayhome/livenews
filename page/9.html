文章摘要

文章主要介绍了如何使用OpenTelemetry为GitHub Actions的CI/CD管道增加可观察性。OpenTelemetry是一个开源的可观察性框架，能够以标准、供应商无关的方式收集 traces、metrics 和 logs。文章解释了为何要使用 OpenTelemetry 观察 CI/CD 管道，包括实现端到端可见性、性能优化、错误检测与调试，以及依赖分析等优势。通过配置 OpenTelemetry Collector 和 GitHub Receiver，可以捕获工作流事件作为 traces，并通过 GitHub API 获取 metrics。文章还提供了具体的设置步骤，包括配置 GitHub 网络钩子和访问令牌，以实现对 GitHub Actions 的全面监控。

Real-time CO2 monitoring without batteries or external power

文章摘要

KAIST研究团队开发了一种自供电无线二氧化碳（CO2）监测系统，无需电池或外部电源。该系统利用周围细微振动能量，通过惯性驱动 Triboelectric Nanogenerator (TENG) 转换为电能，实现CO2浓度的定期测量和无线传输。系统在13 Hz频率和0.56 g加速度下稳定产生0.5 mW电力，足以支持CO2传感器和蓝牙低功耗系统工作。该技术解决了传统监测系统在安装和维护上的限制，为未来自供电环境监测平台奠定了基础。研究成果发表于《Nano Energy》期刊。

评论摘要
主要讨论点：一种新型的基于“惯性驱动摩擦电纳米发电机（TENG）”系统，利用工业设备或管道振动发电，并实现CO2浓度测量和无线传输的功能。 不同观点： • **tempodox**：认为这个系统非常巧妙，核心是通过TENG将振动转换为电能，从而实现CO2浓度的定期测量和无线传输，且无需电池。他对这个创新表示赞赏。 • **Gravityloss**：提出是否存在一种化学替代方案，比如通过颜色变化来反映CO2水平，类似于碳酸氢盐指示剂。这表明他可能认为化学方法可能是一种更简单或更直观的替代方案。 • **nikolayasdf123**：质疑这个系统的突破性，认为振动发电和CO2监测都不是新概念，因此对为何这个系统被视为重大突破表示困惑，寻求更详细的解释。 • **noisy_boy**：发表了与主题略微偏离的评论，提到通过一个网剧了解到韩国科学技术院（Kaist），并将该机构与这个新技术联系起来。他的评论更多是关于对该机构的认知，而非直接针对技术的讨论。 补充讨论： • **技术创新性争议**：nikolayasdf123对该技术的创新性提出质疑，认为振动发电和CO2监测都已经有现有技术，因此需要更明确的解释来理解这个新系统的独特之处。 • **化学替代方案的思考**：Gravityloss提出了一种化学方法的可能性，尽管这是一种不同的技术路径，但同样可以达到监测CO2水平的目的。这种思路提供了一种与TENG技术不同的视角。 • **对新技术赞赏**：tempodox对该技术表示了直接的赞赏，认为其设计巧妙，特别是其无需电池的特点，显示出对该技术实用性和创新性的认可。

The experience continues until you stop experiencing it

作者: durakot | 评分: 79 | 评论数: 8 | 发布时间: 2025-06-15 16:36
文章摘要

How to modify Starlink Mini to run without the built-in WiFi router

文章摘要

本文介绍了如何将Starlink Mini终端内的内置Wi-Fi路由器板移除，使其仅通过以太网运行，从而为高级用户提供更大灵活性。该过程适用于Starlink Mini 1，需要小心拆解，使用金属撬棍和塑料撬具，但不要移除金属板，因为它既是散热片也是电磁屏蔽。移除路由器板后，可以通过连接器实现直接以太网连接，使用12V电源，并注意控制电磁干扰。终端默认提供DHCP IP地址（192.168.100.0/24网络），连接卫星后通过隧道DHCP服务提供互联网访问。要同时访问终端和管理网络，需添加静态路由。注意，该修改不适用于未来型号如Mini 2。
