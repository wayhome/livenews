Python 3.15: features that didn't make the headlines

文章摘要

Python 3.15即将发布，带来多项实用新特性： 1. **Asyncio TaskGroup取消功能**：新增`TaskGroup.cancel()`方法，可优雅地取消任务组，无需抛出异常，使用更简洁。 2. **上下文管理器装饰器改进**：`ContextDecorator`现在支持异步函数、生成器和异步生成器，覆盖完整生命周期，使上下文管理器成为创建装饰器的更好方式。 3. **线程安全迭代器**：新增`threading.serialize_iterator`包装器和`threading.synchronized_iterator`装饰器，使迭代器在多线程环境下安全使用，避免值跳过或状态损坏。还提供`threading.concurrent_tee`用于跨多个迭代器复制值。 这些小特性虽不如大型PEP引人注目，但同样值得关注，能显著改善开发体验。

评论摘要
主要讨论点：Python 3.15 新特性的评价以及 Python 语言的发展方向 不同观点： • **积极支持派**：认为新特性很实用，特别是 frozendict、Iterator 同步原语、ContextDecorator 改进等小功能往往最有用，标准库的增强值得在项目中测试 • **技术质疑派**：指出 ContextDecorator 的行为变更虽然修复了问题，但没有 opt-in 机制可能导致现有代码意外崩溃；有人对 lazy imports 的实现细节存疑；发现文档中 Counter 示例有错误 • **语言设计批评派**：认为 Python 正在失去其"禅意"和简洁性，lazy loading 等特性是"最后一根稻草"；质疑为什么每种语言都要添加所有特性，Python 已失去魅力 • **迁移实践派**：在 AI 代码生成时代，已将 10 万+行 Python 代码迁移到 Go 等更快的语言；Wes McKinney 等知名开发者也在转向其他语言 • **AI 影响观点**：认为在 LLM 时代几乎不再直接写代码，对语言设计失去兴趣，担心编程语言研发可能因此停滞 补充讨论：有人分享了 Python 内部管理和 free-threading 的访谈链接；提醒 3.15 尚未发布（4 个月后）；部分开发者表达对 Python 的怀念但已不再使用
