Creating Debian packages from upstream Git

作者: JNRowe | 评分: 98 | 评论数: 6 | 发布时间: 2025-05-26 16:05
文章摘要

本文介绍了2025年创建Debian软件包的最佳工作流程，重点在于保留上游Git历史，以提高软件来源透明度和供应链安全。关键步骤包括： 1. **从上游Git仓库 fork/clone** 开始创建Debian打包仓库。 2. **使用git-buildpackage命令** 和统一的gbp.conf配置。 3. **遵循DEP-14标签和分支命名** 规范。 4. **使用pristine-tar和上游签名** 确保供应链安全。 5. **在debian/copyright中使用Files-Excluded** 过滤不需要的文件。 6. **使用补丁队列** 方便在Debian和上游分支间变基和挑选更改。 7. **利用Salsa进行自动化反馈和人工评审**。 通过打包命令行工具Entr演示具体步骤： 1. 创建新目录并克隆上游Git仓库。 2. 使用dh_make创建初始Debian打包。 3. 将打包草案作为合并请求（MR）提交，并使用Salsa CI验证质量。 4. 在Debian Sid容器中运行本地构建并迭代打包过程。 该流程确保了上游和Debian更改的清晰分离，并使用最新的工具链进行构建。

评论摘要
主要讨论点：Debian打包过程的复杂性及其文档质量 不同观点： • **mrweasel**：认为Debian的打包基础设施完整但复杂，尤其是对新手而言。文档不完善，特别是git-buildpackage工具的文档不够直观，新手难以确保未来升级是否顺利。 • **dundarious**：将Debian与Arch Linux进行比较，指出Arch的PKGBUILD文件和其文档更加简单明了，易于上手。Arch的wiki也更为简洁和实用。 • **sevg**：承认DEB格式功能强大，但对新手而言，Debian的打包过程和自动化的部分难以理解和发现。相比之下，Arch的PKGBUILD文件更容易理解，Debian的文档较差，导致入门门槛较高。 • **denkmoon**：分享了一个工具Debcraft，认为它能够有效隔离构建环境，简化Debian打包过程，并提供了一个链接供参考。 • **pornel**：表示Debian打包过程看起来复杂，但实际上并非如此困难。提到自己维护的cargo-deb工具，可以在无需配置的情况下构建.deb包。 • **pabs3**：详细描述了Debian打包的迭代过程，包括使用debuild、lintian等工具，反复修正错误，以及通过mentors和sponsor请求的过程，强调了实际操作中的反复修正和反馈环节。 补充讨论： • **工具对比**：讨论中提到了多种工具，如git-buildpackage、Debcraft、cargo-deb和debuild，显示了不同用户对不同工具的偏好和使用经验。 • **文档质量**：多个评论提到了Debian文档的不足，特别是对新手不够友好，这也是用户认为Debian打包过程复杂的一个重要原因。 • **系统对比**：有评论将Debian与Arch Linux进行对比，Arch的简单易懂被多次提及，反映了不同Linux发行版在打包过程中的差异和各自的优缺点。 争议焦点：Debian打包过程的复杂性和文档的不足是主要争议点，尤其是与Arch Linux相比时，这种差异更加明显。用户对如何简化Debian打包过程和改善文档有不同建议和经验分享。

A new class of materials that can passively harvest water from air

作者: Tycho | 评分: 389 | 评论数: 24 | 发布时间: 2025-05-26 13:14
文章摘要

研究团队在宾夕法尼亚大学化学工程实验室意外发现了一种新型纳米结构材料，能够从空气中捕获水分并在无需外部能量的情况下将水滴释放到表面。该材料结合了亲水性纳米孔和疏水性聚合物，通过毛细管凝结现象，在低湿度下也能凝结水汽，且水滴不会迅速蒸发。这种材料由Daeyeon Lee、Amish Patel等研究人员开发，具有在干旱地区收集水和利用蒸发冷却电子设备或建筑物的潜力。该发现已发表在《Science Advances》上，并被认为将引发新的研究方向。

评论摘要
主要讨论点：新型纳米材料从空气中取水的技术及其相关物理学和能量问题 不同观点： • **与现有技术类似，需能量输入**：gus_massa 认为该技术与现有的除湿袋类似，虽然可以吸收和释放水分，但需要外部能量来移除和处理水分。他们批评了宣传中暗示的“无需外部能量”的说法。 • **能量隐性输入，未明确说明**：hollosi 指出，实验中材料的温度是通过冷却装置控制的，虽然文章未明确提及，但这并不违反物理定律。 • **违反热力学第二定律的质疑**：mppm 提出，该材料在常温和低于100%的湿度下凝结水滴，这似乎违反了热力学第二定律。他们认为可能存在未说明的冷却装置或测量误差。 • **潜在的能量差解释**：salomon812 认为该材料可能依赖于某种形式的热差（如冷热差异），类似于布朗棘轮效应。尽管宣传中声称无需外部能量，但实际可能需要隐性的能量输入。 • **材料调控与智能应用的潜力**：andrewrn 对材料的未来应用持积极态度，认为通过调节孔径可以实现智能服装等创新应用，但也批评了宣传中的“违反物理学”措辞。 • **水收集与脱盐效率的比较**：elil17 强调从空气中收集水的能量需求高于脱盐过程，因此脱盐在效率上更具优势。 • **历史技术背景**：PaulHoule 提供了相关历史技术的链接，指出类似技术早已存在，如空气井和雾收集器，认为不应夸大新发现的独特性。 • **被动过程无需能量输入**：davedigerati 认为该材料通过吸收和凝结过程自发运作，无需额外能量输入，可以减少对空调或除湿机的依赖。 • **技术批评过于苛刻**：fuddy 认为评论中对该技术的批评过于严厉，指出水凝结过程在自然界中普遍存在，无需视为“违反物理学”。 • **机械或光伏辅助的能量输入**：ggm 指出，尽管该过程可以被动进行，但如果有机械或光伏辅助，可以提高效率。 • **连续循环的潜在应用**：TimByte 对材料的连续凝结和释放过程表示赞赏，认为这使其在多种应用中具有潜力。 • **广泛应用的设想**：bilsbie 提出了该技术在农业、家居、能源生产和水资源管理等多个领域的潜在应用。 补充讨论： • 一些评论者关注该技术的宣传和科学表述问题，认为不应夸大其突破性或违反物理学，以免误导公众。 • 也有评论者对该技术的未来应用持积极态度，认为在智能服装、农业和水资源管理等领域具有创新潜力。 • 争议的焦点在于该材料是否真正无需外部能量输入，以及是否违反热力学第二定律。部分评论者认为可能存在未说明的能量差或测量误差。

Remote Prompt Injection in Gitlab Duo Leads to Source Code Theft

文章摘要
