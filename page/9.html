Mithril.js: small (8.96 KB gzipped) modern client-side JavaScript framework

作者: Brysonbw | 评分: 33 | 评论数: 7 | 发布时间: 2025-04-01 19:07
文章摘要

Mithril.js 是一个现代的客户端 JavaScript 框架，用于构建单页应用（SPA）。它体积小（压缩后 8.96 KB），速度快，内置路由和 XHR 工具。Mithril 支持 IE11 和多种现代浏览器，无需额外 polyfills。可以通过 CDN 或 npm 安装，并提供 TypeScript 类型定义。文档和 API 示例可在官方网站查看，社区支持活跃。贡献者可以通过 Zulip 社区和相关文档获得帮助。

Notes on the Pentium's microcode circuitry

文章摘要

本文介绍了奔腾处理器中的微码ROM（只读存储器）的结构和工作原理。微码ROM用于将复杂的机器指令分解为若干简单的微指令来执行。在奔腾处理器中，微码ROM分为两个矩形库，总共存储4608条微指令，合计414,720位。每个微指令长90位，由两个库各输出45位组成。ROM内部由288行和720列的晶体管网格构成，通过晶体管的存在与否来存储0或1。微码ROM通过金属布线层控制处理器的电路。奔腾的微指令比8086更长、更复杂，反映了其指令集的复杂性提升。文章还详细描述了NMOS晶体管的构造及微码ROM中位的编码方式。
