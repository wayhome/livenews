Last Week on My Mac: Losing confidence

作者: frizlab | 评分: 416 | 评论数: 52 | 发布时间: 2025-12-01 22:56
文章摘要

文章批评了macOS系统错误提示不透明的问题，指出其经常出现故障却未向用户提供明确报错信息，导致用户信心受损。作者以Safari网页存档失败等实例说明，这种"静默故障"让用户难以排查问题，只能通过变通方案解决。文章认为诚实、清晰的错误报告对维护用户信心至关重要，并指出AI领域同样存在因"幻觉"等模糊化错误描述导致用户信任流失的问题。多位用户评论也反映了对苹果系统信心下降的亲身经历。

评论摘要
### 主要讨论点： 用户对当前 macOS 质量的普遍不满，以及对苹果软件发展方向和质量的争议。部分用户对 Linux 或 Windows 作为替代方案的讨论。 ### 不同观点： #### **对 macOS 质量的不满** • **UI 和功能退化**：用户批评 macOS 的 UI 设计（如 iOS 化设置面板）变得混乱，破坏了原有的逻辑性和效率，认为桌面操作系统应该注重流畅性而非花哨设计。 • **Bug 积累**：多位用户指出 macOS 和苹果其他软件（如 Apple TV、Notes、Safari）中的小问题长期未修复，甚至在新版本中引入更多问题。 • **开发优先级问题**：苹果更注重新功能而非修复已有问题，导致系统质量下降，可能与公司内部激励机制（如晋升偏向新功能开发）有关。 #### **对苹果生态的失望与替代方案** • **转向 Linux**：部分用户因 macOS 质量下降转向 Linux，赞赏其开源、可定制性和稳定性，尽管承认 Linux 在“抛光”上不如 macOS。 • **Windows 的兼容性优势**：有用户认为 Windows 在向后兼容性上表现更好（如能运行老旧软件），而 macOS 和 Linux 在这方面较弱。 • **硬件依赖**：部分用户喜欢苹果硬件但厌恶其软件，被迫使用 macOS 仅因某些专业软件或硬件限制。 #### **对苹果未来的担忧与期待** • **创新 vs. 稳定**：用户希望苹果能像“Snow Leopard”时代一样专注优化而非盲目推新功能（如 AI 工具），否则可能失去忠实用户。 • **平台锁定效应**：用户因数据迁移和软件替代成本高而暂未放弃 macOS，但不满情绪加剧可能推动未来转向。 ### 补充讨论： • **争议焦点**：macOS 是否仍是“最佳桌面系统”？支持者认为其仍优于 Windows 和 Linux（如 UI 一致性），反对者则认为其质量已不可接受。 • **行业趋势**：AI 可能降低操作系统迁移成本，但当前用户更希望苹果优先解决基础体验问题。 • **历史对比**：部分用户怀念早期 macOS（如 10.6 时代）的稳定性，认为当前版本背离了“Think Different”的初衷。
