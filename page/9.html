文章宣布 bunny.net 将 `Bunny DNS` 改为免费：取消 DNS 查询收费，每账号可免费托管最多 500 个域名，仅保留平台每月最低 1 美元消费。其核心理念是让更快的互联网更普惠，并把 DNS 作为整个平台入口，整合加速、安全与智能路由，同时持续改进功能，如自动迁移、1-Click 加速/防护、IPv6 与 DNSSEC 支持。

评论摘要
主要讨论点：Bunny.net 将 DNS 查询收费取消并提供免费 DNS 托管后，大家围绕其竞争力、产品定位、成本模式、功能缺口与实际体验展开讨论。 不同观点： • 支持与看好者：认为 Bunny 是少见有竞争力的欧洲替代方案，服务快、价格低、体验好；相比部分欧洲公司涨价激进，Bunny 更务实。有人举例称其容器服务 16 个节点、约 20k API 请求每月仅 $3.60，Bluesky 也表示其 CDN 使用体验很好。 • 理性肯定者：认可“DNS 免费”是积极动作，但指出这并非行业首创；Bunny 不靠大量“亏本引流”，更像是小额融资后走有机增长路线，因此免费力度不如 Cloudflare 也可理解。 • 持保留态度者：担心按量计费带来失控账单，尤其异常爬虫/LLM 流量可能导致高额费用；且“超额即停”保护似乎只覆盖 CDN，不覆盖其他产品。也有人认为其产品线割裂，基础功能和需求响应不够一致。 • 功能与易用性批评者：认为官网对“为何重要”解释不足；静态网站部署不如 Cloudflare Pages 顺滑；DNS 记录导入会漏项；API Key 缺少细粒度权限，存在泄露后误改 MX 等风险；还希望支持 IPv6-only 源站。 • 讨论澄清者：有人疑惑“免费”究竟是免 DNS 查询费还是免托管费，最终指出是取消查询计费、最多 500 域名免费托管，但账户仍有每月最低 $1 消费；也有人说明 Bunny DNS 属于权威 DNS/内容 DNS，而非代理型服务。 补充讨论： • 争议焦点主要在“免费是否真的有吸引力”与“低价是否伴随功能、监控和计费风险”。 • 还有人借机吐槽 Cloudflare 频繁人机验证，并追问 Bunny 在 bot 防护上的处理方式。
