Curl-impersonate: Special build of curl that can impersonate the major browsers

作者: mmh0000 | 评分: 523 | 评论数: 24 | 发布时间: 2025-04-03 15:24
文章摘要

**curl-impersonate** 是一个特殊版本的 curl，能够模拟 Chrome、Firefox、Edge 和 Safari 四大浏览器。其主要目的是让 TLS 和 HTTP 握手过程与真实浏览器完全一致，从而绕过基于 TLS 指纹和 HTTP/2 指纹的网站检测。该工具可以通过命令行使用，也可以作为库集成替代常规的 libcurl。 为了实现浏览器模拟，curl-impersonate 进行了多项修改，包括使用与浏览器相同的 TLS 库（如 Firefox 的 NSS 和 Chrome 的 BoringSSL），调整 TLS 扩展和 SSL 选项，以及改变 HTTP/2 设置。该项目支持多个版本的浏览器，并为每个浏览器提供了包装脚本以便于使用。 文档和安装说明可在项目目录中找到，使用时需注意某些命令行标志可能会改变 curl 的 TLS 特征从而被检测。

评论摘要

文章摘要

Ferron 是一个用 Rust 编写的高性能、内存安全的Web服务器。它具有以下特点：高性能（利用Rust的异步能力）、内存安全、可扩展性（模块化架构）和安全性（注重安全实践和并发处理）。主要组件包括： - **ferron**：主服务器。 - **ferron-passwd**：用于生成用户条目和密码哈希的工具。 目前，Ferron 仍在开发中，可通过克隆代码库并使用 Cargo 构建和运行： ```bash git clone https://github.com/ferronweb/ferron.git cd ferron cargo build -r cargo run -r --bin ferron ``` 服务器配置可参考 Ferron 文档。Ferron 使用 MIT 许可证，并欢迎社区贡献。
