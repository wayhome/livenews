文章摘要

文章摘要

Kotlin LSP 是一个为 Kotlin 语言提供的 Visual Studio Code 插件，基于 IntelliJ IDEA 和 Language Server Protocol (LSP) 实现，目前处于预览前的探索阶段。该项目支持 JVM Kotlin Gradle 项目的基本功能，如项目导入、代码导航、代码操作、重构和代码完成等，但仅限 JVM 项目。当前版本适合实验和玩具项目，不建议日常使用，因其稳定性未得到保证。该插件主要在 macOS 和 Linux 平台的 VS Code 上测试通过，其他 LSP 编辑器需手动配置。部分源码暂时闭源，未来将完全开源。反馈和问题可通过 GitHub 提交。

文章摘要

Show HN: Curved Space Shader in Three.js (via 4D sphere projection)

作者: bntr | 评分: 53 | 评论数: 12 | 发布时间: 2025-05-22 10:52
文章摘要

这篇文章介绍了使用Three.js实现的**Curved Space Shader**，它通过4D球面投影来模拟弯曲空间效果。该着色器最初为Unity游戏《Sfera》用HLSL编写，现已用GLSL重写并应用于Three.js。项目提供了一个在线演示和视频展示，解释了背后的数学原理：每个3D模型通过4D旋转和投影进行变换，先投影到4D单位球面，再通过立体投影返回到3D空间。用户可以通过鼠标和键盘进行交互，控制场景中的旋转、缩放和摄像机移动。项目中的动画模型和音乐分别来自Three.js示例和CC0授权的资源。
