Why LLMs Can't Write Q/Kdb+: Writing Code Right-to-Left

作者: gabiteodoru | 评分: 130 | 评论数: 23 | 发布时间: 2025-07-08 10:40
文章摘要

文章讨论了大型语言模型（LLMs）在编写q/kdb+代码时遇到的困难，主要问题在于评估顺序的不同。q/kdb+及其祖先语言如APL、J、k采用从右到左且无运算符优先级（RL-NOP）的评估方式，而LLMs在这种方式下表现不佳。例如，在处理表达式时，LLMs常混用Python和q的语法，导致错误。文章还指出，尽管右到左书写在代码中是必要的，但LLMs不擅长这种模式，因为它们的训练数据中q代码相对稀缺，且这种训练可能需要对模型架构进行重大修改。由于经济激励不足和训练数据的匮乏，行业不太可能为这些小众语言重新训练大型模型。文章最后提出了一种实用解决方案，即引入Qython作为桥梁，以帮助LLMs更好地处理RL-NOP语言的代码编写。

评论摘要
主要讨论点：LLM（大型语言模型）在处理非线性、不同语言评估顺序以及代码生成方面的能力和局限性。 不同观点： • clord认为当前的LLM在处理非线性思维（如从数据或返回值反向推导代码）时存在困难，并提出未来LLM是否能够处理非线性结构，或在非线性空间中工作再映射回线性输出。 • FeepingCreature指出，LLM在生成Python代码时，有时会插入不必要的导入语句，这是因为模型对可能需要的模块进行了对冲导入。 • am17an提到，LLM在生成代码时会插入随机的空白字符，似乎存在不同长度的空白标记。 • trjordan认为，训练数据集的大小也可能影响LLM的表现，并建议对不同语言的错误进行量化分析。 • briandw提到，扩散模型有可能解决非线性问题，例如扩散编码模型可以训练为从右到左生成代码。 • electroly对比了APL和NumPy的语法顺序，认为如果APL在今天开发，可能会更倾向于从左到右的评估顺序。 • i000指出，R语言的右赋值语法（`1 -> x`）似乎被LLM过度使用。 • sitkack建议，可以通过允许模型在一个方向上思考并反转输出结果来克服顺序问题。 • vessenes认为，从右到左的评估需要从末尾开始或在工作记忆中保持表达式，而这正是LLM不擅长的。 • aghilmort讨论了主流模型缺乏可逆因果推理能力，并提出了一些技巧和方法来改进模型在这方面的表现。 • knome提到，LLM在解析和生成某些自定义语言代码时，经历了从糟糕到逐渐改善的过程。 • tantalor认为，难以被LLM处理的语言也对普通大众不友好，建议语言设计者使语言更LLM友好，这也有助于提高语言的人类友好性。 • cess11指出，LLM在处理不同编程语言时存在混淆和不稳定的情况，并质疑使用LLM进行软件开发的实用性。 • leprechaun1066认为，LLM在处理如q语言等不同范式语言时的困难，不仅仅是因为评估顺序，而是因为训练数据和思维方式的局限。 补充讨论： • 讨论中提到了多种改进LLM处理非线性和不同评估顺序语言的方法，包括训练扩散模型、使用因果标记、优化输入输出格式等。 • 有争议的焦点在于LLM是否能够有效地处理非线性结构和不同评估顺序的语言，以及如何改进模型的表现。 • 语言设计者是否应该使语言更LLM友好，以同时提高语言的人类友好性，也是一个值得注意的讨论点。

文章摘要

美国联邦上诉法院推翻了联邦贸易委员会（FTC）的一项“点击取消”规则，该规则要求公司使取消服务与注册一样简便。法院认为，FTC在制定规则过程中未遵循完整的程序，特别是未进行初步监管分析，而这一步骤在预计年度经济影响超过1亿美元时是强制要求的。尽管FTC辩称其无需进行初步分析，且在最终规则中分析了替代方案和合规成本，但法院认为其分析过于简略，未给予行业团体足够时间提出异议。此判决由第八巡回法院的三名法官做出，其中包括两名特朗普任命的法官。这一决定也得到了多个行业团体的支持，他们起诉FTC未遵循适当程序。

A Virginia public library is fighting off a takeover by private equity

作者: sharkweek | 评分: 200 | 评论数: 16 | 发布时间: 2025-07-10 03:05
文章摘要

《Literary Hub》报道，弗吉尼亚州的塞缪尔斯公共图书馆（Samuels Public Library）成功阻止了一家私人 equity 公司——图书馆系统与服务公司（LS&S）的接管。此前，该图书馆因拒绝下架LGBTQ主题书籍而遭到反LGBTQ团体的攻击，地方官员因此扣留了其资金。尽管图书馆最终恢复了运营，但在2025年，地方当局仍试图将管理权外包给LS&S。然而，在社区的强烈反对下，LS&S撤回了投标。然而，由于资金被削减，图书馆的未来仍不确定。LS&S以削减成本和裁员著称，常引发社区抗议。此次事件显示了私有化与地方政治之间的复杂关系。

评论摘要
主要讨论点：公共利益与利润驱动之间的矛盾，以及图书馆是否应受社区或私人利益的控制。 不同观点： • [anon7000] 认为利润驱动常常与人类福祉和社会繁荣相对立。以健康保险公司为例，说明利润驱动如何导致服务质量下降和成本上升。这种单一的利润激励机制如果不改变，将会导致社会窒息。 • [mkw5053] 指出有人试图通过制造危机来推行私有化"效率"解决方案，但所涉及的图书馆运营良好，并不需要这种改变。 • [0x3444ac53] 提供了有关书籍禁令的具体信息和链接，让讨论更加具体化，帮助读者了解事件背景。 • [MyOutfitIsVague] 强调图书馆应该服务整个社区，而不是被少数声音控制。多数人不应剥夺少数人获取特定书籍的权利，指出了“多数暴政”的问题。 • [BrenBarn] 认为社会需要重新定义责任、正义和正当程序，特别是在追究不道德行为者的责任时。建议对富有的运营者采取更严厉的措施。 • [evanjrowley] 指出私人资本对公共设施的侵蚀，特别是在弗吉尼亚州北部，私人资本对公共资源的侵占问题。 • [ssuds] 推荐了Brendan Ballou的书《Plunder》，进一步讨论了私人资本在各个行业的影响，包括图书馆领域。 • [zx8080] 质疑美国是否有任何由国家提供且不以盈利为目的的服务，质疑公共服务的私有化趋势。 • [windex] 认为亿万富翁通过购买选举影响公共政策，导致公共设施被私有化，这种趋势类似于回到封建时代。 • [insane_dreamer] 简单表达了对资本主义巅峰状态的无奈。 • [charcircuit] 认为标题有误导性，指出图书馆已经被私人资本控制，并提出效率不应总是目标，利润和效率并非唯一衡量标准。 补充讨论： • 争议焦点在于图书馆是否应该由社区控制还是由私人资本控制，以及利润驱动是否必然导致公共利益受损。 • 讨论中多次提到私人资本对公共设施的侵蚀，以及如何有效追究不道德商业行为的责任。 • 一些评论提供了具体的书籍和事件链接，使讨论更加具体和有据可查。 • 有人指出多数决策可能导致的“多数暴政”问题，强调了保护少数群体权利的重要性。
