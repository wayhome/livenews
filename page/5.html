1990 Networking: LAN Manager 2.0

文章摘要

微软于1990年发布了LAN Manager (LM) 2.0，这是其网络产品线的一部分，始于1984年的MS-NET，最终演变为Windows NT文件共享。LAN Manager 1.0于1988年作为OEM产品发布，微软与3Com合作开发了网络驱动程序NDIS规范。1990年，微软决定直接销售LAN Manager 2.0，绕过OEM，导致与3Com关系恶化。 关于LAN Manager 2.0的发布时间存在争议。尽管有证据显示1990年6月底微软完成了“最终”版本，但缺乏明确的发布公告。一份1990年8月的 press release 提到 LAN Manager 2.0 服务器需要 OS/2 1.21，而该版本当时仅通过OEM提供，使得直接销售受限。InfoWorld 报道3Com于1990年9月底发布了基于LAN Manager 2.0的3+Open，而微软可能在1990年8月直接销售了LAN Manager 2.0。 微软知识库文章提供了更新信息，指出LAN Manager 2.00a为CSD1，2.00b为CSD2。1990年6月的版本为CSD0，而11月的版本为2.00b。因此，1990年6月到11月之间有多次更新。
