截至2023年，美国约有1423万套住房，其中480万套为空置房，约3.5%是季节性或度假屋。佛罗里达州的度假屋最多，超过80万套，其次是加利福尼亚州和纽约州。按比例计算，新英格兰地区（如缅因州、新罕布什尔州、佛蒙特州）的度假屋占比最高。总体来看，度假屋主要集中在新英格兰、中西部北部、东南部和西部州。自1940年代以来，佛蒙特州、新罕布什尔州和缅因州一直是热门度假屋地区，佛罗里达州和亚利桑那州在20世纪后半叶因空调普及而变得更受欢迎。通过更细致的地区数据，可以发现约53%的度假屋集中在度假屋占比超过20%的普查区。

Tinyio: A tiny (~200 line) event loop for Python

作者: tehnub | 评分: 23 | 评论数: 7 | 发布时间: 2025-07-22 22:02
文章摘要

"tinyio" 是一个简化的 Python 事件循环库，约200行代码，旨在替代复杂的 `asyncio`，特别适用于简单场景。它使用 `yield` 而非 `await` 来暂停和恢复协程，支持同时等待多个协程，出错时会取消所有协程并传播错误。它允许在线程中运行同步函数，并提供简单的睡眠功能。`tinyio` 的 API 包括 `Loop`、`run_in_thread`、`sleep` 和 `CancelledError`，易于使用且无需复杂的 `futures` 或 `tasks`。出错时，所有协程都会收到 `CancelledError`，并有机会优雅地关闭。错误会传播到线程中，且可通过设置 `exception_group` 来收集错误。

文章摘要

这篇文章介绍了CSS中的`font-size-adjust`属性，并声称包括Google、MDN和CSS规范在内的所有人都误解了它的用途。文章解释了`font-size`实际上是指字符周围的框高度，而不是字符本身的大小，不同字体的字符大小可能差异很大。`font-size-adjust`可以调整字体，使字符在不同字体中具有可比性。虽然通常认为该属性主要用于字体回退情况，但作者认为其更重要的用途是统一页面中多种字体的显示比例。文章建议将`font-size-adjust: ex-height 0.53`添加到CSS重置中，以确保字体大小一致，推荐值0.53基于Helvetica字体的比例。
