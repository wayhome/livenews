文章摘要

Oxlint 宣布推出基于类型感知的代码检查功能，重点包括 no-floating-promises 等规则。该预览版通过文档化决策过程和技术细节，寻求社区合作讨论。用户可通过安装 oxlint-tsgolint 并使用 --type-aware 标志快速体验。性能测试显示，相比 typescript-eslint 耗时1分钟的项目，现在可在10秒内完成，这得益于使用 Go 编写的 typescript-go 技术。技术架构采用 Rust 编写的 oxlint 作为前端，Go 编写的 tsgolint 作为后端，通过简单管道通信。团队评估了多种方案后，选择不自行开发类型检查器，而是通过调整 typescript-go 的内部 API 来实现类型检查。虽然存在维护挑战，但团队认为这是当前最优解。
