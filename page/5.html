本文介绍了Bezel公司如何利用OpenAI图像API和大型语言模型（LLM）构建一个自我改进的广告图像生成器。首先，使用API的“/create”和“/edit”端点生成和编辑图像。为了提高图像质量，他们开发了一个评估系统，利用LLM（如o3模型）作为评判工具，检测图像中的文本模糊和视觉不协调等问题。通过迭代反馈循环，系统逐步修正图像缺陷，特别是文本模糊问题。实验表明，经过约3次迭代，图像质量显著改善，但随后改进逐渐趋于平稳。该方法通过持续评估和修正，实现图像生成的自我优化。

Show HN: Evolved.lua – An Evolved Entity Component System for Lua

作者: blackmat | 评分: 39 | 评论数: 8 | 发布时间: 2025-05-21 15:46
文章摘要

**evolved.lua** 是一个为 Lua 设计的高效、灵活的实体组件系统（ECS）库。它采用基于原型的架构存储实体和组件，使用 SoA（数组结构）方式将组件存储在连续数组中，以实现快速迭代和处理。通过分组实体和组件，库可以高效过滤查询，并最小化垃圾回收（GC）压力。该库注重性能优化，同时保持 API 简单直观，易于使用。它支持创建复杂系统和过程，允许使用查询、延迟操作、批量操作，以及按特定顺序处理实体。此外，库提供了如实体构建器和片段钩子等功能，增强了灵活性和可扩展性。要求 Lua >= 5.1 或 LuajIT >= 2.0，可通过 Luarocks 安装。

"Microsoft has simply given us no other option," Signal blocks Windows Recall

作者: beatthatflight | 评分: 9 | 评论数: 1 | 发布时间: 2025-05-22 00:04
文章摘要

Signal Messenger is protecting users of its Windows Desktop version from the privacy risks posed by Microsoft's AI tool, Recall, in Windows 11. Recall takes frequent screenshots and stores user activity, potentially compromising private messages. To counter this, Signal has implemented a default block on Windows screenshotting the app, though users can manually disable this if needed. Despite Microsoft making improvements to Recall, such as making it opt-in and encrypting data, concerns remain about its impact on privacy. Signal is using a copyright protection API to prevent Recall from indexing conversations, highlighting the lack of proper developer tools to manage such features. 文章摘要

Ratatoi是一个C语言库，用于替代标准库中的`atoi`函数。它的特点是，如果在转换过程中检测到溢出，它会调用`abort()`使程序崩溃并显示"Aborted (core dumped)"。这样设计是为了优先确保内存安全，而不是让程序在错误状态下继续运行，从而避免在每个使用`strtol`的地方手动检查错误。该项目采用MIT许可证，包含`ratatoi.c`、`ratatoi.h`等文件。目前有2个星标，无发布版本或包。
