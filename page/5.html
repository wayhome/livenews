文章摘要

文章讨论了WebAssembly (Wasm) 是否能直接支持DOM操作，并指出Wasm可能永远不会直接访问DOM，但通过JavaScript间接调用DOM API已经足够成熟，适用于各种Web应用。Wasm与JavaScript严格分离，但通过“粘合代码”可以实现与JavaScript API的无缝集成。文章通过示例展示了如何利用JavaScript作为中介，让Wasm调用如`console.log`这样的Web API。Wasm模块通过导入和导出功能与JavaScript交互，且使用数组和整数索引来处理JavaScript对象引用。尽管未来可能引入直接调用Web API的机制，但目前的方案已能有效减少代码量并提升性能。Wasm与JavaScript的集成仍在不断发展中。

Reverse engineering GitHub Actions cache to make it fast

文章摘要

本文介绍了Blacksmith如何通过逆向工程GitHub Actions缓存机制，实现无代码更改的缓存加速。最初，他们通过 fork 流行的 GitHub Actions 并指向自己的快速缓存来提升性能，但这带来了维护负担。为解决此问题，他们决定逆向工程 GitHub Actions 缓存，利用网络代理技术，将缓存请求透明地重定向到自建的 MinIO 集群，而无需用户修改代码。通过使用 NGINX 作为代理服务器，他们在 VM 内配置轻量级代理，将缓存相关的请求重定向到自建缓存，其他请求则正常处理。最终，实现了最高10倍的缓存性能提升，同时保持了用户体验的无缝衔接。
