Show HN: Bramble – Local-first password manager

作者: MegagramEnjoyer | 评分: 117 | 评论数: 16 | 发布时间: 2026-07-02 19:29
文章摘要

Bramble是一个本地优先的开源密码管理器，核心理念是"无账户、无服务器、无云端存储"——所有数据仅保存在用户自己的设备上。 **跨平台支持**：提供Chromium浏览器扩展、iOS和Android原生应用，所有平台共享同一个Rust加密核心和保险库格式。 **核心特性**： - 密码保险库是单个加密文件，存储在用户选择的位置（可通过Dropbox/Google Drive或点对点直接同步） - 采用Argon2id密钥派生和AES-256-GCM加密，所有内容（包括站点名、用户名）完全加密 - 支持通行密钥(Passkeys)、TOTP二次验证码生成 - 移动端集成系统级自动填充和生物识别解锁 - 提供恢复代码作为密码之外的备份解锁方式 **设计理念**：将加密操作封装在Rust核心中，主密码不触及JavaScript堆，确保安全性的同时保持用户对数据的完全控制。

评论摘要
**主要讨论点：** 一个本地优先、开源、P2P同步的密码管理器项目引发的技术路线和安全理念争论 **不同观点：** • **本地优先支持派**：认为大科技公司权力过大，本地存储更安全透明，赞赏完全离线方案（tmpfs、mune2gu-chan、catapart） • **云端存储倾向派**：担心本地存储面临设备丢失、勒索软件攻击等风险，认为远程安全存储配合自托管更可靠（tamimio） • **实用主义质疑**：缺少iOS支持是致命问题；需要完善的浏览器自动填充功能；与成熟方案（KeePass、vaultwarden）相比优势不明（commandersaki、ZenoArrow、shaunkoh） • **技术架构讨论**：为何选择nostr而非iroh；native app开发遇到应用商店困境；P2P是否意味着数据经过他人设备（ind-igo、tmpfs、banderberg） • **信任和透明度关切**：密码管理器需要明确开发者身份、代码审查流程、商业模式；AI辅助编码需要更严格审查（hoistbypetard） **补充讨论：** 有开发者分享类似项目经验（saveoursecrets.com、Tablinum），询问AI开发工具使用情况和自建同步引擎的必要性。项目仅接受Monero支付也引发好奇。

60% Fable cost cut by converting code to images and having the model OCR it

作者: dimitropoulos | 评分: 185 | 评论数: 25 | 发布时间: 2026-07-03 15:50
文章摘要

pxpipe是一个本地代理工具，通过将Claude Code的输入内容（系统提示、工具文档、历史记录）转换为图像格式来大幅削减token消耗。 核心原理：图像的token成本由像素尺寸决定，而非内容量。密集文本转为PNG后，每个图像token可承载约3.1个字符，而文本token仅1个字符。实测可将输入token减少至原来的约1/10（如25k文本token转为2.7k图像token），总体费用降低59-70%。 使用简单：运行`npx pxpipe-proxy`启动代理，然后将Claude Code指向该代理即可。提供实时仪表板监控节省效果。 注意：这是有损压缩方案，适合处理大量上下文的场景，但对需要精确数值的任务可能存在局限。

评论摘要
主要讨论点：通过将文本转换为图像来减少LLM API的token使用成本 不同观点： • **定价漏洞派**：认为这是利用Claude/Gemini后端OCR但不收费的计费漏洞，可能很快会被修复（aabhay, genxy） • **实际效果质疑派**：去年实测表明虽减少输入token，但输出token激增，最终更贵更慢；违反信息论基本原理（lpellis, __hugues） • **实用主义派**：实际使用图像prompt效果很好，成为日常工作流的一部分（OSaMaBiNLoGiN, chickensong承认虽"cursed"但有效） • **道德批判派**：强烈反对这种"retarded"的做法，认为是剥削定价系统、制造数字垃圾的不负责任行为，主要责任在Anthropic的定价缺陷（anigbrowl） 补充讨论：有人提出PDF解析和URL链接等替代方案；多人分享相关技术资源和白皮书。核心争议在于实际成本效益（输入vs输出token权衡）和使用此类漏洞的道德性问题。

文章摘要

Tinkerfont 是一个免费的浏览器扩展，用于在实时网页上检查、替换和测试字体。 **核心功能：** - **检查**：右键查看文字的字体族、粗细、大小、颜色和对比度 - **检测**：显示页面所有字体及使用次数 - **替换**：从 1900+ 个开源字体中搜索，或上传自定义字体文件，一键应用 - **作用域**：可限定替换范围（如导航栏、标题区） - **持久化**：按域名保存规则，支持 JSON 导入导出 **技术实现：** 基于 Manifest V3，使用 content scripts 检测和替换字体，mutation observer 监听 DOM 变化，所有数据存储在本地。Firefox 版本共享大部分代码。官网用 Next.js 构建，部署在 Cloudflare。 支持 Chrome 和 Firefox，无需账号，数据完全本地化。
