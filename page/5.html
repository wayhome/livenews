The “S” in MCP Stands for Security

作者: skilldeliver | 评分: 660 | 评论数: 36 | 发布时间: 2025-04-06 09:42
文章摘要

文章讨论了MCP（Model Context Protocol）这一新标准在促进大型语言模型与工具和数据集成方面的优势和潜在安全风险。MCP允许AI代理连接工具、维持会话并共享上下文，但其默认设置并不安全，可能导致命令注入、工具中毒、静默重定义和跨服务器工具劫持等安全问题。文章详细描述了这些风险，并指出MCP目前缺乏认证标准、上下文加密和工具完整性验证机制。为应对这些问题，文章建议开发者进行输入验证、固定服务器和工具版本、清理工具描述，平台构建者应展示完整工具元数据并强制执行会话安全，用户则应避免连接到随机服务器并监控会话行为。文章最后提出建立像ScanMCP.com这样的工具来审计和标记MCP工具的风险。

评论摘要
主要讨论点：MCP（Multi-Component Protocol）的安全性及其实现中的潜在问题 不同观点： • [lbeurerkellner] 认为MCP工具调用的安全问题主要在于间接提示注入（indirect prompt injection），尤其是在代理系统中使用MCP时，不同MCP服务器之间的行为可能被操纵（工具遮蔽，tool shadowing）。此外，MCP的动态特性使其服务器可能随时变恶意，而当前的MCP客户端不会通知用户这些变化。 • [anaisbetts] 则认为这些攻击并没有跨越权限边界，类似于其他开发者工具和生态系统（如NPM或VS Code Extensions）中的问题。MCP服务器在用户级别运行代码，可以直接访问数据而不需要欺骗AI。 • [yismail] 质疑文章的真实性，怀疑其是否由AI生成，并指出作者的资料可疑。 • [neomantra] 强调MCP实现中缺乏审计和度量，很多开发者盲目运行MCP服务器，缺乏安全性意识。随着MCP的发展，框架和工具将逐渐支持安全性和可观察性。 • [TeMPOraL] 提出设计一个既安全又能保持MCP现有功能的挑战，并指出安全和有用性是相互对立的 forces。 • [rcarmo] 支持[anaisbetts]的观点，认为MCP的安全问题与以往的协议问题类似。 • [metalrain] 讨论了即使软件实现是安全的，如何确保其被正确使用的问题，特别是当有多个选项时如何避免错误。 • [aledalgrande] 强调许多MCP实现中存在不安全的shell调用问题。 • [chrisweekly] 认为当前的MCP实现非常不安全，并提到在移动浏览器上访问文章时遇到的技术问题。 • [balls187] 担心AI工具的采用会导致类似于“curl随机脚本并执行”的安全问题。 • [ramesh31] 认为MCP被误解了，它主要是作为本地工具连接LLM进程的手段，而不是一个远程RPC服务器。 • [daxfohl] 对MCP的存在目的感到困惑，质疑其与传统确定性代理的区别。 • [est] 以USB-C的复杂性来类比MCP，暗示其设计可能存在问题。 • [neuroelectron] 认为MCP可能是为了允许Anthropic监视用户的提示和输出以最大化其训练数据。 • [mentalgear] 指出MCP的问题包括内部可能的恶意MCP和外部LLM代理中毒问题，缺乏机制来验证工具的完整性。 补充讨论： • 争议的焦点在于MCP的安全性设计缺陷及其潜在的攻击场景，特别是工具遮蔽和间接提示注入。 • 一些评论者质疑MCP的实际用途和安全实现，而另一些评论者则认为这些问题与其他开发者工具中的问题类似。 • 还有对MCP文档和理解上的困惑，以及对用户盲目运行MCP服务器的安全担忧。

Microcomputers – The First Wave: Responding to Altair

作者: cfmcdonald | 评分: 77 | 评论数: 7 | 发布时间: 2025-04-06 21:30
文章摘要

本文简要介绍了唐·塔贝尔（Don Tarbell）在个人电脑发展初期的贡献。塔贝尔最初通过自制电脑部件和销售集成电路安装板进入个人电脑领域。他在1972年成功组装了一台包含8位处理器、4000字节内存和多种外围设备的电脑。1975年，随着Altair 8800套件的发布，个人电脑爱好者的兴趣激增，塔贝尔也参与成立了南加州电脑协会（SCCS），并担任秘书。他发现Altair套件存在内存不足和无法永久存储数据等问题，于1976年推出了更便宜的塔贝尔卡式接口，通过普通卡式录音机进行数据存储，解决了这一难题。塔贝尔的创新代表了20世纪70年代个人电脑从爱好者的 niche 市场向全国性产业的转变，他也是早期通过提供补充硬件响应市场需求的创业者之一。
