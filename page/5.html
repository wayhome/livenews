Run Android ARM64 VR APKs on Apple Vision Pro

作者: LorenDB | 评分: 146 | 评论数: 6 | 发布时间: 2026-08-10 03:12
文章摘要

Klepton是一个开源项目，能让Android ARM64 VR应用（APK）在Apple Vision Pro和macOS上运行，无需JIT编译。其核心是klepton-ld工具，可将Android的.so库转换为Apple的.dylib/.framework格式。项目采用三层架构：Guest层（转换后的代码）、Klepton运行时层（提供bionic、NDK、JNI等Android兼容层）、以及底层平台层（使用MoltenVK将Vulkan转Metal，ANGLE将GLES转Metal）。技术亮点包括修补寄存器x18冲突、支持运行时加载等。目前Beat Saber已能在macOS和visionOS上运行，Steam VR Link支持仍在开发中。项目专注于Java-thin应用，不包含完整的Android运行时环境。

评论摘要
主要讨论点：围绕Apple设备（特别是Vision Pro和iPad）的开放性问题，以及社区技术破解尝试的讨论 不同观点： • **批评Apple封闭政策**：有用户强烈批评Apple在Vision Pro和iPad上重复"过度保护"策略，认为Apple将用户当作"需要保护的婴儿"，严格限制macOS以外的软件开发自由。同时肯定了小型技术社区努力突破这些限制的价值。 • **对Apple反制的担忧**：有评论以讽刺口吻暗示Apple不会欢迎这类破解项目，隐含对项目可持续性的担忧。 • **技术实现细节讨论**：开发者从技术角度分析了darwin系统的底层限制，指出x18寄存器在异常返回时会被清零，这使得Quest应用无法在调度窗口内保持状态——这揭示了技术突破面临的系统层面障碍。 • **实用性关注**：有用户关注项目的实际可用性，要求提供截图等直观展示。 • **内容透明度诉求**：有评论要求披露是否使用了LLM工具，反映出对AI生成内容透明度的关注。 补充讨论：整体氛围在赞赏技术创新和担忧平台限制之间摇摆，体现了开发者社区对封闭生态系统的复杂态度——既欣赏突破尝试，又清楚认识到技术和政策层面的现实限制。

Show HN: Ante, a coding agent in a single binary that runs offline

作者: ubermon | 评分: 111 | 评论数: 14 | 发布时间: 2026-08-10 15:59
文章摘要

Ante 是一个开源的终端编码代理工具，由 Antigma Labs 开发。它是单个约 15MB 的 Rust 二进制文件，无需外部依赖。 **核心优势：** - **性能优异**：在 Terminal-Bench 2.1 测试中达到 82.7% 准确率 - **资源高效**：相比 Claude Code，内存占用减少 7 倍，CPU 使用减少 9 倍，磁盘 I/O 减少 5 倍 - **原生离线**：内置推理引擎，支持本地 GGUF 模型运行，无需 API 密钥或网络连接 **主要功能：** - 支持交互式 TUI、无头模式、服务器和网关模式 - 兼容 12+ 个 AI 提供商（Anthropic、OpenAI、Google Gemini 等） - 支持多代理编排、渠道集成（Slack/Discord） - 零供应商锁定，可自由切换模型 安装简单：通过 curl 命令一键安装，目前支持 macOS 和 Linux（Windows 建议使用 WSL）。

评论摘要
主要讨论点：Ante 作为轻量、单文件、支持本地模型的编码代理，其开源透明度、打包方式、性能定位及适用场景受到讨论。 不同观点： • 多人质疑“只链接 GitHub 却无代理源码”，认为二进制发布易让人误以为开源；“探索智能体时代如何开源”的表述也被批评含糊。开发者则在 README 补充源码与遥测常见问题，但未消除“无源码”争议。 • 有人认可降低 Claude Code 等工具内存占用的方向，但认为 harness 本质只是简单循环，即使用 Python/TypeScript 也应很轻量，并以 pi agent 为例。 • 对“重视 harness 而非模型或提示词”的路线存在分歧：前沿厂商似乎更重视模型，但其捆绑 harness、补贴定价也说明二者价值边界尚不明确。 • 自包含约 15MB 二进制被视为便捷：集成 TUI、ripgrep、PDF/OCR 和 llama.cpp，无运行时依赖或账户，可发现本地 GGUF、估算显存并离线运行。反方追问为何内置常见开发工具，以及集成范围为何止于此。 • 开发者承认本地模型与前沿模型有差距：Qwen3.6 27B 在 Terminal-Bench 2.1 得分56.2%，主张敏感或高频任务用本地模型，困难任务切换托管模型。 补充讨论：用户关心游戏开发效果，并建议增加轻量 GUI；遥测可通过 `ANTE_TELEMETRY=off` 关闭，离线模式仍在开发且存在不足。

An Interesting Fourier Transform – 1/f Noise (2007)

作者: q7m | 评分: 111 | 评论数: 12 | 发布时间: 2026-08-07 01:56
文章摘要

这篇文章探讨了幂律函数的傅里叶变换特性。核心发现是：时域幂律函数 t^α 对应频域幂律 ω^-(α+1)，两域存在反向关系——一域衰减越快，另一域衰减越慢。 文章指出一个关键点：当 α = -0.5 时，时域（t^-0.5）和频域（ω^-0.5）具有相同的衰减率，这种对称性非常独特。 作者认为这可能是解开"1/f 噪声"之谜的关键。1/f 噪声是一个困扰物理学界80多年的现象，广泛存在于电子放大器、高速公路交通流量、古典音乐响度、DNA编码等众多领域。文章暗示幂律函数的这种傅里叶变换对称性可能为理解 1/f 噪声的本质提供了数学基础。
