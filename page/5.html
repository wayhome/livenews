PyPI Blog: Token Exfiltration Campaign via GitHub Actions Workflows

作者: miketheman | 评分: 57 | 评论数: 5 | 发布时间: 2025-09-16 21:09
文章摘要

黑客通过篡改GitHub Actions工作流窃取PyPI发布令牌，但未实际入侵PyPI或发布恶意包。攻击者针对存储PyPI令牌的仓库，窃取部分令牌但未使用。PyPI安全团队已作废受影响令牌并通知相关维护者，建议改用短期有效的"可信发布者"机制增强防护。事件由GitGuardian研究人员发现并协助调查，PyPI团队于9月5日收到警报后展开响应，15日完成处置。该事件凸显了开源供应链安全的重要性。

评论摘要
主要讨论点：[关于GitHub Actions工作流被攻击导致PyPI令牌泄露的讨论] 不同观点： • Python与JS的安全性对比：有人认为Python由于有标准库，攻击面比JS小。举例说明一个Flask应用仅有15个依赖项，而NPM攻击更多。 • Trusted Publishing的有效性：有评论者认为配置Trusted Publishing可以预防此类攻击，并举出实例证明其有效性。 • 第三方CI系统的风险：有人对将API密钥托管给第三方CI系统表示担忧，并质疑为何还允许运行其他第三方提供的“actions”。 • 攻击手段的讨论：有评论者提出，如果攻击者能修改GitHub Actions工作流以窃取令牌，那么他们也可能修改使用Trusted Publishing的工作流，通过添加看似无害的外部Action来篡改包内容。 补充讨论： • 争议焦点：是否应该完全信任第三方CI系统，以及如何平衡便利性与安全性。 • 其他讨论点：对Mike处理此次攻击的赞赏，以及对未来如何保护项目的建议。
