文章摘要

**itter.sh** 是一个通过 **SSH** 访问的微型博客平台，旨在提供无干扰的社交体验。用户通过终端操作，每次发布最多180字符的内容（称为"eets"），支持标签和提及。平台无浏览器和算法推送，强调简洁和高效。 **主要功能：** 1. **注册与登录**：通过 SSH 命令注册和登录。 2. **发布与互动**：使用命令发布 eets、查看时间线、关注用户等。 3. **账户管理**：编辑个人资料、查看帮助、清除屏幕等。 **技术栈**：基于 Python、AsyncSSH 和 Supabase 构建，主打怀旧终端体验。

Fastgron: Make JSON greppable, super fast

作者: fanf2 | 评分: 3 | 评论数: 0 | 发布时间: 2025-05-10 14:42
文章摘要

**fastgron** 是一个高性能 JSON 到 GRON（可 grep 的扁平化 JSON）转换工具，使用 C++20 开发并利用了 simdjson 库。它能将 JSON 转换为离散的赋值形式，便于搜索和查看数据路径，特别适用于处理大量 JSON 数据且文档不佳的 API。相比同类工具 **gron**，**fastgron** 在处理大文件时速度快50倍（在M1 MacBook Pro上达到400MB/s输入和1.8GB/s输出）。它还支持将过滤后的 GRON 数据重新转换回 JSON。支持多种安装方式，包括 Arch、Homebrew、Nix 和 Ubuntu，并提供丰富的命令行选项用于路径过滤、颜色输出、流模式等功能。处理大文件时表现尤为突出，例如将840MB文件转回JSON只需8秒。
