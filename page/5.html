文章摘要

Eclipse SUMO 是一个开源、多平台、支持多模式交通系统的微观连续交通模拟软件包，能够处理大型交通网络。它支持模拟道路车辆、公共交通和行人，并提供丰富的工具用于路径规划、可视化、网络导入和排放计算等任务。SUMO 可增强自定义模型，提供多种 API 用于远程控制模拟，适用于自动化驾驶、车辆通信、交通管理等场景。它具备跨平台特性（Windows、Linux、macOS），并支持从多种格式导入道路网络，如 OpenStreetMap。SUMO 还具有高效的性能表现，适用于大规模模拟。每年在柏林举行的 SUMO 用户会议汇聚了全球交通和模拟领域的专家，分享最新研究与项目成果。SUMO 的未来发展由 Eclipse 基金会的 openMobility 兴趣小组主导。

Introduction to Computer Music

文章摘要

《计算机音乐导论》电子教科书由杰弗里·哈斯教授编写，旨在为计算机音乐初学者提供深入的知识，适合作曲家、初级音频工程师及其他对音乐技术感兴趣的音乐人。全书涵盖以下主题： 1. **声学**：讲解声音的特性，如振幅和频率及其感知。 2. **工作室设备**：介绍麦克风类型、技术及信号处理。 3. **MIDI**：详细说明MIDI的运作原理和代码方案。 4. **合成**：包括波形、滤波器、调频调制及数字合成语言介绍。 5. **数字音频**：涉及数字采样、录音及D-A转换器工作原理等。 6. **历史**：简述电子音乐的发展历史和重要文献。 附录提供参考资料和相关链接。该教科书始于2004年，并持续更新，供免费学习和教学使用。
