主要讨论点：围绕“Relax.ai by Civo”作为英国主权 AI/LLM 推理服务的可信度、实用性、定位与信息透明度展开。 不同观点： • 信息透明度不足：多人质疑页面缺少“谁在运营、Civo 是谁、数据中心在哪、公司结构、创始人是否英国居民”等关键信息；也有人抱怨加载很慢，最终只跳到文档站，无法了解产品能力。 • 支持英国/地域多元 AI：有评论认为这是正确方向的一小步，英国在训练和构建大模型上落后，需要尽快拥有类似 Mistral 的本土模型；也有人欢迎更多地理分布的云/AI选择。 • “主权 AI”营销受质疑：有人好奇“某国主权 X”是否已成为有效营销话术；另有人用英国王室开玩笑，讽刺“主权”概念表述含混。 • 技术与产品能力关注：有人询问是否支持 prompt/prefix caching，认为这是按 token 计费 API 的严肃使用必需功能；也有人问文档中是否支持 opencode 等工具。 • 成本与模型能力争议：有人认为较小、较弱、可在消费级硬件运行的模型，理应比需要 1TB 内存的大模型便宜很多，质疑价格/价值定位。 • 品牌与命名批评：有评论认为 RelaxAI 名字很糟，像随便挑的 .ai 域名，甚至让人联想到“慢但便宜”；也有人建议可接管 PyPI 上废弃的 relax 包名。 补充讨论：有人提到英国本土相关玩家 Doubleword，认为谈主权 LLM 推理不能忽视其伦敦推理优化实验室；另有人建议若国家要做主权 AI，应招募 Qwen 核心团队成员。
