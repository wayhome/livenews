Gemini Diffusion

作者: mdp2021 | 评分: 842 | 评论数: 40 | 发布时间: 2025-05-22 01:13
文章摘要

Google在I/O大会上发布了Gemini Diffusion，这是其首个使用扩散模型（而非传统的自回归方式）的大语言模型。与逐字生成文本的传统模型不同，扩散模型通过逐步优化噪声来生成输出，具有更快的速度和更好的纠错能力，尤其在编辑、数学和代码任务中表现突出。作者测试显示，Gemini Diffusion能在数秒内创建交互式网页，速度达857 tokens/秒。尽管名为扩散模型，它仍基于Transformer架构，类似于BERT的掩码语言建模，但能处理更高比例的掩码 tokens。目前尚未有独立基准测试，但Google称其性能媲美Gemini 2.0 Flash-Lite，且速度快5倍。

Prime Path Coverage in the GNU Compiler Collection

作者: matt_d | 评分: 6 | 评论数: 0 | 发布时间: 2025-05-23 06:14
文章摘要

本文介绍了一种在GNU Compiler Collection 15中实现的 prime path coverage 支持，这是一种通过程序执行路径进行结构化覆盖率测试的指标。该方法在测试数量和覆盖率之间取得平衡，要求循环被执行多次或跳过。研究表明，prime path coverage 涵盖了修改条件/决策覆盖（MC/DC）。通过使用后缀树修剪重复子路径，算法效率从 $O(n^2m^2)$ 提升至 $O(n^2m)$。该方法通过控制流图分析，以语言无关的方式观察和检测路径，并准确报告实现覆盖所需的代码执行顺序。

文章摘要

Kotlin LSP 是一个为 Kotlin 语言提供的 Visual Studio Code 插件，基于 IntelliJ IDEA 和 Language Server Protocol (LSP) 实现，目前处于预览前的探索阶段。该项目支持 JVM Kotlin Gradle 项目的基本功能，如项目导入、代码导航、代码操作、重构和代码完成等，但仅限 JVM 项目。当前版本适合实验和玩具项目，不建议日常使用，因其稳定性未得到保证。该插件主要在 macOS 和 Linux 平台的 VS Code 上测试通过，其他 LSP 编辑器需手动配置。部分源码暂时闭源，未来将完全开源。反馈和问题可通过 GitHub 提交。

文章摘要

本文讨论了Flatpak项目的现状与未来。尽管Flatpak在应用打包格式上取得了一定成功，受到开发者和用户欢迎，且被Fedora等Linux发行版采用，但其核心开发进展缓慢。演讲者Sebastian Wick指出，虽然项目维护和安全修复仍在进行，但缺乏对新功能的审查和重大更新。关键开发者的离开导致代码合并过程延迟，新的贡献者也难以快速融入。此外，Wick提到OSTree工具的局限性，并建议采用OCI图像工具以简化开发流程。总体而言，Flatpak功能稳定，但发展受到制约，未来需要更多开发者参与以推动创新。
