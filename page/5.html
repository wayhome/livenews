California bill aims to phase out harmful ultra-processed foods in schools

作者: PaulHoule | 评分: 112 | 评论数: 19 | 发布时间: 2025-03-27 17:45
文章摘要

加州立法者于2025年3月19日提出AB 1264法案，旨在逐步淘汰校园中的有害超加工食品。该法案将首次法定定义何为超加工食品，并要求科学家与大学专家合作识别特别有害的产品，到2032年将这些食品移除出学校食堂。评估标准包括食品是否含有被其他地方禁用的添加剂、是否与健康危害有关、是否导致食物成瘾以及是否含有过量的脂肪、糖或盐。科学家需在2026年7月1日前发布首份报告，并每两年更新一次清单。该法案得到两党支持，此前加州已通过类似法律禁止含有毒化学物质的食品。超加工食品与多种健康问题相关，包括肥胖、心脏病和儿童多动症。尽管有行业反对，但立法者希望借此促使食品公司改进配方。

MCP server for Ghidra

文章摘要

GhidraMCP 是一个允许大型语言模型（LLM）自动逆向工程应用程序的 Model Context Protocol（MCP）服务器。它利用 Ghidra 的核心功能，为 MCP 客户端提供多种工具，包括反编译和分析二进制文件、自动重命名方法和数据、列出方法、类、导入和导出等功能。安装步骤包括下载 GhidraMCP 插件和 Python MCP 客户端，然后在 Ghidra 中安装扩展。用户可以通过编辑配置文件将 Claude Desktop 或 5ire 等 MCP 客户端与 GhidraMCP 集成。该项目使用 Apache-2.0 许可证，主要使用 Java 和 Python 编写。

Things that go wrong with disk IO

文章摘要

这篇文章讨论了在编写涉及文件读写的应用程序时需要注意的几个数据完整性问题，特别是在事务性环境中。主要问题包括：数据未写入磁盘、数据写入错误位置、读取数据出错以及数据在磁盘上损坏。这些问题在Linux系统上尤为常见，文章引用了《Parity Lost and Parity Regained》和《Characteristics, Impact, and Tolerance of Partial Disk Failures》两篇论文，探讨了这些问题的实际发生频率。 文章还解释了相关术语，如扇区、块和页，并指出不同数据库系统（如Postgres、SQLite、MySQL、RocksDB）如何通过默认使用fsync确保数据完整性。然而，fsync并非总是成功，且难以确定具体失败的写入操作。此外，文章强调了数据校验和的重要性，以检测和防止数据损坏。最后，建议使用如ZFS等支持数据校验的系统来提高数据可靠性。
