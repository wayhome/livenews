文章摘要

JavaFactory 是一个利用大型语言模型（LLM）自动生成重复性 Java 代码的工具。其生成结果比传统 AI 代码生成器更可预测和稳定。核心组件包括： 1. **模式定义**：用自然语言定义每个工作单元（如测试生成、实现生成等），包括目标、规则、输出格式和示例代码。 2. **基于注解的引用收集**：通过注解明确指定所需类，分为两类： - `@JavaFactoryData`：递归收集指定的类（如领域模型）。 - `@JavaFactoryApi`：仅收集一级的引用类，可指定API的实现、测试和固定类（如Reader, Writer）。 JavaFactory 适用于对传统AI代码生成器不满、希望更明确控制任务单元和引用结构的开发者，特别是在分层架构等重复性结构环境中。通过一次定义规则，可以反复自动化生成代码。

RepoRoulette: Randomly sample repositories from GitHub

作者: deontology | 评分: 5 | 评论数: 0 | 发布时间: 2025-05-18 00:10
文章摘要

**RepoRoulette** 是一个可以从 GitHub 随机抽样仓库的工具，提供了三种抽样方法： 1. **ID抽样**：基于GitHub仓库的序列ID随机抽样，可能因无效ID（如私有或废弃仓库）导致成功率低。 2. **时间抽样**：根据时间范围（日期/小时）随机选择时间点，获取那些时间段内更新的仓库，支持按特性过滤。 3. **BigQuery抽样**：利用Google BigQuery的GitHub公开数据集抽样，支持高级过滤和大数据处理，但需要Google Cloud平台和相关设置。 此外，还有**GH Archive抽样**，通过GitHub Archive项目记录的公共时间线事件抽样仓库。 **优点**：处理大规模样本效率高，支持强大过滤和历史数据访问。 **缺点**：BigQuery方法可能费用高，受限于GCP账户和API速率限制。 工具安装可通过 `pip install reporoulette` 或从源码安装。

The Windows Subsystem for Linux is now open source

文章摘要

2025年5月19日，微软宣布Windows Subsystem for Linux（WSL）正式开源。这个项目经过多年准备，代码已在GitHub上的Microsoft/WSL仓库开放给社区。WSL由多个组件组成，包括命令行可执行文件、WSL服务、Linux初始化和守护进程，以及文件共享实现等。尽管一些组件如Lxcore.sys和P9rdr.sys尚未开源，但其他如WSL2的Linux内核和WSLg（图形支持）早已开放。WSL最初在2016年BUILD大会上发布，从WSL 1演进到依赖Linux内核的WSL 2，并逐步增加了GPU支持、图形应用和systemd支持。2021年，WSL从Windows代码库中分离，并通过微软商店独立发布，最终于2022年发布稳定版1.0.0。开源WSL旨在加速开发和满足社区需求，期待社区的进一步贡献和项目演进。
