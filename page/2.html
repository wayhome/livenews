Show HN: Kage – Shadow any website to a single binary for offline viewing

作者: tamnd | 评分: 277 | 评论数: 28 | 发布时间: 2026-06-14 17:25
文章摘要

kage 是一个网站离线克隆工具，可将网站完整保存到本地供离线浏览，并自动移除所有 JavaScript 代码。它使用真实的 Chrome 浏览器渲染页面，等待页面完全加载后保存 DOM 快照，然后删除脚本并下载 CSS、图片、字体到本地。核心功能包括：clone（克隆网站）、serve（本地预览）、pack（打包成单个 ZIM 文件或可执行文件）、open（打开打包文件）。支持自动遵守 robots.txt、从 sitemap.xml 抓取、断点续传等特性。适用于保存需要长期访问的网页内容，避免因 JS 失效或网站下线而无法查看。

评论摘要
主要讨论点：关于 kage（网站离线归档工具）的功能、使用场景和技术实现的讨论 不同观点： • **支持者观点**：认为该工具对离线访问很有用，特别是在飞机上、网络覆盖差的地点、或需要保存公司 wiki 文档时。多位用户表示会尝试使用 • **质疑静态服务器的必要性**：有用户指出既然结果是静态的，为什么需要服务器进程？建议直接用浏览器打开文件，这样在没有安装 kage 的机器上也能使用 • **替代方案推荐者**：部分用户推荐其他工具更优，如 SingleFile（打包成单个 HTML 文件，方便传输）、httrack、RSS 订阅等。有人提到"丑陋的 HTML 存档"比"完美归档"更实用 • **技术安全关切**：有开发者注意到项目使用了 `--no-sandbox` 启动 Chrome，从安全角度质疑这个设计选择 补充讨论： 用户还关注一些实际问题：如何避免对目标网站造成过大负载、能否只抓取网站子集、是否支持复杂网站（如 Apple Docs）。有人建议结合 mitmproxy 提高归档保真度，也有人询问与类似工具 gwtar 的对比。另有技术讨论涉及 demo GIF 的生成方式。

这是 Bitsy 游戏引擎的欢迎页面。Bitsy 是一个轻量级的游戏制作工具，专门用于创建小型游戏、虚拟世界和互动故事。页面提供了四个主要功能入口：制作游戏、游玩游戏、学习文档和加入论坛。此外还列出了相关资源链接，包括 Bitsy 的合作项目、经典版本、媒体报道，以及在 itch.io、Mastodon 和 GitHub 等平台上的社区存在。整体呈现出一个友好、简洁的创作工具生态系统。

评论摘要
主要讨论点：Bitsy游戏引擎及其创作的游戏体验 不同观点： • **工具推荐派**（flymasterv）：推荐Playdate平台的类似工具Pulp，认为它是Bitsy的替代选择 • **游戏性质疑派**（hankbond）：认为大多数Bitsy作品更像互动诗歌/故事而非传统游戏，希望找到更具传统游戏元素的作品 • **怀旧支持派**（gnoll_of_gozag, zokiboy）：肯定Bitsy的影响力和美学价值，认为作品既清新又复古 • **开发体验派**（alaskahoffman）：作为实际开发者，认为Bitsy适合小型项目，但处理大量文本或复杂功能时会受限 补充讨论：评论反映了Bitsy在独立游戏社区（如itch.io、cohost）的流行度，以及创作者对其"简约引擎"定位的不同期待——从艺术表达工具到游戏开发平台的认知差异。
