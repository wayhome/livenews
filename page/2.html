Show HN: Dlg – Zero-cost printf-style debugging for Go

作者: 0xFEE1DEAD | 评分: 11 | 评论数: 2 | 发布时间: 2025-07-27 18:02
文章摘要

`dlg` 是一个用于 Go 语言的轻量级日志工具，支持 printf-style 调试。它在生产构建中完全消失，从而实现零成本开销。通过不使用 `dlg` 标签进行构建，所有日志调用将从二进制文件中移除，不影响运行时性能。`dlg` 提供两个主要函数 `Printf` 和 `SetOutput`，支持运行时配置堆栈跟踪和并发安全。调试模式通过 `dlg` 标签启用，允许显示堆栈跟踪和自定义输出。该工具设计注重性能和简约，确保在生产环境中无任何内存或 CPU 开销。

评论摘要
主要讨论点：调试中使用 printf 输出的优缺点及改进建议 不同观点： • [smcameron] 认为 printf 调试虽然有些烦人，尤其是在调试完成后需要手动删除这些打印语句，但他提供了一种解决方案，即使用像 stacked git 这样的工具，通过一个 "stg pop" 命令快速去除这些语句，简化了清理过程。 • [kitd] 对 [smcameron] 的观点表示认可，但提出补充意见，认为堆栈跟踪中不需要包含 Printf 内部的行，只需展示调用 Printf 的行即可，以减少不必要的噪音和干扰。 补充讨论： • [smcameron] 提供了关于 stacked git 的参考链接，供其他开发者参考使用，显示出工具选择在调试中的重要性。 • [kitd] 的补充意见集中在调试输出的优化上，强调了减少不相关信息以提高调试效率的重要性。 • 争议的焦点在于调试信息的详细程度，[smcameron] 侧重于调试的完整性和清理的便捷性，而 [kitd] 则关注调试输出的简洁性和有效性。

URL-Driven State in HTMX

作者: lorenstewart | 评分: 189 | 评论数: 27 | 发布时间: 2025-07-29 22:09
文章摘要

文章介绍了如何在HTMX中通过URL管理应用状态，避免复杂的客户端状态处理。核心思想是将状态存储在URL参数中，使页面状态可书签化和共享。文章通过一个示例演示了这一模式的实现步骤： 1. **服务器读取URL状态**：服务器端点读取URL参数并渲染初始视图。 2. **使用表单和隐藏字段保持状态**：通过HTML表单和隐藏字段在不同交互中保持状态一致。 3. **自动更新浏览器URL**：利用`hx-push-url`自动更新URL，确保状态同步。 这种方法依赖于URL作为单一状态来源，通过服务器端渲染和简单的HTML机制实现状态管理，避免了复杂的JavaScript操作。CSS类和隐藏字段帮助保持和反映当前状态。
