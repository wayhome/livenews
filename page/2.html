文章摘要

Anime.js 是一个快速、多功能的 JavaScript 动画库，能够突破浏览器限制，通过单一API实现网页上的各种动画效果。它具有直观的API，支持逐属性参数设置、灵活的关键帧系统、内置缓动效果和增强的CSS变换。此外，它还支持SVG图形变形、线条绘制和路径跟随，并可以通过Scroll Observer API实现滚动同步动画。Anime.js 提供高级交错效果和拖拽功能，并支持响应式动画和模块化导入，以保持较小的包体积。该库还包括详细的文档和示例代码，帮助开发者快速上手。Anime.js 是免费的，并依赖赞助商的支持。

文章摘要

Benchi 是一个简化的基准测试框架，利用 Docker 创建隔离环境进行基准测试和收集指标。其主要功能包括 Docker 集成、指标收集、自定义钩子以及进度监控。用户可以通过配置文件定义基础设施和工具，使用 Docker Compose 管理环境，并实时监控容器状态和指标。结果以 CSV 格式存储，包含修剪平均值处理后的聚合指标，以及每个基准测试运行的详细日志和原始指标。Benchi 还支持通过命令行参数自定义输出目录和过滤测试工具。Docker 网络和环境变量的使用确保了测试环境的可配置性和互通性。安装和使用可通过 Go 命令或提供的脚本完成。

Show HN: Offline JavaScript PubSub between browser tabs

作者: l1am0 | 评分: 46 | 评论数: 11 | 发布时间: 2025-04-03 14:09
文章摘要

TabSub 是一个通过浏览器本地存储实现的跨标签页发布-订阅（PubSub）机制的 JavaScript 工具。它无需服务器，所有消息通过 localStorage 共享，仅在同域下有效。作者测试了 10 个并发写入，未出现消息丢失或顺序错误，但不能保证大规模并发安全，使用需自担风险。TabSub 提供了 `publish`、`subscribe` 和 `state` 等函数来发布消息、注册监听和获取主题当前状态。示例展示了如何同步多个标签页中的音频播放。TabSub 已在 GitHub 开源，采用 MIT 许可。

文章摘要

Age LAN Server 是一个支持《帝国时代》1、2、3决定版进行局域网（LAN）多人游戏的离线 web 服务器。它允许玩家在没有互联网连接的情况下进行游戏，即使官方服务器维护或关闭，LAN 功能仍可使用。该项目目前处于维护状态，仅修复错误和更新依赖项。要完全离线游玩，玩家需要自定义启动器来绕过游戏的联网限制，并可能使用 Steam 模拟器。 支持功能包括场景模式、地图传输、游戏恢复、模组支持、大厅聊天和跨平台联机（Steam 和 Xbox）。但也存在一些限制，如无法进行排名比赛、无法观战、好友列表显示所有在线用户等。此外，成就、排行榜、玩家数据等功能在离线模式下无法使用。 服务器最低系统要求包括 Windows 10、Linux kernel 2.6.32 及以上、macOS Big Sur 等，客户端则需对应游戏的特定版本。
