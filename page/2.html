这篇文章讲述了1995年左右，高中生Matt Wright创建了Matt's Script Archive网站，分享简单的网站工具（如留言板、访客簿、计数器）。其中WWWBoard成为早期广泛使用的论坛软件。虽然这些脚本满足了普通用户需求，但存在严重的安全漏洞和设计缺陷。2001年，伦敦Perl程序员组织推出nms项目，提供更安全的替代版本。文章指出，当某个工具被广泛使用后，安全问题不可避免会暴露。作者认为不应责怪Wright（他当时还是学生），但这揭示了普通用户需求与开发者专业标准之间的矛盾，以及广泛传播的不安全代码对互联网安全的长期影响。

评论摘要
主要讨论点：Matt's Script Archive 在90年代的影响力及其安全性问题 不同观点： • **怀旧派**（madrox, arscan, knadh, tonyoconnell）：认为 Matt's Script Archive 是学习 Web 开发的宝贵资源，启发了职业生涯。madrox 用它改造了实时聊天，arscan 扩展了论坛功能支持线程和分页，knadh 在青少年时期提供公共托管服务。他们认为当时互联网环境更友好。 • **安全批评派**（Twirrim）：从 ISP 从业者角度指出，这些脚本在2000年代中期造成了严重安全问题，需要定期清理垃圾邮件中继等混乱状况。 • **时代差异派**（madrox）：强烈反对将当时的"vibe coding"与现代开发类比。指出90年代黑客攻击主要是炫技而非牟利，没有大规模机器人扫描漏洞，被黑最多是涂鸦而非窃取信用卡或推销比特币。认为不应忽视两个时代的根本差异。 补充讨论：kristopolous 将其类比为早期的 CPAN、DockerHub；tgorgolione 建议建立历史网站保护协会；Dwedit 分享了利用 wwwboard 漏洞的恶作剧。
