It Takes Two Neurons to Ride a Bicycle

这篇论文提出了一个仅用两个神经元的网络来控制自行车骑行。过去的方法要么需要大量学习时间(如强化学习需要1700次练习),要么需要复杂的数学分析。而人类学骑车并不需要这些。 作者开发了一个通用机器人模拟器来模拟自行车的物理运动,并设计了极简的神经网络控制器。该网络能够引导自行车朝目标方向行驶,表现出与人类相似的特点:长距离目标精确,但短期内受稳定性影响。这种行为不是刻意设计的,而是网络控制方式的自然结果。论文还指出骑车的反直觉性:向右转需要先向左推车把使车身右倾。

评论摘要
主要讨论点：关于"两个神经元控制自行车"研究的技术有效性和实际意义 不同观点： • **质疑创新性**：actinium226认为这只是重新发明了PID控制，输入是期望状态减去实际状态，本质上就是PID的工作原理 • **质疑简化程度**：mk_stjames指出模拟过于简化，忽略了蹬踏控制，真正困难的是从零速度启动时的平衡问题，而非论文所说的"阻尼不稳定性"，任何学骑车的5岁孩子都能证明启动是最难的部分 • **质疑方法论**：ebhn认为研究者只是手写了一个函数然后根据实现方式称之为神经元，但也承认简单网络能完成复杂任务是令人鼓舞的 • **技术细节讨论**：wrsh07强调输入特征的重要性，指出如果给网络提供了导数(θ̇和γ̇)等预处理特征，会大大降低网络复杂度需求 • **神经元能力探讨**：fintler提到单个神经元通过树突区室就能计算XOR等非线性函数，暗示两个神经元可能是浪费 补充讨论：有人开玩笑提到自动驾驶自行车、画骑车的鹈鹕等话题；shomp观察到2个神经元对应2个轮子的巧合；文章发表于2004年

Zig: Build System Reworked

作者: tosh | 评分: 284 | 评论数: 18 | 发布时间: 2026-05-30 08:38
文章摘要

Zig编程语言在2026年5月26日对构建系统进行了重大重构。主要变化是将`build.zig`的编译过程分为两个独立进程：配置器（configurer）和制造器（maker）。配置器以调试模式编译用户的构建逻辑并生成二进制配置文件，制造器以发布模式编译并执行构建图。 这次改进带来三大性能提升：1) 每次修改只需重新编译用户的`build.zig`代码，而非整个构建系统；2) 当配置未变化时可跳过重新运行构建逻辑；3) 执行构建图的进程现在启用了优化。基准测试显示`zig build --help`命令的执行时间从150ms降至14.3ms，性能提升超过90%。此外，第三方工具如ZLS也能从序列化配置文件中受益。

评论摘要
主要讨论点：Zig 0.16.0 版本发布后，开发者对该语言的评价、使用场景和未来发展的讨论 不同观点： • **积极派**：认为 Zig 是优秀的"工具语言"和"车库修补"语言，简单易上手，0.16.0 的新 IO 机制带来高效代码，编译速度出色，跨平台编译能力"纯魔法" • **实用主义者**：将 Zig 定位为"双语言编程"中的低级语言选择，比 C++ 和 Rust 更易重新上手，比 C 更现代，填补了简单性与现代工具之间的空白 • **观望派**：关注语言稳定性问题，质疑异步 IO 等大特性频繁变动说明语言"非常不稳定"，询问稳定版发布时间表 • **怀疑派**：质疑 Zig 相比 Node.js/TypeScript 的优势，对字符串处理的繁琐表示不满，希望有可选的 RAII 支持 • **好奇者**：Rust 用户询问是否应该尝试 Zig，关注两者的优劣对比 补充讨论： 版本迭代速度引发关注（0.17 预计数周内发布，而 0.16 用了超过一年）；Bun 项目从 Zig 转向 Rust 引发编译时间讨论；有人询问 MIT (Expat) 许可证细节；Andrew Kelley 访谈视频激发学习兴趣

西北大学医学院的一项新研究发现，女性在绝经后更易受脑部雌激素流失的影响，这可能解释了为何女性患阿尔茨海默病的风险更高。研究聚焦于大脑细胞间的细胞外基质（ECM），发现雌激素流失、衰老和女性性别与ECM功能障碍密切相关，而ECM对记忆功能至关重要。研究表明，绝经后卵巢停止产生雌激素，仅大脑等组织产生少量雌激素。这一发现为开发针对ECM的新疗法提供了方向，也强调了雌激素对女性大脑健康的重要性。
