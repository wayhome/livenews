Popcorn: Run Elixir in WASM

作者: clessg | 评分: 78 | 评论数: 7 | 发布时间: 2025-05-15 17:14
文章摘要

Popcorn 是一个允许在浏览器中运行 Elixir 代码的库，通过客户端 AtomVM 运行时执行编译后的 Elixir 代码。它提供了 Elixir 与 JavaScript 互操作的 API，处理序列化、通信以及保持浏览器响应。 ### 主要功能： 1. **执行环境**：通过 WebAssembly（WASM）在浏览器中运行 Elixir。 2. **API**：提供 JS 和 Elixir 之间的消息传递机制。 3. **示例**：包括 Elixir REPL、文档交互示例和生命游戏模拟。 ### 使用步骤： 1. **添加依赖**：在 `mix.exs` 中添加 `{:popcorn, "~> 0.1"}`。 2. **构建运行时**：运行 `mix popcorn.build_runtime` 生成 WASM 和 JS 库。 3. **HTML 配置**：在 HTML 文件中引入生成的 JS 文件。 4. **Elixir 入口**：定义一个永不退出的 `start/0` 函数，并通过 `Popcorn.Wasm.send_elixir_ready` 通知 JS。 ### API 详解： - **JS API**：`Popcorn.init()` 初始化，`call()` 和 `cast()` 用于发送消息到 Elixir。 - **Elixir API**：`Popcorn.Wasm.send_elixir_ready()` 通知 JS 初始化完成。 ### 注意事项： 该库仍在开发中，API 不稳定，部分功能未实现。详细限制见文档。 通过 Popcorn，开发者可以在浏览器中运行 Elixir 代码并与 JS 交互。

评论摘要
