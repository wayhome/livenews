Maru OS – Use your phone as your PC

作者: fsflover | 评分: 181 | 评论数: 28 | 发布时间: 2025-07-29 19:24
文章摘要

Maru是一个将手机与桌面计算结合的操作系统，可以让手机通过连接HDMI屏幕和键鼠，变身为一个轻量级的桌面电脑。它基于Android Oreo构建，无预装软件，运行流畅。当手机连接显示器时，Maru会自动启动桌面模式，并在5秒内启动。桌面模式支持多任务处理和生产力应用，底层为Debian Linux，可自由定制。手机和桌面环境共享存储和网络连接，实现无缝切换。Maru让个人计算更简单，所有工作在一台设备上即可完成。

How the brain increases blood flow on demand

作者: gmays | 评分: 50 | 评论数: 4 | 发布时间: 2025-07-29 19:13
文章摘要

这篇文章主要介绍了哈佛医学院的一项新研究，该研究揭示了大脑如何快速有效地将血液输送到需要更多氧气和营养的活跃区域。研究发现，大脑依赖于血管内皮细胞间紧密交织的通道进行通讯，这些通道通过所谓的缝隙连接迅速传递信号，从而调节血流量。该研究发表在《Cell》杂志上，有助于更好地理解神经退行性疾病以及脑成像（如功能性磁共振成像，fMRI）的解读。如果这些发现能在动物和人类中得到进一步验证，可能会为治疗认知问题提供新思路。这项研究还强调了联邦资助对科学研究的重要性。

评论摘要
主要讨论点：关于大脑研究及其资助背景的讨论 不同观点： • Insanity认为大脑试图理解自身运行机制是一个引人入胜的话题，表达了对该研究的兴趣和赞赏。 • bozhark以一种幽默的方式质疑大脑是否可以“变硬”，虽然这是一个调侃，但反映了对大脑物理性质或研究结果的某种疑惑或调侃态度。 • searine提到了该研究由多个著名机构资助，但这些机构的资金被大幅削减，暗示了对科研资金不足的担忧和批评。 • HardCodedBias对研究中的具体机制表现出兴趣，特别是关于血流量是否根据大脑的计算/代谢需求调整，还是大脑直接向内皮细胞发出信号，显示出对研究细节和未解问题的关注。 补充讨论： • searine指出的科研资金削减问题可能对未来类似研究产生影响，是一个潜在的争议点。 • HardCodedBias指出的研究细节问题显示出对现有研究的不满足，认为需要更深入的解释或进一步研究，表明了对科学研究严谨性的要求。

More honey bees dying, even as antibiotic use halves

作者: pseudolus | 评分: 143 | 评论数: 16 | 发布时间: 2025-07-29 19:37
文章摘要

尽管加拿大限制了养蜂业中抗生素的使用，蜜蜂的死亡率仍在上升。一项由圭尔夫大学研究人员主导的研究发现，随着抗生素使用减半，蜜蜂的越冬死亡率反而从不到20%上升到超过40%。研究表明，抗生素的减少可能导致蜜蜂对致病微生物的抵御能力下降，因为它们的微生物群受到破坏。此外，二氧化氮（NO2）污染也被发现是蜜蜂死亡率上升的一个意外因素，因为它干扰了蜜蜂的觅食能力。研究人员呼吁采用“同一健康”方法，综合考虑人类、动物和环境健康，寻找替代抗生素的解决方案，如益生菌。目前，加拿大正在开展一个全国性项目，研究蜜蜂的微生物群以应对这一问题。

评论摘要
主要讨论点：蜜蜂种群健康下降的原因及相关因素 不同观点： • JumpCrisscross：蜂蜜蜂并非北美本土物种，它们在与本土传粉者（如大黄蜂）的竞争中占优势，导致生物多样性下降。此外，家庭后院的养蜂活动可能无意中消灭了本地的大黄蜂和蝴蝶种群。 • mushroomba：现代养蜂实践类似于工厂化养殖，Tim Rowe的《The Rose Hive Method》提出了一种利用进化改善蜜蜂活力的方法。然而，商业养蜂的当前实践可能无法持续，尤其是对于对蜂蛰过敏的人。 • miellaby：文章将蜜蜂健康问题归因于抗生素和NO2，但实际上主要原因应为新烟碱类农药，这些化学物质对昆虫有广泛的杀伤作用。 • imzadi：如果养蜂人通过使用抗生素保持蜜蜂健康，停止使用抗生素可能导致蜜蜂健康状况下降，因为之前的抗生素使用可能杀死了健康的细菌。 • alionski：工业界和政府应更多关注野生蜜蜂的保护，因为“拯救蜜蜂”实际上是指野生蜜蜂，而非作为“牲畜”的蜂蜜蜂。 • horacemorace：昆虫数量的减少对环境有巨大影响，过去夏季经常需要清理挡风玻璃上的昆虫尸体，而现在不再需要。 • endo_bunker：抗生素使用与蜂群死亡之间的关系可能是因为抗生素主要用于不健康的蜂群。 • ceedan：蜂群崩溃症可能由瓦螨传播的病毒和杀虫剂引起。 • giantg2：细菌问题对养蜂人来说不是主要问题，可以使用抗生素治疗欧洲幼虫病，但美洲幼虫病不可治疗，生物组研究正在进行中。 • thebees：非洲化蜜蜂（“杀人蜂”）在许多中美洲和南美洲地区是主要的蜂蜜生产者。 • animitronix：蜜蜂问题主要是杀虫剂问题，而非抗生素问题。 • 7734128：或许应该避免使用抗生素。 • Gnarl：提出射频辐射可能是一个因素。 • more_corn：问题主要在于杀虫剂。 补充讨论： • 讨论中涉及多个可能影响蜜蜂健康的因素，包括外来物种竞争、抗生素使用、农药（尤其是新烟碱类）、瓦螨传播的病毒、射频辐射等。 • 争议的焦点在于主要导致蜜蜂种群下降的原因，有人认为是农药，有人认为是抗生素或外来物种竞争，还有人提出其他环境因素。 • 讨论还涉及保护野生蜜蜂的必要性和现代养蜂实践的可持续性问题。

Show HN: A GitHub Action that quizzes you on a pull request

作者: dkamm | 评分: 70 | 评论数: 12 | 发布时间: 2025-07-29 18:20
文章摘要

**PR Quiz** 是一个 GitHub Action，利用 AI 根据 pull request 生成测验，帮助开发者检验对代码的理解。它要求用户拥有 OpenAI API Key 和 ngrok 认证 token，并在 GitHub 仓库中设置为 secrets。当 pull request 通过审核后，系统会触发测验生成，并在临时 web 服务器上通过 ngrok 提供访问。测验有时间限制和尝试次数限制，还可以排除特定文件。该工具确保代码不会发送给第三方，仅与 OpenAI 模型交互，也可修改为支持自托管模型。
