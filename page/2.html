Scientists program stem cells to mimic first days of embryonic development

作者: StemCells | 评分: 14 | 评论数: 3 | 发布时间: 2025-03-21 01:45
文章摘要

科学家通过CRISPR技术编程干细胞，成功模拟了胚胎发育的最初几天。这项由加州大学圣克鲁兹分校团队开展的研究，利用胚胎样结构（胚胎模型，embryoids）来研究早期胚胎发育过程，而无需实际使用胚胎。他们使用小鼠干细胞，通过修改基因组的表达，控制特定基因的激活，引导形成胚胎发育所需的主要细胞类型。结果显示，80%的干细胞在几天内自组织成类似胚胎的基本结构，并表现出与活体胚胎相似的基因激活模式和细胞集体行为。该模型为研究胚胎发育及相关病理问题提供了新工具。研究发表于《Cell Stem Cell》期刊。

Landrun: Sandbox any Linux process using Landlock, no root or containers

作者: Zoup | 评分: 362 | 评论数: 17 | 发布时间: 2025-03-22 13:56
文章摘要

**landrun** 是一个轻量级、安全的 Linux 进程沙箱工具，利用 Linux 内核的 Landlock LSM 实现内核级安全控制。相比于 firejail，landrun 更轻量、用户友好且内核集成度高。其主要功能包括： - 基于 Landlock LSM 的内核级安全 - 轻量快速执行 - 目录级的细粒度访问控制 - 支持读写路径设置 - 可选的执行权限 - TCP 网络访问控制（需内核 6.8 及以上） **安装**： - 快速安装：`go install github.com/zouuup/landrun/cmd/landrun@latest` - 源码安装需克隆仓库并使用 Go 构建。 **使用**： - 基本语法：`landrun [选项] <命令> [参数...]` - 选项包括设置只读、读写路径，执行权限，TCP 端口绑定和连接等。 **示例**： - 运行命令并设置目录只读权限、TCP 端口绑定等。 **安全性**： - 通过 Landlock LSM 实现文件系统和网络访问控制，增强进程隔离和安全性。 **要求**： - 需要 Linux 内核 5.13 及以上（网络限制需 6.8 及以上），Go 1.24.1 及以上。 该工具适用于需要细粒度访问控制和安全隔离的场景。

Stop using the elbow criterion for k-means

作者: Anon84 | 评分: 23 | 评论数: 3 | 发布时间: 2025-03-23 02:51
文章摘要

这篇文章呼吁停止在k-means聚类中使用肘部法则来选择簇数，因为该方法缺乏理论支持且容易导致错误结论。作者指出，学术界应采用其他已被广泛认可的替代方法，如轮廓系数、差距统计等。文章建议教育工作者避免教授肘部法则，并鼓励研究人员和审稿人拒绝基于该方法得出的结论。通过这样做，可以提高聚类分析的准确性和可靠性。

评论摘要
主要讨论点：不同方法在确定数据聚类数量（K）时的有效性和理论依据 不同观点： • [whatshisface] 支持肘部法，认为该方法有简单的理论依据。他指出，如果数据确实有k个明显分离的簇，那么分割不同簇的收益应远大于分割同一簇的收益。如果这一点不成立，数据本身就没有明显分离的簇。 • [tetris11] 倾向于使用轮廓系数法，主要因为其实验结果（尤其是生成图像的效果）吸引人。他还指出，轮廓系数法在大K值时表现良好，但在K=1时表现不佳。 • [rgavuliak] 不认同肘部法，基于其多年经验，认为肘部法在实践中并不有效，从未见过显著的分离效果。 补充讨论： • 争议焦点在于肘部法是否在实践中有效。一方面，[whatshisface] 强调其理论合理性，另一方面，[rgavuliak] 基于实践经验对其有效性提出质疑。 • [tetris11] 的评论引入了另一种方法——轮廓系数法，并通过个人经验提供了该方法在不同K值下的表现情况，为讨论增加了方法比较的维度。
