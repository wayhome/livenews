Ovld – Efficient and featureful multiple dispatch for Python

作者: breuleux | 评分: 3 | 评论数: 0 | 发布时间: 2025-05-29 19:45
文章摘要

`ovld` 是一个用于 Python 的高级多重调度库，允许根据函数参数的类型和值进行调度，而无需使用 `isinstance` 语句。它支持多参数调度，速度快，并提供多种高级功能，如变体、混合和依赖类型。通过装饰器定义不同版本的函数来处理不同类型和值，还支持递归定义和代码生成。此外，`ovld` 允许设置优先级和使用 `call_next` 来控制调度顺序，适用于调试和扩展。示例展示了如何处理基本类型、列表和依赖类型的函数定义与调用，如阶乘计算。
