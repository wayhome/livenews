LLM Workflows then Agents: Getting Started with Apache Airflow

作者: alittletooraph2 | 评分: 67 | 评论数: 7 | 发布时间: 2025-03-31 18:32
文章摘要

`airflow-ai-sdk` 是一个用于在 Apache Airflow 中操作大型语言模型（LLM）和 AI 代理的 SDK，基于 Pydantic AI。它允许用户直接在 Airflow 管道中调用 LLM 并编排代理任务，使用基于装饰器的任务语法，如 `@task.llm`、`@task.llm_branch` 和 `@task.agent`。SDK 提供自动输出解析、分支控制等功能，支持多种 LLM 模型（如 OpenAI、Anthropic 等）。通过该 SDK，用户可以轻松将 LLM 工作流集成到 Airflow 管道中，从简单的 LLM 调用到复杂的代理工作流均可实现。示例代码和安装说明详见 GitHub 仓库。

KOReader: Open-Source eBook Reader

作者: charleshan | 评分: 39 | 评论数: 3 | 发布时间: 2025-03-31 19:52
文章摘要

KOReader是一款支持多种文档格式的电子书阅读应用，适用于Cervantes、Kindle、Kobo、PocketBook和Android设备。它支持固定页面格式（如PDF、DjVu）和重排电子书格式（如EPUB、FB2），并集成了Calibre、Wallabag、Wikipedia等服务。KOReader专为电子墨水屏设备优化，具有无动画的自定义UI、分页菜单和可调对比度。该应用高度可扩展，通过插件实现额外功能，并且在一些旧设备上具有更快的翻页速度。KOReader由全球志愿者开发和维护，支持通过Liberapay捐赠。主要功能包括多语言界面、自定义排版选项、在线词典查询和OTA更新等。安装步骤和开发指南可在其官网和Wiki上找到。
