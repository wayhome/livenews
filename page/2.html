Memory Integrity Enforcement

作者: circuit | 评分: 292 | 评论数: 24 | 发布时间: 2025-09-09 18:25
文章摘要

苹果公司发布了Memory Integrity Enforcement (MIE)技术，这是其历时五年研发的重大安全升级，通过结合Apple芯片硬件和操作系统安全功能，为用户设备提供全天候的内存安全保护，且不影响性能。MIE旨在防御复杂的高级威胁，特别是针对iOS系统的间谍软件攻击，这些攻击通常利用内存安全漏洞。苹果此前已通过Swift语言、安全内存分配器和Pointer Authentication Codes (PAC)等技术提升内存安全。该公司还参与了Arm的Enhanced Memory Tagging Extension (EMTE)规范的改进，以确保同步、强制性的内存安全保护，并通过深度硬件和操作系统集成实现突破性的安全机制。
