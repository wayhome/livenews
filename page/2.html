smartfunc: Turn Docstrings into LLM-Functions

作者: alexmolas | 评分: 33 | 评论数: 8 | 发布时间: 2025-04-08 09:43
文章摘要

`smartfunc` 是一个将 docstrings 转换为 LLM（大语言模型）功能的 Python 库，基于 Simon Willison 的 `llm` 库构建。通过使用装饰器，开发者可以轻松地将函数的文档字符串转换为 LLM 提示，并使用指定的后端（如 GPT-4）生成结果。该库支持使用 Jinja2 模板和 Pydantic 模型定义响应结构，允许通过 `.env` 文件存储 API 密钥，并具有异步支持和多供应商生态系统。其目标是在快速原型设计中提供简洁的解决方案，专注于简单易用，而非复杂的功能集。以下是一个示例： ```python from smartfunc import backend from pydantic import BaseModel class Summary(BaseModel): summary: str pros: list[str] cons: list[str] @backend("gpt-4o-mini", system="You are a helpful assistant.", temperature=0.5) def generate_poke_desc(text: str) -> Summary: """Describe the following pokemon: {{ text }}""" pass print(generate_poke_desc("pikachu")) ``` 这个库的主要优势在于其简洁性和对特定功能集的专注，适用于快速原型设计和简单任务。
