Linux kernel 6.14 is a big leap forward in performance and Windows compatibility

作者: CrankyBear | 评分: 84 | 评论数: 6 | 发布时间: 2025-03-26 15:54
文章摘要

Linux kernel 6.14, released in March 2025, brings significant performance improvements and enhanced Windows compatibility, making it a major update for both gamers and general users. Key features include the NTSYNC driver, which boosts performance of Windows applications and games on Linux via Wine and Steam Play. It also adds support for AMD RDNA 4 graphics cards and the RADV driver, enhancing gaming graphics performance. For AI workloads, the kernel introduces the AMDXDNA driver for AMD's neural processing units. Other enhancements include better power management for AMD and Intel processors, Rust language integration, support for Qualcomm's Snapdragon 8 Elite, and fixes for vulnerabilities like GhostWrite. Overall, this release marks a substantial advancement in Linux's capabilities across multiple domains.

Microsoft Study: AI Makes Human Cognition "Atrophied and Unprepared"

作者: greybox | 评分: 38 | 评论数: 13 | 发布时间: 2025-03-26 16:54
文章摘要

微软和卡内基梅隆大学的一项研究发现，随着人们在工作中越来越依赖生成式人工智能，他们的批判性思维使用减少，可能导致认知能力退化。研究人员指出，自动化剥夺了人们处理常规任务的机会，使其在面对例外情况时缺乏判断力和准备。研究招募了319名知识工作者，他们 self-reported 了936个使用生成式AI的实例。调查显示，过度依赖AI工具可能导致用户对自己完成任务的能力信心下降，例如教师用DALL-E生成图片、交易员用ChatGPT提升技能、护士验证AI生成的教育手册等。

评论摘要
主要讨论点：AI对人类认知能力的影响，尤其是在解决问题和理解系统方面。 不同观点： • [gatinsama] 认为理解系统的工作原理是无法委派给他人的，尤其是对于复杂的项目，理解和决策系统的运作方式是最困难的部分。如果不理解系统，就无法知道它是否按预期工作。 • [vunderba] 指出，过度依赖像ChatGPT这样的工具会削弱人们的批判性思维能力。这种依赖使得人们失去了培养内在有价值技能的机会，而这种技能只能通过刻意的练习来提高。将LLM与计算器的发明相比较是不恰当的，因为计算器是用来辅助解决更大问题的。 • [lenerdenator] 表示，AI像Google搜索一样，使信息的记忆成为可选的认知负担，而人们通常会抛弃这种负担。不过，个人的认知问题不一定需要AI来造成萎缩和 unprepared。 • [masfuerte] 认为这种现象并不是新的，早在1990年代银行员工的工作自动化时就出现了类似的情况。随着软件处理例外情况的能力增强，员工的技能逐渐萎缩，处理更难例外的能力下降。 • [sollewitt] 提出，LLM可以在语言学习中发挥积极作用，提供“认知健身房”的效果。LLM可以提供灵活的对话和解释，超越Duolingo等工具的局限性。 • [greybox] 引用微软的研究指出，自动化可能导致人类认知的萎缩和 unprepared，因为剥夺了人们在日常任务中锻炼判断力的机会。 • [0x20cowboy] 分享个人经验，承认在疲劳或烦躁时会过度依赖LLM，直接复制错误信息而不加思考，这种行为让他感到自己的认知能力下降，但同时有一种奇怪的满足感。 • [piltdownman] 提到使用AI需要额外的“合成思维努力”来引导AI响应，这可能增加认知负担。有人认为，这种“合成思维努力”可以作为评估AI使用成本/收益的关键绩效指标。 • [deadbabe] 认为，发展中国家的儿童由于缺乏AI工具，必须依靠自己的脑力解决问题，从而可能获得超越发达国家儿童的机会。对发达国家儿童的描述则较为负面。 • [moralestapia] 认同认知能力下降的观点，特别是在COVID后教育水平下降的背景下。同时认为能够正确推理的人类会变得更加有价值。 补充讨论： • 争议焦点在于AI工具对人类认知能力的影响，尤其是对批判性思维和问题解决能力的潜在削弱。 • 一些人认为AI可以作为有效的学习工具，提供传统方法无法比拟的优势，如语言学习中的灵活对话。 • 微软的研究被多次引用，以支持关于自动化导致认知萎缩的讨论。 • 对发达国家和发展中国家儿童的对比讨论，引发了对AI工具普及不均可能导致教育机会不平等的担忧。 总体来看，讨论围绕AI对人类认知的双重影响展开，既有对潜在负面影响的担忧，也有对其作为学习工具的积极评价。
