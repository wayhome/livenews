Deleting multiplayer from the Unreal engine can save memory

作者: mariuz | 评分: 95 | 评论数: 7 | 发布时间: 2025-04-06 10:23
文章摘要

这篇文章讨论了在Unreal引擎中移除多人游戏相关功能以节省内存的可行性。尽管Unreal引擎的多人游戏功能集成良好，便于开发，但对于单人游戏项目，这些功能会占用不必要的内存。文章详细分析了即使在单人游戏中，某些变量（如与网络复制相关的数据）仍会占用内存空间，如"bReplicates"变量和一些自定义结构体，分别占用了120和216字节。通过手动移除这些变量，作者成功将每个actor的内存占用减少了328字节。不过，这种优化不易实现，因为Unreal的头文件工具（UHT）不支持通过预处理宏动态排除这些变量。最终，作者通过手动注释相关代码完成了优化，但建议在生产环境中谨慎操作。

评论摘要
主要讨论点：关于ABZÛ游戏中对AActor和UPrimitiveComponent的优化及其影响 不同观点： • [mwkaufma] 认为通过移除多人游戏模式以及AActor和UPrimitiveComponent中的其他冗余部分，特别是内置的重叠事件，不仅节省了内存，还减少了幽灵读写的发生。内置重叠事件被视为一种反模式。 • [joegibbs] 指出即使进行了优化，拥有成千上万个actor仍然会造成性能负担。他建议通过实例化这些actor或者使用处理UObjects的actor来减少actor数量，除非有特殊需求。 • [Fokamul] 批评大公司不关注这些细节优化，认为他们会依赖玩家购买新硬件来解决问题，而不是雇佣引擎核心开发人员进行优化。 补充讨论： • [bengarney] 提到即便在拥有10万个actor的情况下，通过减少3-4个纹理也能节省更多内存，暗示纹理优化可能比actor数量优化更有效。 • [spockz] 进一步探讨了除了内存节省，actor数量的减少是否会带来性能提升，特别是缓存行的利用效率。 • [out-of-ideas] 提到了一个与此讨论无关的技术问题，涉及到页面加载的循环请求，并通过正则表达式阻止特定请求来加速页面加载。 • [keyle] 质疑这些优化在生产构建中是否会产生实际效果，表明对实际应用效果的关注。 争议焦点： • 主要争议在于优化的实际效果和必要性。一些观点认为actor数量的减少能带来显著的性能提升，而另一些观点则认为还有其他更有效的优化手段，或者这种优化在实际应用中效果有限。 总结：讨论围绕ABZÛ游戏中的技术优化展开，涉及内存和性能的权衡，以及对大公司优化态度的批评。不同的技术建议和实际效果的质疑构成了讨论的主要张力。

LLM-hacker-news: LLM plugin for pulling content from Hacker News

作者: kwiktrip | 评分: 4 | 评论数: 0 | 发布时间: 2025-04-08 10:32
文章摘要

"llm-hacker-news" 是一个 LLM 插件，用于从 Hacker News 获取内容。用户可以通过指定对话的 ID 将整个对话线程输入到 LLM 中，例如使用命令 `llm -f hn:43615912`。对话 ID 可在 Hacker News 链接中找到。安装插件需运行 `llm install llm-hacker-news`。开发者可以克隆代码，创建虚拟环境并安装依赖以进行本地开发，依赖安装命令为 `llm install -e '.[test]'`，测试运行命令为 `python -m pytest`。该项目采用 Apache-2.0 许可证，主要使用 Python 编写。

What a refugee camp reveals about economics

文章摘要

这篇文章介绍了马拉维Dzaleka难民营的经济状况。在这个难民营，每位居民每月收到9美元的援助。尽管表面上看起来像是一个典型的周日，人们从教堂出来，成双成对地逛街，但实际上，这里的大多数人并没有全职工作。文章通过这一场景探讨了难民营中的非正式经济活动和居民如何利用有限资源谋生。文章还反映了在全球贸易政策动荡背景下，经济学家对难民营经济模式的兴趣和研究。

评论摘要
主要讨论点：马尔代夫（Malawi）通过放宽工作权并提供入籍途径是否会有更大的经济收益 不同观点： • 观点一：支持放宽工作权和提供入籍途径。 - 论据：这种政策可能为马尔代夫带来更大的经济收益。 - 例子：通过让更多的人合法工作并提供成为公民的途径，可以促进经济活力和增长。 - 隐含假设：移民和劳动力市场的自由化能够刺激经济，类似于其他国家通过类似政策获得的成功经验。 • 观点二：对放宽工作权和入籍途径持保留或反对态度。 - 论据：担心可能对本地劳动力市场造成冲击，导致失业率上升或工资下降。 - 例子：一些国家在放宽移民政策后，面临本地工人失业或社会福利系统负担加重的问题。 - 隐含假设：需要平衡外来劳动力与本地劳动力的需求，以避免负面经济和社会影响。 补充讨论： - 争议焦点：政策的实施细节和可能的长期影响。例如，如何确保外来劳动力的质量和数量不会对本地市场造成冲击，以及如何设计合理的入籍途径以避免社会不满。 - 其他讨论点：不同利益相关者的观点，如企业可能支持该政策以获取更多劳动力，而工会可能担忧外来劳动力对本地工人的影响。 - 政策背景：需要考虑马尔代夫的具体国情，包括经济结构、劳动力市场现状以及社会接纳能力。
