这篇文章介绍了一个名为 `safe-npm` 的安全工具，旨在防止因 npm 包被恶意篡改而引发的供应链攻击。其主要功能包括： 1. **安全安装**：只安装发布超过设定天数（默认为90天）的 npm 包版本，降低使用近期被篡改包的风险。 2. **工作原理**：通过检查包的发布时间，筛选符合版本要求和安全时间要求的版本进行安装。 3. **使用方式**：支持全局安装或从源码构建，提供多种配置选项如最小天数、忽略特定包、严格模式等。 4. **应用场景**：适用于需要高安全性的生产环境或希望减少供应链攻击风险的开发场景。 该工具适合对安全性要求较高的开发者或团队使用。
