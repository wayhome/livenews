IBM debuts sub-1 nanometer chip technology

作者: porridgeraisin | 评分: 262 | 评论数: 24 | 发布时间: 2026-06-25 15:33
文章摘要

IBM于2026年6月25日发布了全球首个亚1纳米芯片技术，采用0.7纳米(7埃)节点。该芯片采用革命性的"nanostack"三维架构，在指甲大小的芯片上集成近1000亿个晶体管，密度是IBM 2纳米芯片的近两倍。相比2纳米芯片，新技术性能提升50%或能效提升70%，可应用于生成式AI、云基础设施等领域。Nanostack是业界首个三维纳米片设计，通过垂直堆叠晶体管实现更高密度。该技术标志着芯片制造进入埃级时代，IBM预计该架构可支持未来十年的芯片缩放发展。

评论摘要
主要讨论点：IBM宣称的0.7nm芯片技术的真实性和商业化前景 不同观点： • **营销夸大派**：多位评论者（buran77, monirmamoun）认为这是营销噱头，芯片上没有任何结构真正达到0.7nm，实际使用~5nm工艺特征，IBM历史上有夸大宣传记录（如"量子传输"广告） • **行业惯例解释派**：jadar指出这是行业通行做法——"纳米"数字已与实际晶体管尺寸脱钩多年，0.7nm仅表示密度约为上一代的两倍 • **商业模式质疑派**：多人困惑IBM的商业化路径。lizknope提到IBM曾付15亿美元让Global Foundries接手其晶圆厂；victor106和giwook质疑IBM如何利用这些技术，是否授权给代工厂 • **技术极限探讨派**：throw0101d和bozhark关注物理极限——图片显示"15层硅原子"，讨论摩尔定律是否存在分子级物理边界 补充讨论： • IanCutress提供了7000字深度技术分析文章 • cubefox指出5年商业化时间表暗示仍有重大未解决问题 • elisbce建议用"立方厘米晶体管密度"等更难造假的指标 • 技术细节讨论涉及High NA EUV光刻技术和ASML设备

Un-0: Generating Images with Coupled Oscillators

作者: babelfish | 评分: 135 | 评论数: 15 | 发布时间: 2026-06-25 20:50
文章摘要

Unconventional AI发布了Un-0图像生成模型，这是首个基于物理动力系统（耦合振荡器）的大规模图像生成器。该模型在ImageNet 64×64数据集上达到FID 6.74，性能媲美传统方法首次发布时的水平。Un-0利用数千个相互耦合的Kuramoto振荡器来生成图像，振荡器之间的耦合强度是模型的主要可学习参数。该方法旨在通过物理计算实现约1000倍的能效提升。团队已开源模型权重、训练和评估代码，以推动基于物理动力系统的AI研究。

评论摘要
主要讨论点：一种基于Kuramoto振荡器的新型图像生成方法 不同观点： • **技术潜力派**：认为这是有趣的创新方向。dimatura推荐了相关书籍《Sync》，andybak联想到模拟计算的历史价值，foax和_def看到了与DCT压缩、FM合成的技术关联 • **实用性质疑派**：WhitneyLand指出n²扩展性问题——生成4K图像需要5万亿个点对点连接，认为64x64像素的演示说明存在根本局限。luciana1u直接批评"更慢且更差" • **验证需求派**：ainch和TaupeRanger要求更多细节。ainch质疑能效优势是否真实存在，TaupeRanger指出这只是在传统硬件上的模拟，需要专用硬件才能实现宣称的优势 • **功能怀疑派**：OutOfHere质疑能否生成多类别复杂图像（如"宇航员在月球骑马"） 补充讨论：NopIdoN注意到其需要复杂的损失函数；fusionadvocate询问与储备池计算的关系；italiansolider提醒需要物理学背景才能深入理解；mrr7337坦承没看懂

OpenKnowledge 是一个开源的本地优先 Markdown 编辑器和 LLM 知识库，集成了 Claude、Codex 和 Cursor。它提供所见即所得的编辑体验，类似 Google Docs 或 Notion。支持通过 git 进行团队协作和自动同步。 提供 macOS 桌面应用和跨平台 CLI 工具（需 Node.js 24+）。项目采用 GPL-3.0 许可，使用 Bun 和 TypeScript 构建，包含 Web 应用、CLI、桌面端、服务器等多个模块。欢迎公开贡献。
