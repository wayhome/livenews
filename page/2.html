Show HN: Extend UI – open-source UI kit for modern document apps

作者: kbyatnal | 评分: 153 | 评论数: 17 | 发布时间: 2026-06-10 16:09
文章摘要

这是一个开源UI组件库，专为现代文档应用设计。提供PDF、DOCX、XLSX和CSV文件查看器，支持边界框引用、文件上传、电子签名等功能。可直接集成到用户界面、AI代理或内部工具中。主要组件包括：多格式文档查看器、文档分割工具、文件系统浏览器、Schema构建器（支持表单和JSON配置）、文件缩略图、布局块、边界框引用、文档编辑器和电子签名功能。适用于需要文档处理能力的应用场景。

评论摘要
主要讨论点：一个React文档查看器组件库的发布，支持PDF、DOCX、XLSX等格式的渲染和预览。 不同观点： • **性能问题派**：多位用户（pea、plastic041）反馈首页在M3/M4 MacBook上存在明显卡顿，建议采用懒加载而非一次性加载所有组件；点击操作响应慢（1-2秒） • **积极支持派**：部分开发者（dvt、hobofan）认为该工具非常有用，特别是对于本地AI文档工作流和应用内预览场景，可避免服务器端PDF转换方案 • **技术质疑派**：有用户（promiseofbeans）质疑PDF渲染能力，指出PDF edge case很多，询问相比Mozilla PDF.js的优势；spankalee批评只支持React而非Web Components，不利于Web生态 • **功能反馈派**：qreoct发现Excel查看器的搜索功能无法正常工作；stinger询问是否支持Markdown；KolmogorovComp报告移动Safari无法加载 补充讨论：CraigJPerry关注bounding box处理和页面虚拟化实现细节；egeozcan和phonon分别提出文档说明不足和竞品对比的问题；carlosjobim称赞Miller columns设计；warthog好奇XLSX编辑器的底层实现架构。

GeoLibre 1.0

作者: jonbaer | 评分: 154 | 评论数: 8 | 发布时间: 2026-06-10 17:39
文章摘要

GeoLibre是一个轻量级云原生GIS平台，基于Tauri、React、TypeScript、MapLibre GL JS、DuckDB-WASM和deck.gl构建。支持跨桌面和Web环境运行，可视化、探索和分析地理空间数据。 主要功能包括：MapLibre地图工作区、本地/远程数据加载、插件市场、多种高级数据格式（GeoParquet、PMTiles、3D Tiles等）、数据格式转换、SQL工作区、矢量/栅格处理工具、Python/Jupyter集成。浏览器版本托管在GitHub Pages上，完全在客户端运行，无需服务器账户，数据处理保证隐私。支持通过URL参数分享和嵌入项目。

评论摘要
主要讨论点：关于GeoLibre 1.0版本发布的反馈和评价 不同观点： • **积极支持派**：认为浏览器端GIS工具非常便利，技术栈（MapLibre + DuckDB + React + PMTiles）表现优秀，适合加入个人实验室使用。特别提到相比QGIS在M2 Mac上的3D功能问题，这个方案更实用 • **性能质疑派**：实测发现明显问题——网页版加载文件时出现IO错误，桌面版只能处理小文件（~30MB），大文件（>1GB）导入时卡住后界面空白、图层丢失。认为作为QGIS轻量替代品还有很长的路要走 • **应用场景派**：视其为ArcGIS Online Map Viewer的免费替代品，对非营利组织野外数据采集有价值 • **批评派**：认为营销话术过多，过分强调技术库而非实际解决的问题；另有评论直接称其为"AI垃圾" 补充讨论：有用户对开发速度表示惊讶（"两周内完成整个项目？"），也有人表达了尝试意愿但未深入评价。地图数据细节（如垃圾桶位置）的准确性获得正面反馈。

World Capitals Voronoi

作者: vincnetas | 评分: 39 | 评论数: 15 | 发布时间: 2026-06-08 15:20
文章摘要

这是一个基于球面Voronoi图的世界地图可视化项目。它根据最近首都城市重新划分了世界版图——每个区域由距离最近的首都决定。 计算采用球面Voronoi图算法，考虑了地球曲率来精确计算距离。数据来源于Natural Earth的1:10m文化矢量数据集（首都城市）。 这种可视化方式打破了传统国界，展示了一种基于地理距离的另类世界划分方式。类似项目还有"美国Voronoi图"。

评论摘要
主要讨论点：基于首都位置的Voronoi图重绘世界地图的可视化效果及其产生的有趣地缘政治变化 不同观点： • 技术赞赏派：称赞可视化的帧率和延迟表现"绝对魔幻"，互动体验流畅，作品质量高 • 地缘政治观察派：关注领土变化的政治敏感性，如台北占据中国大陆大片领土、渥太华和墨西哥城占据美国领土等会引发争议 • 技术细节派：指出模型将首都视为单点导致的问题（如梵蒂冈分到过多领土而未考虑罗马市界）；发现多首都国家会被进一步分割 • 区域变化观察派：发现有趣的领土重组，如都柏林占据英国大片领土、哥本哈根获得瑞典南部、喀拉拉邦和泰米尔纳德邦归属斯里兰卡、加拿大基本保持完整（除BC省） • 功能扩展建议派：希望看到统计数据（哪些国家得失最大、变化最小、距原属国最远的区域）和包含海洋的版本 补充讨论：有评论指出乌克兰首都拼写错误（"Kiev"应为"Kyiv"），反映地名政治化问题。整体氛围友好，多数评论带有幽默和欣赏态度。
