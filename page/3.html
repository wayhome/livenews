Using Atomic State to Improve React Performance in Deeply Nested Component Trees

作者: 18nleung | 评分: 7 | 评论数: 1 | 发布时间: 2025-10-26 20:39
文章摘要

本文介绍了如何使用原子状态(Atomic State)来优化深度嵌套的React组件树的性能。作者团队在开发临床试验数据采集UI时，最初使用React的useState和Context管理状态，但随着组件层级加深(4层嵌套结构)，性能问题凸显 - 任何节点的更新都会导致整个树重新渲染。实际应用中组件更复杂，包含多种数据类型、条件可见性和动态节点等，使得渲染代价更高。 文章对比了受控和非受控输入的优缺点：受控输入能实现复杂UI模式但会导致频繁重渲染；非受控输入可避免不必要渲染但实现复杂条件UI时需要命令式解决方法。最终团队采用原子状态作为解决方案，既保持了React的开发体验，又解决了性能问题。

More than DNS: Learnings from the 14 hour AWS outage

作者: birdculture | 评分: 83 | 评论数: 7 | 发布时间: 2025-10-27 15:56
文章摘要

本文总结了AWS美国东部1区（us-east-1）2020年10月20日发生的严重中断事件。此次中断持续16小时，影响了140项AWS服务，包括EC2等核心服务，造成巨额收入损失。根本原因是DynamoDB DNS管理系统中的一个潜在竞争条件（TOCTOU漏洞），导致区域端点DNS记录错误且未自动修复。AWS在三个可用区（AZ）运行独立的DNS执行器（Enactor），但其中一个执行器因极端延迟导致DNS计划过期，触发了连锁故障。由于DynamoDB和EC2是AWS的基础服务，故障迅速扩散至该区域70%的服务。作者分析了AWS的事后总结，指出大规模分布式系统的复杂性使得简单归因（如人才流失或DNS问题）过于片面，并强调了正确评估小概率事件的重要性。
