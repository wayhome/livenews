Telum II at Hot Chips 2024: Mainframe with a Unique Caching Strategy

作者: rbanffy | 评分: 101 | 评论数: 8 | 发布时间: 2025-05-19 10:27
文章摘要

IBM在Hot Chips 2024上推出了其最新的主机处理器Telum II，该处理器具有独特的缓存策略。Telum II拥有八个运行频率高达5.5 GHz的核心，并配备360 MB的片上缓存。它采用了虚拟L3和虚拟L4缓存策略，以解决传统L3缓存设计中数据重复和容量限制的问题。每个核心拥有一个36 MB的L2缓存，这些巨大的L2缓存通过“饱和度指标”在核心之间共享被逐出的缓存行，从而减少数据重复。此外，IBM通过将虚拟L3缓存行插入中间LRU位置来控制L2容量使用，确保核心缓存优先级。尽管这种设计增加了标签比较的复杂性，但由于L2缓存的低缺失率，这一开销被有效控制。Telum II还集成了DPU和板载AI加速器，采用三星5纳米工艺制造。

Kelp – simple replacement for homebrew on macOS

作者: amai | 评分: 65 | 评论数: 13 | 发布时间: 2025-05-19 14:55
文章摘要

Kelp 是一个用 Go 编写的简单工具，作为 Homebrew 的替代品，用于在 MacOS 上安装二进制包。它解决了 Homebrew 公式等待和多电脑同步更新问题，支持同时安装多个包（即将支持）。用户可以通过 releases 页面下载安装，配置文件位于 `~/.kelp/kelp.json`，默认安装路径为 `~/.kelp/bin`。Kelp 支持指定版本安装、手动升级、检查更新等功能。若包不在 GitHub releases 中，用户可直接提供 HTTP(S) 链接进行添加。当前 Kelp 主要为 MacOS 设计，Linux 支持尚未实现。如遇 GitHub API 限流，可设置 GitHub 令牌环境变量解决。项目以满足个人工作流为主，功能请求一般不被接受。

Diffusion Models Explained Simply

作者: onnnon | 评分: 90 | 评论数: 10 | 发布时间: 2025-05-19 13:06
文章摘要

Transformer-based large language models predict the next word in a sequence by training on large datasets, using tokens to represent language components. In contrast, diffusion models, which are crucial for image generation, work by gradually adding noise to images until they resemble pure noise. The model is trained to reverse this process, effectively "denoising" the image back to its original form. Unlike language models, diffusion models operate on entire images, using a compressed representation generated by a variational autoencoder (VAE) to handle the complexity. During training, the model learns to predict the noise added to images and improves through rewards based on prediction accuracy. A key technique, classifier-free guidance, ensures the model generates images aligned with provided captions. Although currently not as competitive as transformers in text generation, diffusion models hold potential for text applications and continue to drive AI advancements, particularly in image generation.
