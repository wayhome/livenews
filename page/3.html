Tilt: dev environment as code

作者: saikatsg | 评分: 86 | 评论数: 17 | 发布时间: 2025-04-26 19:14
文章摘要

Tilt 是一个开源工具，用于简化在 Kubernetes 上开发微服务应用的过程。它允许开发者通过代码定义开发环境，并自动化从代码更改到环境更新的所有步骤，包括文件监控、容器镜像构建等。Tilt 类似于运行 `docker build && kubectl apply` 或 `docker-compose up`。其主要功能包括一键安装、多语言支持（如 NodeJS、Python、Go 等）、详细的 API 参考以及社区贡献指南。Tilt 遵循 Apache-2.0 许可证，并重视安全问题报告。通过 Tilt，开发者可以更高效地管理和开发基于 Kubernetes 的微服务应用。

HTTP Feeds: a minimal specification for polling events over HTTP

作者: sea-gold | 评分: 42 | 评论数: 5 | 发布时间: 2025-04-26 17:12
文章摘要

HTTP Feeds 是一种通过普通HTTP API实现异步事件流和数据复制的方法。它定义了一个简单的规范，通过HTTP GET请求轮询事件流，使用CloudEvents格式和`application/cloudevents-batch+json`媒体类型返回按时间顺序排列的事件序列。通过`lastEventId`参数支持从特定事件开始获取后续事件，实现无限轮询以订阅实时 feeds。HTTP Feeds 允许系统在没有消息代理（如Kafka或RabbitMQ）的情况下进行异步解耦。 客户端通过不断发送带有`lastEventId`的请求来获取新事件。如果返回空数组，表示没有更多事件，客户端可等待一段时间后重试。此外，还支持长轮询，服务器在超时或有新事件时返回响应，从而降低延迟。事件的唯一标识`event.id`用于追踪处理进度，建议使用时间排序的UUIDv6或数据库序列来生成，以确保事件顺序一致性。当连接数超过10K时，服务器处理并发连接的成本可能成为问题。

评论摘要
主要讨论点：对基于游标的分页GET API的评价与替代方案的讨论 不同观点： • [wackget] 认为这种API设计仅仅是重新发明了已有的事物，没有创新，特别是常见的游标分页API已经能够实现类似功能。 • [hombre_fatal] 认为需要增加高层次的解释或动机说明，比如为何选择这种设计而不是使用传统的"afterId"参数进行排序的API。他强调了设计选择的背后需要有清晰的逻辑和灵感。 • [sea-gold] 提到这个话题在之前已经被讨论过（2022年4月），并提供了相关讨论链接（95条评论），暗示该话题并非新颖，且已有较多讨论。 • [lud_lite] 关注实际应用场景，提出了如果需要"追赶"（如丢失事件后重新获取），是否需要不断循环调用API，并质疑这种设计是用于社交媒体类型的feed流还是数据同步（如数据库复制）。他还提到了对事件生产者存储事件时长的期望问题。 • [fefe23] 强烈反对这种API设计，认为这是一个糟糕的想法，建议使用HTTP服务器发送事件（Server-sent Events, SSE）来替代，因为SSE可以保持连接开放，无需轮询即可实现实时更新，并能从之前看到的事件恢复。 补充讨论： • [lud_lite] 特别关注API在不同场景下的适用性，尤其是数据同步和事件存储策略。 • [fefe23] 提供了具体的替代方案（SSE）的文档链接，认为这是比重新设计分页API更合适的选择。 • 争议的焦点在于这种API设计的必要性和适用场景，部分评论者认为已有更好的技术方案（如SSE）可以实现相同甚至更好的效果。

Stuffed-Na(a)N: stuff your NaNs

作者: dgroshev | 评分: 82 | 评论数: 13 | 发布时间: 2025-04-26 14:04
文章摘要

"Stuffed-Na(a)N" 是一个 JavaScript 库，利用 NaN（Not-a-Number）的特性进行数据编码和传输。通过将数据编码为 NaN 数组，该库能够在数学运算中保留和传递数据，且由于 NaN 的特性，这些数据难以被简单复制和粘贴，从而提供一定的隐私保护。该库具有紧凑、快速和隐私优先的特点，并提供企业版以支持更多功能和更好的压缩效率。安装通过 npm 进行，也可以直接在浏览器中使用。此外，文章还介绍了 IEEE 754 浮点数表示以及 NaN 的内部表示形式，并通过幽默的方式解释了该技巧的实现和应用。

Robot Dexterity Still Seems Hard

作者: mhb | 评分: 51 | 评论数: 8 | 发布时间: 2025-04-26 17:53
文章摘要
