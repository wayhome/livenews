Of course the Apple Network Server can be hacked into running Doom

作者: classichasclass | 评分: 26 | 评论数: 2 | 发布时间: 2025-06-01 02:05
文章摘要

本文介绍了在价值超过1万美元的苹果服务器（运行IBM AIX系统）上运行《Doom》游戏的过程。尽管该服务器不能运行Linux或NetBSD，且与NCommander的AIX Doom不同，作者成功地将Doom移植到Apple Network Server（ANS）上，该服务器运行的是AIX 4.1.5。由于ANS的音频驱动不支持声音，因此该版本的Doom是静音的。AIX是一个从UNIX System V和BSD发展而来的操作系统，最初用于IBM RT PC，后来成为苹果网络服务器的主要操作系统。尽管AIX 4具有多媒体能力并曾移植过其他游戏，但并未包括Doom。作者使用Chocolate Doom和SDL 1.2完成了移植，并将在IBM PowerPC AIX笔记本上进行测试。最终的Doom版本无需额外系统前提，即可在CDE环境下运行。

文章摘要

本文介绍了1974年使用的钚动力心脏起搏器。这种起搏器采用含2至4居里钚-238的温差电池作为电源，利用钚衰变产生的热量发电，以刺激心脏保持规律跳动。美国目前仍有50至100人使用这种核动力起搏器。当患者去世后，起搏器需被取出并送至洛斯阿拉莫斯国家实验室回收钚。起搏器的电子元件嵌入环氧树脂中，外壳由钛制成，能抵御枪击和火化等极端情况。起搏器表面辐射剂量为每小时5至15毫雷姆，患者每年全身暴露量约为0.1雷姆，其配偶则为7.5毫雷姆。该设备由Cordis、Medtronic和Coratomic三家公司生产，直径约2.75英寸，由洛斯阿拉莫斯国家实验室捐赠。

评论摘要

文章摘要

AtomVM是Bogdan Erlang抽象机（BEAM）的轻量级实现，可执行从Erlang或Elixir源代码编译的字节码指令。它支持BEAM操作码和Erlang/OTP标准库的精简子集，专为微控制器优化，适用于物联网应用开发。AtomVM具备进程生成、监控、消息传递、抢占式调度和高效垃圾回收等高级功能，并能直接与微控制器的外围设备和协议（如GPIO、I2C、SPI、UART）交互，还支持ESP32等设备的WiFi网络功能。开发成本可低至2美元。相关文档、示例代码和教程正在完善中。
