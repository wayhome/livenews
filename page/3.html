Raspberry Pi 5 support (OpenBSD)

作者: brynet | 评分: 183 | 评论数: 8 | 发布时间: 2025-09-01 21:03
文章摘要

OpenBSD为arm64架构添加了Raspberry Pi 5 Model B的支持，包括RAMDISK安装方式。但目前存在三个已知问题：1) 无法从PCIe存储HAT启动（缺少U-Boot支持）；2) "d0"版树莓派5的WiFi无法使用；3) 主动散热风扇无法工作（缺少pwm/clock驱动，正在开发中）。该修改已获kettenis@和deraadt@批准。

评论摘要
主要讨论点：[Raspberry Pi 5的硬件支持情况，特别是U-boot、OpenBSD和Linux的支持现状以及WiFi失效的原因] 不同观点： • Raspberry Pi 5的U-boot支持缺失问题：用户[fartfeatures]质疑Raspberry Pi 5的U-boot支持为何比Raspberry Pi 4更难实现，暗示可能有独特的硬件挑战。 • Linux和BSD的支持现状：用户[qhwudbebd]询问Raspberry Pi 5和Compute Module 5是否有主流Linux支持，并提到过去IO功能不可用的问题，暗示对新硬件的支持延迟。 • OpenBSD对Raspberry Pi的支持：用户[colechristensen]和[drnick1]讨论了在Raspberry Pi上使用OpenBSD的动机和体验，引发了对OpenBSD与Linux选择的讨论。 • WiFi失效的硬件原因：用户[bootload]详细解释了Raspberry Pi 5的硬件修订（从BCC1到BCD0）导致WiFi功能失效，引用Eben Upton和Geoff Geerling的评论，指出这是成本削减措施的结果。 补充讨论： • 硬件修订的影响：用户[bootload]提到芯片步进（steppings）可能带来 unintended consequences，如WiFi功能的失效，这对开发者（如计划使用OpenBSD防火墙的用户）造成了实际影响。 • 散热器驱动问题：用户[snvzz]对OpenBSD无法控制Raspberry Pi 5的主动散热器（风扇）表示困惑，质疑操作系统的职责范围以及板上MCU的作用。 • 争议焦点：主要集中在Raspberry Pi 5硬件修订对功能的影响（如WiFi失效）以及操作系统对新硬件的支持责任（如散热器驱动）。
