Go: Support for Generic Methods

作者: f311a | 评分: 258 | 评论数: 16 | 发布时间: 2026-05-27 09:02
文章摘要

该提案建议 Go 支持“泛型具体方法”：允许方法像函数一样声明类型参数，但仅限具体类型的方法，不扩展到接口方法。原因是接口的动态实现机制难以高效支持泛型方法调用。提案认为方法不仅用于实现接口，也适合类型相关的代码组织与链式调用。核心改动是修改语法，使方法声明可带类型参数，目标版本为 Go 1.27。

评论摘要
主要讨论点：Go语言即将支持泛型方法（generic methods），社区对此反应不一 不同观点： • **支持派**：认为这填补了Go泛型的重要缺口，能让API设计更合理，避免使用奇怪的包级函数。多位开发者表示会重构现有库来使用这个特性 • **质疑实现派**：不理解为什么实现困难，认为可以通过运行时反射或类型转换实现，即使限制为指针类型也比没有好 • **批评Go设计哲学派**：认为Go团队总是先说不需要某功能，后来又慢慢添加，设计过于保守。有人将其比作"拔牙般痛苦"，批评这种渐进式设计不如一开始就做对 • **Rust倡导者**：以亲身经历对比，认为Rust的类型系统（Mutex、Option等）更优秀，能避免空指针和竞态条件，审查代码时只需关注逻辑 • **怀旧简洁派**：记得Go最初将"缺少泛型"作为简洁性的特点来宣传，对现在的方向转变感到有趣 补充讨论：有人讽刺这只是语法糖，也有人担心提案会像uint128那样被以各种理由拒绝。Go团队的辩护者指出这是"暂缓非永不"的策略，团队规模小需要渐进式开发。

Investigating how prompt politeness affects LLM accuracy (2025)

作者: KnuthIsGod | 评分: 83 | 评论数: 21 | 发布时间: 2026-05-26 07:43
文章摘要

这篇论文研究了提示语的礼貌程度如何影响大语言模型的准确性。研究者创建了50个涵盖数学、科学和历史的选择题，并将每题改写成五种语气版本（非常礼貌、礼貌、中性、粗鲁、非常粗鲁），共250个提示语。使用ChatGPT 4o测试后发现，与预期相反，粗鲁的提示语表现更好：非常礼貌提示的准确率为80.8%，而非常粗鲁提示达到84.8%。这一结果与早期研究不同，表明新一代LLM对语气变化的响应方式可能已经改变，凸显了研究提示语用学特征的重要性。

评论摘要
主要讨论点：一项研究发现粗鲁的提示词比礼貌提示词让GPT-4o表现更好（准确率84.8% vs 80.8%），引发对研究方法和结果普适性的讨论。 不同观点： • **质疑研究设计**：礼貌提示词设计不佳，像对待店员而非同事（如"Can you kindly consider"不自然）；粗鲁提示词也不像英语母语者所写；样本量仅250个问题偏小 • **统计显著性存疑**：4%的差异配合250样本量，统计显著性勉强达标，结果可靠性存疑 • **模型时效性问题**：GPT-4o已是旧模型（2024年），需要用2026年前沿模型重新测试；不同模型结果可能完全不同 • **短期vs长期效应**：研究仅测试单次回答，粗鲁提示可能短期有效但长期产生负面影响，类似人类反应模式 • **与其他研究矛盾**：该结果与大多数文献相反，其他研究多显示礼貌更有效 • **个人习惯派**：部分用户坚持礼貌用语，认为这是关于自己的习惯而非AI效果 补充讨论：有用户分享实际经验（过度礼貌导致AI生成错误测试）；也有人好奇粗鲁反馈是否会影响AI后续"人格"表现；还有讽刺评论质疑将此类AI用于自主软件工程的想法。

Biff is a command line datetime Swiss army knife

作者: burntsushi | 评分: 45 | 评论数: 7 | 发布时间: 2026-05-28 02:58
文章摘要

Biff是一个命令行工具，用于处理日期时间的算术运算、解析、格式化等操作。主要功能包括：打印当前时间、在不同时区间转换、添加或减去时间段、计算时间跨度、格式化时间戳、生成日期序列（如每月第二个星期二）、从日志文件中提取和转换时间戳等。支持多种时间格式（RFC3339、RFC9557等）、时区处理、时间舍入、相对时间表达式（如"next sat"、"1 week ago"）。该工具采用MIT或UNLICENSE双重许可，提供详细的用户指南和命令行帮助文档。

评论摘要
主要讨论点：关于命令行工具 Biff 的功能、历史和相关讨论 不同观点： • **Biff 的历史含义**：yzydserd 和 e40 指出 Biff 原本是 BSD/CSH 中用于通知邮件到达的工具，与当前讨论的新工具同名但功能完全不同 • **新 Biff 的功能定位**：burntsushi（作者）展示 Biff 是一个时间处理和数据标记工具，可以处理 Git 日志、时间转换、排序和格式化等复杂任务 • **技术实现亮点**：作者强调 Biff 通过 `biff tag exec` 实现并行处理来加速 Git 操作，并询问是否有更快的方法获取单个文件的最近提交时间 • **工具对比**：smartmic 提到已在使用 dateutils 进行时间处理，计划对比两者的易用性 补充讨论： ramon156 注意到作者同时开发了 jiff 库（时间处理库），推测 Biff 基于 jiff 构建。elcaro 的评论似乎在测试 Biff 的输出格式，发现了一个格式问题（"M05" 而非标准月份格式）。整体讨论围绕工具的实用性、性能优化和历史渊源展开。
