FatGid: FreeBSD 14.x kernel local privilege escalation

作者: WhyNotHugo | 评分: 73 | 评论数: 4 | 发布时间: 2026-05-21 12:15
文章摘要

这是一份关于 FreeBSD 14.x 内核本地提权漏洞（CVE-2026-45250）的技术报告。漏洞存在于 `setcred(2)` 系统调用中，由于 `sizeof` 类型错误导致内核栈缓冲区溢出。任何非特权本地用户都可在权限检查前触发该漏洞，实现从内核崩溃到完全提权的攻击。研究者开发了针对启用 SMAP/SMEP 保护的 amd64 GENERIC 内核的工作利用链（仅需加载 zfs.ko）。该漏洞在 2025 年 11 月已在主分支静默修复，但未回溯到稳定版本，FreeBSD 14.4-RELEASE 仍受影响。

评论摘要
主要讨论点：关于某个FreeBSD本地提权漏洞(LPE)的披露方式和影响范围的讨论 不同观点： • **批评过度营销**：认为本地提权漏洞不够严重，不值得专门建立网站和命名，质疑这种做法的必要性 • **质疑补丁状态**：指出漏洞页面声称未修补，但实际上官方昨天已发布14.4版本的修复通知，存在信息不一致 • **强调实际影响**：认为此漏洞影响重大，因为FreeBSD被广泛用于TrueNAS和大量网络设备，对运维人员来说是实际威胁 补充讨论：评论反映了安全社区对漏洞披露方式的不同态度——部分人认为过度包装，部分人关注技术细节准确性，还有人从实际部署角度评估风险。核心分歧在于如何平衡漏洞严重性评估与披露形式。

We Reverse-Engineered Docker Sandbox's Undocumented MicroVM API

作者: yakkomajuri | 评分: 50 | 评论数: 4 | 发布时间: 2026-05-21 14:50
文章摘要

Docker 悄然推出了基于 microVM 的 Sandbox API，用于安全运行 AI 编程代理的不受信任代码。与共享内核的容器不同，microVM 提供独立内核隔离，安全性更高。作者逆向工程了这个未公开的 API，发现可通过 `/vm` HTTP 端点创建和管理虚拟机，每个 VM 拥有独立的 Docker 守护进程。这为不受信任代码执行、AI 代理、多租户插件等场景提供了类似 Docker 容器的统一管理方式，但目前仅支持 macOS/Windows 且需要嵌套虚拟化。作者基于此构建了开源的 Sandbox Agent SDK。

评论摘要
主要讨论点：Docker Sandboxes 的技术实现、平台支持和安全隔离价值 不同观点： • **产品更新说明**（pploug）：文章信息已过时，Docker 已发布独立的 sbx 二进制文件（50MB），无需 Docker Desktop • **Linux 支持质疑**（whimblepop）：认为不支持 Linux 令人意外，指出 Podman 通过 libkrun 可在 Linux 上透明启动 microVM • **技术实现澄清**（nyrikki）：Docker 在 Linux 上完全支持 KVM 虚拟化，只是默认不启用（因性能和资源开销）。本质上是在独立 VM 实例中运行容器，而非共享 VM。推荐尝试 Podman，因其允许 SSH 进入虚拟机查看底层实现 • **安全价值质疑**（andix）：质疑 VM 级隔离对 AI Agent 场景的实际意义。认为即使容器被突破，Agent 通常拥有大量权限（如访问令牌、安装软件包），可通过其他方式造成危害，VM 隔离未必解决核心问题 补充讨论：争议焦点在于技术实现的跨平台一致性，以及在 AI Agent 场景下，VM 级隔离相比容器隔离是否真正提升了安全性。

What Do Gödel's Incompleteness Theorems Mean?

作者: baruchel | 评分: 116 | 评论数: 14 | 发布时间: 2026-05-18 17:59
文章摘要

这篇文章探讨哥德尔不完备性定理的真正含义。1931年，25岁的哥德尔证明了任何数学形式系统都无法完备——总会存在真实但无法从公理推导出的数学陈述，这排除了数学"万有理论"的可能性。文章采访了多位逻辑学家、数学家和哲学家，讨论该定理的深远影响：它表明数学真理的复杂性超越任何有限公理集，某些数学问题原则上无法用现有方法解决，需要创造性的概念创新。这模糊了客观真理与人为构建数学之间的界限，使"真理"在某种程度上取决于我们选择的公理假设。

评论摘要
主要讨论点：哥德尔不完备性定理的意义、影响及可理解性 不同观点： • **完备性定理更重要派**（alan-crowe）：认为哥德尔完备性定理才是真正的奇迹——每个有效陈述都有证明。不完备性定理反而不令人惊讶，因为非标准算术模型本就怪异且边缘。真正的挑战在于如何给搜索赋予"方向感"来找到证明。 • **影响被夸大派**（seanhunter）：认为人们过分夸大了不完备性定理的影响。形式化数学项目并未因此终结，反而随着定理证明器的进步更加活跃。绝大多数陈述仍是可判定的，不可判定陈述（如连续统假设）只具有"小众"意义。 • **软件视角派**（svantana）：作为软件开发者，认为停机问题是最易理解且最有趣的不完备性定理形式，提出是否所有哥德尔定理都能用"软件形式"表述。 • **哲学意义派**（watershawl, hybrid_study）：认为定理暗示宇宙运作的基本规律，总存在"相邻可能"；或意味着人类大脑目前尚未具备理解宇宙的能力。 补充讨论： - bo1024提供了公理、模型、定理的清晰解释框架 - 多人推荐Nagel和Newman的《哥德尔证明》作为入门读物 - MrDrDr指出定理有"足够复杂"的前提条件，Presburger算术就是完备的 - marojejian提到哥德尔本人认为可通过无限逻辑系统序列解决问题

美国国会议员计划提出修正案，禁止联邦公路资金接受者将自动车牌识别系统（ALPR）用于收费以外的任何目的。该修正案由共和党议员Perry和民主党议员García共同发起，若通过将迫使全美各州和地方政府移除ALPR摄像头或仅限于收费用途。ALPR技术因隐私侵犯问题备受争议——摄像头记录所有过往车牌并建立可跨机构搜索的数据库。伊利诺伊州发现Flock公司违法向联邦机构提供数据，德州警察曾用该系统追踪堕胎女性。隐私倡导者警告这构成无证监控系统，但警方认为该技术对破案至关重要。

评论摘要
主要讨论点：关于禁止自动车牌识别系统(ALPR)的两党提案的争议 不同观点： • **支持禁令派**：认为ALPR是大规模监控，侵犯隐私和自由，应该彻底禁止或严格限制。担心数据被滥用、商业化，或用于寻找"可疑行为模式" • **反对禁令派**：认为提案过于极端，会连带禁止有效的交通执法工具（如超速摄像头、闯红灯摄像头）。纽约数据显示测速摄像头使超速减少94%，是重要的安全工具 • **温和限制派**：认为ALPR有合理用途（收费、超速、停车执法、追踪被盗车辆），但需要严格规范：限制数据保留时间（如90天）、禁止商业用途、查询需司法授权、不得跨部门随意共享 • **怀疑提案动机派**：质疑这是"表演性修正案"，由即将退休的民主党议员和边缘共和党议员提出，两人选区和州政府都反对。认为联邦政府是为保护自己的监控权力，防止地方过度使用引发立法限制 补充讨论：有人指出技术规避问题——汽车制造商可能通过车载摄像头收集车牌数据，使禁令失效。也有人认为需要国际层面的信息权利法案来根本解决问题。
