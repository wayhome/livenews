The recently lost file upload feature in the Nextcloud app for Android

作者: morsch | 评分: 335 | 评论数: 18 | 发布时间: 2025-05-14 05:38
文章摘要

Nextcloud团队解释了Android版Nextcloud应用中文件上传功能的问题。自2024年中期以来，Google撤销了一项关键权限，导致用户无法上传所有类型文件，只能上传照片和视频。尽管Nextcloud自2016年推出以来一直拥有该功能，且未收到安全问题的反馈，但Google仍拒绝恢复权限。这导致数百万用户受影响，只能上传媒体文件，无法上传其他文件。Nextcloud认为这是Google利用其平台所有者地位打压竞争对手的行为，类似于过去微软通过限制功能打压WordPerfect的做法。团队对用户 frustration 表示理解，但目前无法解决此问题。不过，在F-Droid等替代应用商店中，用户仍可使用无限制的版本。

评论摘要
主要讨论点：Google 是否通过限制 API 和权限，对独立开发者及应用（如 Nextcloud）实施不公平待遇，从而保护其自身和大科技公司的利益。 不同观点： • AmazingTurtle 认为，Google 打着“最小权限”的旗号，实际上是在为大科技公司的第一方应用提供特权。独立开发者被迫推出半成品的产品，或者面临被 Play 商店下架的风险。这导致用户失去功能和选择，而小开发者则浪费大量时间与政策机器人争论。 • moonshot5 则认为，Google Drive 并没有提供 Nextcloud 所说的特权待遇，Play 商店中的应用都受到相同的权限限制。他还指出，过去 MANAGE_EXTERNAL_STORAGE 权限曾被滥用，因此这些限制是有一定理由的。 • jeroenhd 指出，SAF（存储访问框架）是可以使用的，虽然有一些限制，但 Nextcloud 的声明并不完全合理。 • scottbez1 提供了历史背景，指出 Google 曾经设计过仅供自家应用使用的 API，并举例说明 Google 如何通过锁定 API 来为自己的应用提供优势，这种行为接近于反竞争。 • dzikimarian 表达了对数据访问受限的强烈不满，特别是无法访问 /sdcard/android/data 目录以及其他文件管理限制，认为这与 iOS 的封闭性类似。 • inigoalonso 将问题上升到法律和垄断层面，认为 Google 的行为违反了欧盟的《数字市场法》，属于滥用平台权力的行为，呼吁加强监管以确保公平竞争。 补充讨论： • thombles 和 jeppester 提到，由于 Google 的限制，SyncThing 等应用已经无法在 Play 商店分发，建议引入类似 DMCA 的法律来防止这种行为。 • aborsy 和 BLenkomo 则认为，用户应有权决定是否授予应用全文件访问权限，而不是由 Google 强制限制。 • igtztorrero 回顾了 Google 过去的企业格言“不作恶”，认为自该格言被移除后，Google 逐渐变得像微软一样，开始采取不透明的商业行为。 • 最后，yard2010 用较为情绪化的方式表达了对 Google 政策变化的不满，认为原本 mediocre的中庸状态也被破坏了。 争议焦点：Google 是否通过 API 和权限限制实施垄断和不公平竞争，损害了独立开发者和用户的利益。这些限制究竟是为了安全考量还是为了维护自身利益，成为各方争论的核心。

文章摘要

研究团队开发了一种高分辨率的远程成像系统，利用多束激光照射远距离目标，并通过两台望远镜收集反射光。该系统基于强度干涉测量技术，能够在一公里以上的距离成像毫米级的文字，分辨率较单台望远镜提升了14倍。与常见的振幅干涉测量不同，强度干涉测量通过比较两个探测器接收光强波动的相关性来获取空间信息。为了克服激光相干性带来的噪声问题，研究人员将100毫瓦的激光分成八束，每束光经过不同大气路径，获得不同的随机相位扰动，从而实现可观测的干涉效果。实验中，团队成功重建了1.36公里外目标上的字母图像。这项技术有望应用于大气湍流下的光学成像和生物医学成像等领域。
