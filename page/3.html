Show HN: Timep – a next-gen profiler and flamegraph-generator for bash code

作者: jkool702 | 评分: 11 | 评论数: 0 | 发布时间: 2025-07-15 06:44
文章摘要

`timep`是一个高效的基于trap的Bash代码分析工具，能够生成每个命令的执行时间，并构建完整的调用栈树，还能选择生成FlameGraph。它记录命令运行时间和元数据，根据函数和子壳层的嵌套深度进行分层。通过`--flame`参数，`timep`可自动生成FlameGraph SVG图像，展示Bash命令及其运行时间，不同层次代表函数和子壳层的嵌套深度。使用方法为在要分析的函数或脚本前加上`timep`命令，输出包括时间分析文件和栈追踪文件，若使用`--flame`，还会生成FlameGraph图像。总运行时间是主进程及其所有子进程的墙钟时间之和。多个可选标志可调整`timep`的行为，如指定输入类型、保留中间文件等。

文章摘要

《GPUHammer: 对 GPU 内存的 Rowhammer 攻击是可行的》一文介绍了首个在 GPU 内存上实现 Rowhammer 位翻转攻击的研究。该攻击在 NVIDIA A6000 GPU 的 GDDR6 内存上成功实施，绕过了如 TRR 等内存内防御机制，利用用户级的 CUDA 代码在所有测试的 DRAM 库中诱发了位翻转。攻击者可借此在共享的、时间分片的 GPU 环境中篡改其他用户的数据。在一项概念验证中，研究人员通过单个位翻转将深度神经网络模型的准确率从 80% 降至 0.1%。虽然启用错误校正码（ECC）可以缓解此风险，但会对 GPU 的机器学习推理任务造成最高 10% 的性能下降。 研究通过逆向工程 GPU 的 DRAM 地址映射，克服了 GDDR 内存的高延迟、未知映射和不透明防御机制等挑战，成功实现了多线程、多线程束的高强度锤击攻击，并通过与内存刷新的同步绕过了内存防御。
