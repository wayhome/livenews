Show HN: A local secrets manager with easy backup

文章摘要

**yacs** 是一个命令行工具，用于在本地安全地存储、管理和检索加密凭据。它通过AES加密和一个主密码来保护数据，确保凭据安全。主要功能包括： 1. **初始化**：设置新的凭据存储，包含主密码和提示。 2. **添加凭据**：支持添加字符串和二进制类型的凭据，并附带描述。 3. **检索凭据**：通过键名检索特定凭据。 4. **查看键和描述**：列出所有键及其描述。 5. **重置**：删除凭据存储并重新开始。 该工具使用PBKDF2从主密码生成加密密钥，并结合随机生成的IV来确保每次加密都是独特且安全的。安装通过 `pip install yacs-cli` 完成，支持基本操作如初始化、添加、检索和重置凭据。项目基于MIT许可证。

评论摘要
主要讨论点：工具是否使用AEAD（经过认证的加密算法）以及数据存储格式选择。 不同观点： • 观点一：认为工具不是AEAD，没有使用价值。 - 论据：评论者CBLT指出，该工具似乎不使用AEAD（经过认证的加密算法），并表示没有理由使用非AEAD工具。 - 例子：虽然没有具体举例，但隐含的意思是AEAD更安全，因此优先选择具备AEAD的工具。 • 观点二：对将所有数据存储在巨大JSON中的方式不认同。 - 论据：评论者认为将所有数据存储在一个巨大的JSON文件中并不是最理想的简单存储方式。 - 例子：评论者个人更倾向于使用SQLite或其他可以方便使用rsync同步的格式，表明这些格式在实际操作中更具灵活性和实用性。 补充讨论： • 争议焦点：工具是否使用AEAD以及其使用价值。评论者明确表示如果工具不支持AEAD，则没有使用的理由，显示出对加密安全性的高度重视。 • 存储格式的偏好：评论者对JSON存储格式提出质疑，并提出了SQLite或其他支持rsync的格式作为替代选项，表明在数据存储格式选择上存在不同的实际需求和偏好。 总结：讨论围绕工具是否具备AEAD特性和数据存储格式的选择展开，一方关注安全性，另一方关注存储格式的实用性和可操作性。

文章摘要

这篇文章研究了咒骂作为对疼痛的反应是否能减轻痛感，特别关注情感激发和分心作为潜在机制。实验比较了传统咒骂词“fuck”和两个新造的类咒骂词“fouch”和“twizpipe”的效果。参与者（N=92）在进行冷压疼痛测试时重复说这些词。结果显示，传统咒骂词“fuck”显著提高了疼痛阈值和耐痛能力，且情感、幽默和分心评分增加。然而，新造词“fouch”和“twizpipe”尽管在情感和幽默评分上高于中性词，但对疼痛阈值或耐痛能力无影响。研究还发现分心并非关键机制，而情感激发值得进一步研究。

文章摘要

HackerNewt是一款第三方Hacker News客户端，通过独特的评论树展示方式，解决传统界面评论过窄和层级不清的问题。其优点包括：评论宽度保持不变、始终显示当前评论的父评论、通过滑动控制子树浏览，以及轻松跳过不感兴趣的子树。此外，应用还提供自定义板块、搜索、阅读列表等功能，提升阅读体验。不过，部分用户反馈应用曾出现加载问题，但开发者迅速修复。该应用不隶属于Hacker News官网，隐私保护良好，免费下载但包含内购。
