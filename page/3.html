黑幕诗歌（Blackout Poetry）是一种创造性诗歌形式，通过在已有文本上涂黑（遮盖）不想要的词语，留下来的词组成新的诗句。通常使用旧报纸或书籍页面作为基础，读者根据个人创意和理解选择保留的词语，形成独特的诗歌作品。这种艺术形式不仅鼓励重新审视和再利用现有文字，还提供了一种简便而有趣的创作方式，适合各个年龄层和技能水平的文学爱好者。通过黑幕诗歌，人们可以探索语言的美感，并发掘隐藏在普通文本中的诗意。

Any program can be a GitHub Actions shell

作者: woodruffw | 评分: 222 | 评论数: 20 | 发布时间: 2025-04-08 01:20
文章摘要

在GitHub Actions中，可以使用`shell`关键字指定运行`run`代码块的shell类型。虽然对于工作流而言，该关键字是可选的，但对于动作定义则是必须的。默认情况下，GitHub会根据运行环境选择合适的shell，如Linux和macOS使用bash，Windows使用pwsh。不过，用户也可以自行指定shell，并且GitHub会为某些shell自动添加特定标志，例如`bash --noprofile --norc -eo pipefail`。 值得注意的是，用户可以将`shell`设置为任何在`$PATH`中的可执行文件，而不仅限于GitHub预定义的shell类型。这允许一些非传统用法，例如使用C语言或动态修改`$PATH`。从安全角度看，这种灵活性可能带来潜在风险，因为文件写入操作可能导致意外的代码执行。 总体而言，GitHub Actions的shell执行机制比预期的更为灵活，但也因此可能引入一些安全隐患。

Intelligence Evolved at Least Twice in Vertebrate Animals

作者: rbanffy | 评分: 154 | 评论数: 20 | 发布时间: 2025-04-08 08:36
文章摘要

文章探讨了脊椎动物智力演化的问题，特别关注鸟类和哺乳动物的智力是否源自共同祖先或独立演化而来。研究表明，尽管鸟类和哺乳动物的大脑结构不同，鸟类仍展现出高度认知能力，如计划未来、使用工具等。2025年2月发表在《科学》上的一系列研究提供了证据，表明鸟类和哺乳动物的复杂神经回路并非继承自共同祖先，而是独立演化而来。这意味着脊椎动物的智力可能多次演化，但其神经复杂性却表现出惊人的相似性。该研究为了解智力演化提供了重要见解，并挑战了人类智力的优越性观念。

Neural Graffiti – Liquid Memory Layer for LLMs

作者: vessenes | 评分: 56 | 评论数: 6 | 发布时间: 2025-04-08 04:24
文章摘要

"Neural Graffiti" 是通过在 transformer 模型推理的最后阶段注入记忆痕迹来实时改变预训练大型语言模型（LLM）行为的一种实验性技术。该技术使用名为 "Spray Layer" 的插件层，灵感来源于神经可塑性和涂鸦艺术，无需微调或重新训练模型。Spray Layer 会缓慢演化，基于过去的上下文引入细微的行为变化，影响模型如何关联词汇和概念，从而改变其输出和“思维”方式。虽然无法精确控制生成特定词汇，但可以引导模型倾向于某些概念，并能跟踪其影响程度。该技术旨在赋予AI模型更多主动行为和个性，但会使模型变得像拥有独特精神世界的“实体”，可能不适合商业部署。

评论摘要
主要讨论点：对基于控制向量的方法的有效性及其在深度学习模型中的应用的评价和争议 不同观点： • [cgadski] 认为该方法通过在最后隐藏层添加控制向量来引导模型输出的思路存在问题。具体来说，线性映射W被随机初始化，导致方法无效。此外，干预仅发生在最后隐藏层，无法真正改变模型的“思考”方式。该评论还批评了当前深度学习领域中存在的不真诚和无意义的语言包装现象。 • [enoch2090] 提到在实际操作中遇到的问题，包括聊天上下文的不确定性以及模型无法记住概念的现象。即使多次告知模型自己喜欢猫，模型在回答最喜欢的动物时仍给出与之前输入无关的答案。 • [qeternity] 批评行业内每六个月就重新发明概念的现象，认为该方法只是对控制向量的重新发明，缺乏新意。 • [profchemai] 认为该方法可能有潜力，但在缺乏证据（如基准测试和比较）的情况下，它只是一个花哨的名称和图形，类似于通过门控机制对先前向量进行上下文化。 • [r00t-] 以讽刺的语气称该方法为“毫无实质内容”，只是用 buzzword 和漂亮的图形包装。 • [nurettin] 提出一个伦理问题，询问是否可以通过 affectionate 的方式谈论犯罪和罪犯来激进化模型。 补充讨论： • 该方法被批评为缺乏创新，且在实际应用中效果不佳，特别是在记忆和上下文理解方面。 • 讨论中涉及对深度学习领域中语言使用和概念包装的批评，以及对新方法实际效果的怀疑。 • 一个值得注意的伦理问题被提出，即模型是否可能被激进化，这涉及到人工智能安全和伦理的更广泛讨论。

Deleting multiplayer from the Unreal engine can save memory

作者: mariuz | 评分: 147 | 评论数: 11 | 发布时间: 2025-04-06 10:23
文章摘要

这篇文章讨论了在Unreal引擎中移除多人游戏相关功能以节省内存的可行性。尽管Unreal引擎的多人游戏功能集成良好，便于开发，但对于单人游戏项目，这些功能会占用不必要的内存。文章详细分析了即使在单人游戏中，某些变量（如与网络复制相关的数据）仍会占用内存空间，如"bReplicates"变量和一些自定义结构体，分别占用了120和216字节。通过手动移除这些变量，作者成功将每个actor的内存占用减少了328字节。不过，这种优化不易实现，因为Unreal的头文件工具（UHT）不支持通过预处理宏动态排除这些变量。最终，作者通过手动注释相关代码完成了优化，但建议在生产环境中谨慎操作。

评论摘要
