Plain – a web framework for building products with Python

作者: brylie | 评分: 106 | 评论数: 21 | 发布时间: 2025-03-29 03:55
文章摘要

Plain 是一个基于 Python 的 web 框架，是 Django 的分支，旨在引入新想法并保留成熟的模式。它支持通过单个命令进行本地开发，并提供多种包以满足不同需求，如构建产品、身份验证、后台管理、开发工具和前端集成等。Plain 被设计用于创建新业务、内部工具或个人项目，其主要包包括： 1. **基础包**：如 URL、视图、模板、表单等核心功能。 2. **认证包**：包括用户认证、OAuth 支持、无密码登录等。 3. **管理包**：自定义管理后台、功能标志、客户支持等。 4. **开发包**：提供本地开发环境、测试、代码格式化等工具。 5. **前端包**：集成现代 CSS、JavaScript 工具，支持文件路由和资源自托管。 Plain 通过模块化设计，使主要功能可选并能独立演进。

评论摘要

The Wrong Way to Use a Signed Distance Function (SDF)

作者: AnthonBerg | 评分: 6 | 评论数: 0 | 发布时间: 2025-03-29 18:10
文章摘要

文章简要介绍了使用有向距离函数（signed distance functions, SDFs）进行粒子与几何体碰撞检测的方法。通常，SDF用于光线追踪和着色器中以定义无网格几何体，但文章探讨了一种“非传统”用法：生成点云几何体。通过计算粒子与球体中心的距离，判断粒子是否与球体相撞。若距离小于球体半径，则粒子在球体内，否则在外部或表面。文章还提到，通过重新定义距离函数，可以扩展至检测与多个几何体（如盒子、环面等）的碰撞。SDF的优势在于其可替换性和组合性，使得碰撞检测更加直观和灵活。

文章摘要

文章主要介绍了1855年由Daniel McCallum设计、George Holt Henshaw绘制的纽约和伊利铁路组织结构图的历史和设计背景。该图旨在提高铁路系统的责任制、运营效率和沟通，但由于McCallum的严格管理导致员工不满，最终引发财务困难和美国铁路工程师首次罢工，他被迫辞职。尽管如此，这张图以其精美的设计和独特的树状结构引人关注，树枝代表运营部门，叶子则代表基层员工。该图在很长一段时间内鲜为人知，直到2005年研究者Charles Wrege和Guideon Sorbo Jr.对其进行详细研究，并推测其设计灵感可能来源于当地常见的植物Salix caprea（山柳），其形态与图中的树枝和叶子结构相似。文章还提到历史学家Alfred Chandler Jr.对该图的描述和分析。

Body Doubling

作者: tosh | 评分: 31 | 评论数: 2 | 发布时间: 2025-03-29 18:48
文章摘要

**身体双人法**（Body Doubling）是一种通过与另一人共同 presence 来帮助完成任务的策略，常用于家务、写作或计算机工作等任务。该方法可以通过物理 presence、电话、视频或社交媒体实现，旨在通过共享目标提高任务完成率。对一些人是共同做类似任务效果最佳，而对另一些人只需在同一空间即可。此方法尤其受到注意力缺陷多动障碍（ADHD）患者的欢迎，用于管理症状和减少分心。虽然长期研究不足，但专家认为该策略通过“外部化动机”帮助ADHD患者提高专注力和生产力。身体双人仅作为支持系统，不参与任务，主要通过减少干扰帮助患者保持专注。该方法也被视为传统ADHD治疗（如药物）的替代或补充方案。

评论摘要
主要讨论点：在工作环境中使用共同工作（如在电话中一起工作）的方式是否有效及其实际应用 不同观点： • [支持观点] **eraviloi** 认为共同工作的方式非常有效，尤其是在需要推动任务完成和解决复杂问题时。他指出，这种方式虽然会花费数小时，但能有效避免员工因各种借口不完成工作。对于复杂任务，两个人一起工作（“两个头脑胜过一个”）能提高效率和质量。 • [质疑观点] **TZubiri** 则对共同工作的方式持质疑态度，认为这种方式类似于在传统办公室工作，可能并不适用于所有工作环境。他的评论带有一些讽刺意味，暗示这种方法可能只是让员工在形式上更“高效”，但未必真正提高生产力。 补充讨论： • **eraviloi** 强调了共同工作在不同任务类型中的效果差异，简单任务可能只需要提供动力，而复杂任务则能从协作中获益。 • **TZubiri** 的评论指出，共同工作可能只是形式上的公司化管理方式，暗示这种方式未必能真正提升工作效率。 争议焦点：共同工作的方式是否真正有效，尤其是在不同任务复杂度和工作环境下的适用性。
