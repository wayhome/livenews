High strength bio-concrete for the production of building components

作者: PaulHoule | 评分: 9 | 评论数: 0 | 发布时间: 2025-05-23 12:40
文章摘要

本文介绍了一种基于微生物诱导碳酸钙沉淀（MICP）的高强度生物混凝土，作为传统波特兰水泥混凝土的潜在替代品。生物混凝土在生物矿化过程中不产生二氧化碳排放，且能以碳酸盐形式固碳，具有CO2中和潜力。然而，实现与传统混凝土相当的抗压强度和足够的组件深度一直是挑战。研究通过使用尿素酶活性碳酸钙粉末（UACP）、优化骨料密实度、以及自动停止流压注射方法，测试了多种水泥化参数，最终达到52.5 MPa的抗压强度和140 mm的 cementation深度，这在以往研究中未见报道。研究结果显示，均匀密实和足够的骨料密实度是获得高质量水泥化的关键，这为生物混凝土用于预制承重建筑组件开辟了新可能性。

Yes-rs: A fast, memory-safe rewrite of the classic Unix yes command

作者: ericdiao | 评分: 124 | 评论数: 18 | 发布时间: 2025-05-27 01:20
文章摘要

"yes-rs" 是一个用 Rust 重写的 Unix 经典命令 `yes`，具有更高的内存安全性和性能。原版的 `yes` 命令用 C 编写，存在内存安全问题和性能局限。而 "yes-rs" 具有以下特点：内存安全、速度极快、支持零成本抽象、可实现无畏并发，并完全使用 Rust 编写，易于通过 Cargo 安装和管理。用户可以通过 `cargo install yes-rs` 安装，并用其输出 "y" 或其他自定义字符串。该项目旨在展示 Rust 在系统编程中的优势。

TIL: timeout in Bash scripts

作者: lr0 | 评分: 184 | 评论数: 22 | 发布时间: 2025-05-26 11:34
文章摘要

文章讲述了在使用Bash脚本设置web服务器时，遇到了一个无限循环的问题。最初使用`until`命令检查服务器状态，但如果服务器崩溃，脚本会无限等待。为解决此问题，作者尝试使用`timeout`命令给检查过程添加超时功能，但由于`until`是shell关键字，无法直接对它使用`timeout`。最终解决方案是将`until`包裹在一个Bash子进程中执行，或者将`until`逻辑移到一个单独的脚本文件，再对该脚本使用`timeout`。这种方法有效解决了无限等待的问题。

文章摘要

Hacker News（HN）最初使用Paul Graham创建的Arc语言编写，基于Racket实现。但为了提升性能，HN现已转向使用SBCL（Steel Bank Common Lisp）。这一变化使得HN能够更高效地运行，尤其是在多核环境下。过去，长讨论线程需要分页加载评论，而现在不再需要。技术上，通过开发Arc到JS的Lilt和Arc到Common Lisp的Clarc工具，实现了Arc的分阶段构建，从而简化了重新实现过程。尽管HN的许多反滥用措施代码未公开，但系统成功完成了向Common Lisp的平稳过渡。这一变化标志着HN在技术架构上的重大升级。
