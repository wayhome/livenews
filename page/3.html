文章摘要

LM Studio 0.3.17 引入了对 Model Context Protocol (MCP) 的支持，允许用户将本地和远程MCP服务器连接到应用，并通过 `mcp.json` 文件或新的“Add to LM Studio”按钮添加MCP服务器。新版本增加了11种新语言支持，总数达到33种，并修复了多个漏洞，改进了UI，新增了'Solarized Dark'主题。用户可以通过应用内更新或官网下载升级。MCP服务器提供工具和资源访问，需谨慎安装不可信来源的服务器。应用会在模型调用工具时显示确认对话框，用户可以管理工具权限。MCP服务器配置文件 `mcp.json` 位于系统特定路径，建议使用应用内编辑器修改。新功能还包括聊天外观设置、显示生成统计、支持固定下载面板等。开发者可以创建“Add to LM Studio”按钮简化MCP服务器添加。

Howdy – Windows Hello style facial authentication for Linux

作者: LorenDB | 评分: 35 | 评论数: 6 | 发布时间: 2025-06-23 18:34
文章摘要

Howdy 是一个为 Linux 提供类似 Windows Hello™ 面部认证功能的软件。它利用内置的红外发射器和摄像头进行面部识别，通过 PAM 系统实现登录、锁屏、sudo 等场景下的密码替代。Howdy 支持 Debian/Ubuntu、Arch Linux、Fedora 和 openSUSE 等发行版，安装方式各有不同，部分需要额外配置。它依赖于 Python 3.6+、meson、ninja 等工具构建，并可通过命令行管理面部模型。安装后需运行 `sudo howdy add` 进行面部录入。如遇问题，可通过查看 Wiki 或 GitHub 上的类似问题进行排查。用户还可以通过贡献代码或提交功能请求参与项目。

评论摘要
主要讨论点：开源人脸识别认证项目的质量、功能、安全性及技术实现与商业版本的对比 不同观点： • **[bsimpson]** 认为该开源项目与商业版本（如智能手机上的面部识别）相比，可能会有更多的误报和漏报，因为商业版本需要支持所有人使用，经过了广泛测试。 • **[joelthelion]** 表示更希望看到对指纹识别器的良好支持，而不是面部识别。 • **[fsateler]** 指出该项目虽然活跃，但最新版本发布于2020年，质疑为何没有新版本发布。 • **[aitchnyu]** 分享了使用体验，认为界面应提示正在处理面部信息，并在失败时提供重试按钮。此外，担心该模型可能被红外照片欺骗，但也对红外摄像头实验表示了兴趣。 • **[charcircuit]** 强调该项目与"Windows Hello"不同，仅从2D图像提取特征，容易被纸张等简单物品欺骗。此外，批评该项目仅处理用户认证，无法像Windows Hello那样用于磁盘加密和通行密钥，且面部特征以明文保存，存在安全隐患。 • **[deafpolygon]** 质疑项目为何依赖于Python2，暗示技术选择可能过时。 补充讨论： • 项目的安全性是讨论焦点之一，特别是面部识别的可靠性和数据保存方式。 • 项目与商业产品的功能对比，如Windows Hello的多功能性，也是讨论的一个重要方面。 • 技术实现的细节（如2D图像 vs 深度重建）和技术依赖（如Python2）引发了对项目实用性和未来发展的关注。

文章摘要

Iroh 是一个基于公钥拨号的 API，能够自动寻找并维持最快网络连接，支持打洞技术以实现直接连接，失败时可回退到公共中继服务器。它使用 QUIC 协议，提供认证加密、并发流、数据报传输等功能，避免线头阻塞。Iroh 提供了多个预定义协议，如 iroh-blobs 用于内容寻址的大规模数据传输，iroh-gossip 用于建立发布-订阅网络。此外，Iroh 还支持 Rust 以外的其他语言通过 FFI 绑定使用。项目包含多个子模块，如核心库 iroh、中继服务器实现 iroh-relay 等，并采用 Apache-2.0 和 MIT 双重许可。
