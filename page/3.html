Hexatetrahedral Rails

作者: julik | 评分: 17 | 评论数: 5 | 发布时间: 2025-07-27 12:56
文章摘要

文章讨论了软件开发中的六边形架构（Hexagonal Architecture）在Rails应用中的实践及其面临的挑战。作者指出，约十年前受领域驱动设计（DDD）和Alastair Cockburn的六边形架构启发，许多Rails项目采用了这种架构风格，但如今这些项目在升级和维护时遇到了复杂性问题。作者戏称这些项目为“hexatetrahedral Rails applications”，因为它们常常引入了超出预期好处的复杂性，甚至变成了不必要的“ complicationments”。 六边形架构的初衷是通过模块化和小接口组合实现解耦，但在Rails中实施时，往往导致不必要的间接层和维护负担。作者质疑这种解耦的必要性，尤其当应用的主要交付方式是Web时。除非应用需要嵌入到其他程序中，否则过度解耦可能弊大于利。作者建议从过去的实践中提取有价值的经验，而非盲目追随时尚。

Making Libcurl Work in WebAssembly

作者: tambourine_man | 评分: 34 | 评论数: 2 | 发布时间: 2025-07-30 13:09
文章摘要

本文介绍了如何在不修改代码的情况下，使基于libcurl的应用程序在WebAssembly中通过WebSocket代理实现网络通信。由于WebAssembly无法直接进行TCP连接，因此通过在服务器端运行websockify代理，将TCP连接封装成WebSocket连接，从而使libcurl可以正常工作。 关键步骤包括： 1. 使用WebSocket代理服务器（websockify）处理TCP连接。 2. 解决浏览器混合内容安全策略问题，建议使用wss://（安全WebSocket）而非ws://。 3. 通过设置SOCKS5代理服务器，使libcurl能够连接到任意HTTP服务。 具体实现可参考GitHub上的示例项目（https://github.com/r-wasm/ws-proxy）。这样，无需对现有代码进行大幅修改，即可使libcurl在WebAssembly环境中正常运行。

评论摘要
主要讨论点：libcurl在WebAssembly环境下的使用及其具体工作机制 不同观点： • [kamranjon] 对文件下载后的去向存在疑问，不确定文件是被存储在浏览器的内存中、通过WebSockets传送到后端服务，还是利用新的文件系统API写入本地磁盘。这反映出对libcurl在浏览器中使用时具体数据流向的不确定性。 • [immibis] 认为在浏览器环境中运行时，不需要libcurl，可以直接使用浏览器本身的功能。他指出只有当运行第三方代码且该代码设计上并未考虑在浏览器中运行时，才需要使用libcurl。 补充讨论： • [kamranjon] 的疑问揭示了在WebAssembly和浏览器环境下使用传统库（如libcurl）可能带来的困惑，尤其是关于文件处理和数据流向的问题。 • [immibis] 强调了浏览器环境与传统后端环境的不同，指出第三方代码使用libcurl的原因可能是其未针对浏览器环境进行设计和优化。 • 争议的焦点在于是否需要在浏览器环境中使用libcurl。kamranjon对具体实现机制不明确，而immibis则认为通常不需要libcurl，除非处理非浏览器原生设计的代码。 这个讨论反映了在现代浏览器环境中使用传统库的复杂性以及潜在的实现细节问题。

文章摘要

CLJ-COLL 是一个在 Common Lisp 环境中实现 Clojure 集合和序列 API 的库。它提供了类似 Clojure 的不可变数据结构，如 Cons、Queue、PersistentList、Vector、Set 和 Map，并通过 Clojure 的 API 访问。该库旨在让 Clojure 程序员更容易使用 Common Lisp，但不包含完整的 Clojure 语言特性，如 `def`、`defn`、`fn` 和 Clojure 样式解构。它支持 DOSEQ 以及 Clojure 兼容的 map/reduce/transduce 操作。库中包含 257 个函数，其中大部分直接来自 Clojure 的 `clojure.core` 和 `clojure.set` 命名空间。虽然不支持 Clojure 的 LOOP/RECUR，但可以使用 Common Lisp 的迭代机制。该库还提供了与 Clojure 类似的打印和读取表语法支持，并包含单元测试和文档。对于希望在 Common Lisp 中使用 Clojure 风格集合和序列 API 的开发者来说，CLJ-COLL 是一个有用的工具。
