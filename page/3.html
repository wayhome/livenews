Wtfis: Passive hostname, domain and IP lookup tool for non-robots

作者: todsacerdoti | 评分: 77 | 评论数: 6 | 发布时间: 2025-05-12 22:15
文章摘要

"wtfis" 是一个被动的主机名、域名和IP查询工具，专为人类易读而设计。它通过多个OSINT服务收集信息，并尽量减少API调用以避免达到免费 tier 的限额。主要功能包括： 1. 使用 Virustotal 作为主要信息源，获取主机名、IP的最新分析数据、信誉评分、流行度排名和分类等。 2. 可选使用 IP2Whois 获取更高质量的 whois 数据。 3. 使用 IPWhois 获取IP的地理位置和ASN信息。 4. 通过 Shodan 获取开放端口、操作系统和标签等信息。 5. 使用 Greynoise 判断IP是否为常规扫描或商业应用。 6. 通过 URLhaus 和 AbuseIPDB 查询是否为恶意URL或IP。 安装通过 `pip install wtfis` 或 `brew install wtfis`，配置需要设置多个API密钥。使用命令 `wtfis [选项] 实体` 查询信息。
