Strace-macOS: A clone of the strace command for macOS

作者: signa11 | 评分: 57 | 评论数: 5 | 发布时间: 2025-11-19 01:18
文章摘要

这篇文章介绍了`strace-macos`项目，这是一个为macOS开发的系统调用跟踪工具。主要特点包括： 1. **核心功能**：基于LLDB调试器API，纯Python实现，无需禁用系统完整性保护（SIP）。 2. **特性**： - 支持JSON和文本输出格式 - 可按系统调用名称或类别过滤（如文件、网络操作） - 提供符号解码、彩色输出和统计摘要 3. **安装方式**：支持通过Nix Flakes或手动安装，要求macOS 12+（主要在Apple Silicon上运行）。 4. **使用示例**：可跟踪命令、附加到运行进程，并支持多种过滤选项。 5. **对比Linux strace**：具备类似功能，但部分高级过滤（如正则表达式、路径过滤）尚未实现。 项目目前处于测试阶段，适合开发者用于macOS系统调试。
