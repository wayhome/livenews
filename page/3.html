Bare metal printf – C standard library without OS

文章摘要

这篇文章讨论了如何在无操作系统的裸机系统上利用Newlib实现紧凑的C标准库，特别是实现`printf`功能。文章首先对比了在完整操作系统和裸机系统上运行`printf`的区别，指出裸机系统缺乏底层支持，需要手动实现基本I/O功能。Newlib作为一个可定制的C标准库工具包，通过实现如`_write`这样的基本函数 primitives，使得像`printf`这样的复杂功能可以在裸机环境中运行。文章还介绍了交叉编译工具链的概念，并解释了如何针对RISC-V等平台进行配置和编译。最终，通过实现UART等简单I/O设备的功能，开发者可以在裸机环境中使用`printf`输出信息。

主要讨论点：嵌入式编程中的底层开发、库的选择与实现、以及如何处理输入输出（如printf） 不同观点： • **ChuckMcM** 认为嵌入式编程中重复造轮子很常见，但作者描述的架构通过特定环境库实现了可移植代码。他强调了在“裸机”环境下运行C程序所需的crt0启动代码和I/O驱动原语，并介绍了通过设置钩子使STDIN和STDOUT在特定设置下工作的方法。 • **dailykoder** 关注QEMU中UART寄存器的定义，质疑接收和发送缓冲区地址相同的问题，并讨论RISC-V的处理方式，建议对齐到字大小。 • **Rochus** 提到Newlib库的复杂性，特别是在适配到新系统时。他分享了自己从Newlib转向PDCLib和uClibc的经验，并提供了一个GitHub链接展示其工作成果。 • **Neywiny** 提到在学校学习时OS处理printf的简化教学方式，并指出理解嵌入式libc中没有默认输出路径的重要性。他推荐了解SWO和半托管（semihosting）技术。 • **smackeyacky** 讨论了Newlib的复杂性，特别是在系统复杂度增加时，例如从串行接口转向位图显示。他质疑Newlib是否支持在系统复杂度增加时替换钩子。 • **rurban** 反对使用过度复杂的stdio库，认为简单的uart_puts在DEBUG模式下足够，并批评为包含studio而增加的成本（220k）。 • **saagarjha** 批评了简单的缓冲区溢出代码示例，强调现代编程不应再出现这种错误。 • **gitroom** 表达了对学习过程中被忽略的细节的兴趣，并提出抽象层是否帮助或混淆了学习基本概念的问题。 • **MuffinFlavored** 建议去掉`stdio.h`，直接使用`syscall`来处理`write()`等操作。 • **einpoklum** 认为printf实现不需依赖裸机环境，建议使用依赖字符输出函数的跨平台实现，例如`putchar_()`，并推荐了一个独立的printf实现。 • **sylware** 讨论了在RISC-V汇编中避免伪指令和寄存器别名的实践，并提到使用简单的C预处理器处理汇编代码的经验。 • **eqvinox** 对文章标题感到困惑，期待看到更基础的printf实现解析，如格式化字符串和varargs处理，并提到FreeBSD的printf易于定制。 补充讨论： • 争议焦点在于嵌入式环境中库的复杂性和适用性，特别是Newlib的复杂性与简化需求的对立。 • 关于UART寄存器定义和RISC-V处理方式的技术细节也有一定讨论，反映了对底层硬件理解的分歧。 • 讨论中多次提到教学简化与实际应用复杂性之间的差距，特别是在学习嵌入式系统时被忽略的细节。 • 不同开发者对抽象层和系统复杂度增加时的处理方式有不同的实践和建议。

文章摘要

文章讨论了自闭症发病率上升的问题，特别是美国卫生与公众服务部部长罗伯特·肯尼迪关注的这一优先事项。文章指出，虽然自闭症诊断率确实在上升，但从历史数据看，这种增长可能并非实际发病率的增加，而是由于多种因素导致的数据偏差。首先，早期数据主要来自成年人，且很多人在成年后才被诊断，而自闭症患者的平均寿命较短，导致早期的数据被低估。其次，自闭症的定义和诊断标准在历史上发生了变化。例如，1980年《精神疾病诊断与统计手册》第三版（DSM-III）发布前，自闭症诊断非常罕见且标准严格，而DSM-III之后诊断标准放宽，导致诊断数量增加。因此，自闭症发病率的“增加”部分是由于诊断标准变化和历史数据偏差造成的。

评论摘要
主要讨论点：肥胖及代谢健康对自闭症发生率的影响 不同观点： • nsbk认为代谢健康是影响自闭症发生率的重要因素，尤其是肥胖的父母会增加孩子患自闭症的可能性。他引用了数据，指出肥胖父母将孩子自闭症风险提高了约4倍，并认为肥胖流行可能是自闭症发生率上升的原因。 • 该观点还扩展到其他代谢健康相关问题，如糖尿病和高血压，可能也对自闭症发生率有影响。 补充讨论： • 评论中没有直接反驳的观点，但nsbk自己也提到，由于时间有限，没有详细阅读文章，因此其观点可能基于部分信息或推测。 • 强调了代谢健康对儿童神经发育影响的潜在重要性，提示需要更多关注和研究。 • 提到具体数据（4倍风险增加）但没有提供详细来源或研究背景，这可能引发对数据准确性和适用性的进一步讨论。
