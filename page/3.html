文章摘要

Howdy – Windows Hello style facial authentication for Linux

文章摘要

Howdy 是一个为 Linux 提供类似 Windows Hello™ 面部认证功能的软件。它利用内置的红外发射器和摄像头进行面部识别，通过 PAM 系统实现登录、锁屏、sudo 等场景下的密码替代。Howdy 支持 Debian/Ubuntu、Arch Linux、Fedora 和 openSUSE 等发行版，安装方式各有不同，部分需要额外配置。它依赖于 Python 3.6+、meson、ninja 等工具构建，并可通过命令行管理面部模型。安装后需运行 `sudo howdy add` 进行面部录入。如遇问题，可通过查看 Wiki 或 GitHub 上的类似问题进行排查。用户还可以通过贡献代码或提交功能请求参与项目。
