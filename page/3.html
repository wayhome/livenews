作者: wut42 | 评分: 526 | 评论数: 43 | 发布时间: 2025-06-20 14:57
文章摘要

Chris McCord，Elixir的Phoenix框架的创建者，介绍了其最新的项目——Phoenix.new。这是一个全在线的编码代理工具，专为Elixir和Phoenix设计，旨在简化实时协作应用的开发。Phoenix.new运行在浏览器中，提供一个临时的虚拟机环境（Fly Machine），允许用户和代理自由操作而不会影响本地机器。它拥有完整的根访问权限，可以安装软件包、运行程序，甚至修改操作系统层面的配置。该工具集成了VSCode界面和GitHub，并通过Fly.io的基础设施提供私有、可分享的URL和实时预览功能。此外，Phoenix.new使用无头浏览器测试前端更改，实时交互和监控应用日志，显著减少开发中的重复性工作。McCord希望通过Phoenix.new解决将应用快速上线的问题，使其成为构建实时应用的理想选择。

Unexpected security footguns in Go's parsers

作者: ingve | 评分: 162 | 评论数: 14 | 发布时间: 2025-06-18 11:35
文章摘要

文章主要讨论了Go应用程序中解析不可信数据带来的安全风险，特别是在JSON、XML和YAML解析器中的意外行为可能被攻击者利用，导致认证绕过、授权控制突破以及敏感数据泄露。文章通过三个攻击场景具体说明： 1. **(Un)Marshaling意外数据**：Go解析器可能暴露开发者本想保密的字段数据。 2. **解析器差异**：不同解析器处理相同输入的差异可能被利用来绕过安全控制。 3. **数据格式混淆**：解析器处理跨格式数据时可能产生可被利用的结果。 文章还列举了多个实际案例，并给出强化解析器配置的建议，包括如何应对Go标准库中的安全缺口。例如，使用结构体标签控制字段的序列化和反序列化行为，以及如何避免暴露敏感字段等。最后，文章总结了这些解析器的潜在安全问题和应对策略。

评论摘要
主要讨论点：Go 语言中处理 API 数据和序列化/反序列化时的各种问题与安全性考量 不同观点： • glenjamin 认为，使用 DisallowUnknownFields 会使得处理前后兼容的 API 变更更加困难，尤其是在常见的、通常被认为是理想模式的场景中。 • asimops 指出，在安全设计中，不应该将客户端原始数据转发给认证服务，强调了“解析而非验证”的逻辑，并提供了一个参考链接。 • tptacek 表示，Go 的 `encoding/xml` 库不适合用于 SAML 解析，并建议不要使用 SAML，或者自己编写解析器。 • anitil 对 JSON、YAML、XML 可以被同一个字符串解析表示惊讶，并指出这在现实世界中会引发复杂的后果。 • octo888 建议，在数据模型中不应直接复用结构，特别是在不同请求和响应场景中，如在创建用户请求中包含 "IsAdmin" 字段是不合适的。 • piinbinary 提出，可以通过将结构体中的字段设为小写来实现私有化，从而避免某些安全问题，并提供了一个代码示例。 • aintnolove 认为，像 Protocol Buffers 这样的工具可以提供跨语言的一致性体验，并表示开始理解其吸引力。 • em-bee 强调，解析器不应负责数据验证，应该在解析后进行数据提取和验证，且只处理已知的字段。 • e_y_ 比较了 Go 的结构标签与 Rust 宏和 Java 注解，认为 Go 的标签方式显得落后且容易出错。 • neuroelectron 认为，这些问题存在多年，甚至像是故意设计的漏洞。 • jerf 反对将这些问题归咎于 Go 本身，认为许多问题是用户错误和 JSON、XML 本身固有的混乱性造成的，并详细解释了 JSON 解析器处理重复键等问题时的两难境地。 • Rikudou 幽默地表示，PHP 经常被批评，但连 PHP 都不会进行大小写不敏感的 JSON 解析。 补充讨论： • 争议的焦点之一是 Go 的 JSON 和 XML 解析器的设计是否足够安全和合理，尤其是在处理未知字段和重复键时。 • 另一个讨论点是数据模型和请求/响应结构的设计，是否应该为不同用途设计不同的数据结构，而不是直接复用。 • 还有对各种数据格式（JSON、YAML、XML）解析时的意外行为进行了讨论，特别是这些行为在现实应用中可能导致的安全问题。 • 最后，关于 Protocol Buffers 等其他序列化方法的讨论，提供了另一种思路，以解决跨语言和一致性问题。

Axolotls May Hold the Key to Regrowing Limbs

作者: noleary | 评分: 31 | 评论数: 5 | 发布时间: 2025-06-19 23:48
文章摘要

Axolotls, a type of salamander capable of regrowing missing body parts, are helping scientists uncover the secrets of limb regeneration. In a study published in *Nature Communications*, researchers led by James Monaghan from Northeastern University genetically engineered axolotls to glow and tracked the molecular pathways involved in regeneration. They discovered that retinoic acid, a vitamin A derivative, plays a crucial role in determining which type of limb should regrow, with higher concentrations leading to more extensive regrowth. The enzyme CYP26B1 controls retinoic acid levels, while the *Shox* gene is essential for proper limb regeneration. Axolotls share these genetic pathways with humans, suggesting potential for future applications in human medicine, such as developing treatments to regenerate limbs rather than form scar tissue. Though human limb regeneration is still far off, foundational research like this is crucial for progress.
