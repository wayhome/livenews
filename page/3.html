Jqfmt like gofmt, but for jq

文章摘要

`jqfmt` 是一个类似于 `gofmt` 的工具，专门用于格式化 `jq` 命令行脚本。它帮助用户在阅读或编写复杂的 `jq` 查询时，通过在适当位置添加换行符来提高可读性。开发者因经常处理包含大量 `jq` 的 Shell 单行脚本，创建了 `jqfmt` 来解决格式问题。该工具支持格式化数组、对象以及操作符，并提供了命令行选项来定制输出格式。尽管最初依赖 `gojq`，但由于其无法提供可遍历的语法树，开发者自行提取了相关代码。`jqfmt` 以 MIT 协议开源，并欢迎社区贡献。

评论摘要
主要讨论点：围绕工具 **jq** 及其相关工具（如 **jqfmt**）的讨论，包括使用体验、优缺点以及替代方案。 不同观点： • **支持并分享使用经验**：[rwiggins] 对 jq 有很高的评价，并分享了自己常用的一个 jq 单行命令来分析文档结构，同时对 jqfmt 工具进行了测试和反馈，认为其格式化功能不错，但希望有些默认行为可以改进。 • **澄清误解**：[Hendrikto] 指出 "jq formatter" 在搜索时容易引起误解，因为 jq 本身可以格式化命令，而不是直接格式化 JSON 数据，帮助读者更好理解讨论背景。 • **质疑单行命令的复杂性**：[s17n] 认为如果需要格式化单行命令，可能它就不应该被写成单行，暗示 jq 命令有时过于复杂，对工具的存在表示一定质疑，但仍认可工具的创新性。 • **对工具默认设置的建议**：[kiitos] 建议 jqfmt 工具应该默认启用一些常用格式化规则，而不是让用户手动启用每一个规则，从而提升用户体验。 • **对 jq 的批评和使用困难**：[xmonkee] 表示不喜欢 jq，认为其命令难以记忆和使用，且文档难以理解。每年仅使用一次，但每次都需要重新学习，暗示工具的学习曲线陡峭。 • **替代工具推荐**：[mikeocool] 提到最近使用 fx (fx.wtf) 作为 jq 的替代工具，提供类似 JavaScript 的接口，可以完成类似 jq 的处理任务。 • **幽默评论**：[guerrilla] 以幽默方式表示对标题的误解，增加了一些轻松的讨论氛围。 • **工具作者回应及推广**：[noperator] 作为 jqfmt 工具的作者，回应了讨论，并推广了自己开发的另一个工具 sol，用于 shell 单行命令的美化。 • **对命名和工具类比的批评**：[ForOldHack] 对工具命名提出了批评，认为类似 jq、gofmt、jqfmt 这些工具的命名方式容易混淆，并表达了对老式设备的怀念。 • **jq 在复杂任务中的局限性**：[quotemstr] 认为 jq 在处理大数据集的复杂任务时表现不佳，尤其是与 Python 和 Pandas 等工具相比，运行速度较慢，暗示在某些情况下应选择更强大的工具。 补充讨论： • jq 的复杂性和学习曲线是争议的焦点，部分用户认为其命令难以记忆和使用，而另一部分用户则高度评价其功能和灵活性。 • 关于 jqfmt 工具的反馈主要集中在其默认行为和易用性上，部分用户希望能有更简便的使用体验。 • 替代工具如 fx 被提出，显示出用户对 jq 以外的选择也持有开放态度。

Sutton SignWriting is a writing system for sign languages

作者: janpot | 评分: 17 | 评论数: 1 | 发布时间: 2025-07-19 11:54
文章摘要

SignWriting是一种用于手语的书写系统，可以书写包括美国手语、巴西手语、突尼斯手语等多种手语。它由Valerie Sutton于1974年发明，基于她先前为舞蹈设计的符号系统。SignWriting使用视觉符号来描绘手势、面部表情和身体动作，具有二维书写特点，不同于传统的一维线性书写。该系统已被用于出版青少年小说、翻译《圣经》、为YouTube视频添加字幕以及研究手语读写能力。SignWriter是其用于MS-DOS的文字处理软件。SignWriting在巴西被广泛应用，并被用于编写包含9,500多个手语符号的巴西手语词典。此外，它在德国也被用于提高聋人的书面德语能力。

评论摘要
主要讨论点：对设计一种全球通用的手语符号系统的目的和实用性的质疑与讨论 不同观点： • 观点一：质疑该符号系统的目的。认为该系统可能是为了赋予聋人一种与 spoken languages 平行的共享全球语言，但同时指出已经存在多种手语（如非ASL）。这让人怀疑创造新系统的必要性。 • 观点二：该符号系统可能是为视力正常但同时聋哑和有阅读障碍的人设计的。但同时提出疑问，这些符号是否真的能有效帮助这类人群。 • 观点三：有人认为这个系统可能是为了教人们使用手语，但同样提出反对意见，认为这种方式不够信息丰富或有效。 • 观点四：尽管对上述目的都有质疑，评论者还是承认这种特征性书写系统（featural scripts）总体上很有趣，并对将其纳入Unicode的努力表示赞赏。 补充讨论： • 评论中涉及到对不同群体（如全球聋人、视力正常但有听力和阅读障碍的人、手语学习者）的需求和实用性的讨论。 • 争议的焦点在于该手语符号系统的实际用途和目标群体不明确，且对其能否解决预期问题存在怀疑。 • 尽管有批评，评论者对符号系统在概念上的创新性和技术上的成就（如进入Unicode）表示肯定。
