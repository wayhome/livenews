Curry: A functional logic programming language

文章摘要

Curry是一种集成函数式和逻辑式编程的语言，结合了函数式编程的特点（如嵌套表达式、高阶函数、强类型、惰性求值）和逻辑式编程的特点（如非确定性、内置搜索、自由变量、部分数据结构）。它支持纯声明式编程、类型推断、非确定性操作和自由变量等特性。Curry的开发是一个国际项目，提供了一个用于研究、教学和应用集成函数逻辑语言的平台。Curry有多种实现，如PAKCS、KiCS2和MCC。Curry还拥有自己的包管理器CPM、文档生成工具CurryDoc和API搜索引擎Curr(y)gle。
