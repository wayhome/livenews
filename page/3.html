uv: An extremely fast Python package and project manager, written in Rust

作者: chirau | 评分: 352 | 评论数: 47 | 发布时间: 2025-06-23 16:27
文章摘要

**uv** 是一个用 Rust 编写的高速 Python 包和项目管理工具，能够替代 pip、pipx、poetry、pyenv 等多个工具。它具有以下特点： 1. **速度快**：比 pip 快 10-100 倍。 2. **项目管理**：支持锁文件、工作区等功能，类似于 rye 或 poetry。 3. **依赖管理**：支持内联依赖元数据，可管理单文件脚本的依赖。 4. **Python 版本管理**：安装和管理多个 Python 版本。 5. **工具执行和安装**：类似 pipx，可运行和安装 Python 包提供的命令行工具。 6. **跨平台**：支持 macOS、Linux 和 Windows。 7. **高效磁盘空间使用**：通过全局缓存进行依赖去重。 安装可通过 curl 或 pip 进行，文档可在 [docs.astral.sh/uv](https://docs.astral.sh/uv) 查看。

评论摘要
主要讨论点：用户对Python包管理工具 `uv` 的评价与使用体验 不同观点： • **支持 `uv`，认为其高效且易用**： - 用户 [acheong08] 提到在共享服务器上，由于包和驱动问题以及 `pip` 缓存占用大量空间，切换到 `uv` 后问题解决，体验大幅提升。 - 用户 [samsartor] 从 `conda` 转向 `uv`，并赞赏其处理非PyPI依赖（如GitHub、内部仓库等）的能力。 - 用户 [polivier] 对 `uv` 的速度印象深刻，比 `pip` 快很多。 - 用户 [leonheld] 喜欢 `uv` 的脚本执行功能，通过 `#!/usr/bin/env -S uv run` 轻松运行Python脚本。 - 用户 [mh-] 也提到 `uv` 的速度快得让人怀疑是否工作正常。 - 用户 [eats_indigo] 和 [IceHegel] 表示 `uv` 带来了显著的开发质量提升，尤其是在与 `Ruff` 结合使用时。 - 用户 [pu_pe] 认为 `uv` 快得没有理由再用 `pip` 或 `conda`。 - 用户 [6ak74rfy] 强调 `uv` 无需手动管理环境，自动处理Python版本和运行代码。 • **对 `uv` 的某些功能或配置存在疑问或建议**： - 用户 [andy_ppp] 提到希望 `uv` 能自动设置 `PYTHONPATH`，以便更容易地从指定目录导入包。 - 用户 [larkost] 指出在资源受限的系统（如AWS T2.micro 运行Windows）上，`uv` 会尝试打开过多并发下载，导致超时问题，并建议通过环境变量限制并发数。 补充讨论： • **`uv` 的技术优势与创新**： - 用户 [theLiminator] 认为 `uv` 是“重新发明轮子”的成功案例，专注的目标使其比其他工具更高效。 - 用户 [kissgyorgy] 详细解释了 `uv` 的优化技术，如Range请求和内存解析，使其速度远超其他包管理器。 • **其他用户对 `uv` 的初步尝试与未来展望**： - 用户 [nrvn] 分享了一种运行小型可执行脚本的新方法。 - 用户 [linsomniac] 正在尝试将 `uv` 与NixOS结合使用，并对未来的开发工作充满期待。 争议焦点： • 目前争议不大，主要是一些功能上的改进建议，如 `PYTHONPATH` 的自动设置和并发下载的优化。总体上，用户对 `uv` 的评价非常积极。
