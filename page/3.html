文章摘要

本文探讨了Erlang编程语言的核心思想，指出其最重要的贡献并非仅仅是轻量级进程和消息传递，而是"behaviours"这一概念。作者起初认为Erlang的亮点在于其轻量级进程和消息传递机制，但后来认识到这些只是实现可靠分布式系统的工具。Erlang最初由Ericsson开发，用于构建电话交换机系统，具有处理大规模用户的能力。1998年，Ericsson决定禁用Erlang，开发团队随后将其开源，且大部分核心成员离职创办了Bluetail公司。Joe Armstrong是Erlang的主要设计者之一，他在2002年开始撰写博士论文，主题为"在软件错误存在的情况下构建可靠的分布式系统"。论文中强调了"behaviours"的概念，类似于Java或Go中的接口，允许不同的实现以实现通用功能。通过一个键值存储的例子，文章展示了如何利用"gen_server"行为实现状态管理。作者认为，"behaviours"是Erlang最核心的思想，超越了轻量级进程和消息传递。

C++: terser (shorter) lambda == SHORTY (ab-use?)

作者: signa11 | 评分: 44 | 评论数: 11 | 发布时间: 2025-04-09 06:15
文章摘要

`shorty` 是一个 C++ 库，旨在通过更简洁的语法来使用 lambda 表达式和函数操作，而不是替换 C++ 的核心功能。它提供了多种简化的操作符和函数调用方式，如使用 `$lhs`、`$rhs` 来处理排序条件，使用 `$i`、`$n` 等符号访问函数参数，以及通过 `$` 或 `$call` 调用可调用对象。此外，库支持元组操作、参数捕获、类型转换和赋值操作等功能，简化了代码书写。通过这些特性，开发者可以用更少的代码实现复杂的函数操作。库的实现依赖于 C++20 的 ranges 和 views 等现代特性。

评论摘要
主要讨论点：C++中一种新的模板和语法糖实现，尤其是其复杂性、实用性和创新性。 不同观点： • [tempodox] 认为这种新的模板层次增加了C++的“黑魔法”特性，使得错误信息更难以读懂，表达了对可读性的担忧。 • [GrantMoyer] 分享了一个具体实现（27行代码），并提到自己曾尝试实现类似功能，但因无法合理实现成员调用语法而改变方向。他对该实现的实用性持怀疑态度，但也不确定是否真的有用，尤其是对Unicode名称持批评态度。 • [hsfzxjy] 认为这种实现看起来很“诅咒”，但对美元符号$作为标识符的有效性表示惊讶。 • [foxhill] 一开始对新的语法持怀疑态度，但逐渐接受了这种实现，尤其提到尽管美元符号语法不可取，但并不影响整体接受度。 • [notpushkin] 简单地对该实现表示赞赏，并联想到Python中的类似实现（dry-python/lambdas）。 • [porridgeraisin] 直接表达了对这种实现的恐惧和不认同。 • [pjmlp] 从C++23的角度出发，认为没有看到这种实现的明显好处。 • [nialv7] 认为这并不是新想法，提到了表达式模板（Expression Templates）作为类似概念已经存在。 • [pwdisswordfishz] 认为这类似于已经被淘汰的Boost.Lambda，质疑其创新性。 补充讨论： • 争议焦点在于这种新语法（尤其是美元符号$）的可读性和实用性。 • 部分评论者对其复杂性表示担忧，认为增加了C++的“黑魔法”特性，而另一些评论者则逐渐接受，甚至看到了其潜在的价值。 • 一些评论者提到了类似实现（如Boost.Lambda和表达式模板），质疑其创新性或实用性。

文章摘要

这篇文章简要介绍了人类对金星表面的探索历史。只有四艘航天器曾成功传回金星表面的图像，均由1975年至1982年间苏联的“金星”（Venera）探测器拍摄。这些图像显示了金星黄色的天空和荒凉的地表，揭示了一个可能曾经类似地球但经历了 catastrophic 气候变化的世界。哲学教授Ted Stryk利用俄罗斯科学院的数据，重建了这些原始的全景图像。文章还呼吁支持NASA的科学预算，并邀请读者加入行星学会以支持空间科学探索。

评论摘要
