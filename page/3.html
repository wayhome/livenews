文章摘要

**snapDOM** 是一个高保真的 DOM 捕获工具，能够将任意 HTML 元素转换为可缩放的 SVG 图像，同时保留样式、字体、背景、阴影 DOM 内容、伪元素等。它轻量无依赖，完全基于标准 Web API，支持导出为 SVG、PNG、JPG、WebP 或 canvas。主要功能包括捕获整个 DOM 树、嵌入样式和字体、处理 Shadow DOM 和伪元素等。此外，它还具有高性能，尤其在处理大型或复杂 DOM 结构时表现突出，优于其他类似库。可通过 NPM、CDN 或脚本标签引入使用，并提供多种捕获方法如 `snapdom.toPng`、`snapdom.toCanvas` 等。

Unlocking Ractors: Object_id

文章摘要

文章主要讨论了Ruby中的Ractors及其目前的局限性和未来改进方向。Ractors旨在将CPU密集型任务移出主线程以实现并行处理，但由于Ruby虚拟机存在全局锁和一些未解决的bug，目前在并行性能上可能还不如单线程代码。不过，开发团队正在积极修复这些问题，例如通过消除如`fstring_table`等内部数据结构的锁竞争来提升性能。尽管如此，仍有一些锁竞争点需要解决，比如`#object_id`方法。该方法原本依赖对象地址生成ID，但由于GC压缩导致对象地址变化，ID不再稳定，Aaron Patterson在Ruby 2.7中通过引入ID表解决了这一问题。文章作者计划在Ruby 3.5中正式弃用`_id2ref`方法，并继续优化Ractors的性能。
