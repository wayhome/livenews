Show HN: I built an AI agent that turns ROS 2's turtlesim into a digital artist

作者: ponta17 | 评分: 20 | 评论数: 4 | 发布时间: 2025-05-31 10:17
文章摘要

**turtlesim_agent** 是一个基于 ROS 2 TurtleSim 的 AI 代理，利用自然语言指令将经典的 TurtleSim 模拟器转变为创意画布。通过 LangChain 驱动，该代理可将文本描述转换为图形绘制，使模拟的小海龟成为数字艺术家。用户可以用英文描述形状或绘图意图，AI 代理会解析指令并通过 TurtleSim 的运动命令执行绘制。项目支持多种语言模型，需要配置相应的 API 密钥。用户可自定义使用的 LLM 模型，并通过配置文件指定模型名称。项目提供了基本形状和彩虹绘制的演示范例，展示了大型语言模型与外部环境交互的创意潜力。 **使用步骤：** 1. 克隆并构建 ROS 2 工作空间。 2. 设置 API 密钥。 3. （可选）通过 LangSmith 进行追踪和调试。 4. 配置 LLM 模型。 **依赖：** - ROS 2 Humble Hawksbill - Python 3.10+ - 其他依赖见 `requirements.txt` **注意：** 项目结果可能因语言模型的非确定性而有所不同。

Surprisingly fast AI-generated kernels we didn't mean to publish yet

作者: mfiguiere | 评分: 346 | 评论数: 20 | 发布时间: 2025-05-30 20:03
文章摘要

文章介绍了意外生成的非常快速的AI生成CUDA内核，这些内核在某些情况下甚至超过了PyTorch中专家优化过的生产内核。关键结果包括：Matmul (FP32) 性能达到torch.matmul的101.3%；Conv2D性能达到torch.nn.Conv2D的179.9%；Softmax性能达到torch.softmax的111.8%；LayerNorm性能达到torch.nn.LayerNorm的484.4%；以及Conv2D + ReLU + MaxPool的性能达到参考值的290.1%。这些内核是使用简单的合成数据生成方法意外获得的，该方法通过自然语言推理优化想法并行生成多个代码变体，从而避免了传统顺序修正中的局部最小问题。文章强调了这种方法在性能内核生成方面的潜力，并视为未来探索的第一步。

文章摘要
