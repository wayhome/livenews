Reverse engineering GitHub Actions cache to make it fast

作者: tsaifu | 评分: 110 | 评论数: 11 | 发布时间: 2025-07-23 13:17
文章摘要

本文介绍了Blacksmith如何通过逆向工程GitHub Actions缓存机制，实现无代码更改的缓存加速。最初，他们通过 fork 流行的 GitHub Actions 并指向自己的快速缓存来提升性能，但这带来了维护负担。为解决此问题，他们决定逆向工程 GitHub Actions 缓存，利用网络代理技术，将缓存请求透明地重定向到自建的 MinIO 集群，而无需用户修改代码。通过使用 NGINX 作为代理服务器，他们在 VM 内配置轻量级代理，将缓存相关的请求重定向到自建缓存，其他请求则正常处理。最终，实现了最高10倍的缓存性能提升，同时保持了用户体验的无缝衔接。

Tram Trains

作者: ortegaygasset | 评分: 23 | 评论数: 10 | 发布时间: 2025-07-23 14:37
文章摘要

本文讨论了如何在较小城市中建设经济实惠的公共交通，重点介绍了“ tram-train”（电车-火车）系统。许多城市面临铁路线在市中心终止而不延伸到另一侧的问题。为解决此问题，一些大城市通过建设隧道或高架桥实现铁路贯通运行，但这成本高昂。对于小城市，如德国卡尔斯鲁厄（Karlsruhe），则采用了tram-train模式，将电车与火车网络结合。卡尔斯鲁厄通过改造轨道和供电系统，使电车可以直接驶入市中心，减少换乘，提高效率。尽管tram-train速度较慢，因为它需要与道路交通共享空间，但该系统大幅提高了客流量，例如布雷滕线的客流量增加了400%。如今，该网络每年载客1.7亿人次，总长超过660公里。

Interactive Programming in C (2014)

作者: ofalkaed | 评分: 4 | 评论数: 0 | 发布时间: 2025-07-23 17:16
文章摘要

这篇文章介绍了如何在C语言中实现交互式编程，即在程序运行时修改和扩展功能。这种方法特别适用于游戏开发等非批处理应用，可以减少调试和调整的繁琐过程。关键技巧是将几乎整个应用程序构建为共享库（shared library），并且避免在全局或静态变量中保存状态。文章通过一个简单的“生命游戏”示例演示了这种方法：编辑代码后，无需重启程序，修改会立即生效。共享库通过一个结构体（struct）封装的API与主程序交互，避免使用函数指针产生的问题。这种技术可以在Linux等类Unix系统上使用libdl实现，类似于Windows上的DLL方法。文章还详细介绍了API的五个主要函数：`init()`、`finalize()`、`reload()`、`unload()`和`step()`，用于处理状态初始化、资源释放和动态加载。

Checking Out CPython 3.14's remote debugging protocol

作者: ingve | 评分: 63 | 评论数: 6 | 发布时间: 2025-07-23 09:57
文章摘要

Python 3.14引入了一个新功能，允许通过`python -m pdb -p pid`将pdb调试会话连接到一个正在运行的Python进程。这使得开发者可以在无需提前修改代码或重启程序的情况下，动态调试运行中的进程。文章介绍了如何使用`sys.remote_exec`方法向指定进程ID的Python进程注入并执行代码。具体来说，开发者可以在一个Python REPL中调用`sys.remote_exec(pid, script_path)`，让目标进程执行指定的脚本。文章通过一个简单的累加整数的程序演示了该功能的实际应用，展示了如何在不中断程序运行的情况下，远程注入代码以查看调用栈信息。这一新功能降低了调试Python程序的门槛，简化了调试流程，并减少了对CPython内部细节的依赖。

评论摘要
