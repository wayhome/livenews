文章摘要

Testing Without Mocks: A Pattern Language (2023)

作者: jcartw | 评分: 69 | 评论数: 8 | 发布时间: 2025-03-25 12:00
文章摘要

本文讨论了自动化测试的重要性以及常见问题，尤其是广泛测试和使用mock（模拟）测试的弊端。广泛测试速度慢且不稳定，而mock测试虽然快且可靠，但会锁定代码实现，使重构困难，且需要补充广泛测试。文章提出了一种不使用广泛测试和mock的替代方案，即结合"可社交的状态测试"和"Nullables"技术，以避免上述问题。Nullables看似测试替身，但实际上是生产代码的一部分，具有"关闭"开关。这种方法保证了测试的速度、可靠性和可维护性，但需要在生产代码中加入Nullables，这是其主要权衡。文章还提供了具体代码示例和模式，如A-Frame架构和基础设施包装器，以帮助实现这种测试方法。

**Postgres Language Server** 是一个为 Postgres 提供语言工具和实现语言服务器协议（LSP）的项目，旨在提升开发者体验和提供可靠的 SQL 工具。该项目基于 Postgres 自身的解析器 **libpg_query**，确保 100% 的语法兼容性。它采用客户端-服务器架构，具有传输无关的设计，可以通过 LSP、CLI、HTTP API 或 WebAssembly 模块访问功能。主要特性包括自动补全、语法错误高亮、类型检查（通过 **EXPLAIN**）和受 **Squawk** 启发的 linter。项目当前专注于优化核心功能，并欢迎社区贡献。更多详情和贡献机会可查看项目的问题和讨论。
