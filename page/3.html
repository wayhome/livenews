Die analysis of the 8087 math coprocessor's fast bit shifter (2020)

作者: Jimmc414 | 评分: 69 | 评论数: 6 | 发布时间: 2026-06-22 13:40
文章摘要

这篇文章介绍了Intel 8087浮点协处理器的历史和技术细节。1980年Intel推出8087芯片，使微型计算机的浮点运算速度提升100倍，但价格高达数百美元。8087采用了数值分析专家William Kahan设计的浮点架构，后来成为IEEE 754标准，影响深远。 文章重点分析了8087的二进制移位器设计。该芯片包含4万个晶体管，移位器占据了大量面积。它采用两级桶形移位器设计：第一级移位0-7位，第二级移位0-7字节，组合可实现0-63位的任意移位。移位器在浮点加减法、CORDIC超越函数运算中起关键作用，其高效设计对芯片性能至关重要。

评论摘要
主要讨论点：8087数学协处理器的快速位移器设计分析 不同观点： • **历史案例分享**：tasty_freeze 提到 Northstar 的 S-100 卡使用 BCD 算术实现浮点运算，采用微码 ROM 和 4 位 ALU，支持最多 14 位数字表示，通过指针移动而非数据移动实现规范化 • **设计疑问**：SyzygyRhythm 质疑为何不采用 log2 对数排列（32-16-8-4-2-1位）的移位器设计，认为这种方式子级更少且无需额外解码器，对文章中提到的两阶段设计（位移和字节移）感到困惑 • **相关讨论提醒**：bell-cot 指出 8 天前有关于 8087 加法器的相关讨论（138点，28评论） 补充讨论：trollbridge 幽默表示该话题极具吸引力，担心会花费大量时间深入研究。整体讨论围绕历史处理器架构设计选择展开，特别关注位移器的实现方式及其效率考量。

文章摘要

`deno desktop` 是 Deno 2.9 版本推出的功能，可将 Deno 项目打包成独立的桌面应用程序。它使用 Web 技术构建 UI，默认采用系统原生 WebView 保持体积小巧，也支持打包 Chromium 实现跨平台一致渲染。主要特点包括：完整的 Node 兼容性、自动识别主流前端框架（Next.js、Astro 等）、进程内通信替代 IPC、支持跨平台编译、内置二进制差分自动更新。使用简单，只需一个 TypeScript 文件配合 `Deno.serve()` 即可创建桌面应用，还提供窗口管理、菜单、通知、热更新等完整桌面开发能力。

评论摘要
主要讨论点：Deno Desktop 作为跨平台桌面应用开发框架的技术特点、优劣势及与竞品的比较 不同观点： • **支持者观点**：认为这是智能的产品策略，原生支持 TypeScript、有完整的 npm 生态系统，相比 Tauri 多 150MB 体积但换来可靠的渲染引擎是值得的权衡，且比 Electron 更轻量 • **原生UI倾向者**：质疑 Web 技术作为 UI 工具的定位，指出 Web 技术无法很好地遵循宿主操作系统的原生 UI 模式和交互规范，即使是无样式的按钮也无法保证在不同系统和浏览器中的原生外观 • **技术细节关注者**：关心 CEF 共享运行时的版本管理问题（不同应用需要不同 CEF 版本时如何处理）、权限系统的用户可见性、桌面环境的扩展能力（如 socket、ODBC 连接等） 补充讨论： 有用户反馈 Hello World 示例出现白屏无响应；有人询问移动端支持计划；文档存在错误（Electrobun 被标记为仅 macOS 但实际支持三平台）；有开发者计划尝试迁移现有应用，特别关注隐藏浏览器窗口和 cookie 拦截等高级功能的支持情况

主要讨论点：微软与油气公司签署20年天然气发电合同为数据中心供电的决策及其影响 不同观点： • **支持方**：认为这是商业上的双赢。西德州天然气价格为负值（曾达-$9/MCF），石油开采必须处理伴生气，微软能以$1-2/MCF锁定长期低成本能源，油企也能减少损失 • **质疑环保承诺方**：指出微软承诺2030年实现碳负排放，但现在部署数千兆瓦化石燃料发电设施，目标可信度存疑。有人讽刺"为股东创造价值的同时毁灭了地球" • **替代方案支持者**：认为德州太阳能和储能成本极低，电网新增装机几乎全是可再生能源，质疑为何不选择更清洁的方案。Google已与能源公司签署光伏发电协议作为对比 • **合同期限质疑方**：认为20年合同期过长，无法预测未来需求变化，应该签5年短期合同并设置续约选项 补充讨论： - "Solar Turbines"命名引发争议，实际是燃气轮机公司却用"太阳能"命名被批评误导性 - 有人建议利用油田长期燃烧浪费的伴生气为数据中心供电 - 涉及GE Vernova 7HA大型燃气轮机，配备排放控制设施，非简易设备
