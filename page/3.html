The impact of file position on code review

作者: whatever3 | 评分: 51 | 评论数: 16 | 发布时间: 2025-07-17 18:14
文章摘要

该文章探讨了文件排序对代码评审结果的影响。通过分析GitHub上219,476个Pull Requests的评审评论，以及一项有106名参与者的在线实验，研究发现：文件在PR中较早出现时，会收到更多评论，且文件位置会影响缺陷检测效果。具体而言，对于某些缺陷，若文件排在最后，参与者发现缺陷的概率降低64%。文章建议代码评审工具应考虑文件排序对评审质量的影响。研究结果在ESEC/FSE '22会议上发表。

评论摘要
主要讨论点：代码文件结构和代码审查的顺序与方法 不同观点： • [kevinsync] 认为文件和文件夹结构类似于地理 mapping 或城市规划，应该设计成易于人类理解的空间组织形式，文件的存放位置应有明确的逻辑。他批评了一些云存储服务尝试重塑或抽象化深层次文件系统树的做法，认为这违背了人类的理解习惯。 • [analog31] 通过音乐课的例子提出，审查代码时不必追求一次性完成整个选择，而是可以通过逐步改进技术和理解来进行，类似于音乐学习中的分段练习。 • [jsbg] 指出在代码审查中，位于前列的文件通常会收到更多评论，但并不意味着后面的文件被忽视。他建议保持较短的 Pull Request (PR) 以避免此类问题。 • [progbits] 不认同从上至下审查文件的方式，习惯于先查看高层次的变化（如 schema 更改、接口等），然后根据核心思路审查实现细节，经常会在不同模块或函数之间跳跃。 • [semperos] 分享了一个 Firefox 插件，可以随机化 GitHub PR 中的文件顺序，提供了一种不同的审查方式。 • [MarkusQ] 总是优先审查有 bug 的文件，强调了审查的优先级。 • [taeric] 质疑文件审查顺序是否能反映审查质量，认为早期文件的评论可能影响后续文件的处理方式，建议不要仅凭顺序判断审查的全面性。 • [slongfield] 希望 GitHub 代码审查能优先显示头文件 (.h) 再显示实现文件 (.cc)，以提高审查效率。 • [aerostable_slug] 开玩笑地提出可将恶意代码藏在较后审查的文件中，暗示顺序可能影响安全性。 • [jpalawaga] 及其同事在审查时会明确指出核心文件，帮助审查者快速理解变化，但也提到有人可能偏好无上下文审查以锻炼独立判断能力。 • [gavinhoward] 对相关论文表示赞赏，虽然不具突破性，但对其正在进行的设计工作有帮助。 • [deckar01] 支持小而自包含的提交，但认为 GUI 工具对行级提交的支持不足，建议训练 LLM 进行分解。 • [breatheoften] 认为将源文件视为无序 blob 是错误的，强调代码库应是有序的结构，批评了一些构建系统抽象对此的掩盖。 • [Daviey] 表示未曾考虑过这种角度，但意识到会更加 diligent，感谢分享。 • [12_throw_away] 通过前缀命名文件以提高可读性，类似于书籍章节的顺序，可能与文学编程有关。 补充讨论： - 文件结构和审查顺序对代码理解和审查效率的影响是讨论的核心。 - 不同审查者有不同的习惯和策略，如从高层次变化开始、优先审查核心文件或 bug 文件等。 - 随机化文件顺序的工具提供了一种新的审查方式，但具体效果因人而异。 - 小而自包含的 PR 和有序的文件结构被认为是提高审查质量和效率的重要因素。

404 Media披露了美国移民和海关执法局（ICE）的新面部识别应用“Mobile Fortify”的细节。该应用允许ICE官员通过手机摄像头扫描人脸，快速比对2亿张照片数据库，获取包括姓名、出生日期、国籍、身份识别号以及该人是否被判驱逐出境等信息。该工具连接了多个政府数据库，如国务院、海关和边境保护局（CBP）、FBI以及州级记录，未来还可能加入更多商业数据库。电子前沿基金会（EFF）指出，这一技术不仅用于确认身份，还可能被滥用，限制个人权利。

3D-printed living lung tissue

作者: gmays | 评分: 18 | 评论数: 3 | 发布时间: 2025-07-17 17:20
文章摘要

Dr. Emmanuel Osei及其团队在UBC奥肯那根校区开发了一种3D生物打印的肺组织模型，该模型能够模拟人类肺部的复杂结构，为研究肺部疾病和开发新药物提供了更有效的测试平台。该模型使用光敏聚合物修饰明胶和聚乙二醇二丙烯酸酯制成的生物墨水，打印出包含多种细胞类型和通道的水凝胶， mimicking血管结构。这一创新使研究人员能够在体外更准确地研究肺部疾病的病理机制，并测试潜在的治疗方法。研究团队已通过将模型暴露于香烟烟雾提取物等刺激物，成功观察到炎症反应，证明该模型可用于复杂肺病机制的研究。这项研究发表在《Biotechnology and Bioengineering》上，得到了Mitacs和Providence Health Care的支持，标志着呼吸系统疾病研究和药物开发的重要进展。

评论摘要
主要讨论点：3D打印活体组织及其在药物测试和医疗应用中的潜力 不同观点： • [ls-a] 期望点击链接后能看到3D打印活体肺组织的高清图片，显示出对该技术成果的兴趣和期待，重点关注技术呈现的视觉效果和实际成果。 • [Jimmc414] 对使用3D打印组织测试人类药物的伦理和科学性提出疑问，质疑这种方法是否合适或有效，反映出对新技术应用的谨慎态度。 • [cynicalsecurity] 强调生物研究的重要性，指出人工细胞当前面临的免疫排斥问题，并认为CRISPR基因编辑技术是潜在的解决方案。尽管技术尚未成熟，但强烈主张加大对人工组织和器官替代研究的投入，显示出对该领域未来发展的信心和紧迫感。 补充讨论： • [cynicalsecurity] 提到了当前技术的局限性，特别是免疫系统对人工细胞的攻击问题，以及CRISPR基因编辑技术作为解决方案的潜力，但同时也承认这些技术仍在发展中，表明了对现状的清醒认识。 • 争议的焦点在于3D打印组织技术是否已经成熟到可以替代传统药物测试方法和人体器官移植。一方面，[ls-a] 表现出对技术进展的期待；另一方面，[Jimmc414] 则对其应用的合理性和有效性提出质疑，而[cynicalsecurity] 则强调了继续投资和研究的必要性。
