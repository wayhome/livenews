Nixtml: Static website and blog generator written in Nix

作者: todsacerdoti | 评分: 71 | 评论数: 8 | 发布时间: 2025-12-02 14:54
文章摘要

这篇文章介绍了 `nixtml`，一个用 Nix 编写的静态网站和博客生成器，灵感来自 Hugo。主要内容包括： 1. **功能特点**：支持从 Markdown 生成静态页面，可管理内容、模板和静态资源，并提供分页和 RSS 生成功能。 2. **快速入门**：通过 Nix Flake 配置网站，定义元数据、内容目录、静态资源和集合（如博客文章）。 3. **模板系统**：支持 HTML 函数式生成或字符串模板，提供标准布局（如首页、页面、集合分页等）。 4. **内容管理**：自动遍历目录，将 Markdown 文件转换为 HTML。 5. **集合功能**：可对内容分组、分页并生成 RSS 源。 适用于希望用 Nix 构建静态网站或博客的用户。

评论摘要
