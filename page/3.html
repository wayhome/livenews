PyGraph: Robust Compiler Support for CUDA Graphs in PyTorch

作者: mfiguiere | 评分: 42 | 评论数: 3 | 发布时间: 2025-04-24 19:28
文章摘要

本文介绍了一种名为PyGraph的方法，旨在为PyTorch提供对CUDA Graphs的强大编译器支持。CUDA Graphs旨在通过捕捉和启动一系列GPU任务来减少CPU开销，但由于其静态结构和数据复制开销，实际部署中往往导致性能下降。PyGraph通过三项关键优化解决这些问题：扩大CUDA Graphs的适用范围、减少GPU内核参数复制开销、基于成本效益分析选择性部署CUDA Graphs。PyGraph无缝集成到PyTorch2的编译工具链中，无需手动修改代码即可提升性能。实验表明，PyGraph在多种机器学习基准测试中显著提升了性能。

Fundamental flaws of SIMD ISAs (2021)

作者: fanf2 | 评分: 99 | 评论数: 13 | 发布时间: 2025-04-24 14:42
文章摘要

本文讨论了SIMD（单指令多数据流）架构的特点和其在现代消费级CPU中的应用，特别是非谓词打包SIMD ISA。打包SIMD架构将多个数据元素打包进固定宽度的寄存器中，例如128位寄存器可包含16个字节或4个单精度浮点数。自1990年代中期以来，这种架构非常流行，包括x86（如MMX、SSE、AVX）、ARM（NEON）、POWER（AltiVec）等。 然而，这种架构存在几个缺陷。首先，固定寄存器宽度限制了硬件并行性的扩展，新一代SIMD需要新增指令和寄存器，导致ABI、操作系统和编译器需更新，且每代之间缺乏二进制兼容性。其次，流水线问题要求循环展开以避免流水线停滞，但这会降低代码密度并增加寄存器使用压力。最后，当处理数组元素数量不是寄存器元素数量的倍数时，需要额外的尾部处理逻辑。 这些缺陷影响了打包SIMD架构的性能和易用性，尽管其旨在提高数据处理性能。

评论摘要
主要讨论点：SIMD（单指令多数据）的优缺点及在不同硬件架构中的应用 不同观点： • TinkersW 认为 SIMD 的固定宽度是一个优点，因为它简化了代码编写，且可以在编译时确定数据结构的大小。他还指出，通过自定义容器可以有效处理尾部数据，而无需使用掩码或标量循环。 • xphos 强调了在 SIMD 中结合加载和地址寄存器递增指令的重要性，以避免冯·诺依曼瓶颈。他指出，许多自定义 SIMD 核心无法足够快速地发出指令，导致 CPU 引擎空转。 • pornel 提出，如果能够在执行编译机器代码时更新指令，或采用 SIMT（单指令多线程）模型，许多 SIMD 的问题可以得到解决。这种方法可以通过结构化程序来提高性能。 • sweetjuly 认为循环展开主要是为了摊销循环成本，而不是因为流水线问题。现代乱序核心在调度操作时，不论循环内复制数量，都会有相似的表现。 • dragontamer 指出，对于 GPU 而言，SIMD 的固定宽度和尾部处理并不是问题。GPU 可以有效处理分支发散问题，且灵活宽度的 SIMD 设计更难实现。 • bOb1029 更倾向于通过高层次的抽象（如 .NET 的 Vector）来处理 SIMD，而不是直接与底层架构交互。 • lauriewired 提到，ARM 的 SVE 和 RISC-V 的向量扩展都是长度无关的，这使得编译时只需为一个代码路径编译，避免了多二进制树的问题。 • freeone3000 指出 x86 SIMD 存在寄存器别名问题，需要明确告知处理器输入类型以正确处理溢出和符号。 • gitroom 表示，保持低层次控制是确保程序顺畅运行的唯一方法，质疑抽象的有效性。 • convolvatron 认为 SIMD 缺乏水平操作和广义的通信模型。 • timewizard 则认为，新的 SIMD 代需要新的操作码是合理的，且 x86 编码允许内存操作数，避免寄存器溢出。 补充讨论： • SIMD 指令更新和多版本问题的讨论（pornel）。 • 对不同硬件架构（如 GPU 和 x86）处理 SIMD 问题的对比分析（dragontamer）。 • 对抽象和高层次编程在处理 SIMD 中的作用的讨论（bOb1029）。 • 对 SIMD 在不同指令集架构（如 RISC-V 和 ARM）中的实现差异的讨论（lauriewired）。 争议焦点： • SIMD 的固定宽度是优点还是缺点（TinkersW 与 pornel、lauriewired 的不同看法）。 • 高层次抽象与低层次控制在处理 SIMD 时的有效性（bOb1029 与 gitroom 的不同实践经验）。 • 新的 SIMD 代需要新的操作码和控制逻辑是否是必要代价（timewizard 与 主要观点的对立）。

文章摘要

这篇文章研究了一个主导在线平台的内容审核对竞争的影响。作者通过一个外生冲击，即最大的成人内容平台删除非验证内容（占视频库80%），发现该政策导致平台流量在一个月内下降41%。然而，大部分流失的流量被其他竞争平台吸收，尤其是较少监管的边缘网站，其访问量在六个月内增加了55%，而主流平台仅增长10%。搜索引擎在流量重新分配中起关键作用，边缘平台通过搜索推荐和聚合器获得更多流量。主导平台则更积极地使用版权投诉移除竞争对手内容。研究强调，内容审核的不对称影响可以重塑市场竞争，推动用户流向较少监管的平台。
