ESA’s Moonlight programme: Pioneering the path for lunar exploration (2024)

文章摘要

ESA的Moonlight计划旨在建立欧洲首个专用于月球电信和导航服务的卫星 constellation，以支持未来400多项月球任务。该计划将实现如卫星导航、视频会议和文件共享等服务在月球上的无缝使用。Moonlight将由五颗卫星组成，其中一颗用于高数据率通信，四颗用于导航，通过三个地面站与地球连接，覆盖范围达40万公里。该项目优先覆盖月球南极，该地区因地形优势适合未来操作。 Moonlight的第一步是2026年发射的Lunar Pathfinder卫星，作为后续完整星座的先导。随后，Moonlight服务将逐步部署，计划在2028年底开始初步运行，2030年全面运行。ESA正与NASA和JAXA合作制定LunaNet标准，以确保兼容性，并计划在2029年进行首次月球导航互操作性测试。此外，ESA还在考虑未来的火星通信和导航基础设施（MARCONI），利用Moonlight的经验和技术。Moonlight的启动仪式在米兰国际宇航大会上举行，标志着欧洲在支持月球商业市场和国际合作方面迈出了关键一步。

The impact of file position on code review

作者: whatever3 | 评分: 53 | 评论数: 17 | 发布时间: 2025-07-17 18:14
文章摘要

该文章探讨了文件排序对代码评审结果的影响。通过分析GitHub上219,476个Pull Requests的评审评论，以及一项有106名参与者的在线实验，研究发现：文件在PR中较早出现时，会收到更多评论，且文件位置会影响缺陷检测效果。具体而言，对于某些缺陷，若文件排在最后，参与者发现缺陷的概率降低64%。文章建议代码评审工具应考虑文件排序对评审质量的影响。研究结果在ESEC/FSE '22会议上发表。

评论摘要
主要讨论点：项目中的文件/文件夹结构设计及其在代码审查中的影响 不同观点： • kevinsync认为，文件/文件夹结构类似于城市规划，应该设计成具有美学和人类易于理解的空间组织，方便人们找到所需内容。他对云存储服务尝试改变或抽象化深层文件系统树结构的做法持批评态度。 • Brajeshwar支持这种观点，并分享了自己在团队中成功应用良好命名和结构化约定的经历，强调了长期维护项目时命名和结构的重要性。 • jsbg指出，在PR审查中，过多的前期评论可能导致后续文件得不到充分关注，建议保持PR简短以避免此类问题。 • analog31通过音乐课程的例子说明，审查过程中不一定需要完整地查看所有内容，重点是培养自我批评和改进的能力。 • semperos的同事开发了一个随机化文件审查顺序的插件，以应对文件审查顺序对审查质量的影响。 • progbits习惯于从高层次的变更开始审查，如架构或接口变更，然后逐步深入到实现细节，这种方法与传统的自顶向下审查方法不同。 • slongfield希望GitHub代码审查能够优先显示头文件（.h）而非实现文件（.cc），以提高审查效率。 • taeric质疑文件顺序对审查质量的影响，认为基本评论和模式可以在早期提出，后续文件的审查可以由开发者自行完成。 • aerostable_slug开玩笑说可以将恶意代码放在“后期”审查的文件中，暗示审查顺序可能带来的潜在风险。 • MarkusQ则表示自己总是优先审查包含错误的文件，以确保解决关键问题。 • jpalawaga的团队在审查中会明确指出变更的核心文件，帮助审查者快速理解变更内容，但也有人认为让审查者自行理解变更可能更有益。 • gavinhoward对相关论文表示欣赏，认为其帮助了自己正在设计的工作，尽管并非突破性成果。 • deckar01偏好小而自包含的提交，但对基于行的GUI工具不满，建议训练LLM来分解提交。 • breatheoften强烈反对将源文件视为无序blob，认为这严重影响了读者快速理解代码库和独立推断变更的能力。 • Daviey表示这一角度未曾考虑过，但会更加 diligent，感谢分享。 补充讨论： - 文件/文件夹结构设计在团队合作和长期项目维护中的重要性。 - PR审查顺序对审查质量和效率的影响，包括审查者习惯和策略的差异。 - 审查过程中对高层次变更和细节实现的不同关注点。 - 工具和插件在提高代码审查效率中的潜在作用。 - 对代码组织和审查顺序带来的潜在安全风险的关注。

文章摘要

2023年夏天，英国林肯郡出土了一个罗马十二面体。这种十二面青铜器自1739年首次发现以来，其用途一直令考古学家困惑不已。这些文物可追溯至公元二至四世纪，主要发现于罗马帝国西北部，包括英国、法国、德国等地区。十二面体每个角上都有一个小球，每个面有一个不同直径的孔。尽管已有许多理论推测其用途，如武器、装饰、测量工具或宗教象征物，但均未得到确认。考古学家迈克尔·根根伯格认为，十二面体可能与古希腊哲学中的宇宙象征有关，尤其是柏拉图和毕达哥拉斯的思想，可能作为一种护身符或仪式用品。最有可能的解释是其与凯尔特传统和德鲁伊教有关。

Mistakes Microsoft made in the Xbox security system (2005)

文章摘要
