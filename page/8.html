Kelp – simple replacement for homebrew on macOS

作者: amai | 评分: 74 | 评论数: 15 | 发布时间: 2025-05-19 14:55
文章摘要

Kelp 是一个用 Go 编写的简单工具，作为 Homebrew 的替代品，用于在 MacOS 上安装二进制包。它解决了 Homebrew 公式等待和多电脑同步更新问题，支持同时安装多个包（即将支持）。用户可以通过 releases 页面下载安装，配置文件位于 `~/.kelp/kelp.json`，默认安装路径为 `~/.kelp/bin`。Kelp 支持指定版本安装、手动升级、检查更新等功能。若包不在 GitHub releases 中，用户可直接提供 HTTP(S) 链接进行添加。当前 Kelp 主要为 MacOS 设计，Linux 支持尚未实现。如遇 GitHub API 限流，可设置 GitHub 令牌环境变量解决。项目以满足个人工作流为主，功能请求一般不被接受。

Spaced repetition systems have gotten better

作者: domenicd | 评分: 926 | 评论数: 77 | 发布时间: 2025-05-18 11:42
文章摘要

文章主要介绍了**间隔重复系统（Spaced Repetition Systems, SRS）**在提升长期记忆方面的应用，特别是通过一种新的算法**FSRS**（Free Spaced Repetition Schedule）来优化学习效率。传统的间隔重复系统（如SuperMemo-2）依赖固定公式决定复习间隔，当用户答错时会重置间隔，这种方法较为机械且可能导致挫败感。而FSRS利用机器学习技术，根据每张记忆卡的难度、记忆稳定性及遗忘速度等因素动态调整复习时间，更精准地在用户即将遗忘时进行测试，从而提高学习效率并减少每日复习负担。这种新算法通过预测记忆卡何时会降到90%的回忆概率来安排最佳复习时间，使得学习过程更加高效和个性化。

Programming in Martin-Lof's Type Theory: An Introduction (1990)

作者: todsacerdoti | 评分: 51 | 评论数: 1 | 发布时间: 2025-05-17 06:30
文章摘要

《Programming in Martin-Löf's Type Theory: An Introduction》由Bengt Nordström、Kent Petersson和Jan M. Smith合著，1990年由牛津大学出版社出版，现已绝版。本书介绍马丁-勒夫类型理论及其在编程中的应用，全书共200页，提供Postscript和PDF格式下载。书中内容涵盖类型理论的基础概念及其在计算机科学中的实践，适合对逻辑和类型理论感兴趣的研究者与学生。

评论摘要
主要讨论点：Martin-Löf类型论是否是当今人们使用的理论基础，还是只是一个未实现的有趣想法。 不同观点： • 观点一：Martin-Löf类型论是现代许多技术的基础 - 论据：一些人认为Martin-Löf类型论确实是当今许多技术的基础，特别是在编程语言理论和形式化验证领域。例如，像Haskell和Coq这样的语言都受到了类型论的深刻影响。 - 例子：依赖类型编程、形式化验证工具以及Agda语言等都基于或受到类型论的启发。 • 观点二：Martin-Löf类型论只是一个有趣的理论，未完全实现 - 论据：另一些人认为尽管Martin-Löf类型论在理论上很有趣，并且在某些领域有应用，但并没有成为主流或广泛应用的理论基础。 - 例子：工业界大多数软件开发并不直接使用类型论，而是依赖于更为传统和实用的编程范式。 • 观点三：类型论的影响是间接的 - 论据：还有人认为Martin-Löf类型论的影响是间接的，它启发了其他理论和技术的发展，这些技术在现代计算中找到了应用。 - 例子：类型论启发了诸如Homotopy类型论（HoTT）等新研究方向，这些方向在学术界有重要影响，但未必直接用于工业界。 补充讨论： - 争议焦点在于Martin-Löf类型论的实际应用范围和影响力。 - 支持者强调其在学术和特定技术领域的深远影响，批评者则指出其在实际工业应用中的局限性。 - 讨论中提到了具体技术和语言（如Haskell、Coq、Agda）作为论据，这表明实际应用的案例在支持和反对观点中都扮演了重要角色。

科学家通过设置在Jicarón岛的摄像陷阱发现，白脸卷尾猴（Cebus capucinus imitator）的雄性个体携带了婴儿吼猴（Alouatta palliata coibensis），起初以为是同类婴儿，但颜色差异引起研究人员的注意。进一步观察显示，这是一只吼猴幼崽，且不止一个个案，共有四只年轻雄性卷尾猴在15个月内绑架了至少11只吼猴幼崽。卷尾猴并未表现出照顾、玩耍或食用这些幼崽的行为，研究人员怀疑这是一种“文化时尚”，可能与Jicarón岛独特的生态条件有关。由于吼猴种群濒临灭绝，理解这种行为对保护工作至关重要。目前，绑架原因尚不明确，但这种异常行为引发了广泛讨论。

评论摘要

作者: e-topy | 评分: 146 | 评论数: 38 | 发布时间: 2025-05-19 10:12
文章摘要
