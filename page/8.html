文章摘要

BreakerMachines 是一个为 Ruby 和 Rails 设计的现代电路断路器库，具有线程安全、支持异步和纤维（fiber）、内置回退机制、高效内存使用和监控等特点。它基于 state_machines 构建，支持对分布式系统的保护，防止级联故障。该库提供对冲请求、多后端支持、百分比阈值、动态断路器和丰富的回调与检测功能。此外，它还集成了 ActiveSupport::Notifications，并提供详细的文档和多种测试指南。BreakerMachines 旨在解决微服务架构中的常见问题，如过度重试导致的自我 DDoS 攻击，帮助开发者构建更健壮的系统。

Writing Bounds-Safe Code in C with Arrays

文章摘要

本文讨论了如何在C语言中使用数组编写边界安全的代码，避免指针运算带来的错误。作者建议使用数组类型代替指针运算，因为数组类型自带长度信息，编译器可以在静态数组的情况下检测越界错误。对于运行时长度数组，可以通过`-fsanitize=bounds`在运行时检测越界。文章还介绍了如何使用`array_slice`宏来安全地选取子数组，并讨论了C语言中可变长度类型在结构体和函数返回中的使用限制。最后，作者提到了一些未解决的问题和可能的解决方案，如引入依赖类型和C++的尾随返回类型。作者还提供了一个实验性库以探索这些想法。
