Show HN: SQL-tString a t-string SQL builder in Python

作者: pgjones | 评分: 81 | 评论数: 14 | 发布时间: 2025-05-16 12:48
文章摘要

SQL-tString 是一个用于构建 SQL 查询的 Python 库，类似于 f-string，但能防止 SQL 注入。它通过 `t-strings` 来插入变量，并将这些变量转换为 SQL 占位符，同时支持预定义的表和列名。使用 `sql_context` 可以限制允许的列和表名，防止注入攻击。如果变量设为 `Absent`，库会自动移除相关参数，适用于可选更新或条件语句。此外，还支持 `IsNull` 和 `IsNotNull` 来处理 SQL 中的 `NULL` 条件。默认使用 `qmark` 参数样式，但也支持其他如 `asyncpg` 样式。对于 Python 3.12 和 3.13，可通过 `locals()` 使用该库。该项目基于 MIT 许可证，目前有 43 个星标。

评论摘要
主要讨论点：T-SQL字符串模板的使用及其相关功能和安全性 不同观点： • throwaway127482认为，对于不同部分的查询需要不同的列集，当前设计可能需要提供子查询中所有支持的列的超集，这看起来有些危险。 • hombre_fatal赞赏该功能，认为它可以避免传统方式中通过多个if语句构建where子句的复杂性，使得查询语句更直观，减少调试困难。 • bvrman（sqlbind的作者）指出，简单查询可以通过其他方式编写，但动态查询（根据条件删除部分查询）是一个真正的问题，并认为该解决方案非常巧妙。 • schultzer关注SQL解析器的实现，建议基于BNF语法构建词法分析器和解析器，并进行一致性测试。 • caturopath解释了`sql_context(columns="x")`的用法，并指出columns是一个字符串集合，可能导致误解。 • jitl关心SQL重写的机制，尤其在处理非标准SQL功能和复杂查询时，同时询问是否支持模板嵌套。 • badmonster询问如何在不使用手动字符串拼接的情况下，安全地组合查询片段，特别是条件构建WHERE子句或JOIN。 • ilyagr建议允许类似Rust的`format!`功能，通过`sql(t"SELECT {}", a - 1)`实现动态SQL构建。 • bencyoung认为Absent功能可能导致误删WHERE子句，造成潜在危险。 • sirfz指出T-SQL字符串强化了参数化查询，并可能用于构建统一的SQL客户端接口。 • owlstuffing提倡语言应内置类型安全的SQL操作，提到Java通过Manifold项目实现这一目标。 • 90s_dev赞赏该库但批评了使用词法作用域进行占位符查找的设计，认为应通过显式字典传递参数。 补充讨论： • 争议焦点在于Absent功能的安全性，部分用户担心误删重要查询部分。 • 另一个焦点是T-SQL字符串中占位符的处理方式，部分用户认为词法作用域设计不理想，建议使用显式字典传递参数。 • 用户对SQL重写和动态查询构建的功能表示关注，尤其是处理复杂查询时的安全性和可控性。 • 不同用户对T-SQL字符串模板的功能有不同的期待，包括对简单查询和复杂查询的支持程度。

Energy drinks linked to rise in colorectal and blood cancer

作者: _xerces_ | 评分: 36 | 评论数: 7 | 发布时间: 2025-05-17 15:06
文章摘要

一项由纽约研究人员进行的新研究发现，常见于能量饮料中的牛磺酸可能促进白血病细胞生长和增殖。发表在《自然》期刊上的研究表明，牛磺酸为白血病细胞提供能量，通过糖酵解过程加速癌细胞繁殖，使病情恶化。研究使用携带SLC6A6基因的小鼠和人类白血病细胞样本，发现该基因将骨髓中的牛磺酸转移至癌细胞。尽管牛磺酸对身体有天然益处，但过量可能加剧白血病，并可能与其他癌症有关。研究人员建议谨慎考虑牛磺酸补充剂在癌症治疗中的使用，并呼吁进一步研究其对其他癌症的影响。

评论摘要
主要讨论点：关于一项研究是否支持“牛磺酸与白血病细胞生长相关”的结论，以及对该研究结果的解读和更广泛的科学研究环境的影响。 不同观点： • [fabian2k] 认为文章标题误导，研究实际上只是发现牛磺酸受体在白血病细胞中起到调节糖酵解的作用，而非白血病细胞直接依赖牛磺酸获取能量。他强调牛磺酸和葡萄糖在细胞代谢中的不同角色，并指出研究结果不应被过度解读为牛磺酸导致癌症恶化。 • [Legend2440] 则解读研究表明牛磺酸通过糖酵解帮助白血病细胞更快繁殖，虽然不直接导致癌症，但可能加速已有癌症的扩散。这与[fabian2k]的观点有一定冲突，后者认为“白血病细胞依赖牛磺酸”的说法不准确。 • [_xerces_] 指出该研究仍在进行中，并提到一个假设，即牛磺酸通过影响肠道菌群进而可能损害肠粘膜，暗示研究的潜在长期影响尚待观察。 • [monster_truck] 对研究中使用小鼠模型表示不满，认为在解读研究结果时应明确指出“在小鼠中”的结果，以免误导大众。 • [dynm] 认为研究并非简单的观察性研究，而是有实验支持，包括在小鼠和人类白血病细胞系中的实验结果，但他也不认为现有证据足以证明牛磺酸导致癌症，只是建议出于谨慎考虑可能避免摄入牛磺酸。 • [ck2] 认为不应完全忽视牛磺酸等补充剂的潜在危险，但同时强调微塑料和永久化学物质对健康的更大威胁，暗示牛磺酸与癌症的关联可能被过度关注。 补充讨论： • [BenFranklin100] 关注研究背后的科学资助环境，指出该研究依赖的先进技术（如scRNA-seq和CRISPR）得益于NIH的资助，而当前某些政治动向可能对生物医学研究产生负面影响。 争议焦点： • 主要争议在于研究结果的解读：是否能证明牛磺酸直接或间接影响白血病细胞的生长和扩散，以及这种影响是否足以建议大众避免摄入牛磺酸。

文章摘要

Erlang-RED 是一个基于 Erlang 的可视化低代码编程环境，旨在替代 Node-RED 的 NodeJS 后端，实现与其流程代码的 100% 兼容（JavaScript 功能节点除外）。该项目利用 Erlang 的天然并发和消息传递优势，提升 Node-RED 的性能和并发处理能力。开发过程采用基于测试流的开发策略，通过一组测试流确保节点功能与 Node-RED 匹配。当前支持部分节点和功能，如 `catch`、`change`、`debug`、`delay`、`exec`、`function` 等，但一些复杂功能如动态延迟、多输出端口、JSONata 高级功能等尚未支持。项目架构体现了节点间的紧密联系，以确保正确的节点交互和异常处理。

文章摘要

《Blood in the Machine》一文揭示了硅谷和美国共和党（GOP）联手推动在预算协调法案中加入修正案，旨在禁止各州制定任何监管人工智能（AI）的法律。该修正案由肯塔基州议员Brett Guthrie提出，禁止各州在十年内对AI技术实施任何法律或监管措施。此举旨在防止州政府如加利福尼亚州对AI企业施加限制，进而保护硅谷巨头如OpenAI、特斯拉等的商业利益。与此同时，多位科技巨头如萨姆·阿尔特曼、埃隆·马斯克等人在沙特阿拉伯与特朗普会面，签署了数十亿美元的AI相关商业协议。这一行动被批评为严重违背民主原则，意图让AI行业不受公众监管影响，进一步巩固其在全球的影响力。文章强调，这不仅是立法上的操控，更是对公众参与技术监管权利的剥夺。
