文章摘要

这篇文章介绍了 yes-we-scan.app 网页应用的开发背景和技术原理。作者为了让旧 USB 扫描仪重新可用，利用 v86 在浏览器中模拟 x86 机器运行 Alpine Linux 和 SANE 扫描软件。技术架构包括：用 C 程序连接扫描仪并传输数据，通过 USB/IP 将 USB 数据转为 TCP 包，用 tcpip.js 处理网络协议栈，最后通过 WebUSB API 连接实体 USB 设备。扫描数据实时压缩为 JPEG 或 PNG 格式。该应用理论上支持数百款扫描仪型号，目前仅在作者的 Canon 扫描仪上测试过。

这是 Flipper One 设备的技术规格文档。主要内容包括： **硬件规格**：尺寸 155×67×40mm，配备 256×144 单色屏幕、触摸板和多个按键。 **核心配置**：主 CPU 为 Rockchip RK3576（8核，含 GPU 和 6 TOPS NPU），MCU 为树莓派 RP2350B 双核，8GB RAM，64GB 存储，7000mAh 电池。 **接口丰富**：3个 USB 口（含 USB-C PD 充电）、HDMI 2.1（支持 4K@120Hz）、双千兆网口、3.5mm 音频、microSD 卡槽、SIM 卡槽。 **扩展能力**：背部 M.2 B-key 接口支持 PCIe/USB/SATA 等多种协议，可扩展存储或通信模块。 **连接**：Wi-Fi 6（MT7921）、蓝牙 5.2。 设备仍在开发中，规格可能调整。

Gnutella: A Protocol Outliving the World That Created It

作者: rickcarlino | 评分: 7 | 评论数: 0 | 发布时间: 2026-05-22 02:24
文章摘要

Gnutella是一个点对点文件共享协议，诞生于2000年代初期。它作为AOL内部项目泄露后，因去中心化设计无法被关闭，迅速获得数百万用户。用户使用它主要是为了下载MP3音乐文件，而非出于对技术本身的兴趣。 协议的核心功能是点对点搜索引擎：用户通过客户端（如LimeWire）连接到网络节点，输入搜索关键词，查询在网络中传播并返回结果，然后直接从其他用户电脑下载文件。 Gnutella在2000-2010年代盛极一时，随后因音乐产业变化、流媒体兴起和用户习惯改变而衰落，但协议至今仍在运行。它证明了去中心化技术可以被普通用户大规模采用，只要能解决实际问题。

All the bugs they found

文章摘要

这篇文章讲述了作者开发的WASM运行时Epsilon被AI代理发现的安全漏洞。AI发现了20多个漏洞，多数是DoS攻击，但有几个是严重的沙箱逃逸漏洞，允许恶意WASM模块突破隔离访问其他模块的私有状态。 文章详细介绍了三个有趣的漏洞： 1. **零值非空漏洞**：Go的clear()函数将funcref局部变量初始化为0而非null(-1)，导致攻击者可调用存储索引0处的私有函数。 2. **幻影块参数漏洞**：验证器在处理带参数的block时错误地消耗了栈顶值，使得null funcref下方的i32常量0暴露出来，被误当作有效函数引用调用。 3. 第三个漏洞文章未完整展示。 这些漏洞源于运行时依赖验证器的类型检查，执行时funcref用int32表示，安全性完全依赖验证阶段的正确性。

评论摘要
