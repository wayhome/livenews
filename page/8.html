ToyDB rewritten: a distributed SQL database in Rust, for education

作者: erikgrinaker | 评分: 123 | 评论数: 8 | 发布时间: 2025-05-11 19:49
文章摘要

toyDB是一个用Rust编写的分布式SQL数据库，作为教育项目从头构建。它使用Raft算法实现线性一致的状态机复制，支持基于MVCC的快照隔离ACID事务，并提供可插拔的存储引擎（BitCask和内存后端）。其查询引擎基于迭代器，支持启发式优化和时间旅行查询，SQL接口包括连接、聚合和事务等功能。项目旨在简明易懂，而非追求性能、可扩展性和高可用性。使用Rust编译器可以构建并启动一个本地五节点集群，并通过命令行客户端执行SQL操作。toyDB的架构类似于典型的分布式SQL数据库，主要通过Golden脚本进行测试，并附带一个用于运行各种工作负载的基准工具。

Kosmos 482 crashes back to Earth, disappearing into Indian Ocean after 53 years

作者: susam | 评分: 5 | 评论数: 0 | 发布时间: 2025-05-13 08:47
文章摘要

苏联太空探测器Kosmos 482在发射53年后于2023年坠落地球，掉入印度洋，未造成损害或人员受伤。该探测器原计划作为金星探测计划Venera的一部分，但由于火箭故障而滞留在地球轨道。其主要部分于1981年重新进入大气层，而降落装置则在轨道上停留了超过50年。Kosmos 482设计用于承受金星大气，若其1,091磅的降落装置被发现，可能仍保持完整。根据联合国条约，任何残骸仍归俄罗斯所有。这一事件凸显了太空垃圾对地球构成的潜在风险。

Show HN: The missing inbox for GitHub pull requests

作者: pvcnt | 评分: 23 | 评论数: 4 | 发布时间: 2025-05-12 17:29
文章摘要

Mergeable 是一个为 GitHub 拉取请求（pull requests）提供更好管理的工具。其主要功能包括：通过灵活的搜索查询将拉取请求组织成不同部分，数据存储在浏览器本地；支持键盘快捷键快速导航；可连接多个 GitHub 实例，包括 GitHub Enterprise；突出显示需要您操作的请求。该工具无需安装任何 GitHub 应用程序，并提供公共实例供使用，同时也支持自托管。文档和源码可在其官网和 GitHub 仓库中找到，项目基于 PnPM、Turborepo 和 Vite 构建，本地运行命令为 `pnpm run dev`。

评论摘要
主要讨论点：GitHub项目管理工具及其功能完善性 不同观点： • Jerrygoyal认为GitHub的项目功能已经解决了他遇到的问题，暗示GitHub现有工具能有效满足项目管理需求。 • Rokkamokka支持GitHub项目工具，但也提到他们在工作中自行开发了一个类似的仪表板工具，用来跟踪团队的审查状态，暗示GitHub缺乏类似的内置功能是个错失的机会。 • Dvektor对该想法表示赞同，并指出当前公共实例上存在TLS证书问题，显示出对功能实现细节的关注，同时表示会持续关注项目进展。 补充讨论： • 讨论中提到了自行开发工具的实践，反映出部分用户可能需要更个性化的功能，而GitHub默认功能未能完全满足这些需求。 • 存在技术问题（如TLS证书问题）也被提及，表明用户对工具的稳定性和可用性有一定期望。 • 总体上，争议焦点在于GitHub是否充分提供了用户所需的项目管理和跟踪功能，部分用户认为有改进空间。
