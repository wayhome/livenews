Don't Guess My Language

作者: e-topy | 评分: 146 | 评论数: 38 | 发布时间: 2025-05-19 10:12
文章摘要

文章主要批评了使用IP地理定位来决定网页显示语言的做法，认为这种方法不准确且导致用户困扰。IP地址只能显示请求来源地，不能反映用户偏好的语言，尤其在使用VPN、旅行或多语言国家的情况下会出错。文章强调国家和语言没有一对一的对应关系，例如比利时、瑞士、印度和加拿大等国有多种官方语言。正确的做法是读取浏览器发送的"Accept-Language"头部信息，它准确反映了用户的语言偏好。文章建议尊重这一信号，并允许用户自行更改语言设置。若要使用地理定位，只能用于货币、运输和法律等事项，而非语言选择。最后，文章强调软件应尊重用户的偏好，而不是随意猜测。

文章摘要

Kelp 是一个用 Go 编写的简单工具，作为 Homebrew 的替代品，用于在 MacOS 上安装二进制包。它解决了 Homebrew 公式等待和多电脑同步更新问题，支持同时安装多个包（即将支持）。用户可以通过 releases 页面下载安装，配置文件位于 `~/.kelp/kelp.json`，默认安装路径为 `~/.kelp/bin`。Kelp 支持指定版本安装、手动升级、检查更新等功能。若包不在 GitHub releases 中，用户可直接提供 HTTP(S) 链接进行添加。当前 Kelp 主要为 MacOS 设计，Linux 支持尚未实现。如遇 GitHub API 限流，可设置 GitHub 令牌环境变量解决。项目以满足个人工作流为主，功能请求一般不被接受。
