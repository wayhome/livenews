**tinyio** 是一个简化版的 Python 事件循环库，仅约200行代码，旨在解决 **asyncio** 的一些复杂性和错误处理问题。它适用于简单场景，当任何协程出错时，整个事件循环会崩溃，所有协程都会取消。与 **asyncio** 不同，它使用 **yield** 而不是 **await** 来暂停和恢复协程。 ### 主要特点： 1. **简单性**：没有 **futures** 或 **tasks**，API 非常少，包括 **Loop**、**run_in_thread**、**sleep** 和 **CancelledError**。 2. **错误处理**：一个协程出错会取消所有协程，错误会传播到整个事件循环和线程中运行的同步操作。 3. **嵌套支持**：允许嵌套事件循环。 4. **线程支持**：通过 **run_in_thread** 可以在线程中运行同步函数，并返回可被 **yield** 的协程。 5. **语法**：使用 **yield** 来暂停协程，支持等待单个或多个协程。 ### 示例： ```python import tinyio def slow_add_one(x: int): yield tinyio.sleep(1) return x + 1 def foo(): four, five = yield [slow_add_one(3), slow_add_one(4)] return four, five loop = tinyio.Loop() out = loop.run(foo()) assert out == (4, 5) ``` ### 安装： ```bash pip install tinyio ``` ### 为什么用 **yield** 而不是 **await**： 因为 **await** 语法需要额外定义如 **tinyio.Task** 这样的类，而 **yield** 更简单直接。
