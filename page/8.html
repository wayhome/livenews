Ubuntu Adopts Chrony and NTS for Secure Network Time

作者: ulrischa | 评分: 3 | 评论数: 0 | 发布时间: 2025-06-18 19:26
文章摘要

Ubuntu 25.10 将使用 Chrony 取代 systemd-timesyncd 进行时间管理，并默认启用网络时间安全（NTS），以增强安全性。NTS 比传统的网络时间协议（NTP）更安全，因为它通过 TCP 端口 4460 和 NTP 的 UDP 端口 123 进行时间同步，确保与时间服务器建立安全连接，防止恶意服务器提供错误时间。此更改仅在新安装的 Ubuntu 25.10 中默认启用，而从 Ubuntu 25.04 升级的用户将仍使用 systemd-timesyncd，但可以通过命令手动切换到 Chrony 和 NTS。总体而言，这一改动提升了系统安全性，对日常使用影响不大。

本文是一位来自汉堡的游客首次访问慕尼黑后的感想。他对比了两座德国标志性城市，强调了慕尼黑作为巴伐利亚王朝首都的皇家背景及其丰富的文化历史，如维特尔斯巴赫家族的影响、路德维希一世对艺术和教育的贡献，以及慕尼黑众多的博物馆和宫殿，如纽芬堡宫和慕尼黑王宫。相比之下，汉堡由于历史上的自由贸易城市地位，发展得更具多样性和独立性，宗教和建筑风格也更为简约。作者指出，两座城市的历史和宗教差异塑造了它们各自独特的城市风貌，慕尼黑的富裕和文化积淀尤为显著。
