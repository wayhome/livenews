一项初步研究发现，嚼口香糖可能会将数百至数千个微塑料颗粒释放到唾液中并被摄入。美国化学学会（ACS）2025年春季会议上发表的这项研究显示，无论是天然还是合成口香糖，都会在咀嚼过程中释放微塑料。研究测试了五种合成口香糖和五种天然口香糖，结果发现每克口香糖平均释放约100个微塑料，有些甚至高达600个。一个大的口香糖可能释放多达3000个塑料颗粒。如果按每人每年嚼160至180根口香糖计算，可能摄入约30,000个微塑料。研究还发现，微塑料主要在前两分钟内脱落，且天然和合成口香糖的释放量相似，均含有聚烯烃等塑料成分。研究人员强调，虽然尚未确定微塑料对人体的危害，但建议人们采取措施减少暴露。

Nōdo – Call Node.js from Ruby

作者: namiwang | 评分: 4 | 评论数: 0 | 发布时间: 2025-03-26 02:16
文章摘要

**Nodo** 是一个允许从 Ruby 调用 Node.js 的工具，通过在一个长期运行的 Node 进程中执行 JavaScript 代码，避免每次调用时重新初始化 JS 对象。它使用 Unix 套接字进行进程间通信，性能优于传统的 process/eval 方法。 **主要功能**： 1. **定义 JS 函数**：像定义 Ruby 方法一样定义 JS 函数。 2. **支持异步函数**：从 Ruby 同步调用 JS 异步函数，Ruby 调用会阻塞直到 JS 函数resolve。 3. **使用 npm 模块**：通过 `require` 或 `import` 加载 npm 模块。 4. **动态导入 ES 模块**：支持动态导入 ES 模块。 5. **定义 JS 常量**：可以在 Ruby 类中定义 JS 常量。 6. **初始化时执行自定义 JS**：可以在类初始化时执行自定义 JS 脚本。 7. **继承**：子类可以继承父类的函数、常量、依赖和脚本，但函数可以被重写。 8. **延迟函数定义**：函数代码可以在对象实例化时生成，而非类定义时。 **安装**：在 Gemfile 中添加 `gem 'nodo'` 并确保 Node.js 已安装。
