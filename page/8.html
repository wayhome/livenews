文章摘要

Gemini CLI GitHub Actions是一款免费、强大的AI编码辅助工具，适用于团队协作。它可以作为自主代理自动处理常规编码任务，也可以作为按需协作伙伴，接受任务委派。该工具通过触发事件（如新问题或拉取请求）在后台异步工作，利用项目全 context 自动处理任务，如智能问题分类、加速拉取请求审查和按需协作等。它具备企业级安全和控制，支持无凭证认证、细粒度控制和完全透明。现已推出beta版，全球可用，存储库位于google-github-actions/run-gemini-cli。用户可自定义工作流并贡献代码，免费配额丰富，支持Google AI Studio及Vertex AI等。

Capela是一个未发布的分布式编程环境，旨在通过将应用逻辑和存储统一在一个系统中来简化开发。它使用增强了复杂类型系统的Python方言，支持自动复制和持久化分布式类实例，方法调用具有强可串行化语义。Capela程序状态直接持久化，允许随时间修改，类似于对象数据库和智能合约。系统分为多个分区，每个分区是单线程状态机，通过跨分区事务协议进行交互。用户通过HTTP JSON API调用方法，例如对键值对的设置和获取操作。在开发过程中，Capela利用Jepsen测试库验证其安全性和容错性，通过在集群中注入各种故障进行测试，如进程终止、网络分区和时钟操作等。测试显示，Capela在早期开发阶段表现良好，但仍有一些典型问题待解决。
