Gig Companies Violate Workers Rights

作者: Improvement | 评分: 120 | 评论数: 13 | 发布时间: 2025-05-12 13:13
文章摘要

根据人权观察（Human Rights Watch）2025年发布的报告《陷阱：美国平台工作中的算法、工资和劳动剥削》，美国主要数字劳工平台（如Amazon Flex、DoorDash、Uber等）将零工工人错误分类为独立承包商，剥夺其劳动权益。这些公司使用不透明的算法分配工作并决定工资，导致工人在完成工作前无法得知收入。工人们往往赚取低于最低工资的收入，且面临不稳定的工资和工作随时被终止的风险。由于平台算法不透明，工人难以挑战有关其工作或工资的决定。此外，工人还需自行承担车辆、保险等费用，进一步加剧经济不安全感。尽管这些公司市值巨大，但工人们仍面临低工资和缺乏社会保障的困境。

评论摘要
主要讨论点： gig经济中的劳动者权益和平台责任分配问题 不同观点： • **[adocomplete]** 认为Uber等平台在车费分配中拿走了过高的比例，司机承担了所有的工作和车辆损耗，但收入不到总费用的一半，这种分配不合理。 • **[n_ary]** 指出，gig经济中的劳动者往往为了生计不敢对平台提出异议，因为他们处于绝望的境地，而平台则掌握了绝大多数的议价权，这种权力失衡很难改变。 • **[flkiwi]** 强调gig公司对劳动者权利的漠视，平台在出现问题时总是推卸责任，且消费者缺乏有效的投诉渠道。但同时也提到一些公司开始推出更负责任的服务模式。 • **[ApolloFortyNine]** 认为平台算法的不透明是当前最需要解决的问题，虽然Uber已经显示了收入预估，但无法强制要求用户只接受 profitable 的订单。同时，劳动者有权选择通过缩短车辆寿命来换取当前收入。 • **[econ]** 提出应消除员工和企业家之间的区别，建议设定不同级别的最低工资，允许雇主通过支付费用来放弃某些福利，以激励短期合同的灵活性。 • **[SirMaster]** 认为gig工作本就不应被视为全职工作，这正是gig经济的初衷。 • **[ProllyInfamous]** 分享了自己在gig平台上的负面经历，指出平台对劳动者的不公平对待，并表示这种情况可能至今仍未改善。 补充讨论： • **[breakyerself]** 希望有一些非营利版本的gig平台。 • **[Extropy_]** 提出了“gig工作是否应被视为正式雇佣”的问题。 • **[guiriduro] 和 [qmr]** 的评论带有讽刺意味，对讨论中的某些显而易见的问题进行了调侃。 争议焦点： • gig经济中平台与劳动者之间的收入分配不均。 • 平台对劳动者权利的漠视和问题责任的推卸。 • 是否应通过立法或其他方式增加平台算法的透明度和公平性。 总体来看，讨论围绕gig经济中劳动者权益、收入分配及平台责任展开，不同参与者从各自经验和视角出发，提出了对现状的批评和改进建议。

Dart added support for cross-compilation

作者: Alifatisk | 评分: 63 | 评论数: 9 | 发布时间: 2025-05-08 13:15
文章摘要

`dart compile` 命令用于将 Dart 程序编译为目标平台的可执行文件或模块。通过子命令指定输出类型，包括： 1. **exe**：生成包含 Dart 运行时的独立可执行文件。 2. **aot-snapshot**：生成不含 Dart 运行时的 AOT 模块，需使用 `dartaotruntime` 运行。 3. **jit-snapshot**：生成 JIT 模块，包含中间代码和优化后的代码表示。 4. **kernel**：生成便携的中间代码模块。 5. **js**：生成可部署的 JavaScript 文件。 6. **wasm**（开发中）：生成 WebAssembly 二进制文件。 编译命令示例： ```sh dart compile exe bin/myapp.dart -o /tmp/myapp ./tmp/myapp ``` 支持跨平台编译，如为 Linux 系统编译： ```sh dart compile exe --target-os=linux --target-arch=x64 hello.dart ``` `dart compile` 取代了旧的 `dart2native`、`dart2aot` 和 `dart2js` 命令。开发时也可直接使用 `dart run` 命令运行程序。
