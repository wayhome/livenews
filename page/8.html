The Windows Subsystem for Linux is now open source

作者: pentagrama | 评分: 1562 | 评论数: 78 | 发布时间: 2025-05-19 16:14
文章摘要

微软在2025年5月的Build开发者大会上宣布，Windows Subsystem for Linux（WSL）正式开源。这个决定是多年努力的结果，WSL的代码已在GitHub上发布，供社区下载、修改和贡献。WSL由多个组件构成，包括命令行工具、服务和Linux内核相关部分等。虽然一些组件如Lxcore.sys和文件系统重定向驱动仍未开源，但其他如WSLg和WSL2的Linux内核早已开放。WSL最初在2016年发布，经历了从WSL 1到WSL 2的演变，逐步支持GPU、图形应用和systemd等功能。2021年，WSL从Windows代码库中分离并独立发布，最新版本为WSL 2.5.7。开源WSL旨在加速其发展，并感谢社区多年来的贡献和支持。
