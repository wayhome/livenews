“Language and Image Minus Cognition”: An Interview with Leif Weatherby

作者: Traces | 评分: 31 | 评论数: 3 | 发布时间: 2025-06-11 14:03
文章摘要

Leif Weatherby的著作《Language Machines》讨论了大型语言模型（LLMs）引发的理论问题，尤其是“剩余人文主义”（remainder humanism）这一概念。剩余人文主义指的是一种将人类能力与机器对立的思维模式，无论是AI怀疑论者如Emily Bender和Noam Chomsky，还是AI风险研究者，都陷入了这种对立。Chomsky等人认为语言本质是认知，而机器只是模仿。与此同时，另一派则过度吹捧AI，设想超级智能的到来，同样忽视了实际技术。Weatherby主张，应从法国结构主义视角重新审视语言和文化系统，LLMs并非解决认知与文化分离的工具，但能促使我们重新审视这一问题。他批评当前人文领域对语言研究的忽视，呼吁重新参与这一讨论。

评论摘要
主要讨论点：人类学习与大型语言模型（LLM）学习方式的比较，以及AI能力的局限性与未来发展 不同观点： • [roenxi的观点] 认为人类和大型语言模型在处理和分类语言或图像时使用数据的方式不同。尽管人类日常通过感官（如视听）接收大量数据，但与ChatGPT等模型的训练数据量相比，人类在字符识别上花费的时间较少，且人类的学习过程涉及更多的物理和社会背景。虽然LLM和人类的学习方式明显不同，但人类使用的数据量并不少。 • [joe_the_user的观点] 认为任何对AI的“明确限制”的批评最终都会被超越，因为AI会逐渐超越这些设定的基准。提出“剩余理论”（remainder theory），认为我们不应试图定义AI不能做的事情，因为这些限制最终会被克服。同时，认为那些试图提出AI的“积极理论”（positive theory）的人实际上是在创造一种虚幻的实质感，因为这些理论所描述的能力可能会很快被AI实现。 补充讨论： • [roenxi] 强调人类学习过程中的主动性和探索性（如追求新奇性），认为这是目前大型语言模型尚未具备的策略。 • [joe_the_user] 则侧重于AI能力的动态性和未来性，认为现在定义AI的局限性为时过早，因为这些局限性可能会随着技术进步而消失。 争议焦点：人类与AI在学习和处理信息上的本质区别以及AI未来是否能够完全超越这些区别。

When random people give money to random other people (2017)

作者: munificent | 评分: 119 | 评论数: 13 | 发布时间: 2025-06-13 16:49
文章摘要

这篇文章讨论了一个由Uri Wilensky提出的问题：在一个房间里有100个人，每人有100美元。每过一段时间，每个有钱的人会随机选择一个人并给他1美元。经过一段时间后，金钱的分布会如何变化？直觉上人们可能认为分布会趋于均匀，但模拟结果显示，财富不均会迅速出现并持续存在。 这种现象的原因在于，尽管过程是完全公平和随机的，但系统状态的图结构并非完全规则。大多数状态下，每个人的财富变化导致图的顶点连接度接近常数N。在没有破产的状态下，长期来看每个状态几乎等可能出现。然而，由于某些人几乎破产的可能性很高，实际分布中会出现极端不均，最富有者的预期财富大约为N log N。 文章还讨论了起始条件变化和连续近似的问题，并提到这与物理学中的玻尔兹曼分布计算类似。

评论摘要
主要讨论点：通过一个金钱分配的模拟实验讨论随机性和不平等的产生及其影响 不同观点： • Noelia-：认为随机性和时间会导致系统内出现不平等，即使规则完全公平。不平等并不总是由于某些人的错误行为，而是随机性长期作用的结果。因此，问题在于理解后应如何应对不平等。 • NooneAtAll3：对模拟中的数学部分提出质疑，指出游戏图节点出度和分布的计算可能有误，且认为模拟的“几乎稳定分布”缺乏理论依据，尤其是当有超过30%的“不良”节点时。 • dgan：提出如果让富裕的参与者专门给予最贫穷的参与者，而不是随机给予，系统是否会更加公平。 • thaumasiotes：质疑实验中N人拥有N^2美元的设定，认为N人拥有M美元可能更自然。同时指出长周期内每个状态等概率的描述有误，因为某些不平等分布状态会有更多可能性。 补充讨论： • pfortuny：用掷硬币的类比说明，经过多次试验后，结果偏离初始值且可能偏离较大，这与模拟中的不平等现象类似。 • k__：认为模拟中财富不平等迅速出现并持续存在，但个体的经济地位可能上下波动，这种现象仍然算是公平的。 • gnabgib：提到相关讨论，暗示该话题曾在其他平台上引起广泛讨论。 • staplung：提供Peter Norvig的相关研究笔记本链接，供进一步了解该模拟的数学和编程细节。 • wordglyph：建议引入信用机制，使没有钱的人也能继续参与分配，以期达到更均衡的结果。 • deadbabe：提议将该模拟设计成一个加密货币游戏，让玩家随机转移资金，并通过固定时间段的限制来保持公平性。 • MichaelRo：用税收和福利制度的类比来评论金钱随机转移的现象，暗示政府通过税收和福利再分配财富以保持社会公平。 争议焦点： • 数学模型的准确性：NooneAtAll3对模拟中的数学假设提出质疑，特别是节点的出度和分布问题。 • 不平等的解释和应对：Noelia-和dgan关注如何理解和应对模拟中出现的不平等现象，尤其是通过再分配机制。 • 模拟设定的合理性：thaumasiotes质疑实验初始条件设定的自然性和长周期状态概率描述的准确性。

GPU-accelerated Llama3.java inference in pure Java using TornadoVM

作者: pjmlp | 评分: 35 | 评论数: 0 | 发布时间: 2025-06-13 21:00
文章摘要

GPULlama3.java 是一个使用 TornadoVM 在 GPU 上加速执行 Llama3 推理的纯 Java 项目。它基于 Llama3.java，支持 Llama 3 系列模型（包括 3.1 和 3.2），并通过 TornadoVM 自动实现硬件加速。该项目旨在通过 JVM 的新特性（如 GPU 加速和向量加速）提升性能，目标是达到与最快的原生 CUDA 实现相当的性能。项目提供了在不同硬件（如 NVIDIA、Intel、Apple Silicon）上的性能数据，并给出配置指南。当前，Apple Silicon 上的性能受限于 OpenCL 驱动，未来计划加入 Metal 后端以优化性能。要运行该项目，需要 Java 21、TornadoVM 和 Maven 等工具。

文章摘要

文章讲述了作者如何通过理解电子游戏的成瘾机制来克服拖延症。作者多年来尝试了各种提高生产力的方法，但都效果不佳。通过观察自己在玩游戏时能够长时间专注，他开始研究游戏如何通过快速重复的“游戏循环”和即时强烈的“反馈”来吸引玩家。作者将这种机制应用到日常任务中，把任务分解成更小的微任务，并通过完成任务后立即给予反馈（如揉掉便签纸）来增强动力和成就感。最终，他使用热敏打印机打印待办清单，并结合游戏化的任务分解和反馈机制，成功改善了拖延问题。
