Pytest for Neovim

文章摘要

**pytest.nvim** 是一个为 Neovim 集成的 Python 测试插件，支持使用 **pytest** 进行测试，并包含 Docker 支持。该项目仍在开发中，未来会添加更多功能，并欢迎贡献。 ### 主要功能： - 运行当前缓冲区的测试：`:Pytest` - 查看测试输出：`:PytestOutput` - 绑定测试到当前缓冲区（保存时自动运行测试）：`:PytestAttach` - 解绑测试：`:PytestDetach` - 启用/禁用 Docker 支持：`:PytestEnableDocker` 和 `:PytestDisableDocker` ### 默认快捷键： - `TT`：运行 pytest - `Ta`：绑定 pytest 到缓冲区 - `Td`：解绑 pytest ### 配置： - Docker 支持可通过配置启用，包括容器名称、路径等。 - Django 支持需安装 **pytest-django** 扩展。 - 如果 Docker Compose 启用，将优先使用其配置。 ### 安装方法： 使用插件管理器如 **Lazyvim** 或 **Packer** 安装 **richardhapb/pytest.nvim**。 该插件允许在 Neovim 中直接运行 pytest 测试，并支持 Docker 容器内的测试执行。
