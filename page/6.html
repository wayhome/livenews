Using Tailscale with an OrbStack VM on macOS

作者: highpost | 评分: 66 | 评论数: 7 | 发布时间: 2026-05-25 22:10
文章摘要

这篇文章介绍了如何在 macOS 上使用 OrbStack 虚拟机配合 Tailscale 构建开发环境。主要步骤包括：通过 cloud-init 配置 Ubuntu VM，使用 Tailscale 认证密钥将 VM 加入 tailnet 网络，并启用 Tailscale SSH 实现远程访问。文章特别说明了 macOS 沙箱限制下如何通过 Keychain 安全存储认证密钥，以及如何配置访问控制列表（ACL）和标签来管理权限。配置完成后，用户可以通过 MagicDNS 或本地代理从任何地方 SSH 连接到 VM，无需暴露主机端口，还能直接使用 git 等工具进行远程操作。

评论摘要
主要讨论点：OrbStack 与 Tailscale 结合使用的实践经验和安全考量 不同观点： • **OrbStack 优势派**：认为 OrbStack 是 macOS 上最好的容器/VM 集成方案，网络、文件共享、SSH 都很便捷，远胜 Docker Desktop 和 Podman Desktop • **便利性应用派**：利用 Tailscale + OrbStack 实现多环境隔离（工作/家庭双 tailnet、多仓库实例互不干扰）、远程访问开发环境、跨设备查看仪表板等实用场景 • **安全顾虑派**：指出 OrbStack 的便利性建立在宽松的安全模型上，其默认配置缺乏真正的文件系统隔离；Tailscale 在 OrbStack 中更多是便利工具而非硬安全隔离 补充讨论： • **权限继承问题**：VM 中的 Tailscale 会继承宿主机用户权限而非 VM 标签设备权限，需断开宿主机连接才能实现预期的访问控制 • **最佳实践**：开发者们普遍采用 Docker/OrbStack 环境 + Tailscale sidecar 模式进行开发，便于环境复制和端口管理 • **近期改进**：OrbStack 最近才添加真正的文件系统隔离选项，之前的沙箱效果不理想

EU fines Temu €200M for allowing sale of illegal products

作者: jjp | 评分: 176 | 评论数: 27 | 发布时间: 2026-05-28 14:18
文章摘要

欧盟因中国电商平台Temu销售危险婴儿玩具和不合格充电器等非法产品，对其处以2亿欧元罚款。欧盟委员会称Temu未能识别和评估产品的系统性风险。调查发现大量充电器未通过基本电气安全测试，婴儿玩具含超标化学物质或存在窒息隐患。Temu需在8月28日前提交整改计划。Temu回应称不同意该决定，认为罚款不成比例，正在考虑应对方案。这是欧盟《数字服务法》实施以来第二起内容相关罚款。

评论摘要
主要讨论点：欧盟对Temu销售非法产品罚款2亿美元引发的争议 不同观点： • **支持Temu存在价值**：Temu填补了市场空白，欧洲本地中间商选择有限且价格高昂，特别是电子元件等商品。本地商家存在"不标价"的势利做派，实际也是从亚洲进口转售 • **质疑监管有效性**：罚款金额对大公司来说只是"轻拍手指"，不足以改变行为。欧盟的监管方式是"打地鼠"游戏，注定失败。应关注合规期限而非罚款本身 • **强调安全风险**：危险产品可能致命，如劣质电动车电池已引发多起火灾。充电器、婴儿玩具等产品存在严重安全隐患 • **认为处罚不公**：Amazon和eBay也有同样问题但未被罚款，都是同一批供应商在做代发货 • **主张彻底封禁**：Temu涉及数据收集和销售非法产品，应与TikTok一起被禁 • **质疑产品质量趋势**：现代技术应该让优质服装更容易生产，但市场充斥劣质产品，像是"阴谋"——要么垃圾低价，要么优质天价 补充讨论：有人质疑2亿美元数字的真实性；有人建议在源头海关拦截而非事后罚款；有人期待看到更"刺激"的非法产品清单（如武器）而非常规安全问题

评论摘要

Investigating how prompt politeness affects LLM accuracy (2025)

作者: KnuthIsGod | 评分: 83 | 评论数: 21 | 发布时间: 2026-05-26 07:43
文章摘要

这篇论文研究了提示语的礼貌程度如何影响大语言模型的准确性。研究者创建了50个涵盖数学、科学和历史的选择题，并将每题改写成五种语气版本（非常礼貌、礼貌、中性、粗鲁、非常粗鲁），共250个提示语。使用ChatGPT 4o测试后发现，与预期相反，粗鲁的提示语表现更好：非常礼貌提示的准确率为80.8%，而非常粗鲁提示达到84.8%。这一结果与早期研究不同，表明新一代LLM对语气变化的响应方式可能已经改变，凸显了研究提示语用学特征的重要性。

评论摘要
主要讨论点：一项研究发现粗鲁的提示词比礼貌提示词让GPT-4o表现更好（准确率84.8% vs 80.8%），引发对研究方法和结果普适性的讨论。 不同观点： • **质疑研究设计**：礼貌提示词设计不佳，像对待店员而非同事（如"Can you kindly consider"不自然）；粗鲁提示词也不像英语母语者所写；样本量仅250个问题偏小 • **统计显著性存疑**：4%的差异配合250样本量，统计显著性勉强达标，结果可靠性存疑 • **模型时效性问题**：GPT-4o已是旧模型（2024年），需要用2026年前沿模型重新测试；不同模型结果可能完全不同 • **短期vs长期效应**：研究仅测试单次回答，粗鲁提示可能短期有效但长期产生负面影响，类似人类反应模式 • **与其他研究矛盾**：该结果与大多数文献相反，其他研究多显示礼貌更有效 • **个人习惯派**：部分用户坚持礼貌用语，认为这是关于自己的习惯而非AI效果 补充讨论：有用户分享实际经验（过度礼貌导致AI生成错误测试）；也有人好奇粗鲁反馈是否会影响AI后续"人格"表现；还有讽刺评论质疑将此类AI用于自主软件工程的想法。
