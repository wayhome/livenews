Try the Mosquito Bucket of Death

作者: almuhalil | 评分: 107 | 评论数: 25 | 发布时间: 2025-07-30 13:24
文章摘要

本文介绍了作者使用"蚊子死亡桶"（Mosquito Bucket of Death）解决自家后院蚊子过多的问题。该方法通过在一个5加仑的桶内加入水、腐败的植物材料和 sticks，营造一个吸引蚊子产卵的环境。桶中加入的MosquitoDunks®含有对蚊子幼虫致命的细菌（Bacillus thuringiensis），但对宠物和其他野生动物无害。准备工作包括让水发酵几天，然后定期加入MosquitoDunks®。每个桶只需加入四分之一的MosquitoDunk®，有效期约30天，是一种经济有效的蚊子控制方法。作者还提到使用除氯水（如从除湿机收集的水）效果更佳。通过这种方法，可以有效减少蚊子数量，改善户外环境质量。

A Python dict that can report which keys you did not use

作者: gilad | 评分: 64 | 评论数: 11 | 发布时间: 2025-07-27 02:22
文章摘要

文章介绍了一种名为 `TrackingDict` 的 Python 字典子类，能够追踪哪些键被访问过。这在处理大型数据对象或确保从数据库获取的所有数据都在报告中使用时非常有用。`TrackingDict` 通过重写 `__getitem__` 方法记录被访问的键，并提供了两个属性：`accessed_keys` 返回已访问的键，`never_accessed_keys` 返回未访问的键。文章还提供了一个示例，展示如何使用 `TrackingDict` 来检查哪些键在使用中未被访问。最后，文章更新了一个带类型提示的版本，并讨论了该实现的一些潜在问题和改进建议，例如对 `.get()` 方法的支持。

文章摘要

这篇文章讨论了美国政府在基础设施建设方面的能力衰退问题，援引Ezra Klein和Derek Thompson的著作《Abundance》中的观点，指出过度的法规和官僚程序使得即使是小型项目也难以推进。文章以西雅图一个计划建设八个电动车充电车位的小项目为例，该项目自2022年宣布以来，历经三年仍未完成，突显出系统性的执行困难。文章强调，这不是个别 incompetence 的问题，而是整个制度过于注重程序而非结果，导致简单项目复杂化，复杂项目无法实现。Klein和Thompson呼吁建立一个更注重结果的治理模式，以应对住房、能源和基础设施等重大挑战。如果小项目都需三年，如何应对更大挑战？政府执行能力是实现其他目标的前提。

文章摘要

文章指出，尽管许多编程新手希望通过GitHub上标记为"good-first-issue"的问题来参与开源项目，但这些 issues 往往并不适合新手。常见问题包括：过时的问题（已不再需要解决）、无人跟进的问题（已有拉取请求但未处理）、上下文不明确的问题（需要大量背景知识）以及并非项目主要工作内容的问题（开发者在其他平台如Discord或邮件上沟通，GitHub只用来报告bug或请求功能）。作者建议项目维护者在创建"good-first-issue"时应更用心，确保问题描述精确、有帮助且不假设新手具备过多背景知识，以真正帮助新手顺利开始贡献。

主要讨论点：开源项目中新贡献者的引导和文档质量 不同观点： • **gizmo686的观点**：认为贡献者加入项目通常是出于具体的需求（如避免维护自己的分支），而不是抽象的贡献欲望。他强调项目更需要良好的文档和设计指导，帮助贡献者完成他们想做的修改，而不是仅仅引导如何贡献。 • **stephenlf的观点**：支持为新贡献者创建“好的首次问题”（good first issue），认为这是对新手的一种帮助和前瞻性投资。他还指出，许多项目的文档页面是有帮助的，可能与gizmo686的观点存在分歧。 • **thenoblesunfish的观点**：提出引导新人加入项目是一项耗时且需要个人关注的工作，暗示这可能是许多项目的共同难题。 • **hinkley的观点**：提到Grafana项目存在“知识的诅咒”问题，暗示项目维护者可能因为自身对项目的熟悉而低估了新手理解和参与的难度。 补充讨论： • 争议的焦点在于项目是否应该投入更多资源为新贡献者提供详细的引导和文档支持。**gizmo686**认为更重要的还是项目的设计和文档质量，**stephenlf**则强调为新手创造友好和具体的贡献机会的重要性。 • **thenoblesunfish**指出新人引导工作需要个人投入，可能增加了项目维护的难度。**hinkley**通过Grafana的例子进一步说明“知识的诅咒”可能导致项目对新手不友好。 总体而言，讨论围绕如何有效引导新贡献者，以及文档和设计在其中的重要性展开。
