评论摘要
主要讨论点：Linux 包管理工具（如 Flatpak、Snap）的优缺点，尤其是在资源占用（存储、时间、内存）和使用体验方面的争议。 不同观点： • [loloquwowndueo] 认为包管理工具（如 Snap）不尊重用户的计算机资源，生成的依赖副本过多，导致存储空间占用大，并且由于更新下载量大，系统和用户的时间成本高昂。他通过实例说明，安装多个 Snap 应用程序后，系统更新时会占用大量网络和计算资源。 • [INTPenis] 持相对中立的立场，表示 Flatpak 在其日常使用中影响不大，虽然应用程序占用了一些空间，但因为不依赖太多 Flatpak 应用，总体上觉得可以接受。他还提到容器镜像占用的空间比 Flatpak 更多，因此没有太大的困扰。 • [_Soulou] 关注 Flatpak 的内存使用问题，认为虽然磁盘空间可能便宜，但内存资源有限。如果多个 Flatpak 应用加载不同的动态库版本，可能导致内存重复加载，增加内存消耗。 • [qbane] 引用了多个外部讨论链接，指出 Flatpak 存储空间占用过大的问题已有多个用户反馈，并希望有文章能深入探讨这一问题。 • [massysett] 以幽默的方式指出 Flatpak 的命名与其特性相反，IKEA 的平板包装节省空间，而 Flatpak 却占用大量存储空间。 • [account-5] 对 Windows 的可移植应用程序和 Linux 的 Flatpak 进行了比较，认为 Linux 的 Flatpak 机制与 Windows 的便携应用不同，且不清楚为何 Linux 无法实现类似 Windows 的效果。同时表示，如果需要最新版本的软件，还是会选择 Flatpak。 • [butz] 提出了节省 Flatpak 空间的方法，建议选择使用相同运行时环境的应用程序，并注意运行时的版本过渡期可能导致多个运行时共存，增加空间和更新负担。 • [jasonpeacock] 对 Flatpak 不适合服务器使用的观点提出疑问，希望了解具体原因，并指出 Linux 系统中桌面和服务器之间的依赖差异通常不大。 • [wltr] 对原文内容质量表示不满，认为文章低质且像是由 LLM 生成的，评论区讨论比文章本身更有价值。 • [haunter] 对 Flatpak 比 Appimage 更流行表示不解，认为 Appimage 更便携且性能优越。 • [ReptileMan] 批评了当前技术试图避免和重新发明动态链接库（DLL）问题的现象，认为 Linux 没有提供有效的替代方案，同时提到了 Windows 和 OSX 的相关情况。 • [gjsman-1000] 认为 Linux 桌面系统变得过于复杂和臃肿，并以任天堂的 Horizon 系统为例，指出其高效、安全、快速更新的优点，希望 Linux 桌面能朝此方向发展。 补充讨论： • 争议的焦点在于 Flatpak 和 Snap 等包管理工具的空间占用、内存使用以及更新带来的时间和资源消耗问题。 • 部分用户认为磁盘空间虽然便宜，但内存资源有限，且系统更新时下载和应用更新对网络和计算资源的消耗较大。 • 一些用户提供了节省空间的方法和外部讨论链接，进一步探讨了 Flatpak 存储占用过大的问题。 • 还有用户对 Flatpak 比 Appimage 更流行表示不解，提出了对不同包管理工具的比较和选择问题。

Brian Eno's Theory of Democracy

作者: akkartik | 评分: 143 | 评论数: 23 | 发布时间: 2025-05-04 05:12
文章摘要

文章探讨了布莱恩·伊诺（Brian Eno）的艺术观点如何间接反映了他对民主的看法，并结合了政治学家亚当·普热沃斯基（Adam Przeworski）的民主理论。普热沃斯基在其1991年著作《民主与市场》中提出，民主是一种“政党会输掉选举”的制度，并通过博弈论解释了民主的稳定性源于执政党在未来可能重新掌权的预期和不确定性。这种理论将复杂的政治行为简化为一个简单的九字命题，并强调民主的持续性依赖于权力交替的预期和不确定性。然而，这一理论无法完全解释近年来美国等国民主倒退的现象，表明民主的稳定性可能还需要考虑更多外部冲击和其他因素。文章认为，伊诺的艺术理念与这种民主理论有相通之处，强调了多样性和组织在政治中的重要性。

评论摘要
主要讨论点：不同政治制度及其面临的挑战，包括民主、专制、法西斯主义等，以及技术和社会变化对这些制度的影响。 不同观点： • dzink认为，民主通过给予每个人投票权来确保掌权者接受反馈，而不确定性使掌权者更可能听取反馈。相比之下，专制者只接受来自政治或经济利益相关者的反馈，并通过暴力和媒体控制保持权力。 • keiferski指出，随着识字率下降，民主（Democracy）和权力扩散过程（democracy）之间的区别被模糊了。技术本应是民主化的力量，但在政治系统中却未实现这种潜力。 • selecsosi引用了Joseph Tainter的分析，认为社会崩溃与边际收益递减有关，政治党派的议程往往试图从有限的资源中榨取更多。 • antics9支持基本收入和社区在孕育思想中的作用，认为新思想通常由社区生成。 • chaosprint分享了在音乐表演实践中应用不同组织方式的经验，特别是通过代码控制声音的实验，强调了社会规则在技术系统中的重要性。 • whatever1认为，民主和权力分立代表了一种防止社会自我毁灭的机制，尽管它不稳定且昂贵。 • kstenerud反驳认为，民主不能孤立存在，外部竞争和压力影响其运作，尤其是美国的两党制加剧了 polarization。 • James_K批评美国的两党制导致政党没有动力改进，因为它们依赖私人捐赠维持运作。 • t0bia_s强调，民主的真正考验在于权力的和平过渡，而不是第一次选举。 • emsign警告，专制者和法西斯主义者通过让人们怀疑选举结果的合法性来破坏民主。 • thrance认为，民主的不稳定源于经济阶级间的权力不平衡，特别是资本积累在少数人手中的问题。 补充讨论： • 不同评论者对民主制度的优缺点进行了深入分析，尤其是其在面对经济不平等和外部压力时的脆弱性。 • 技术在民主化和专制化过程中的双重作用被多次提及，强调了技术对政治系统的影响。 • 经济不平等和社会分裂被认为是导致民主不稳定和法西斯主义崛起的重要因素。 争议焦点： • 民主制度是否能有效应对当前的经济和社会挑战。 • 技术是否促进了民主化进程，或者反而加剧了不平等和社会分裂。 • 外部压力和两党制对民主运作的影响程度。
