Show HN: I built a hardware processor that runs Python

作者: hwpythonner | 评分: 935 | 评论数: 70 | 发布时间: 2025-04-28 11:44
文章摘要

PyXL 是一种定制硬件处理器，直接在硬件上执行 Python 代码，无需虚拟机、JIT 或解释器。它通过自定义工具链将 Python 文件编译为 CPython 字节码，并转换为自定义汇编代码，最终在基于 Zynq-7000 FPGA 的硬件上运行。相比之下，MicroPython 运行在软件虚拟机上，导致性能较低。在 GPIO 往返测试中，PyXL 仅需 480 纳秒，而 MicroPython 需要约 15,000 纳秒，PyXL 速度快 30 倍，甚至在时钟速度归一化后快 50 倍。PyXL 通过直接在硬件上执行 Python 字节码，实现确定性时序和实时行为，而无需经过解释器或 C 函数调用。

评论摘要

Manuscript of Ismail al-Jazarī's Ingenious Mechanical Devices (ca. 17th century)

作者: YoctoYARN | 评分: 86 | 评论数: 5 | 发布时间: 2025-04-29 02:16
文章摘要
