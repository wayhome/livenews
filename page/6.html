Show HN: Tesseral – Open-Source Auth

文章摘要

Tesseral 是一个开源的认证基础设施，专为 B2B SaaS 设计，支持多租户，并以 API 优先的方式运行，兼容任何技术栈。它提供托管的可定制登录页面、用户模拟、自助服务配置、魔法链接、社交登录（Google、GitHub、Microsoft）、SAML、SCIM、RBAC、多因素认证（MFA）、Passkey、认证应用程序（TOTP）、API 密钥管理、用户邀请和 Webhook 等功能。开发者可以使用其托管服务或自行部署，并通过 SDK（如 React、Express、Flask、Golang）快速集成。详细文档和注册地址可访问 tesseral.com。

文章摘要

这篇文章是关于在Godot中渲染草地的系列教程的第一部分。文章首先分析了现实中草地的视觉特性，包括其光泽度、透光性、斑块状分布以及自阴影效果。草地具有强烈的镜面反射，尤其在逆光下显得更亮，且由于透光性，光照可以穿透草叶。草地的斑块状分布和自阴影特性使其在3D图形中需要特殊处理。 在3D图形中，草地的表现方法有几种。早期游戏常将草地纹理直接绘制在地形上，但这种方法对高草不适用。现代游戏通常使用两种方法：一是使用广告牌技术，将草的图像渲染到平面上，这种方法在远距离效果好，但近距离显得平面化；二是使用实际几何体来表现单个草叶，这种方法更逼真，适用于高品质游戏，如《Ghost of Tsushima》。 文章最后提到，由于现代GPU对顶点数量不敏感，使用完整几何体来渲染草地变得可行，并预告下一篇文章将介绍如何在Godot中实现全几何体草地渲染。

评论摘要

这篇文章简要介绍了国际象棋棋子设计的历史演变。象棋的祖先可以追溯到公元前2500年印度河流域的文明，当时可能使用粘土小雕像作为早期棋子。到公元7世纪，印度出现了一种叫“恰图兰卡”的游戏，具有四种不同的棋子类型，这些类型后来演变为现代象棋的棋子。恰图兰卡传到波斯，发展为“沙特兰兹”，并逐渐演变为现代象棋。在沙特兰兹时期，棋子开始变得抽象，但也有具象的例子。文章还提到象棋在中世纪的传播和演变，包括在不同国家和时期的设计变化。20世纪后，棋子设计继续发展，进入了多样化的现代时期。

Unlocking Ractors: class instance variables in Ruby

文章摘要

文章主要讨论了Ruby中的Ractors在并行计算中的应用及其当前的局限性。作者指出，尽管Ractors理论上可以用于将CPU密集型任务移出主线程以提高性能，但由于解释器实现中的bug和全局锁的问题，目前在实际应用中性能可能更差。特别是，访问类实例变量和模块变量时，多个Ractors需要争夺全局锁，导致性能下降。文章通过一个简单基准测试展示了使用Ractors的代码比单线程代码慢了近8倍。 为了减少锁争用，作者提到了一些潜在的解决方案，比如使用更细粒度的锁或引入读写锁。但由于Ractors的隔离特性，非主Ractors不能写类实例变量，因此读写锁可能是一个可行的方向，即主Ractor写入，其他Ractor并发读取。然而，作者也指出这些方案在实际应用中可能并不理想，因此需要进一步研究和优化。
