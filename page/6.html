Design System Options for Rails

作者: strzibny | 评分: 91 | 评论数: 13 | 发布时间: 2025-04-10 03:55
文章摘要

本文讨论了在Rails应用中选择设计系统的问题，尤其是对于Business Class项目。作者最初考虑直接采用现有设计系统以节省时间，但发现适合Rails的选择有限。文中介绍了几个选项，包括shadcn/ui、shadcn/ui on Rails、daisyUI、Flowbite和RubyUI。 shadcn/ui是一个开源的React组件库，需要在Rails中自行实现。shadcn/ui on Rails提供了部分实现，但不够完整。daisyUI是一个流行的Tailwind CSS组件库，提供了简短的类名和可定制的组件。Flowbite和RubyUI也被提及，但未详细介绍。 作者强调，尽管现有选择各有优劣，但仍需根据具体需求做出最佳决策，尤其是在2025年的预期下，设计系统的选择仍是一个挑战。

评论摘要
主要讨论点：Rails 项目中的设计系统和前端工具选择 不同观点： • [petepete] 认为 GOV.UK Design System 对 Rails 支持良好，尤其在可访问性方面表现突出，JavaScript 使用很少，仅用于增强功能。虽然不是官方支持，但已被许多新 Rails 服务采用。 • [namiwang] 提到在选择设计系统时遇到困难，并创建了一个网站来比较各种选项，以帮助其他有相同困扰的人。 • [pootsbook] 推荐了 CSS Zero，这是一个为 Rails 量身定制的 "opinionated front-end starter kit"，包含 Stimulus.js，具有易于修改和扩展的优点。 • [mikker] 介绍了自己开发的 Nitro Kit，并表示这是基于个人喜好的设计系统，提供免费开源版本以及付费高级版本。 • [danielvaughn] 主张设计系统应与具体技术栈无关，正在开发一种工具，可以将 UI 组件转换为不同目标格式，以实现设计系统的跨技术栈使用。 • [jensenbox] 提到了 DevDojo 的 Pines 和询问为什么没有包括 Bootstrap。 • [straws] 认为 Github 的 Primer 设计系统在解决服务器渲染和部分升级到 React 视图的平衡上做得很好，并希望更多 Rails 生态工具能解决此类问题。 • [gedy] 强调不应将 "设计系统" 与 "组件库" 混为一谈，设计系统应独立于具体技术，并分享了他们使用自定义主题 Bootstrap 的经验。 • [mosselman] 表示 TailwindUI 在 Rails 项目中使用广泛，重新点燃了其创建视图的乐趣。 • [thuanao] 对大多数 UI 库与特定框架（如 React、Tailwind）绑定表示不满，希望有更多独立自包含的 web 组件。 • [perfmode] 提出 RailsUI 是否优于其他选项的问题。 • [dzonga] 认为现在使用 vite-ruby 和 inertia.js 搭配 Rails 以及 Vue、React 或 Svelte 等前端库的开发方式更符合人体工学。 补充讨论： • 争议焦点之一是设计系统是否应与技术栈无关。danielvaughn 强调独立性，而其他人如 petepete 和 gedy 则关注具体实现和现有工具的支持情况。 • 另一个值得注意的点是关于 Bootstrap 的讨论，jensenbox 质疑其未被提及，而 gedy 则指出其在跨技术栈使用中的优势。 • 不同工具和库的比较也是讨论重点，如 CSS Zero、Nitro Kit、TailwindUI 等，各自有支持者并提供不同功能和灵活性。 • 最后，关于 RailsUI 的优越性问题引发了思考，但未有明确结论。

Sleep is essential – researchers are trying to work out why

作者: sohkamyung | 评分: 213 | 评论数: 19 | 发布时间: 2025-04-10 13:07
文章摘要

神经生物学家Dragana Rogulja的团队研究了睡眠剥夺对果蝇和小鼠的影响，发现缺乏睡眠的动物大约十天后会开始死亡，当它们每晚失去约90%的睡眠时。这一发现表明睡眠对维持生命至关重要，且其影响不仅限于大脑。研究揭示，睡眠不足会导致果蝇肠道中的活性氧（ROS）浓度升高，从而引发死亡。这表明睡眠在维持全身稳态中起关键作用，而不仅是大脑的休息。ROS的积累主要发生在肠道，而非大脑，这提示睡眠对全身健康的调节至关重要。借助现代技术如光遗传学和聚焦超声，研究人员正逐渐揭示睡眠如何通过基因、代谢和激素的调节来保持生物体稳态，从而避免细胞功能失效。

评论摘要
主要讨论点：睡眠与健康的关系，特别是与痴呆、阿尔茨海默病、自身免疫疾病、焦虑和睡眠呼吸暂停等问题的关联。 不同观点： • EncomLab认为家族中有痴呆、阿尔茨海默病和自身免疫疾病史，且这些人都伴随焦虑和睡眠障碍，暗示这些疾病之间存在联系，并参与了斯坦福的一项研究以探索未来20年的发病风险。 • ivraatiems分享了自己患有睡眠呼吸暂停的经历，强调了该疾病对睡眠质量及健康的严重影响，并强烈建议有睡眠问题的人进行检查。CPAP治疗虽然不是治愈方法，但显著改善了其睡眠质量和整体健康。 • shit_stabber补充了一个与遗传突变相关的致命失眠症案例，指出这种突变可能导致早发性痴呆和早期死亡。 • proee提到运动（尤其是跑步）显著改善了睡眠质量，但休息日时睡眠质量会下降，并询问了其他运动形式（如举重）是否也有助于改善睡眠。 • trollbridge指出有些人需要的睡眠时间较少，且没有明显的健康问题，认为探索其原因会很有趣。 • pedalpete介绍了其在神经科技/睡眠科技领域的工作，特别是通过刺激技术增加慢波活动以改善深度睡眠质量，并提到相关研究和即将发布的白皮书。 • amai引用了2023年一项关于果蝇和老鼠睡眠剥夺的研究，指出睡眠剥夺可能影响代谢、葡萄糖、甘油三酯和多巴胺水平，并推测自闭症和ADHD可能与持续睡眠剥夺有关。 • holri推荐了一本关于睡眠的书，认为其内容有趣且有帮助。 • esafak从进化角度解释了睡眠的功能，认为睡眠是为了集中能量进行记忆巩固和身体修复，且在高食物链位置的动物睡眠风险较低。 • 1970-01-01对esafak的观点进行了补充，认为睡眠是一种通用的维护和生存窗口，而非仅为特殊原因存在。 • leonidasv分享了个人经验，指出在保证8小时睡眠时其生产力和学习效果最佳，但随着年龄增长和责任增加，保持8小时睡眠变得困难。 • mentos提到了Andrej Karpathy关于高压氧治疗和运动对组织氧供影响的推文，并质疑睡眠是否也有类似关联。 • api认为睡眠的极端脆弱性和占用大量清醒时间的特性表明其具有极其重要的功能，难以被进化优化掉，并提出如果地球有两个太阳，进化压力可能会导致不同的睡眠演化。 • aantix提到服用含硫化合物补充剂后感觉需要的睡眠时间减少，早晨精神焕发，感到奇怪。 • m3kw9从进化角度解释了睡眠的功能，认为睡眠不仅是大脑需要，而是全身各部分都需要修复，且夜晚的自然环境促使了睡眠的进化。 补充讨论： • 睡眠与健康问题的关联是讨论的核心，包括遗传因素、睡眠呼吸暂停、运动对睡眠的影响、进化角度的解释以及科技对睡眠质量的改善。 • 争议的焦点在于睡眠的具体功能和不同个体对睡眠需求的变化，特别是有些人似乎需要的睡眠时间较少，而有些人则需要更多睡眠来维持健康。 • 科技在改善睡眠质量方面的潜力也被提及，特别是通过刺激技术增加深度睡眠质量的可能。

Searchception

作者: Sami_Lehtinen | 评分: 8 | 评论数: 3 | 发布时间: 2025-04-10 17:43
文章摘要

文章讨论了互联网早期浏览器和搜索引擎的明确区分如何在现代被模糊化。像Google和Microsoft通过将地址栏和搜索框合并（ omnibox ），使用户每次访问网站都可能经过搜索引擎，增加了用户对其平台的依赖和数据收集。文章称之为“searchception”——每次在线导航都会变成搜索事件，用户失去了自主权。这种设计使用户更依赖搜索建议和默认搜索引擎，减少了自主选择和独立访问网站的能力。文章建议通过使用具有独立地址栏和搜索框的浏览器，以及教育他人了解这种现象，来重新获得对网络的掌控。

评论摘要
主要讨论点：Omni bar（多功能地址栏）的功能及其影响，特别是其自动建议和默认搜索引擎的功能是否合理，以及对用户自主选择的影响。 不同观点： • **janalsncm** 认为Omni bar解决了显示DNS错误时不实用的问题，自动建议用户可能想访问的网站（如"spotify"自动补全至"spotify.com"）比让用户记住完整的URL更加方便。他还提出，虽然可以讨论默认搜索引擎和垄断的影响，但不能因为希望用户记住所有网址而否定自动建议的功能。 • **esafak** 认为文章提出的观点已经过时，搜索引擎和浏览器的结合早已是常态，浏览器能够识别用户何时输入URL。换言之，esafak对Omni bar和搜索结合的模式持接受态度，并没有对该功能提出过多质疑。 • **treetalker** 引用"searchception"概念，指出浏览器与搜索引擎的结合让每次访问行为都可能变成搜索事件，这些事件可以被追踪、过滤和商业化。treetalker关注的是这种功能背后的隐私和数据商业化问题，表达了对用户行为被追踪的担忧。 补充讨论： • **争议焦点**：一方面，自动建议功能是否侵犯了用户的自主选择权，例如janalsncm提到的从"sp"自动补全至"spotify.com"是否剥夺了用户访问其他可能网站的机会。另一方面，treetalker提出的隐私问题，即用户的每次搜索和访问行为可能被追踪和商业化，也是值得关注的讨论点。 • **技术与隐私的平衡**：评论中隐含了对技术便利性（自动补全、默认搜索引擎）与隐私保护（数据追踪和商业化）之间如何取得平衡的思考。

文章摘要

Ratta Software's SuperNote A6 X2 Nomad, a 7.8-inch Android 11 tablet, was examined by researchers aiming to hack it. After discovering port 60002 open by default, they investigated the firmware and found that the SuperNoteLauncher.apk contained a service handling unauthenticated file transfers. By exploiting a path traversal vulnerability, they could upload files to arbitrary locations on the device. This led to the discovery that placing a malicious firmware update file in the EXPORT directory would trigger a manual firmware update upon reboot. Ultimately, a remote, 0-click rootkit installation was achieved, exploiting these vulnerabilities. This issue was later assigned CVE-2025-32409.

文章摘要

《Learning to Program with Haiku》是由DarkWyrm编写的一系列编程教学，旨在帮助没有编程基础的人学习为Haiku操作系统编写简单程序。这些课程于2010年1月开始发布，采用Creative Commons许可协议，允许非商业用途的免费分发。课程从基础编程概念开始，逐步讲解数据类型、条件判断、循环、数组、指针、内存管理等，最终引导学习者使用C++和Haiku API编写图形用户界面（GUI）程序。每节课都包含PDF下载和评论查看功能，课程结构包括多个单元和复习，帮助学习者循序渐进掌握编程技能。第14课之后，学习者将能够编写简单的GUI程序。课程资源和支持可通过Lulu.com获取。

New White House AI Policies Introduce Government by AI

作者: hn_acker | 评分: 18 | 评论数: 6 | 发布时间: 2025-04-10 19:24
文章摘要

文章主要讨论了美国政府在人工智能（AI）应用上的转变，从拜登政府的探索性使用转向特朗普政府推动的以AI为主导的治理模式。特朗普政府发布了OMB备忘录M-25-21和M-25-22，旨在加速联邦政府对AI的使用，并通过高效的采购流程来实现。这些政策强调AI在提升政府效率和服务方面的潜力，但也引发了对透明度和公众信任的担忧。例如，有报道指出，政府效率部门（DOGE）开发的AI工具被用于监控联邦机构内工作人员的通信，以识别对总统及其议程的批评言论。此外，马斯克曾建议用AI取代政府工作人员。文章指出，如果政府在敏感决策中仓促使用AI而未获得公众信任，可能会阻碍AI在政府流程中的未来应用。最终，这种向AI治理的转变将重新定义联邦运作，并决定AI是否能成为民主化力量或集中权力远离公民监督。文章强调了这些政策在未来美国治理中的关键作用。
