主要讨论点：美国政府将半导体资金转向量子计算的合法性和可行性问题 不同观点： • **法治崩溃论**：政府无视法院裁决，通过不断发布新的非法命令来规避司法监督，美国实际上已不再受法治约束，而是由"沙皇宫廷"的意愿统治 • **技术骗局论**：量子计算是死路一头的研究，IBM在向纳税人转嫁失败成本；整个量子产业充斥欺诈，公司零收入却估值极高，借AI热度炒作；目前没有任何可证明可扩展的量子计算方案，距离实用比核聚变还远 • **执法无力论**：即使违法，资金花完前诉讼也无法完成；"快速花钱就能逃脱责任"的荒谬逻辑；大科技公司违法已成常态 • **利益输送质疑**：特朗普家族通过1789 Capital等投资机构从政府量子项目中获利 • **战略必要性辩护**：美国已永久失去制造能力，必须持续产出新技术保持领先；量子计算可能用于破解密码学 补充讨论：有评论指出量子技术与现有半导体技术重叠有限，质疑在没有成熟设计前就扩大生产规模的做法；也有人认为这反映了2025年后"合法性"已不再是重要问题的新常态。

Dynamic Workflows in Claude Code

作者: mil22 | 评分: 102 | 评论数: 32 | 发布时间: 2026-05-28 16:52
文章摘要

Claude Code 推出动态工作流功能，可通过编排脚本并行运行数十至数百个子代理来处理复杂任务。该功能适用于大规模代码库的漏洞搜索、跨数百文件的迁移、安全审计等场景。早期用户已将其用于代码库审计、框架迁移和关键工作验证。典型案例是 Jarred Sumner 用 11 天将 Bun 从 Zig 重写为 Rust（75 万行代码，99.8% 测试通过）。动态工作流通过将任务分解为子任务并行执行，多角度验证结果直至收敛，支持长时间运行且可中断恢复。目前在 Claude Code CLI、桌面版、VS Code 扩展及 API 中提供研究预览版。

评论摘要
主要讨论点：Claude Code 动态工作流功能是否真正解决了开发者的核心痛点，还是只是增加 token 消耗的手段 不同观点： • **质疑派**：认为当前瓶颈不是速度而是准确性。AI 容易偏离意图、破坏不变量，甚至损坏测试框架却不被发现。需要更多控制机制和人工介入点，而非更快烧钱的方式（SkyPuncher, trjordan, xcskier56） • **Token 消耗担忧派**：多位用户指出该功能会大量并行运行 agent，导致 token 使用激增。有人首次触及使用上限，有人实验迁移项目消耗 20 亿 tokens。怀疑这是 Anthropic 增加收入的策略（ncphillips, Deukhoofd, tra3, vblanco） • **实用派**：认为工作流在大型任务中有价值，特别是自动化上下文管理，让更多工作在"最佳 20% 上下文窗口"完成。TUI 可视化和并行化设计不错（afro88, aabdi） • **质疑 Bun 案例派**：指出用 Bun 重写为例不恰当，因该项目现被视为反模式，团队因无法理解 100 万行 AI 生成的 Rust 代码而停止支持（vld_chk） 补充讨论：多位开发者已自建类似系统（AndyNemmity 使用 9 个月，vblanco 开源了原型），认为 Claude 的实现过度使用 agent 数量。核心分歧在于：决策比执行更耗时，盲目加速可能跑错方向。

Investigating how prompt politeness affects LLM accuracy (2025)

作者: KnuthIsGod | 评分: 83 | 评论数: 21 | 发布时间: 2026-05-26 07:43
文章摘要

这篇论文研究了提示语的礼貌程度如何影响大语言模型的准确性。研究者创建了50个涵盖数学、科学和历史的选择题，并将每题改写成五种语气版本（非常礼貌、礼貌、中性、粗鲁、非常粗鲁），共250个提示语。使用ChatGPT 4o测试后发现，与预期相反，粗鲁的提示语表现更好：非常礼貌提示的准确率为80.8%，而非常粗鲁提示达到84.8%。这一结果与早期研究不同，表明新一代LLM对语气变化的响应方式可能已经改变，凸显了研究提示语用学特征的重要性。

评论摘要
主要讨论点：一项研究发现粗鲁的提示词比礼貌提示词让GPT-4o表现更好（准确率84.8% vs 80.8%），引发对研究方法和结果普适性的讨论。 不同观点： • **质疑研究设计**：礼貌提示词设计不佳，像对待店员而非同事（如"Can you kindly consider"不自然）；粗鲁提示词也不像英语母语者所写；样本量仅250个问题偏小 • **统计显著性存疑**：4%的差异配合250样本量，统计显著性勉强达标，结果可靠性存疑 • **模型时效性问题**：GPT-4o已是旧模型（2024年），需要用2026年前沿模型重新测试；不同模型结果可能完全不同 • **短期vs长期效应**：研究仅测试单次回答，粗鲁提示可能短期有效但长期产生负面影响，类似人类反应模式 • **与其他研究矛盾**：该结果与大多数文献相反，其他研究多显示礼貌更有效 • **个人习惯派**：部分用户坚持礼貌用语，认为这是关于自己的习惯而非AI效果 补充讨论：有用户分享实际经验（过度礼貌导致AI生成错误测试）；也有人好奇粗鲁反馈是否会影响AI后续"人格"表现；还有讽刺评论质疑将此类AI用于自主软件工程的想法。
