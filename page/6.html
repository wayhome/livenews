Adventures in Symbolic Algebra with Model Context Protocol

文章摘要

文章介绍了Anthropic推出的新协议MCP（Model Context Protocol），该协议旨在让语言模型调用外部工具以执行实际任务，而不仅仅是讨论它们。MCP类似于统一的接口标准，允许一次实现后在不同AI模型和工具间复用，类似USB-C在AI工具中的应用，但目前仍处于早期、不成熟的阶段。 作者尝试用MCP解决语言模型在处理张量计算等复杂符号运算时的不足。通过将Mathematica等计算机代数系统与LLM结合，模型负责自然语言理解和规划，而代数系统则执行精确计算。 尽管MCP生态系统目前文档不全、工具简陋，且存在安全风险，但其基本实现类似FastAPI，易于理解。通过简单示例，作者展示了如何利用MCP让模型正确完成大整数因式分解等任务，而不是凭空捏造答案。 尽管技术仍在初期阶段，但MCP展示了与形式验证系统集成的潜力，未来应用前景广阔。

Remote Prompt Injection in Gitlab Duo Leads to Source Code Theft

文章摘要

本文介绍了Legit研究团队在GitLab Duo中发现的远程提示注入漏洞，该漏洞可导致源代码泄露和HTML注入攻击。GitLab Duo是集成在GitLab中的人工智能助手，旨在帮助开发者进行代码建议、安全审查等任务。然而，研究发现，通过在合并请求、提交信息、问题描述和源代码中嵌入隐藏提示，攻击者可以操纵GitLab Duo，泄露私有项目的源代码，篡改代码建议，甚至泄露未公开的零日漏洞。 攻击者利用KaTeX、Base16等编码技巧隐藏提示，成功骗过系统。此外，由于GitLab Duo的响应采用Markdown格式并逐步渲染，攻击者可以注入恶意HTML，控制页面部分内容，发起网络攻击。GitLab已修复此问题，但文章详细解析了整个攻击链，展示了从提示注入到HTML注入的完整过程。

评论摘要

Prime Path Coverage in the GNU Compiler Collection

作者: matt_d | 评分: 10 | 评论数: 1 | 发布时间: 2025-05-23 06:14
文章摘要

本文介绍了一种在GNU Compiler Collection 15中实现的 prime path coverage 支持，这是一种通过程序执行路径进行结构化覆盖率测试的指标。该方法在测试数量和覆盖率之间取得平衡，要求循环被执行多次或跳过。研究表明，prime path coverage 涵盖了修改条件/决策覆盖（MC/DC）。通过使用后缀树修剪重复子路径，算法效率从 $O(n^2m^2)$ 提升至 $O(n^2m)$。该方法通过控制流图分析，以语言无关的方式观察和检测路径，并准确报告实现覆盖所需的代码执行顺序。

评论摘要
主要讨论点：循环的退出条件是否必须被执行/不执行 不同观点： • nullc的观点：nullc提到在处理带有"if(foo)break;"这种逻辑的循环时，经常发现bug，质疑是否所有退出条件都需要明确被执行或不执行。这暗示了对循环退出条件处理的潜在问题和复杂性。 补充讨论： • 讨论焦点：争议的焦点在于循环中的"if(foo)break;"逻辑是否会导致不可预见的问题，特别是在退出条件没有被明确控制的情况下。这可能涉及到代码的可读性、可维护性以及潜在的错误风险。 • 例子：nullc以自己遇到的多起相关bug为例，说明这种模式可能在实际编码中引发问题，但未给出具体bug细节或场景。 总结：讨论围绕循环退出条件的处理，特别是使用"if(foo)break;"逻辑时可能引发的潜在问题。nullc基于自身经验提出了对这种写法的质疑，但没有深入展开技术细节。

文章摘要

Google在I/O大会上发布了Gemini Diffusion，这是其首个使用扩散模型（而非传统的自回归方式）的大语言模型。与逐字生成文本的传统模型不同，扩散模型通过逐步优化噪声来生成输出，具有更快的速度和更好的纠错能力，尤其在编辑、数学和代码任务中表现突出。作者测试显示，Gemini Diffusion能在数秒内创建交互式网页，速度达857 tokens/秒。尽管名为扩散模型，它仍基于Transformer架构，类似于BERT的掩码语言建模，但能处理更高比例的掩码 tokens。目前尚未有独立基准测试，但Google称其性能媲美Gemini 2.0 Flash-Lite，且速度快5倍。

Kotlin-Lsp: Kotlin Language Server and Plugin for Visual Studio Code

作者: todsacerdoti | 评分: 163 | 评论数: 15 | 发布时间: 2025-05-22 02:46
文章摘要

Kotlin LSP 是一个为 Kotlin 语言提供的 Visual Studio Code 插件，基于 IntelliJ IDEA 和 Language Server Protocol (LSP) 实现，目前处于预览前的探索阶段。该项目支持 JVM Kotlin Gradle 项目的基本功能，如项目导入、代码导航、代码操作、重构和代码完成等，但仅限 JVM 项目。当前版本适合实验和玩具项目，不建议日常使用，因其稳定性未得到保证。该插件主要在 macOS 和 Linux 平台的 VS Code 上测试通过，其他 LSP 编辑器需手动配置。部分源码暂时闭源，未来将完全开源。反馈和问题可通过 GitHub 提交。

Graduate Student Solves Classic Problem About the Limits of Addition

作者: sonabinu | 评分: 4 | 评论数: 0 | 发布时间: 2025-05-23 11:15
文章摘要

文章报道了牛津大学研究生Benjamin Bedert解决了关于“无和集”的经典数学问题。无和集是指在一个数集中，任意两个数的和都不是该集合中的第三个数。这个问题源于1965年Paul Erdős提出的一个简单但深刻的问题：任意整数集合中最大无和集的大小是多少？Erdős证明任何整数集合都有一个至少为N/3大小的无和子集，但他认为实际的最大无和子集应远大于此。经过多年研究，Bedert最终证明了在任何整数集合中，必定存在一个远大于N/3的无和子集，解决了这一长达数十年的难题。这一成果被誉为数学界的一项重大突破。
