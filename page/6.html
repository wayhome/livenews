Herdr: Agent multiplexer that lives in your terminal

作者: mzehrer | 评分: 122 | 评论数: 31 | 发布时间: 2026-06-29 04:27
文章摘要

Herdr 是一个运行在终端中的 AI 代理多路复用器。它提供工作区、标签页和窗格管理，支持鼠标操作（点击、拖拽、分割）。可以分离和重新连接会话，代理在后台持续运行。无需 GUI 应用或 Electron，直接显示代理的原生终端界面。 主要特性包括：客户端-服务器架构、支持多个工作区和会话、实时显示代理状态（阻塞/工作中/完成）、复制模式、热更新和会话恢复。安装简单，通过 curl 脚本、Homebrew 或 mise 均可安装。使用 `ctrl+b` 作为命令前缀进行操作，支持与多种 AI 代理集成。

评论摘要
主要讨论点：关于AI代理多路复用工具的选择和使用体验 不同观点： • **Herdr支持者**：认为Herdr简化了多代理管理，特别适合需要在本地和远程环境间切换的场景；支持原生滚动体验，持久化会话方便远程访问（手机/iPad），API友好便于扩展 • **传统工具派**：坚持使用tmux + iTerm2组合，认为这是最好的终端方案；也有人选择Zellij并自定义hook来增强体验 • **IDE集成派**：偏好Emacs（agent-shell + Projectile）或Zed + Terminal Thread + Tmux的组合方案，强调编辑器内的代理集成体验 • **质疑声音**：有用户质疑是否真的需要多个代理，认为即使两个会话都感觉overwhelmed；另有用户指出Herdr不像竞品会在启动时调用多个网络服务 补充讨论：可见性问题被提出为多代理管理的第二大痛点——难以追踪每个代理的实时状态、调用的程序和卡住的位置。部分开发者分享了自建工具（jmux.build）或推荐自托管GUI方案（kandev）。整体而言，社区对工具选择呈现多元化态度，各有偏好。

WASM on the JVM Ships Under the Bytecode Alliance

作者: dustingetz | 评分: 23 | 评论数: 3 | 发布时间: 2026-06-29 11:50
文章摘要

Endive 1.0正式发布，这是一个运行在JVM上的纯Java WebAssembly运行时（原名Chicory），现已加入Bytecode Alliance。主要更新包括： 1. **WasmGC支持**：完整支持WasmGC规范，可运行Kotlin/Wasm、Dart等依赖垃圾回收的语言编译的Wasm模块，GC对象由JVM直接管理。 2. **尾调用优化**：优化了尾调用分派，提升了CPython 3.14等解释器的性能。 3. **tree-sitter库**：将流行的增量解析库编译为Wasm并打包为JAR，无需JNI即可在Java中使用。 迁移简单，只需更改Maven坐标和包名。继续推进"Wasm作为实现细节"的生态，让Java开发者能以普通JAR的形式使用各种原生库。

主要讨论点：关于 endive 项目的技术实现和应用场景的疑问 不同观点： • **垃圾回收机制疑问（zimmi）**：询问 endive 是否自带垃圾回收器，仅在 API 边界传递引用时才使用宿主 GC。提出是否可能完全使用宿主 GC，或者 WebAssembly 的某些固有特性是否使这种方案不可行或效率较低 • **项目定位疑问（fwsgonzo）**：询问 endive 是否用于本地执行 Emscripten 编译的项目，还是针对完全不同的目标，例如 WASM 与 Java 的交互 • **应用场景疑问（iberator）**：直接询问该项目的具体使用场景 补充讨论：三条评论均为提问性质，暂未形成讨论或争议。问题集中在技术实现细节（GC 机制）、项目目标定位（是否支持 Emscripten/Java 互操作）和实际应用价值三个方面，反映出评论者对项目的核心价值主张和技术架构还不够清晰。

1.38 Millimeter Microcontroller

文章摘要

MSPM0C1104是德州仪器(TI)推出的一款通用型微控制器，核心特性包括： **处理器**：24MHz Arm Cortex-M0+内核 **存储**：16KB Flash + 1KB SRAM **模拟外设**：12位ADC，最多10个外部通道，1.5Msps采样率 **数字外设**：3个定时器(支持14路PWM)、DMA、看门狗 **通信接口**：1个UART(支持LIN)、1个I2C、1个SPI **低功耗**：运行87µA/MHz，待机5µA，关断200nA **工作条件**：1.62-3.6V供电，-40至125℃ **封装选项**：提供20引脚TSSOP/VQFN、16引脚SOT、8引脚WSON等多种封装 适用于需要低功耗、模拟采集和通信功能的嵌入式应用场景。

评论摘要
主要讨论点：TI推出的低成本微控制器（$0.20/千片）及其应用场景 不同观点： • **市场竞争视角**：这是TI对CH32V003、PY32、STM32C0等低价芯片的回应，一线厂商参与"底价竞赛"是好事，但1KB SRAM相比竞品（如WCH的2KB）显得紧张，只适合裸机开发 • **实际应用困扰**：该系列已发布近2年，但1.38mm²封装长期缺货，迫使设计者改用更大封装，影响产品小型化设计（LED耳环项目为例） • **应用质疑**：有人质疑实用性——浴室秤等简单设备用现有芯片已足够，这类芯片是否过剩？普通人如何使用？批量采购价格不明确 • **趣味探讨**：性能类比GBA但RAM不足，有人开玩笑问能否运行《波斯王子》或组建微型计算集群 补充讨论：核心争议在于**性价比与实用性的平衡**——芯片价格诱人但SRAM限制严格，封装供应不稳定影响实际采用，应用场景尚不明确。
