HTML-in-Canvas

文章摘要

这篇文章介绍了WICG提出的新HTML Canvas API提案，旨在将HTML内容渲染到Canvas 2D和WebGL中。当前的``缺乏对复杂文本和内容渲染的支持，导致可访问性、国际化、性能和质量问题。该提案包括`layoutsubtree`、`drawElement`、`texElement2D`和`setHitTestRegions`等新方法，用于在Canvas中布局和渲染HTML元素，并改进可访问性和事件处理。渲染后的Canvas图像是静态的，后续元素变化不会自动更新。该提案还讨论了可访问性问题，并排除了对Offscreen Canvas和分离Canvas的支持。

LangExtract: Python library for extracting structured data from language models

作者: simonpure | 评分: 113 | 评论数: 9 | 发布时间: 2025-07-30 14:56
文章摘要

**LangExtract** 是一个 Python 库，利用大型语言模型（LLMs）从非结构化文本中提取结构化信息，支持精确的源文本映射和交互式可视化。其主要特点包括： 1. **精确源映射**：提取的信息映射回源文本的准确位置，支持高亮显示以方便验证。 2. **可靠的结构化输出**：基于少量示例强制执行一致的输出模式，确保结果的稳健性。 3. **长文档优化**：通过文本分块、并行处理和多轮提取策略，解决大文档提取的难题。 4. **交互式可视化**：生成自包含的交互式 HTML 文件，方便查看提取结果。 5. **灵活的LLM支持**：支持云端模型（如Google Gemini）和本地开源模型。 6. **领域适应性强**：通过少量示例定义提取任务，无需模型微调。 使用时，用户通过定义提示和示例来指导模型，并调用 `lx.extract` 函数进行提取。推荐使用 `gemini-2.5-flash` 模型以平衡速度、成本和质量。

文章摘要

Seed7是一种由Thomas Mertes设计的高级编程语言，具备开源解释器和编译器，编译器将Seed7程序转换为C程序并编译为机器码。Seed7支持用户自定义语句和操作符，具有无特殊语法即可定义模板和泛型的能力。它采用静态类型检查，无自动类型转换，提升编译时错误检测能力。Seed7具备自动内存管理，无需垃圾回收，支持异常处理和源码调试。它提供大整数和大有理数类型，支持函数、操作符和语句的重载。预定义多种数据类型和数据库独立API，可连接多种数据库。Seed7代码具有良好的可移植性，适用于Linux、Unix和Windows系统。解释器和示例程序使用GPL许可，运行库使用LGPL许可。
