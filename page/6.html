本文探讨了通过科技增强人类能力的趋势及相关争议。德国科技亿万富翁Christian Angermayer在体验迷幻蘑菇后，致力于推动人类改善，投资于精神健康治疗药物及人类增强技术，旨在让人类更强大、更聪明、更长寿。他还资助了延缓衰老的科研奖项，并参与创办允许使用兴奋剂打破世界纪录的"增强运动会"。文章指出，随着人类增强技术的发展，相关法规却显得过时，亟需调整以应对这些新兴趋势。

评论摘要

Test Postgres in Python Like SQLite

文章摘要

`py-pglite` 是一个 Python 测试库，允许开发者在测试中使用 PostgreSQL 功能，而无需完整安装 PostgreSQL。它通过 PGlite 提供快速、隔离的测试数据库环境，支持 SQLAlchemy 和 SQLModel，且与 Pytest 无缝集成。主要特点包括：超快测试速度、无需 PostgreSQL 安装、完全隔离的测试数据库、自动管理 PGlite 生命周期等。支持手动和自动管理数据库，提供多种实用功能如数据库清理、序列重置等。安装需 Python 3.10+ 和 Node.js 18+，并可通过 `pip` 安装额外依赖如 FastAPI 支持。该库简化了使用 PostgreSQL 进行应用测试的流程。

Show HN: Mustardwatch: Detect what files a program uses, rerun when they change

作者: shachaf | 评分: 5 | 评论数: 0 | 发布时间: 2025-06-06 22:14
文章摘要

**mustardwatch** 是一个使用 Linux `ptrace` API 实现的工具，用于运行命令并追踪其访问的文件（或可能访问的文件），监控这些文件的变化并在变化时重新运行该命令。目前仅支持 x86-64 Linux 系统。用户可以通过命令行选项自定义监控行为，例如监控目录、不跳过常见系统目录、输出监控文件列表等。子进程使用的文件也会被追踪，主进程退出时所有子进程会被终止。基本使用方法为 `mustardwatch [OPTION...] COMMAND [ARG...]`。

文章摘要

文章讨论了小型Forth实现以及小型程序的吸引力。小型程序更易于阅读和理解，例如一个有趣的功能若仅用20行代码实现，会比用2000行实现更引人关注。文章列举了几个例子，如Luke Jackson的25行JavaScript库`ijk`，以及Philippe Brochard的46字节Forth实现。作者还提到Roger K.W. Hui描述的单页C语言解释器，以及William Byrd演讲中提到的精美Lisp解释器。 文章进一步探讨了这些小型程序的意义，指出它们不仅是一种编程娱乐，还揭示了程序的最小复杂性。例如，名片大小的光线追踪器展示了光线追踪器的最低复杂度。作者还提到了Kolmogorov复杂性，即生成某个对象的最短程序长度，并指出小型实现帮助人们理解编程语言的基本概念。最后，提到Justine Tunney实现的436字节LISP，展示了垃圾回收语言的核心可以压缩到如此小的规模。

Jepsen: TigerBeetle 0.16.11

作者: aphyr | 评分: 208 | 评论数: 14 | 发布时间: 2025-06-06 10:53
文章摘要

TigerBeetle是一个专注于安全和速度的在线事务处理（OLTP）数据库，专为双重记账设计。它基于Viewstamped Replication（VR）共识协议，提供强序列化一致性。该数据库仅存储账户及账户间的转账信息，适用于金融交易、库存管理和票务等场景。TigerBeetle优化了高竞争和高吞吐量的工作负载，如中央银行交易和经纪结算。它通过单核处理写入操作，并利用批处理、IO并行化等技术提升性能。 TigerBeetle非常强调容错性，提供了针对内存、进程、时钟、存储和网络故障的明确模型。通过Viewstamped Replication和协议感知恢复技术，它能在单个副本保留记录的情况下继续运行，防止数据丢失。TigerBeetle采用确定性模拟测试来验证故障安全性，并支持无缝的二进制升级，无需人工干预。 此外，TigerBeetle定义了明确的时间模型，使用物理时间戳并确保其严格单调递增。当集群时钟不同步超过一定时间窗口时，系统将拒绝请求以保证一致性。
