《Chrono Trigger》是一款30年前发布的SNES角色扮演游戏，由《最终幻想》和《勇者斗恶龙》团队的顶尖人才联合打造，包括鸟山明（Akira Toriyama）负责美术，坂口博信（Hironobu Sakaguchi）监督，以及田中美久（Yasunori Mitsuda）作曲。游戏讲述了玩家穿越时空，与主角Chrono一起抵抗外星邪恶力量、拯救世界的冒险故事，结合了中世纪幻想和未来科幻元素。其创新之处包括多结局、独特的战斗系统以及深刻的情感表达，如友谊和爱的力量。游戏中的经典场景，如审判戏和与最终Boss Lavos的战斗，展现了其在剧情和玩法上的精妙设计，至今仍被视为游戏史上的经典之作。

Aircraft detection at planetary scale

文章摘要

文章介绍了利用卫星图像进行全球范围飞机检测的技术进展。传统方法只能对少数机场进行不定期监测，而Planet的卫星每天几乎覆盖全球陆地，结合机器学习模型，可以大规模自动化检测飞机活动。该技术能够识别长度或翼展≥25米的飞机，支持经济、国防和情报分析，尤其在冲突地区具有重要价值。通过历史数据，还可以分析飞机活动模式，发现异常行为。文章详细描述了使用PlanetScope和SkySat数据训练模型的过程，并强调该技术为专家和非专家提供了大规模分析的机会。

Mruby/C and picoruby: high level langs in low-level devices?

作者: rahil627 | 评分: 62 | 评论数: 10 | 发布时间: 2025-03-23 09:20
文章摘要

PicoRuby 是一个专为单片微控制器设计的微型 Ruby 实现，具有小尺寸和可移植性特点。它在 32 位架构下仅需 256 KB ROM 和 128 KB 或更少的 RAM。PicoRuby 依赖标准 C 库，如 glibc 或 Newlib，并支持 Raspberry Pi Pico 等微控制器板。它提供了 API 文档和演示视频，并依赖于 mruby/c 实现的虚拟机。PicoRuby 可用于构建 PRK Firmware 键盘固件和 PicoRuby WASI WebAssembly 运行时。构建过程需要 C 工具链、git 和 Ruby 3.0 以上版本。项目仍在开发中，遵循 MIT 许可协议，并获得了 Ruby Association Grant Program 的支持。
