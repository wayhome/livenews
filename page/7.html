Osgint – OSINT tool to find information about GitHub user

作者: CHEF-KOCH | 评分: 98 | 评论数: 12 | 发布时间: 2025-03-24 05:51
文章摘要

OSGINT是一个开源工具，用于查找GitHub用户的各类信息。其主要功能包括：通过电子邮件查找GitHub用户名，通过用户名查找关联电子邮件（但并非每次都有效），以及获取用户资料信息（如账户创建日期、公开Gists、ID、公开PGP和SSH等）。该工具通过分析公开提交记录和GPG密钥来获取电子邮件信息，并利用GitHub的用户API进行数据检索。用户可以通过命令行指定用户名或电子邮件进行查询，并可以选择以JSON格式输出结果。工具还提供了示例输出，展示了查询结果的详细信息。

评论摘要
主要讨论点：GitHub 信息泄露和使用政策的相关讨论 不同观点： • Xaena 认为该代码库的意图可能违反 GitHub 的可接受使用政策，尤其是涉及通过 GitHub 提交的电子邮件信息进行招聘或垃圾邮件的行为，这可能侵犯隐私。他们引用了 GitHub 的使用政策作为参考。 • zellyn 回应称评论中列出的某些电子邮件不准确，部分电子邮件是其他贡献者提交更改时使用的，而非其本人。 • cdblades 指出，代码库的创建者有道德义务在 README 中添加如何避免信息泄露的说明，以保护用户隐私。 • theyknowitsxmas 质疑该代码库的受益者，认为其只会对垃圾邮件发送者有利。 • 1317 认为该代码库没有提供新的信息，除电子邮件外，其他所有信息都直接来自 GitHub 公开的用户资料。 • ExxKA 提到，正当招聘人员停止通过 GitHub 发送垃圾邮件时，该代码库可能会重新引发此类问题。 • danso 提供了技术细节，建议可以使用 GitHub 的 Events API 更高效地获取用户最近提交的电子邮件信息，并给出了代码示例。 • cpursley 提到 reporeach.com 这个网站已经实现了类似的功能（通过代码库获取用户信息）。 • Dotnaught 认为直接在提交记录后添加 .patch 后缀获取电子邮件信息比使用复杂代码更简单。 • areyourllySorry 提到另一个工具 "gitrecon"，也用于类似目的的用户信息收集。 • belter 质疑谁会用真实姓名注册 GitHub，并给出了像 elonmusk 和 donaldtrump 这样的用户名作为例子，暗示这些不太可能是真名。 补充讨论： • 评论中围绕的主要争议焦点是用户信息隐私问题，尤其是在 GitHub 这样的公开平台上，如何避免个人信息（如电子邮件）被滥用于垃圾邮件。 • 部分评论讨论了技术实现细节，如如何更高效地获取用户提交信息，以及现有工具和网站的类似功能。 • 用户对代码库的实际用途和受益者存在质疑，认为其可能只会对垃圾邮件发送者有利，而非普通用户。
