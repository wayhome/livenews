Fifty Years of Open Source Software Supply Chain Security

作者: yarapavan | 评分: 177 | 评论数: 10 | 发布时间: 2025-04-07 18:04
文章摘要

本文探讨了开源软件供应链安全问题，追溯了自1974年美国空军对Honeywell Multics系统的审查，到2024年发现的liblzma库后门（称为xz攻击）等事件。文章指出，软件供应链安全的基本问题五十年来未有根本改变，攻击手段变得更加隐蔽。作者Russ Cox提出了开源软件供应链攻击、漏洞和安全的定义，强调这些概念不涉及硬件供应链和闭源软件。文章还提到2015年Xcode被修改事件，显示供应链攻击的多样性和复杂性。尽管没有简单的解决方案，但通过不断改进防御措施，可以提升安全性。Cox以Go语言开发经验为例，呼吁更广泛地采用有前景的安全措施。

评论摘要
主要讨论点：开源项目的安全性、依赖管理、供应链攻击及防御策略 不同观点： • **ndiddy** 认为Debian及其衍生版（如Ubuntu、Fedora）由于对OpenSSH服务的不必要依赖（如libsystemd）的处理不当，导致更容易受到特定攻击。然而Fedora幸运地通过valgrind测试避免了问题。 • **aadhavans** 指出开源项目的资金问题依然严峻，年轻工程师参与度下降，未来可能出现两种情况：大公司接管关键开源库，或开源库消亡并被公司的专有替代品取代。 • **transpute** 分享了Linux安全峰会上的一个演讲，讨论了强制访问控制（MAC）在多种操作系统中的应用及其对限制恶意应用破坏的能力。 • **edoceo** 提出Docker在镜像管理上的问题，难以限制只从特定的私有 registry 拉取镜像，并询问解决方案。 • **amiga386** 反驳了文章中关于Heartbleed漏洞的论述，认为即使使用内存安全的语言，类似的漏洞仍可能存在，因为OpenSSL的问题源自不安全的缓冲区操作而非单纯的语言问题。 • **EVa5I7bHFq9mnYK** 提到相关新闻，指出朝鲜IT人员已经渗透进财富500强公司，暗示供应链攻击的现实性和严重性。 • **mlinksva** 认为文章未涵盖隔离、最小权限等重要安全措施，指出这些是基础防御策略。 • **lrvick** 强调代码审查、制品签名及全源引导的重要性，并介绍了其所在发行版Stagex的设计选择，如100%确定性、可重现性、所有提交和评审的签名机制，认为这些措施能够有效抵御供应链攻击。 补充讨论： • **neuroelectron** 对文章持怀疑态度，认为可重现性只是表面现象，而非真正的安全保障。讨论了Ken Thompson在1984年提出的“信任信任”攻击，指出被感染的开发工具链可通过“安全”构建传播，暗示即使开源项目也未必安全。 争议焦点： • 开源项目的安全性及防御策略的有效性，特别是在供应链攻击和依赖管理上的处理方式。 • Heartbleed漏洞的根本原因及其在不同编程语言中的可避免性。 • 可重现性是否足以作为开源项目安全性的指标。

Sweetener saccharin shows surprise power against antibiotic resistance

作者: XzetaU8 | 评分: 117 | 评论数: 13 | 发布时间: 2025-04-05 14:07
文章摘要

一项由布鲁内尔大学抗菌创新中心领导的研究发现，常用的人工甜味剂糖精（常见于酸奶和无糖饮料中）能够杀死多重耐药细菌，包括世界上最危险的病原体之一。糖精通过破坏细菌细胞壁，使其破裂死亡，并阻止细菌形成生物膜，从而增强抗生素的效果。研究还显示，糖精载药的水凝胶伤口敷料在实验中表现优于医院使用的银基抗菌敷料。这一发现为应对抗生素耐药性提供了新途径，因为糖精不仅能杀死耐药细菌，还能增强现有抗生素的效果，可能加速开发成本较低的新治疗方法。

评论摘要
主要讨论点：人工甜味剂Saccharin（糖精）的健康影响和使用争议 不同观点： • **支持Saccharin的观点**： - dingdingdang引用了研究，表明Saccharin在特定使用模式下会增加生物膜的形成，但认为效果取决于使用方式。 - teslabox认为Saccharin是人工甜味剂中相对安全的，提及其历史和应用，并将其与Aspartame等其他甜味剂进行比较，指出Saccharin可能在安全性上更优。 • **中立或复杂观点**： - jader201通过列举各种饮品的争议，表达了对饮品健康影响的不确定性，认为除了水以外，几乎所有饮品都有争议，最后调侃说可能水也有问题。 - pshirshov质疑Saccharin的特殊性，指出像糖、盐、乙醇等物质也有杀菌效果，暗示Saccharin并无特别之处。 - tickerticker提出口服Saccharin时如何区分好坏细菌的问题，指出潜在的生物群影响。 • **反对或质疑观点**： - profsummergig提到有关人工甜味剂可能影响肠道生物群的阴谋论，暗示Saccharin可能对肠道细菌有负面影响。 - arijo直接反对所有甜味剂，认为它们有害，并引用视频支持其观点。 - ninetyninenine简单质疑Saccharin是否有毒性。 • **技术性讨论**： - pfdietz提供了具体数据，指出Saccharin在1.4%浓度下的效果，并提到其在小鼠中的口服LD50值，认为可能适合局部应用。 - hinkley指出在体外实验中许多物质都能杀菌，但质疑其在体内（如抵抗肺炎）的效果。 补充讨论： - 评论中多次提到Saccharin与其他人工甜味剂（如Aspartame、Acesulfame Potassium、Sucralose）的比较，讨论了它们的安全性和应用场景。 - 对Saccharin的健康影响存在明显争议，部分评论对其持怀疑态度，而另一些则试图通过科学数据为其正名。 - 对肠道生物群影响的关注是讨论中的一个重要方面，显示出公众对人工添加剂对微生物环境影响的担忧。

Globstar 是一个开源静态分析工具包，帮助开发者和安全工程师编写和运行代码检查器。它使用 tree-sitter 进行强大的 AST 分析，支持从简单的 YAML 接口到复杂的 Go 接口编写检查器。Globstar 具有以下特点： 1. **高速高效**：用 Go 编写，适合大型代码库，独立二进制文件无需担心依赖。 2. **原生支持 tree-sitter**：利用 S-expressions 编写检查器，或用 Go 实现更复杂的逻辑。 3. **CI 友好**：可在任何 CI/CD 管道中运行，无需额外安装依赖。 4. **完全开源**：MIT 许可，可自由用于商业项目。 安装方法： ```sh curl -sSL https://get.globstar.dev | sh ``` 编写检查器示例： ```yaml # .globstar/dangerous_eval.yml language: python name: dangerous_eval message: "Dangerous use of eval() detected." category: security severity: critical pattern: > (call function: (identifier) @func (#eq? @func "eval") arguments: (argument_list [(identifier) (binary_operator)])) ``` 在 CI 中运行： ```yaml jobs: analyze: runs-on: ubuntu-latest steps: - uses: actions/checkout@v3 - name: Install Globstar run: curl -sSL https://get.globstar.dev | sh - name: Run Globstar run: globstar check ```
