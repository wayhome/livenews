hobbes 是 Morgan Stanley 开源的嵌入式编译器和运行时系统，用于高效的动态表达式评估、数据存储和分析。 **核心特性：** 支持表达式评估、数据存储、网络交互、序列转换、模式匹配、文本解析、类型类等功能。可嵌入 C++ 应用程序实现高性能集成。 **构建要求：** LLVM 3.3+、cmake 3.4+、gcc 4.8+ 和 Linux 2.5+ 内核。构建后生成 libhobbes.a 静态库、hi 交互式解释器和 hog 数据记录工具。 **安全警告：** 为性能设计，无沙箱环境和运行时安全检查，直接访问内存且不做边界检查。支持远程代码执行（RPC），仅限可信内网使用。 适用于需要高性能数据处理和动态表达式计算的场景。

评论摘要
主要讨论点：Hobbes编程语言的实时监控能力与零开销特性 不同观点： • **技术优势派（zsombor）**：强调Hobbes能在不影响延迟的前提下实现应用实时监控和运行时行为修改，同时保证类型安全。真正的"零开销"不是营销术语，而是硬性要求，这在需要极致性能的领域尤为重要 • **与KDB的对比**：zsombor认为KDB虽是同类方案之一，但在运行时行为修改和实时监控两方面都存在不足，无法满足真正的零开销要求 • **背景资料提供者（leprechaun1066）**：提供了2017和2019年的历史讨论链接，帮助新读者了解社区对该语言的长期关注 补充讨论：评论突出了Hobbes的核心应用场景——在关键性能路径不能有任何妥协的系统中（如金融交易、实时系统），既要深度可观测性又要保持极致性能。这种需求在传统监控方案中很难同时满足。

文章摘要

作者宣布推出"缩略语疲劳系列"(AFS)，探讨对技术领域缩略语过度使用的警惕。 他的谨慎态度源于两方面：**文化差异**——西班牙语母语背景下缩略语远不如英语普遍；**学术背景**——人文学科更倾向概念创造而非缩略语。 文章指出，英语使用者对缩略语情有独钟，这被科技营销大量利用。缩略语成为群体归属信号：懂的人觉得是"圈内人"，不懂的人则被排除在外。营销团队通过制造大量缩略语（包括公司自创的）来营造专业感。 作者的核心担忧是：**缩略语因其易记易传播的特性而流行，但这种传播力可能与其实际价值无关**。好记的首字母组合（如SOLID）本身就具有模因传播优势，这可能掩盖了概念本身的质量。

评论摘要
主要讨论点：技术和专业领域中缩写词的使用是否合理，以及如何平衡效率与可读性 不同观点： • **支持派**：缩写词在专业领域必不可少，能提高沟通效率和信息密度。技术领域需要命名大量新概念，缩写词是自然选择（如 HTTP 比完整拼写更实用）。在特定受众中使用行业缩写词反而更清晰 • **反对派**：缩写词制造理解假象，总是以读者为代价。是作者懒惰和短视的表现，牺牲了长期可读性。特别批评不先介绍就直接使用缩写词的做法 • **文化批评**：美国军事文化导致缩写词过度使用，成为文化霸权的一部分。其他语言和文化较少依赖缩写词 • **实际问题**：不同领域使用相同缩写词造成混淆（如 LoRa vs LORA）；积累过多缩写词导致认知负担和语言不精确；a11y 等数字压缩形式难以解码 补充讨论：多数人认同缩写词本身不是问题，关键在于使用场景和方式。专业内部交流可接受，但面向公众时应谨慎。需要在效率和可读性之间找到平衡，并注意引入新缩写词时的规范性

主要讨论点：博客流量下降的原因及博客文化的演变 不同观点： • **自然更迭论**（zerobees, draginol）：博客消失是正常的内容平台更迭，类似论坛和Usenet的演变，流量转移到Instagram、TikTok、Reddit等新平台，而非真正消亡 • **技术破坏论**（economistbob）：WordPress在Google资助下移除blogroll（博客互链列表）功能，摧毁了基于相互推荐的发现机制，迫使博客依赖付费广告，导致生态崩溃 • **商业化vs个人价值**（Loic, firefoxd, jl6）：商业博客衰落不影响个人写作的价值，小博客和非商业博客仍在小众空间繁荣（如Gemini协议） • **研究方法质疑**（jefftk, skybrian, bediger4000）：研究存在幸存者偏差，选取的"成功博客"样本（多为营销类、时尚类）不代表整体博客生态，且未考虑Substack等新平台 • **内容质量悖论**（CapitalistCartr, torton）：深度利基博客难获关注，浅层热门内容易成功但多为低质量内容农场，AI时代后者将被淘汰 补充讨论：多位评论者指出信息过载问题（vivzkestrel），以及对教人用AI写博客的博客自身流量暴跌的讽刺（hn_throwaway_99）。整体共识是博客黄金时代已过，但对原因和未来走向存在分歧。

Should DayQuil Be Legal?

作者: paulpauper | 评分: 64 | 评论数: 21 | 发布时间: 2026-07-06 15:44
文章摘要

这篇文章批评了以DayQuil为代表的非处方复方感冒药存在的问题： **主要观点：** - DayQuil等复方药将少量廉价有效成分与多种无效安慰剂混合，以高价出售。一瓶15美元的DayQuil中，唯一有效的对乙酰氨基酚仅占2%（约8克），单买只需16美分，标价高出6000%以上。 - 其他成分如右美沙芬和口服去氧肾上腺素研究证明基本无效。FDA已提议将去氧肾上腺素下架，但监管进程缓慢。 - Sudafed用无效的去氧肾上腺素替代了有效的伪麻黄碱，通过相似命名误导消费者。 - 这种做法不仅价格欺诈，还可能导致药物过量等安全问题，反映出FDA在非处方药监管方面的失职。

评论摘要
**主要讨论点：** 非处方感冒咳嗽药物的有效性争议，特别是DXM（右美沙芬）和phenylephrine（苯肾上腺素）的疗效，以及复方药的市场问题 **不同观点：** • **选择性研究批评派**：认为文章cherry-picking研究结果，DXM和蜂蜜都有正反两面的研究证据，不能只看单一论文就下结论 • **药物可及性派**：真正有效的药物（如真pseudoephedrine）已难以获得，制药公司更愿意销售安慰剂牟利；口服phenylephrine确实无效，但鼻喷雾剂版本有效 • **消费者自负派**：消费者有责任研究产品成分和有效性，或咨询专业人士，这不值得过分愤怒 • **监管失灵派**：FDA缺乏清理无效药物的激励，市场机制也因信息不对称而失效；加拿大药店充斥未标明的顺势疗法产品是不道德的 • **DXM有效性支持者**：多人指出DXM确实有效，甚至有精神活性作用，问题主要出在phenylephrine上 • **防滥用解释派**：复方药混合多种成分是为了防止药物滥用和precursor提取，而非纯粹的商业欺诈 **核心争议：** DXM的真实疗效存在分歧；复方药是商业欺诈还是防滥用措施；应由消费者自负还是加强监管
