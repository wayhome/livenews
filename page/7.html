Debian 13 “Trixie”

作者: ducktective | 评分: 862 | 评论数: 55 | 发布时间: 2025-08-09 18:18
文章摘要

Debian 13 "trixie" 于2025年8月9日发布，开发历时2年1个月30天，将支持5年。该版本包含多个桌面环境，如GNOME 48、KDE Plasma 6.3等，新增14,100个软件包，总计69,830个，并移除8,840个过时软件包，更新了44,326个软件包。系统总大小为403 GB，包含1,463,291,186行代码。支持的架构包括amd64、arm64、armel、armhf、ppc64el、riscv64和s390x，i386架构不再支持。trixie 首次支持riscv64架构，并为云环境提供专用镜像。用户可通过live图像在不安装的情况下试用Debian 13，支持amd64和arm64架构，并提供多种桌面环境选择。

Inside OS/2 (1987)

作者: rbanffy | 评分: 113 | 评论数: 7 | 发布时间: 2025-08-10 13:15
文章摘要

本文介绍了微软的OS/2操作系统，强调其可能成为未来十年的主流操作系统，尤其适用于Intel 80286/80386微型计算机。OS/2具备多任务处理能力、全面的应用程序编程接口（API）以及可扩展至未来硬件的特性，这为其成功奠定了基础。文章概述了OS/2的系统架构，包括三个层次：OS/2内核和系统服务、Windows Presentation Manager（WPM）以及OS/2 LAN Manager。开发者主要需学习OS/2 API，该接口尤其适用于C语言编程。OS/2 SDK提供了优化C编译器、宏汇编器等多种工具。OS/2基于抢占式调度器，通过时间片轮转机制调度任务。API通过动态链接库实现，节省磁盘空间并支持多任务共享。OS/2支持两种运行模式，具备高效的资源管理和应用兼容性。

POML（Prompt Orchestration Markup Language）是一种新型标记语言，旨在为大型语言模型（LLM）的高级提示工程提供结构化、可维护和多功能的解决方案。它通过类似HTML的语法规构，如``、``、``等语义组件，提升提示的可读性、可复用性和可维护性。POML支持整合多种数据类型（如文本、表格、图片），并通过类似CSS的样式系统分离内容与展示，解决LLM对格式敏感的问题。它还提供模板引擎、IDE扩展（如Visual Studio Code）、SDK（Node.js和Python）等开发工具，支持动态生成复杂的提示并进行实时预览和测试。用户可通过VS Code市场安装POML扩展，并配置LLM模型、API密钥和端点以进行测试。

文章摘要

Claude Code IDE for Emacs 通过 Model Context Protocol (MCP) 实现与 Claude Code CLI 的原生集成，打造双向通信桥，使 Claude 能利用 Emacs 的强大功能，如 LSP、项目管理、自定义 Elisp 函数等。其主要功能包括自动项目检测、终端集成、MCP 协议支持、工具集成（如文件操作、编辑状态等）、诊断集成（如 Flycheck、Flymake）、高级差异查看（通过 ediff）、标签栏支持和选择缓冲区跟踪等。Claude 能执行项目范围的搜索、重构，访问特定模式及其功能，并执行自定义 Elisp 函数，从而提供更智能的上下文感知协助。安装需 Emacs 28.1 及以上版本、Claude Code CLI、vterm 或 eat 包，并通过 use-package 配置。
