文章摘要

12世纪哲学家兼神学家迈蒙尼德认为，"天使"是解释宇宙运动的无形力量，包括性高潮等生理现象。在中世纪，天使被视为解释行星运动等物理现象的“天使智能”。尽管现代物理学家不再用天使解释自然现象，但中世纪对天使的讨论促使了关于空间、物体和运动的精密辩论，这些辩论为后来的物理学概念奠定了基础。例如，天使无实体却能作用于物质，这引发了关于非物质力量如何存在和作用的探讨，帮助物理学家思考无形力量和远程作用等概念。天使学与当时物理学的结合激发了对物体和运动关系的深入思考，为现代物理学的发展提供了重要的概念工具。

IronRDP: a Rust implementation of Microsoft's RDP protocol

作者: mikece | 评分: 508 | 评论数: 33 | 发布时间: 2025-03-21 15:35
文章摘要

IronRDP 是一个用 Rust 实现的微软远程桌面协议（RDP），注重安全性。它包括多个 Rust crates，支持多种视频编解码器如未压缩位图、RLE、RDP 6.0 压缩和 RemoteFX。IronRDP 提供一个基于这些 crates 的全功能 RDP 客户端，支持异步 I/O，并展示了一个简单的同步 RDP 客户端示例，可截图并保存为 BMP 文件。此外，项目还提供了在服务器上启用 RemoteFX 的指南。IronRDP 使用 Apache-2.0 和 MIT 双重许可，拥有 1.2k 个星标和 65 个分支，由 29 名贡献者开发。

Mathup: Easy MathML authoring tool with a quick to write syntax

文章摘要

文章主要介绍了Mathup工具的使用方法和特点。Mathup是一个将简单数学表达式转换为MathML的工具，支持命令行、Node.js和浏览器环境使用。在浏览器中，用户可以通过包含脚本或使用自定义元素来解析数学表达式。Mathup提供了一个简单直观的函数`mathup`，可以将类似AsciiMath的表达式转换为MathML，并支持多种选项配置，如小数点符号、行列分隔符等。与MathJax相比，Mathup更加轻量，仅负责解析和转换，渲染则由浏览器完成。文章还提到Mathup主要针对快速书写简单数学表达式设计，不适合需要完全控制MathML的复杂场景。
