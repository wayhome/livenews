Pytest for Neovim

文章摘要

**pytest.nvim** 是一个为 Neovim 编辑器提供的插件，用于集成 Python 测试工具 **pytest**。它支持通过命令和快捷键在 Neovim 中运行、查看、附加或分离测试，并提供 Docker 支持，允许在容器中运行测试。 ### 主要功能： 1. **运行测试**：使用 `:Pytest` 命令运行当前缓冲区的测试。 2. **查看输出**：使用 `:PytestOutput` 查看测试结果。 3. **附加测试**：使用 `:PytestAttach` 自动在保存时运行测试。 4. **Docker 支持**：通过 `:PytestEnableDocker` 和 `:PytestDisableDocker` 启用或禁用 Docker。 ### 安装方法： 使用插件管理器如 **Lazyvim**、**Packer** 或 **Vim-Plug** 安装 `richardhapb/pytest.nvim`。 ### 默认快捷键： - `TT`: 运行当前文件的测试。 - `Ta`: 附加测试到当前缓冲区。 - `Td`: 从当前缓冲区分离测试。 ### 配置选项： 支持自定义 Docker 容器和路径，并可通过回调函数进行高级配置。 该插件仍在开发中，未来会加入更多功能并欢迎贡献。
