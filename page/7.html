Blasting Past WebP - An analysis of the NSO BLASTPASS iMessage exploit

作者: el_duderino | 评分: 222 | 评论数: 9 | 发布时间: 2025-03-27 12:49
文章摘要

本文分析了NSO集团利用的iMessage零点击漏洞（BLASTPASS）。2023年9月7日，Apple发布iOS安全更新，修复了两个被活跃利用的漏洞（CVE），这些漏洞由NSO集团的零点击漏洞利用程序引发，目标是一名在国际非政府组织工作的个人。该漏洞通过恶意PassKit附件，利用iMessage发送恶意图片，无需用户交互即可入侵运行iOS 16.6的iPhone。此前，Apple已向WebP项目报告该漏洞，并在随后发布修复。Google也在Chrome中修复了此问题。尽管Isosceles和Dark Navy博客详细分析了WebP漏洞的技术细节，但未解密如何在零点击场景中实现一键利用。本文作者Ian Beer通过与Amnesty International Security Lab合作，获取了BLASTPASS样本文件和崩溃日志，揭示了NSO如何实现零点击iOS漏洞利用。漏洞核心在于WebP解码过程中的Huffman编码处理不当，导致内存损坏，尽管问题触发后解析停止，但攻击者仍能利用此缺陷。

Open Source Mythology

文章摘要

这篇文章讲述了电视新闻直播中维持运作的复杂性及对技术人员的依赖。文章描述了直播涉及的各种设备和系统，如摄像机、提词器、天气预报图形等，这些设备大多可靠但偶尔会出问题。为了应对设备故障，通常需要备份系统或能解决问题的人，文章称其为“Alex”。Alex在设备出问题时负责修理，但平时有其他主要工作，如操作音频混合器。由于找到并培训这样的人才不易，Alex通常需要随时待命，甚至在家中待命以应对不同时间段的直播问题。文章指出，这种安排使得Alex的值班时间很长，尽管直播时间总共约六小时。

OpenAI adds MCP support to Agents SDK

作者: gronky_ | 评分: 769 | 评论数: 43 | 发布时间: 2025-03-26 18:55
文章摘要

Model Context Protocol (MCP) 是一种为LLM（大语言模型）提供工具和上下文的标准化协议。类似于USB-C为设备提供统一连接接口，MCP为AI模型与各种数据源和工具之间提供标准连接方式。MCP支持两种服务器类型：基于本地子进程运行的stdio服务器和通过HTTP/SSE远程连接的服务器。使用MCPServerStdio和MCPServerSse类可连接这些服务器。在Agents SDK中，MCP服务器通过list_tools()方法让LLM知晓可用工具，并通过call_tool()调用工具。为减少延迟，可以启用工具列表缓存（cache_tools_list=True），并手动清除缓存。MCP操作可自动追踪，记录工具列表调用和相关函数信息。完整示例和追踪功能详见文档。

评论摘要
主要讨论点：MCP（Model Context Protocol）的实用性、复杂性及其在AI工具连接中的角色 不同观点： • **支持简化与反对复杂性**： - [keithwhor] 认为MCP增加了不必要的复杂性，建议回归传统HTTP服务器和OpenAPI，以简化服务器构建。 - [jtrn] 也表示MCP没有提供比OpenAPI更明显的优势，且文档和灵活性较差。 • **MCP的必要性与价值**： - [bob1029] 和 [goaaron] 质疑MCP的附加价值，认为它只是重新发明了已有的解决方案（如JSON schema），并认为这是市场营销驱动的产物。 - [tcdent] 指出MCP已成为行业标准，连接LLM与外部工具，表明其得到了广泛认可。 • **MCP的应用与实际使用**： - [nomilk] 希望看到更多MCP的实际应用示例，而不仅仅是对其工作原理的解释。 - [johnjungles] 提供了一个简化MCP设置的平台，并分享了其在工作流中的实际应用，如PR摘要和问题追踪。 • **MCP与其他架构的竞争**： - [rgomez] 推广了自己的开源项目Ainara，该项目允许AI代理使用本地工具，并认为其架构可以与任何LLM和LLM服务器兼容。 - [polishdude20] 提出未来AI可能不需要MCP服务器，直接通过编写终端代码来完成任务。 补充讨论： • **MCP的复杂性与易用性**： - [simonw] 对将MCP比作USB-C接口表示怀疑，认为其实施可能带来很多困难。 - [jauntywundrkind] 关注MCP的新版本特性，如OAuth 2.1支持和JSON-RPC批处理。 • **MCP的商业角色**： - [paradite] 认为MCP通过AI代理接口使SaaS和软件商品化，更多地惠及MCP客户端而非服务器端和服务提供者。 争议焦点： • MCP是否增加了不必要的复杂性，或者它是否真正解决了现有工具未能有效处理的问题。
