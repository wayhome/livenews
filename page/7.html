Can't disable copilot code reviews

作者: TonyTrapp | 评分: 5 | 评论数: 0 | 发布时间: 2025-08-08 07:23
文章摘要

GitHub用户glyph在2025年8月7日报告了一个问题，即无法彻底禁用Copilot代码审查功能。尽管在所有可能的地方都关闭了Copilot设置，其他贡献者仍然可以请求Copilot进行代码审查，导致 pull request 中充斥无用评论。由于Copilot不是一个普通用户或应用程序，无法直接屏蔽或撤销其权限，用户质疑是否需要迁移出GitHub。 GitHub官方的自动回复表示已收到反馈并会进行审查，但由于提交量大，无法一一回复。另一用户ULTRAPAIN提供了几个可能的解决方案，包括在仓库或组织层面禁用Copilot、使用分支保护规则、创建仓库规则集以及在贡献者指南中明确说明不使用Copilot审查。 该问题尚未得到官方解答。

文章摘要

特朗普 administration发布了一项行政命令，对拨款资助（包括所有联邦支持的科研）实施政治控制。根据命令，任何资助机会的公告都需由机构负责人或其指定人员（通常是政治任命者）审查，这意味着政治任命者将最终决定美国资助的科研领域。 individual grants也需政治任命者批准，且必须符合总统的政策优先事项。该命令允许机构随时取消已授予的资助，如果这些资助不再符合机构优先事项。在新的管控系统到位前，禁止启动新的资助项目。命令还强调政治任命者不应依赖同行评审做决策，需使用独立判断，并要求受资助者每次申请资金时重新证明其资助的必要性。该命令旨在加强对科研的政治控制，可能终结美国科学领导地位的基础系统。
