Static as a Server

作者: danabramov | 评分: 112 | 评论数: 20 | 发布时间: 2025-05-08 17:49
文章摘要

本文介绍了如何使用React Server Components（RSC）构建静态网站，并通过Cloudflare CDN免费托管。传统上，“服务器”和“静态”框架被视为不同工具，但现代框架 increasingly 支持两者输出模式。通过在构建时运行服务器代码并存储响应，可以实现静态网站生成。这种“混合”框架减少了工具碎片化，提供了更大的灵活性和粒度，允许按路由选择服务器或静态渲染。例如，Next.js默认生成静态网站，同时可在需要时选择服务器功能。尽管称为“服务器组件”，它们实际上可以在部署时静态运行。因此，静态网站就是提前运行的服务器。

Block Diffusion: Interpolating Autoregressive and Diffusion Language Models

作者: t55 | 评分: 55 | 评论数: 4 | 发布时间: 2025-05-08 18:18
文章摘要

文章介绍了一种名为“Block Diffusion”的语言模型，它结合了自回归模型和扩散模型的优点。自回归模型生成质量高且适用于任意长度，但无法并行处理；而扩散模型可以并行生成，但生成质量较低且长度固定。Block Diffusion通过将序列分为若干块，每块内进行扩散生成，实现了高生成质量、任意长度、支持KV缓存以及并行采样。该模型提出了一种有效的训练算法和数据驱动的噪声调度方法，以最小化方差，并在语言建模基准上达到了扩散模型中的最先进性能。

文章摘要

Qtap 是一个基于 eBPF 的代理工具，能够在 Linux 内核中捕获加密前的网络流量，提供有关出口连接及其发起进程的详细上下文。它通过附着到 TLS/SSL 函数来截获加密前后的数据，并将其传递给灵活的插件，提供完整的可见性（进程、容器、主机、用户、协议等）。Qtap 无需修改应用程序、安装代理或管理证书，即可帮助理解出口流量的详细情况。它适用于安全审计、网络问题调试、API 开发、第三方集成故障排查、协议学习与探索、遗留系统调查和验证测试等多种场景。Qtap 要求 Linux 内核 5.10+ 并启用 BPF Type Format (BTF)，且需要提升权限来运行。项目目前处于早期开发阶段，欢迎社区反馈和贡献。

文章摘要

这篇文章讨论了动态类型语言中库的稳定性问题，并以Clojure为例，展示了其生态系统的稳定性。作者引用了Clojure社区对稳定性的赞誉，并通过Clojure及其库的代码引入和保留图表，以及Fusebox库的维护实例，证明了Clojure库的稳定性。文章指出，尽管Clojure是动态类型语言，但其惯例和实践使其具有类似静态语言的稳定性。Clojure程序主要由命名空间、函数和数据构成，避免了猴子补丁和对象序列化问题，这使得代码更易预测和维护。这种文化和实践使得Clojure在动态类型语言中显得与众不同，并保持了高度的稳定性。
