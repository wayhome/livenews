文章摘要

Ableton 在 Live 12.4.5 Suite Beta 中推出 Extensions，可用开放的 JavaScript SDK 为 Live 开发自定义工具。它能读取并修改工程中的轨道、片段、MIDI、设备和结构，用于自动化、分析、生成模式及连接外部服务。扩展通过右键菜单运行，与 Max for Live 不同，更侧重工程数据与工作流定制。

评论摘要
主要讨论点：Ableton Live 新推出的扩展 SDK，允许使用 JavaScript/TypeScript 开发扩展 不同观点： • **积极评价派**：认为这是重大进步，降低了开发门槛。JS/TS 生态系统比 Max for Live 更易用，UI 渲染能力强，适合构建外部服务集成工具。有开发者快速实现了 MIDI 乐谱显示工具作为概念验证。 • **技术局限派**：指出当前 API 功能不完整（无法创建 warp markers、访问全局拍号设置等），窗口管理受限，沙箱机制严格导致文件访问困难，实时控制仍需依赖 Max4Live。 • **替代方案倡导者**：推荐使用 Scheme for Max 通过 Lisp 脚本控制 Live API，或使用 VR 手势结合 AbletonOSC 控制。部分用户仍在使用 Python + LOM 或 ClyphXPro 开发。 • **Max for Live 批评者**：强烈不满 Max 的可视化语法和运行时，认为其开发体验糟糕，期待新 SDK 能替代它。批评 Ableton 过去将核心功能锁定在高价版本和 Max for Live 背后。 补充讨论：有用户期待实现"Google Docs 式协同编辑"、Linux 原生支持、以及扩展到 Ableton Move 设备。AI 集成被认为是该 SDK 的重要应用场景。
