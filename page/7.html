Codables – Swift-inspired, declarative JSON serialization

作者: pie6k | 评分: 11 | 评论数: 3 | 发布时间: 2025-11-04 13:34
文章摘要

CodableJSON 是一个声明式的 JSON 序列化库，旨在为 TypeScript/JavaScript 提供全新的数据序列化范式。主要特点： 1. 声明式类序列化：通过装饰器（@codableClass 和 @codable）标记可序列化的类和属性，无需手动编写转换函数。 2. 高性能：比 SuperJSON 快 3 倍，支持 Date、Map、Set 等内置类型。 3. 类型安全：完整 TypeScript 支持，包含自动补全和类型推断。 4. 无依赖：独立库，体积小于 10KB。 5. 框架无关：适用于任何 JS/TS 项目。 6. 安全：内置防原型污染保护。 提供两种使用方式： - 快速 JSON 序列化：直接 encode/decode 处理各种 JS 数据类型 - 声明式类序列化：通过装饰器定义可序列化类，自动处理类实例、引用和循环依赖 内置支持 Date、BigInt、Map、Set 等特殊类型，性能测试显示编码速度比 SuperJSON 快 3-3.5 倍。

评论摘要
主要讨论点：讨论一个新的JSON序列化库Codables的必要性及其特点。 不同观点： • **jb1991**：建议使用"Show HN"标题来更好地展示项目。 • **boxed**：建议在标题中加入"for typescript"以明确目标用户。 • **pie6k**：解释了为什么需要新的JSON序列化库Codables，尽管已经有SuperJSON这样的库存在。主要论点是SuperJSON在处理复杂数据类型和嵌套类时不够方便，而Codables通过现代装饰器减少了样板代码，使过程更加声明式。 补充讨论： • **争议焦点**：是否有必要在已有SuperJSON的情况下开发新的库。pie6k认为SuperJSON在处理复杂数据结构时存在不足，而Codables通过更简洁的方式解决了这些问题。 • **讨论关系**：jb1991和boxed的建议更多是关于项目展示和标题优化，而pie6k的回应则深入探讨了库的技术优势和适用场景。
