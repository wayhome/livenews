Search-R1: Training LLMs to Reason and Leverage Search Engines with RL

作者: jonbaer | 评分: 91 | 评论数: 7 | 发布时间: 2025-04-03 00:02
文章摘要

本文介绍了一种名为Search-R1的模型，它通过强化学习（RL）训练大型语言模型（LLM）在推理过程中自主生成搜索查询并与搜索引擎互动。与仅在推理阶段提示LLM使用搜索引擎不同，Search-R1在多轮搜索交互中优化LLM的表现，利用检索到的标记屏蔽实现稳定的RL训练和基于结果的奖励函数。实验表明，Search-R1在多个问答数据集上的性能比强基准模型提高了10%到26%。本文还探讨了RL优化方法、LLM选择及响应长度对检索增强推理的影响，并提供了代码和模型检查点。

Flame – BBS and MUD

作者: shakna | 评分: 47 | 评论数: 7 | 发布时间: 2025-03-31 12:54
文章摘要

Flame是一个公告板系统（BBS），虽然通过MUD（多用户迷宫游戏）形式实现，但它并非MUD、IRC或聊天室。对不同的人来说，Flame具有多种功能：可以 silent 访问，作为社交替代，灵魂探索之地或虚拟派对区。要连接Flame，可通过telnet访问flame.ucc.gu.uwa.edu.au的4242端口；若受防火墙限制，可使用flame-tunnel.ucc.gu.uwa.edu.au的任意端口。Flame还运行gopher服务器和web服务器。它始于1990年，最初是远程访问BBS，1991年出现在《Your Computer》杂志上，1992年转变为MUD，并保留了原BBS的电话连接。

评论摘要
主要讨论点：围绕MUD（多用户地牢）和类似技术的讨论，包括其历史、应用场景以及技术细节。 不同观点： • [01100011] 认为该系统类似于MUD，并联想到80年代太平洋西北地区的Citadel BBSes。提出由于天气原因，该地区技术发展蓬勃。 • [JKCalhoun] 提到在MacOS上需要通过命令行安装telnet，并分享了连接特定MUD服务器的命令。还设想了一个在MUD中会面的场景，用于 cyberpunk 风格的故事创作。 • [khimaros] 表达了对过去MUD（如GhostMOO）热闹时期的怀念，并询问是否有其他人有相同经历。 • [upghost] 赞赏MUD作为一个在线社交空间的概念，并希望这种形式能更常见。 • [captaincrunch] 表示对讨论内容感到困惑，似乎没有完全理解话题。 • [kaiyuanzg] 关注Flame的实用性，尤其是作为集群管理工具，并与其他解决方案（如Cloudify和OpenStack）进行比较，期待其未来的发展。 补充讨论： • MUD作为一种早期多人在线互动形式，具有历史和文化意义，特别是在80-90年代的技术社区中。 • 讨论中涉及到技术细节，如在现代系统上安装telnet以访问MUD。 • 对MUD的怀旧情感与对其未来发展的期待形成对比，反映出对不同技术时代的社会空间变迁的思考。 • 争议的焦点可能在于对MUD及其现代应用的认知差异，[captaincrunch] 的困惑反映了部分人对该话题的不熟悉。

The Mermaid Chart VS Code Plugin is a tool that allows developers to create and edit Mermaid.js diagrams directly within Visual Studio Code. It supports automatic file recognition, syntax highlighting, and real-time diagram rendering with pan and zoom features. The plugin seamlessly integrates with Markdown, enabling embedded diagrams in documentation. Advanced features include cloud integration, team collaboration, and AI-assisted diagram generation using GitHub Copilot. The plugin can be easily installed from the VS Code Marketplace, offering a frictionless workflow for both individual and team-based projects.
