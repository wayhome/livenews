Fun with uv and PEP 723

文章摘要

文章介绍了如何使用名为 **uv** 的快速Python包和项目管理工具，结合 **PEP 723** 元数据格式，简化Python单文件脚本的运行。过去运行Python脚本需要手动设置环境和依赖，而 **uv** 工具自动处理这些任务，包括创建虚拟环境、安装依赖等。通过在脚本中嵌入元数据（如Python版本和依赖），可以使用命令 `$ uv run pep.py` 直接运行脚本。文章还提供了一个实际例子，展示如何创建可执行脚本提取YouTube字幕，并通过shebang行 `#!/usr/bin/env -S uv run --script` 简化脚本执行。最终，uv使Python在处理一次性脚本时更加便捷，类似于Go语言的自包含二进制文件。

文章摘要

How to Think About Time in Programming

作者: rmason | 评分: 130 | 评论数: 24 | 发布时间: 2025-06-24 20:01
文章摘要

这篇文章讨论了编程中处理时间的复杂性，强调了“持续时间”和“瞬间”两个关键概念。持续时间指的是时间段，如博尔特跑完100米的时间，而瞬间指的是某个具体的时间点，如他冲线的那一刻。文章提出了“绝对时间”的概念，通过从某个参考点（称为“纪元”，如Unix时间从1970年1月1日开始）计算秒数来表示时间点。 文章还介绍了“民用时间”，如公历，它是用于标记时间的高级语言和标准。公历通过年月日时分秒来表示瞬间，并根据特定规则递增。虽然这些表示法对人类友好，但在编程中直接使用可能会导致问题，因此建议使用“秒从纪元”的模型来处理时间，以方便计算机进行计算和比较。 文章最后提到，虽然不同系统可以使用不同的纪元，但通过定义参考点，不同时间系统可以互操作。

How Cloudflare blocked a monumental 7.3 Tbps DDoS attack

作者: methuselah_in | 评分: 219 | 评论数: 22 | 发布时间: 2025-06-20 18:34
文章摘要
