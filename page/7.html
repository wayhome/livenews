Printegrated Circuits: Merging 3D Printing and Electronics

作者: rbanffy | 评分: 67 | 评论数: 10 | 发布时间: 2025-06-30 11:30
文章摘要

本文介绍了Oliver Child正在开发的新技术，旨在更简便地将电子元件嵌入3D打印物体中。这种名为“Printegrated Circuits”的新方法，将印刷电路板和导电材料直接整合到3D打印物品中，从而使这些物品具备智能功能。该技术有望简化生产流程，提升3D打印产品的功能性和应用范围。通过这种创新，未来的消费电子产品可能更加智能和多功能。文章强调了这种技术在消费电子领域的潜在应用和影响。

评论摘要
主要讨论点：在DIY环境中为3D打印添加导电路径以制造电路板（PCB）的可行性及不同方法 不同观点： • **monday_的观点**：提出通过双喷头3D打印机，一个打印普通塑料如PETG，另一个喷头填充锡来创建导电路径。虽然锡的导电性不如铜，但比导电塑料要好。这种方法需要处理表面张力和焊接问题，但具有一定的可行性。 • **p0px的观点**：分享了一个使用Dupont线作为导电路径的类似项目，通过GPIO引脚连接LED眼睛等组件。这个方法更像是手工组装，而非完全3D打印的电路。 • **hdjdbdirbrbtv的观点**：提到Project Binky在CNC铣床上实现了类似功能，表明其他制造方法也可以实现类似结果。 • **nickpinkston的观点**：认为这种方法虽然有创意，但实际效果不如传统铜线/箔带，且仍需组件放置功能。他建议另一种方法是使用能放置铜线或箔带的打印头，结合标准组件放置设备，认为这更具现实可行性。 • **fooker的观点**：质疑这种方法的必要性，认为传统PCB制造只需一个化学步骤，而这种方法可能会导致更差和不可靠的电路。 • **seveibar的观点**：认为这种方法在桌面快速电子原型制作中具有潜力，特别是如果EDA工具支持不同输出格式。他强调了工具链的重要性，并指出即使使用不理想的材料也能加速原型制作。 • **bitwrangler的观点**：提出使用深色3D打印材料作为光阻剂，覆盖在铜板上，然后通过曝光和蚀刻来制作传统PCB，认为这是一种结合3D打印和传统PCB制造的方法。 • **pedalpete的观点**：提到金属材料和多材料FDM打印机的发展，认为未来可以制造较大的电路，但精细度不如传统PCB。 • **rkagerer的观点**：回顾了Next Dynamics NexD1 Kickstarter的失败案例，提醒人们注意类似项目的潜在风险。 • **xg15的观点**：对这种方法的未来持谨慎态度，担心复杂电子设备的检测和维修难度会增加。 补充讨论： - **技术可行性与现实应用**：不同参与者对导电材料的选择、表面处理及实际应用中的性能问题进行了讨论。 - **工具链支持**：seveibar提到工具链的改进可以更好地支持这种新兴的制造方法。 - **历史案例**：rkagerer提到了历史上类似项目的失败案例，提醒人们关注潜在风险。 - **长远影响**：xg15对这种方法的长期影响表示担忧，特别是在设备检测和维修方面。 争议焦点： - 主要争议在于这种方法是否比传统PCB制造更具优势，特别是在导电性、可靠性和实际应用中的可行性方面。

Nimtable: Open-source web UI to browse and manage Apache Iceberg tables

作者: Sheldon_fun | 评分: 23 | 评论数: 5 | 发布时间: 2025-07-01 03:27
文章摘要

Nimtable 是一个专为 Apache Iceberg 设计的控制平台，提供轻量级、易用的界面来管理和优化基于 Iceberg 的数据湖。它支持多 catalog 连接（如 REST Catalog、AWS Glue、S3 Tables、PostgreSQL），并能与 S3 等对象存储无缝集成。平台提供表浏览、交互式查询、AI 辅助探索、文件分布分析及表优化等功能。Nimtable 通过 web 界面或 YAML 配置文件进行设置，并支持 Docker 快速部署。主要功能包括管理 catalog、运行查询、分析文件分布及优化存储布局等。未来计划包括优化压缩、增强监控分析、元数据管理和查询引擎集成等。

评论摘要
主要讨论点：从RDS迁移到Iceberg的体验与生态系统的现状 不同观点： • tlarkworthy认为从RDS迁移到Iceberg后，存储成本大幅下降，数据压缩和表管理效果更好，整体上对Iceberg的成本效益给予高度评价。然而，他指出Iceberg像是一个"解构的"数据库，很多以前在数据库内理所当然的功能现在需要在外部实现，例如写入争用需要外部协调锁和vacuum操作。同时，他期待像DuckDB和ClickHouse等工具能支持更多功能（如谓词下推），以便在通用存储层上实现专用查询引擎。 • konsalexee对tlarkworthy的评论表示赞赏，但提出在实际投入设置之前，如果能有一个互动式的演示来展示其工作原理会更好，暗示对实际操作的上手难度存在担忧。 • whyho的评论较为简短，误以为讨论的是编程语言Nim，显示出对主题的误解，未直接参与到技术讨论中。 • bradhe对Iceberg表示认可，但也指出生态系统中仍缺乏一些基础功能，例如轻松浏览表的工具。他提到目前大家都在自行实现表维护功能，并认为过去50年存储引擎替我们承担了大量工作。bradhe还建议将Iceberg与Lakekeeper结合使用，可能会有更好的效果。 补充讨论： • 争议焦点之一是Iceberg在提供强大成本效益的同时，其外部依赖和工具链的完整性仍存在不足。 • 另一个值得注意的讨论点是用户对Iceberg生态系统的期待，尤其是对更多工具和功能兼容性的需求。 • 演示和上手难度的讨论也表明，尽管Iceberg在技术和成本上有优势，用户在实际使用中仍可能面临一定的学习曲线和操作复杂性。

Creating fair dice from random objects

作者: epipolar | 评分: 34 | 评论数: 8 | 发布时间: 2025-06-28 06:11
文章摘要

研究人员开发了一种算法，可以设计和预测各种奇异形状的公平骰子，如小猫、龙或犰狳形状的骰子。这些骰子通过3D打印制作，并进行了物理实验，结果与计算机模拟的概率预测非常接近。研究从几何角度分析了不规则形状刚体在重力作用下的静止状态，而非依赖动态模拟。实验包括七种不同设计的骰子，每种都被投掷100至1000次，调整形状以使实验结果与预测值相差在3%至4%以内。该算法还能应用于其他领域，如预测物体如何在屏幕上显示或在水中落下时的方向。这项研究不仅有趣，还有助于理解和设计具有特定静止方向的物体。
