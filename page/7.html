Swift Container Plugin

作者: frizlab | 评分: 78 | 评论数: 8 | 发布时间: 2025-04-25 00:28
文章摘要

Apple的Swift Container Plugin是一个允许使用Swift Package Manager构建和发布容器镜像的工具。它简化了将Swift服务器打包成容器镜像的过程，支持一键构建和发布到容器注册表。该插件适用于macOS和Linux平台，需要Swift 6.0或更高版本，并可在本地使用容器 runtime（如Podman）运行镜像。在macOS上开发时，需安装跨平台编译的Swift SDK以适配Linux环境。该项目遵循Apache-2.0许可证，已有178个星标和11个分支。

Sea Monsters Unmasked and Sea Fables Explained by Henry Lee (1883)

作者: apollinaire | 评分: 6 | 评论数: 0 | 发布时间: 2025-04-22 06:06
文章摘要

《揭秘海怪》和《解释海洋传说》是亨利·李于1883年为国际渔业展览会撰写的两本小册子。该展览在伦敦举行，吸引了超过260万名参观者，其中最引人注目的是一个容纳65,000加仑水的大型水族馆。亨利·李是布莱顿水族馆的前博物学家，他通过理性分析和海洋研究的新发现，逐一解释并驳斥了诸如克拉肯和大海洋蛇等海怪传说。他认为这些 sightings 多为巨型鱿鱼等海洋生物的误认。在《解释海洋传说》中，他特别探讨了人鱼传说，认为这些多为海牛和儒艮的误认。李的作品既展示了海洋的神秘性，又体现了科学对海洋世界的探索，成为当时海洋神秘生物传说的重要记录。

PgDog is a transaction pooler logical replication manager can shard PostgreSQL

作者: LinuxBender | 评分: 5 | 评论数: 0 | 发布时间: 2025-04-24 17:58
文章摘要

PgDog 是一个用于 PostgreSQL 的水平扩展解决方案，支持自动分片。它采用 Rust 编写，具有快速和安全的特点，能够管理数百个数据库和数十万个连接。PgDog 作为一个事务池和逻辑复制管理器，支持负载均衡、健康检查与故障转移、事务池管理以及自动查询路由和分片。它可以自动将查询路由到一个或多个分片，支持跨分片查询，并能在内存中组装结果。PgDog 还支持逻辑复制，允许在不停机情况下对数据库进行分片和扩展。其配置灵活，支持运行时调整，无需重启进程。可以通过 Docker 和 Kubernetes 快速部署。

文章摘要
