AIDE – a file and directory integrity checker

作者: smartmic | 评分: 5 | 评论数: 0 | 发布时间: 2025-07-25 21:22
文章摘要

AIDE（Advanced Intrusion Detection Environment）是一个文件和目录完整性检查工具。它通过配置文件中的正则表达式规则创建数据库，之后可以使用该数据库验证文件的完整性。AIDE支持多种消息摘要算法（如md5、sha256等）和文件属性（如权限、大小、时间戳等）的检查。其功能包括支持文本配置文件、正则表达式、数据库压缩、以及在Unix系统上的易安装性。AIDE可在多个Linux发行版、FreeBSD、OpenBSD等系统中通过相应命令安装。其源代码和Git标签均经过GnuPG签名，当前维护者为Hannes von Haugwitz。AIDE使用GPL-2.0许可证，并提供了邮件列表和IRC渠道以获取帮助。该工具最初由Rami Lehti和Pablo Virolainen于1999年开发。

Google in 1999: Search engines escape the portal matrix

文章摘要

1999年，Google的创始人在面对质疑时坚定地认为他们拥有“最好的搜索引擎”。当时主流用户仍在使用AOL、Yahoo等门户网站的搜索服务，这些网站注重的是内部广告收入，而非搜索质量。与此不同，Google的主页简洁，只有一个搜索框，没有广告和多余内容。它通过独特的PageRank算法提供更相关的结果，而其他搜索引擎往往被商业利益驱动。尽管初期关注度不高，Google凭借用户口碑迅速增长，并在1999年6月获得2500万美元融资。创始人拉里·佩奇和谢尔盖·布林宣称，Google的目标是“组织全球信息，使其 universally accessible and useful（普遍可访问和有用）”，并展望未来使用人工智能和百万台计算机。尽管当时看似天方夜谭，但Google最终成为了搜索引擎领域的巨头。

评论摘要

The sad state of font rendering on Linux (2018)

文章摘要

本文讨论了Linux字体渲染的不足，作者以Windows的ClearType渲染为基准，认为其更利于阅读。文章解释了字体渲染的基本概念，如矢量数据的光栅化、子像素渲染、子像素定位、字体微调和抗锯齿。不同操作系统在字体渲染上采取不同策略，Windows集成了所有先进技术，尤其在Windows 7中达到了锐利的字体效果，但也有色彩边缘问题。Windows 8及之后版本则回归灰度平滑，字体较模糊。 关于macOS，作者最初批评其渲染过于模糊和粗体，但在收到反馈后，验证了High Sierra版本之前的macOS使用子像素抗锯齿，效果较好。作者推测，由于微软ClearType技术的专利限制，苹果可能避免使用相关技术，导致其渲染在锐利度上不如Windows理想。
