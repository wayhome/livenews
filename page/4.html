Models.dev: open-source database of AI model specs, pricing, and capabilities

作者: maxloh | 评分: 133 | 评论数: 17 | 发布时间: 2026-05-22 20:26
文章摘要

Models.dev 是一个开源的 AI 模型规格数据库，提供模型定价、能力等信息。项目通过 API 提供数据访问，支持查询模型规格和获取提供商 logo。数据以 TOML 文件存储在 GitHub 仓库中，按提供商和模型组织。 贡献方式： 1. 在 providers/ 目录创建提供商文件夹，添加 provider.toml 配置文件 2. 可选添加 logo.svg（使用 currentColor） 3. 在 models/ 目录创建模型定义文件，包含名称、功能支持、定价、token 限制、支持的模态等信息 4. 对于镜像提供商，可使用 extends 字段复用现有模型定义 项目鼓励社区贡献以保持数据更新。

评论摘要
主要讨论点：这个AI模型数据库/价格表是否有价值，以及它还缺哪些关键功能与数据，才能真正帮助用户比较和选型。 不同观点： • 支持实用性：有人认为该项目“很稳”“很好用”，尤其统一汇总模型与价格信息，对开源项目和日常选型很有帮助；也有人称赞近期性能优化后，大表格依然很快。 • 功能缺失派：最多人要求加入“筛选”而不只是排序，具体包括仅看当前/未过时模型、屏蔽已关闭模型、非LLM模型，以及按工具调用、多模态等能力过滤；还有人吐槽横向滚动不直观。 • 数据维度应扩展：除价格外，评论者希望增加价格变动历史、延迟基准、模型/提供商的质量表现、是否会被路由到更便宜弱模型、模型何时被“削弱”等信息，认为单看token价格会误导真实成本。 • 集成与使用案例：有人希望加入“harness + models”类对比，并举例称 Pi Dev、DeepSeek Pro 可完成与 Claude Code + Opus 4.7 类似工作，说明此类数据库可帮助发现高性价比替代方案。 • 质疑独特性：有人反驳“没有统一数据库”的说法，列出十多个类似项目，认为这属于重复造轮子，争议焦点在于该项目是否真有差异化价值。 • 具体使用疑问：有用户借机追问某“免费模型”是否有隐藏限制，以及通过AIhubmix这类聚合服务相比直接用 opencode-zen 是否有实际好处。 补充讨论：整体上，多数评论并非否定项目本身，而是在“有用”基础上强调：若想长期成立，关键在于持续更新、补齐筛选能力，并加入更能反映真实使用成本与质量的数据。

Show HN: ShadowCat – file transfer through QR Codes in a Browser

作者: unprovable | 评分: 83 | 评论数: 20 | 发布时间: 2026-05-22 11:11
文章摘要

ShadowCat 是一个完全离线的单文件 HTML 工具，用于通过二维码在两台设备间传输数据。主要用于无线功能（蓝牙、NFC等）损坏但摄像头和浏览器仍可用的旧手机。 **核心功能：** - 生成/扫描单个二维码 - 发送文件：将文件分块编码为循环播放的二维码序列 - 接收文件：通过摄像头扫描，自动拼接分块并验证 CRC32 **协议：** 使用 `QRX1` 格式，头部包含文件元信息，数据块采用 Base64 编码并带索引。 **性能：** 500字符×3fps 约 0.83 KB/s，100KB 文件需约2分钟传输。需通过本地 HTTP(S) 服务访问以获取摄像头权限。

评论摘要
主要讨论点：通过QR码实现设备间文件传输的技术方案及其应用场景 不同观点： • **技术优化派**：divan强调使用喷泉码（fountain codes）提升效率，从Luby升级到RaptorQ编码；tripflag建议直接使用二进制数据替代base64以减少帧数；hootz提到音频调制的替代方案 • **实用应用派**：unprovable用于从损坏手机提取数据；MattCruikshank设想用于气隙通信设备，结合加密和一次性密码本实现极致安全；thedougd指出可用于数据渗透，难以被封锁 • **怀旧对比派**：encom怀念蓝牙传输时代的便利性，质疑为何该功能消失 • **技术局限关注**：hoansdz质疑相机性能是否足以处理大量数据；acrophiliac遇到长度限制问题（85700>18672） 补充讨论： 多位开发者分享了类似项目实现（anhldbk的get-beam、Levitating的gist链接），显示这是一个活跃的技术方向。lukew和alex_suzuki对单页面HTML部署方式表示认可。jaysyrk寻求合作机会。整体氛围积极，但对实际性能和数据量限制存在疑问。
