Jjui – A Nice TUI for Jujutsu

作者: Curiositry | 评分: 155 | 评论数: 9 | 发布时间: 2025-05-26 02:16
文章摘要

Jujutsu UI (jjui) 是一个为 Jujutsu 版本控制系统设计的终端用户界面（TUI）。它支持通过自动补全更改 revset、 rebase 操作、修订版本的压缩（squash）、查看修订详情、移动书签、操作日志查看等功能。用户可以通过快捷键进行多种操作，如分割、恢复、编辑文件或修订，查看 diff，以及进行 Git 推送/获取等。安装方式包括通过 Homebrew、Archlinux、Nix、go install 或从源码构建。最低支持的 Jujutsu 版本为 v0.21，项目采用 MIT 许可证，并欢迎贡献。

评论摘要
主要讨论点：用户对版本控制工具 jj 的使用体验、功能评价以及与 Git 等其他工具的比较 不同观点： • **mtndew4brkfst** 是一位有多年 Magit 使用经验的用户，他认为 jj 目前缺少像 Magit 那样的强大功能，但 jjui 是他目前最喜欢的 jj TUI。他对其他 jj TUI（如 Lazyjj 和 jj-fzf）的表现不太满意，认为它们有延迟或不稳定的问题。 • **cube2222** 对 jj 非常满意，认为它已经成为了他工作流中不可或缺的一部分，尤其是与 Git 相比，jj 提供了更好的历史管理体验，并且解决了 Git 中一些令人不快的问题（如 stash 管理）。他还积极推荐其他人尝试 jj。 • **dcre** 认为 jj CLI 已经足够好用，即使他从 GitUp 切换过来也没有感到太大的不便。他指出 jj 的 TUI 让日志操作更加交互化，并且在需要交互的场景下提供了很好的支持。 • **endtime** 对 jj 的总体体验是正面的，但也提出了一些痛点，包括缺乏 GitHub PR 同步功能、原生后端不支持推拉变更、以及某些工具依赖 .git 目录导致兼容性问题。 • **skeptrune** 对 jj 没有特别强烈的需求，但赞赏社区愿意尝试和构建新的 VCS 生态系统的精神。 • **account-5** 对 jj 试图解决的问题持怀疑态度，认为目前 fossil 已经足够好用，不清楚 jj 相较于 Git 有什么显著的优势。 • **silvanocerza** 对 jj 表示了初步的兴趣，认为它可以帮助他更好地理解一些复杂的操作。 • **sam_goody** 提到 jj 目前缺乏一个好的 GUI，并对 VC 资金追逐已有成熟生态的领域而忽视 jj 这样的工具表示惊讶。 补充讨论： • **争议焦点**：主要集中在 jj 是否需要一个像 Magit 那样的强大 TUI，以及 jj 相较于 Git 的优势和痛点。部分用户（如 mtndew4brkfst 和 endtime）指出了 jj 目前存在的一些功能缺失和稳定性问题，而另一些用户（如 cube2222 和 dcre）则对 jj 的现有功能表示满意并积极推荐。 • **功能需求**：endtime 和其他用户提到了一些 jj 目前缺乏但非常有用的功能，如 GitHub PR 同步和推拉变更支持，这些问题对 jj 的广泛应用和推广造成了一定的阻碍。 • **工具兼容性**：endtime 和 silvanocerza 提到了一些旧有工具和脚本对 .git 目录的依赖问题，这显示了 jj 在兼容性方面还需要进一步改进。 总体来看，讨论围绕 jj 的使用体验、功能完善度、以及与 Git 等其他工具的比较展开，用户对 jj 的未来发展充满期待但也指出了一些亟待解决的问题。

The truth about soft plastic recycling points at supermarkets

作者: Kaibeezy | 评分: 69 | 评论数: 20 | 发布时间: 2025-05-26 08:47
文章摘要

这篇文章揭示了英国超市软塑料回收计划的真相。调查追踪了40捆软塑料废物，发现其中70%被焚烧，而非回收，剩余部分则被降级回收为低价值产品，多数流向土耳其。环保组织ClientEarth警告，超市误导消费者。文章呼吁Sainsbury's和Tesco支持到2040年全球塑料生产减少40%，并推动减少一次性塑料包装，转向可重复使用系统。当前，全球正谈判制定《全球塑料条约》以应对塑料危害，文章鼓励公众签署请愿书以促进变革。

评论摘要
主要讨论点：软塑料回收及其替代处理方法（如焚烧）的有效性和可行性 不同观点： • chimprich认为30%的软塑料被回收利用是一个不错的成果，并相信随着时间推移可以提高这一比例。他还认为，对已经分类好的塑料进行焚烧以回收能源是有效率的。 • stevep98指出一些特定产品，如Trex复合甲板，能够很好地利用回收的塑料，同时他也认为如果焚烧技术正确，焚烧并不是一个问题。 • PlunderBunny认为软塑料回收的结果取决于国家，如新西兰将软塑料回收制成围栏柱，并认为应进行研究而不是简单地否定或肯定回收。 • Scramblejams担心回收塑料中的有毒阻燃剂，认为在确保安全之前，埋葬塑料可能更安全。 • lotophage支持将塑料焚烧用于发电，因为塑料具有高能量含量，比褐煤更高效。 • meindnoch同样支持焚烧塑料，认为这样可以减少填埋，并减少对褐煤的开采。 • comrade1234指出在苏黎世只有PET塑料被回收，其他塑料都被焚烧发电，且二氧化碳被捕获再利用。 • Molitor5901认为应减少一次性塑料的使用，因为塑料难以回收，并提到自中国停止进口后，美国的塑料回收项目大多关闭。 • seanalltogether引用Penn和Teller的视频，认为只有玻璃和金属罐是真正的可回收产品。 • ninalanyon主张通过禁止塑料出口和非可再生塑料包装来加速塑料的减少和回收，并认为技术解决方案应由行业自行解决。 • Caelus9认为普通个人应尽量减少使用一次性塑料，但承认这在日常生活中具有挑战性。 • biofox认为将塑料转化为燃料颗粒也是一种回收形式，赋予其第二次生命。 • pfdietz建议将塑料分解回有用原料或单体，作为回收和焚烧之间的中间步骤，并认为应重点消除PVC等含氯塑料。 补充讨论： • REDcycle在澳大利亚的失败案例（lotophage）显示出软塑料回收在实际操作中面临的困难。 • 关于焚烧技术的讨论，强调了现代焚烧设施的过滤和高效性（stevep98, comrade1234, worldsayshi）。 • 有关回收塑料的安全性问题，特别是与食品接触时的潜在风险（Scramblejams）。 • 强调政策和法规在推动塑料回收和减少使用中的作用（ninalanyon）。 • 不同地区对塑料回收和焚烧的处理方式不同，例如新西兰和苏黎世的案例（PlunderBunny, comrade1234）。

AI makes bad managers

作者: zdw | 评分: 52 | 评论数: 12 | 发布时间: 2025-05-26 17:09
文章摘要

文章讨论了在绩效评估季节，一些经理依赖ChatGPT撰写评估报告，认为这种捷径阻碍了他们的成长。绩效评估不仅是评价员工，更是提升管理技能的关键机会。管理需要精确、同理心和战略思维，过度依赖AI如同跳过锻炼，无法增强管理能力。文章建议，AI可用于简历筛选等重复性任务，但在涉及人类行为和模糊决策的管理工作时，应亲自实践以获得成长。关键是将AI视为辅助工具，而非替代管理经验的抽象层。

评论摘要
主要讨论点：AI在员工绩效评估中的作用以及对管理者的影响 不同观点： • UltraLutra认为，绩效评估在实际操作中往往是 arbitrary（随意）的，AI无法创造出优质的内容，只能在语言上进行修饰。他认为大多数管理者并不会投入过多精力，因为他们的上级并不重视评估的质量。有效的管理者会花时间进行评估和人才培养，但管理者并没有被激励去成为有效的领导者。 • Ford认为，AI适合处理繁琐或明确的任务，但不应处理工作核心内容。他指出，AI可以辅助但不能替代管理者在绩效管理中的关键作用。 • Zoechi表示，根据其近40年的工作经验，大多数管理者表现不佳，因此AI只会带来改进。 • Palmotea则提出反讽观点，认为如果所有管理者因为AI变得不好，那么这将成为新的常态，不存在问题。 • Conception指出，员工不应通过绩效评估来了解自己的表现，管理者应通过日常沟通来反馈。绩效评估应是积极的，除非打算让员工进入绩效改进计划（PIP）或解雇。 • Bryanrasmussen以讽刺口吻提到对AI取代管理职位的担忧，并暗示人们试图通过写文章来说服他人AI不能取代管理者。 • NAHWheatCracker分享了个人经历，其管理者总是提供模糊的反馈，导致其对工作改进感到困惑。他认为坏管理者会毁掉这个过程，AI可能会让情况更糟。 • Jredwards反驳认为，如果认为写好绩效评估就是好管理者，那已经是不称职的表现。 • Moret1979以讽刺语气回应，认为AI让坏管理者变得成功。 • Lyu07282怀疑某评论是对管理者工作的过度美化，带有讽刺意味。 • Intellectronica认为，好的管理者可以通过AI辅助变得更好，AI并不会使 mediocre（平庸）的管理者变好或坏管理者变 mediocre。 • Somesortofthing认为，生成很少被阅读的报告是AI的一个很好用例，绩效评估本质上是零和的，一旦排名确定，其他激励机制就会自动生效。 补充讨论： • 争议的焦点在于AI是否能替代或辅助管理者进行有效的绩效评估。部分人认为AI只能处理繁琐任务，不能替代人类管理者的判断和反馈；其他人则认为AI可以提升管理效率，尤其对好的管理者而言是工具，而坏管理者则可能依赖AI导致更差的结果。 • 个人经验分享揭示了绩效评估中存在的模糊反馈和沟通不畅的问题，这可能因管理者风格不同而加剧。 • 对管理者的职责和绩效评估的目的存在不同理解，一些人强调日常反馈的重要性，另一些人则关注评估的正式性和积极性质。

Emilua is an execution engine. As a runtime for your Lua programs

作者: delduca | 评分: 26 | 评论数: 2 | 发布时间: 2025-05-26 12:39
文章摘要
