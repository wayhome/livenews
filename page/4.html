A SQL-Inspired Query Language Designed for Event Sourcing (2025)

作者: goloroden | 评分: 18 | 评论数: 3 | 发布时间: 2026-05-13 19:02
文章摘要

文章介绍了 EventQL：一种为事件溯源场景设计、类似 SQL 的查询语言。它能针对事件类型、主题层级、时间戳和嵌套数据进行过滤、排序、聚合与投影，适合利用索引高效查询事件流。EventQL 强调显式 `PROJECT INTO`、主题层级匹配和 SQL 式表达能力，使查询更直观且便于优化。作者还提到将原先为 GethDB 编写的 EventQL 解析器重构为独立、生产可用的 Rust 库，支持完整语法、强类型 AST 和详细错误信息。

评论摘要

Zenith 是一个实时显示头顶星空的网站，通过极小视场高倍率放大，让地球自转造成的恒星视运动可见。它可按用户位置展示对应天区，位置不上传；使用 Pan-STARRS 天文图像、SIMBAD 数据和地图瓦片技术。不同纬度看到不同“星空丝带”，同纬度东西方向仅时间不同。

评论摘要
主要讨论点：围绕一个用投影/网页方式直观感受地球自转、天空移动的天文工具，大家分享体验、改进建议和概念疑问。 不同观点： • 体验价值：多人认为该工具很酷，能在“零设备”或少设备情况下，让地球自转变得直观、具身化。petee 提到望远镜追踪失效后，孩子们反而因太阳快速移出视野而更震撼。 • 投影使用：dylan604 和 meta-meta 都对“投影到天花板”感兴趣，认为这能带来类似非跟踪望远镜观察天体漂移的体验。 • 功能建议：dylan604 因屏蔽定位请求只能看到默认 Stonehenge，建议允许手动输入经纬度；a-kgeorge 建议增加搜索框，可跳转到特定恒星或坐标。 • 概念疑问：meta-meta 对“天空带一粒米高、2500粒米长”的说明不清楚，询问“一粒米高”是否指手臂长度下的角直径。 • 类似自然观察法：toss1 补充说，在阿尔卑斯、落基、安第斯等有尖锐山脊的地区，可用低空月亮被山体遮挡的方式裸眼观察月亮移动，效果甚至比望远镜中漂移更有冲击力。 补充讨论：开发者 smorgasborg 出面表示可回答问题。争议不明显，主要集中在体验分享、说明清晰度和功能改进。
