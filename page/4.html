Windows RDP lets you log-in using revoked passwords. Microsoft is ok with that

作者: drpixie | 评分: 8 | 评论数: 0 | 发布时间: 2025-04-30 23:48
文章摘要

微软表示，不计划修改Windows中的远程登录协议，该协议允许用户在更改密码后仍能使用已撤销的密码进行远程登录。这一设计决策旨在确保用户不会被锁定，即使系统长时间离线，至少一个用户账户始终能登录。独立安全研究员Daniel Wade指出，这一行为违背了用户的普遍预期，即更改密码应切断所有关联设备的访问权限。旧密码可通过RDP持续访问机器，绕过云验证和多因素认证。微软认为这不构成安全漏洞，不会进行修改。这一问题源于本地存储的凭证缓存机制，可能导致安全风险，尤其是在账户凭证泄露的情况下。
