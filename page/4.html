这篇文章介绍了名为"Claude Code PM"的开源项目管理系统，主要特点包括： 1. 该系统基于GitHub Issues和Git工作树，支持并行代理执行，用于管理Claude代码项目。 2. 核心功能是规范驱动开发，通过将产品需求文档(PRD)转化为史诗(Epic)，再分解为GitHub任务，最后转化为生产代码，实现全流程可追溯。 3. 系统优势包括：上下文持久化、并行任务执行、规范驱动开发、透明化进度追踪、智能任务优先级排序。 4. 采用GitHub Issues作为协作平台，实现人机无缝交接和团队协作，所有工作状态和审计记录都集中在一个地方。 5. 系统架构包含上下文管理、命令定义、代理执行等模块，遵循严格的5阶段开发纪律：构思→文档→规划→执行→跟踪。 6. 项目采用MIT开源许可，目前已获得50星标和5个分支。 该系统旨在解决开发过程中常见的上下文丢失、工作冲突、需求漂移和进度不透明等问题。
