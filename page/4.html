Orthrus-Qwen3: up to 7.8×tokens/forward on Qwen3, identical output distribution

作者: FranckDernoncou | 评分: 195 | 评论数: 9 | 发布时间: 2026-05-15 22:38
文章摘要

Orthrus 是一种双视图扩散解码框架，在保持自回归LLM严格无损输出的同时实现并行生成。基于Qwen3模型，最高约7.8倍加速，KV缓存仅O(1)额外开销，只微调16%参数，并优于投机解码和现有扩散语言模型。

评论摘要
主要讨论点：一种为自回归Transformer加入扩散注意力模块、并保持输出分布与原模型一致的加速方法，是否能降低推理拥堵、减少算力、适用于本地模型，以及相较其他方案的优劣。 不同观点： • 应用前景关注：有人问如果 OpenAI/Anthropic 采用类似方法，是否能缓解下午高峰期的推理拥堵，核心关切是服务端吞吐提升能否转化为用户侧排队减少。 • 技术合理性认可：有评论认为这个思路“很自然”，惊讶于此前没有被尝试或实现，并提到类似 DTree 技巧可能也适用。 • 成本与收益疑问：有人追问这种加速是否等价于类似比例的算力下降，以及“代价是什么”，争议焦点在于速度提升是否伴随额外训练、显存、复杂度或适用范围限制。 • 本地模型应用期待：有评论希望该方法能支持 GGUF、量化版 Qwen 或 DeepSeek，从而显著改善本地大模型运行速度。 • 与扩散模型路线的比较：有人质疑该方法只是从 Qwen3 蒸馏出扩散Transformer；虽然“输出可证明一致”有价值，但完整扩散Transformer理论上可能更快。 • 作者/合作者补充说明：该方法是在冻结的自回归Transformer每层注入可训练扩散注意力模块，扩散头并行预测32个token，再由AR头验证并接受最长匹配前缀；与基础模型输出分布完全一致。实验称 MATH-500 上最高 7.8x TPF、约6x实际加速，只训练16%参数，用不到1B tokens。 补充讨论：作者强调其优势是无需外部draft模型、无单独KV cache、无TTFT惩罚，且准确率与Qwen3-8B一致；限制包括只评估Qwen3、继承基座模型缺陷、目前仅支持greedy与rejection sampling。

My Favorite Bugs: Invalid Surrogate Pairs

作者: meysamazad | 评分: 81 | 评论数: 14 | 发布时间: 2026-05-16 12:49
文章摘要

文章讲述作者最喜欢的一个协同编辑器 Bug：在 TipTap/ProseMirror + Yjs 中，插入相邻的特定 emoji 会导致内容停止同步且无报错。原因是某些 emoji 位于 U+FFFF 以上，在 JavaScript UTF-16 中需用代理对表示；底层 CRDT 在错误位置 splice，切断代理对，产生无效字符。文章借此解释 code units、code points、grapheme clusters 的区别，以及 JS 的 `slice()` 如何可能破坏 emoji。

评论摘要
主要讨论点：围绕 Unicode 字符串处理、CRDT/编辑器按何种粒度切分文本，以及无效编码在不同系统中的实际坑。 不同观点： • 反对按 code unit 处理字符串：认为 CRDT 库若按 UTF-16 code unit 操作，必然会切断 surrogate pair，产生非法 Unicode；Dart、TypeScript 中也有人遇到 emoji 被切半或外部服务拒收的问题。 • 支持按 grapheme cluster 处理用户可见文本：在文本编辑器场景中，emoji、国旗等应作为不可拆分单位；有人提到用 Intl.Segmenter 解决 Mastodon 客户端中旗帜 emoji 被截断的问题。 • 对 grapheme cluster 持谨慎态度：chrismorgan 指出扩展字素簇随 Unicode 规则变化并不稳定，可能类似 PostgreSQL 因 collation 变化导致索引损坏；认为 scalar value 才是技术上安全的边界，但仍可能产生语义“乱码”。 • “emoji 原子节点”只是局部修补：有人认为把 emoji 作为原子节点能避免常见问题，但底层风险仍在，理论上其他文字如 CJK 也可能受影响。 • 有时应避免解码成文本：jonhohle 认为若只需匹配 ASCII，使用二进制正则比强制输入编码更稳健，尤其面对未知来源或遗留数据时，可减少编码转换错误。 • 系统环境也会制造 Unicode bug：dimes 举例服务器默认 LANG 不支持 Unicode，SSH 登录后环境变量被修改，导致问题“自动消失”。 补充讨论： • Windows 文件名可含未配对 surrogate，Linux 文件名可含非法 UTF-8，因此出现 WTF-8 用于往返保存异常字符串。 • 有人建议使用 toWellFormed、属性测试、交互式 playground 等工具发现或修复 Unicode 问题。 • 争议焦点在于：字符串 API 应按 code unit、scalar value 还是 grapheme cluster 操作；安全性、稳定性与用户直觉之间难以兼得。

The sigmoids won't save you

作者: Tomte | 评分: 282 | 评论数: 55 | 发布时间: 2026-05-15 10:51
文章摘要

文章指出，“所有指数增长最终都会变成S曲线”虽正确，但不能据此断言增长会很快放缓。作者用出生率、太阳能和AI能力预测的误判说明：趋势可能在很长时间内仍保持指数型。若不理解机制，应更多依赖林迪法则：已持续越久的过程，往往还会持续更久。

评论摘要
主要讨论点：AI能力/产业增长究竟会持续指数上升，还是进入S型放缓；以及用Lindy法则、sigmoid、趋势线等模型预测AI未来是否可靠。 不同观点： • 不确定性派：认为无论数据或模型多精致，都难以确定AI何时繁荣或崩盘；若能准确预测早已获利巨大。数学模型“有效直到失效”，更应关注逻辑论证、监管、政策和现实后果，而非用sigmoid或Lindy当结论。 • Lindy支持派：主张在不了解趋势极限时，可默认趋势还会持续约已持续时间；可给出粗略置信区间。有人将其用于判断高速成长公司或AI趋势还能持续多久。 • Lindy/趋势线质疑派：指出作者可能因预测AGI很快到来而有立场偏向；趋势不是静态对象，不能简单套Lindy。也有人建议应做贝叶斯拟合并给出置信区间，因为不确定性极高。 • S型/约束派：认为所有指数增长最终都会因限制因素变成sigmoid。例子包括Nvidia数据中心收入三年增15倍但不可能再持续三年；芯片产能、晶圆厂建设、电力、能源和制造链都不是无限可扩张。 • 多重sigmoid派：飞机速度看似长期增长，其实是螺旋桨、喷气、冲压等多代技术接力；AI也类似，GPT-2架构本身已不够，靠多次架构和算法突破叠加。未来是否继续取决于是否出现下一条技术曲线。 • 硬件乐观派：虽然摩尔定律放缓，但当前AI硬件仍低效；模拟矩阵乘、memristor、存算融合等突破可能抬高AI上限。 • 能力衡量怀疑派：认为AI在便利指标上进步，不等于接近真正智能或意识；神经网络只是更好拟合定义好的函数。Wharton图表等“能力Y轴”含义不清，难说新模型真有数倍智能。 • LLM上限派：认为LLM主要是在训练数据内插，需要大量人工数据生产；所谓指数增长或许只是软件复用和库知识释放，未必能超出训练分布。 补充讨论：争议焦点集中在“AI增长曲线的正确模型”“现有基准是否代表真实智能”“供应链/能源是否会成为硬上限”，以及是否会出现新的算法或硬件突破延续增长。

文章考察“新冰毒”（P2P法）是否因化学差异导致更严重精神问题。美国2009-2012年从麻黄碱法转向P2P法；早期P2P会混有较多低活性的l-甲基苯丙胺，但到2019年几乎全为d型。DEA数据显示现代街头冰毒纯度、效力更高，暂无充分证据证明其“化学不同”导致疯狂。

主要讨论点：甲基苯丙胺（meth）“新旧制法”是否导致危害差异，以及应监管还是禁止。 不同观点： • 支持放松管制者认为，伪麻黄碱/麻黄碱路线更简单、纯净，杂质更少；政府若开放监管、控制纯度和小量获取，可减少黑市、卡特尔和健康风险。 • 反对者强调，meth 本身就高度成瘾、缺乏有效治疗且有神经毒性；真正致命的是药物本性，而非单纯污染。 • 另一派认为问题可能在 P2P“新 meth”的杂质或工艺差异，或其使用方式更偏向孤立、妄想；若确有化学差别，应尽快查明。 • 也有人认为“new meth”并不新，只是受管制后从伪麻黄碱路线又回到 P2P；类似芬太尼，禁令反而把市场推向更危险的地下供应。 补充讨论：争议焦点主要是“危害来自纯度/杂质，还是来自 meth 本身与使用规模”。另有观点提到伪麻黄碱并未完全禁售，只是限购。

Naturally Occurring Quasicrystals

作者: lukeplato | 评分: 83 | 评论数: 6 | 发布时间: 2026-05-14 14:32
文章摘要

文章介绍天然准晶极其罕见，通常由小行星高速碰撞、雷击或核爆等极端事件形成。俄罗斯Khatyrka陨石发现三种准晶；内布拉斯加沙丘放电产生一种十二重准晶；另有三位一体核试验遗址准晶，并附相关研究文献。

评论摘要
主要讨论点：围绕准晶体/非周期晶体结构的形成、发现故事及相关自然或极端条件下产生的新材料展开。 不同观点： • 推荐科普叙事：有人推荐 Paul Steinhardt 的《The Second Kind of Impossible》，强调其从理论、实验到俄罗斯陨石场实地寻找准晶体的过程很精彩。 • 关注极端环境产物：有人补充核爆副产物 trinitite 中发现的新型笼状“包合物”结构，作为类似极端条件下形成特殊材料的例子。 • 总结科学要点：评论指出准晶体是非周期结构，形成条件罕见，通常需要瞬时高温；可能来自太空碎片撞击或闪电击中沙地。 • 扩展到自然界案例：有人提到能让等足类动物变蓝并致死的“天然”准晶/旁晶病毒，说明类似有序结构也存在于生物系统。 • 数学关联观点：有人提到数学家和化学家曾讨论这些结构的图案可能与素数分布有关，引出准晶体与数论/图案规律的联系。 • 可视化兴趣：有人重制了文章中的高清 GIF，侧重展示结构美学和可视化效果。 补充讨论：整体没有明显争吵，更多是围绕准晶体主题进行资料补充、相关案例扩展和跨学科联想。
