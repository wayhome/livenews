Show HN: SmartStepper – Multi-Step Form Library with Config-Based Flow

作者: milad_shirian | 评分: 13 | 评论数: 4 | 发布时间: 2025-06-29 13:55
文章摘要

SmartStepper 是一个强大的 React 组件，用于简化多步骤表单的创建，支持状态管理、验证和灵活的 UI 设计。它与 `react-hook-form` 无缝集成，支持 Yup/Zod 验证，并提供可配置的 API，适用于动态表单、用户引导和结账流程等场景。其主要特点包括： 1. **状态机管理**：通过状态机跟踪当前步骤，确保高效的步骤导航和可控的过渡。 2. **配置驱动**：所有步骤逻辑、导航和视图在一个配置对象中定义，无需单独定义步骤或模式数组。 3. **视图与 UI 分离**：鼓励步骤逻辑和 UI 渲染分离，允许自定义每个步骤的 UI 组件。 4. **导航钩子**：提供 `useSmartStepper` 钩子，用于访问导航方法和表单控制。 5. **验证集成**：与 `react-hook-form` 集成，支持 Yup 或 Zod 验证规则，确保数据完整性。 6. **自动注销字段**：导航回上一步时自动注销表单字段，保持表单状态清洁。 安装时需额外安装 `react`、`react-hook-form`、`yup` 或 `zod` 等依赖。基本使用包括导入必要组件、定义步骤组件和创建 Stepper 配置。

Sirius 是一个 GPU 原生的 SQL 引擎，通过 Substrait 查询格式与现有数据库（如 DuckDB）集成，无需重写查询或进行重大系统更改。它适用于交互式分析、金融工作负载和 ETL 任务，在 TPC-H 测试中，SF=100 时相较于 CPU 查询引擎有约 10 倍的速度提升。Sirius 支持 Ubuntu 20.04 及以上版本、NVIDIA Volta 或更高版本的 GPU、CUDA 11.2 及以上，以及 CMake 3.30.4 及以上版本。用户可以通过 AWS 镜像、Docker 镜像或手动安装来配置环境。构建 Sirius 需要克隆其仓库并使用特定命令进行编译，如需使用 Python API，还需额外安装相关包。
