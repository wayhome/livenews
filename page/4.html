Use the Gemini API with OpenAI Fallback in TypeScript

文章摘要

本文介绍了如何在使用Gemini公共API时，设置一个安全回退机制以应对超出请求限制的情况。作者通过使用OpenAI的TS/JS库和一些辅助函数实现这一功能，特别是在一个图表制作应用中，Gemini模型的请求限制为每分钟20次。 首先，定义要使用的模型类型，包括Gemini和OpenAI的模型。然后，创建一个辅助函数`getCompletion`，该函数接收两个配置对象，分别对应两种模型。在请求第一个模型失败时，自动回退到第二个模型。示例代码展示了如何调用该函数并输出结果。 此外，文章还提供了一个用于生成类型安全结构化输出的辅助函数`getJSONCompletion`，并演示了如何使用Zod库来解析和验证响应格式。通过这种方式，可以灵活地在不同AI模型之间切换，并确保输出的可靠性。

作者: taubek | 评分: 70 | 评论数: 13 | 发布时间: 2025-04-07 12:49
文章摘要

欧盟计划在未来几周内提出削减《通用数据保护条例》（GDPR）的提案，以简化法规，提高欧洲企业的竞争力，特别是针对中小企业。欧盟委员会主席冯德莱恩将此作为优先事项，旨在减少企业因复杂法律合规而耗费的时间和成本。尽管承认GDPR在隐私保护方面的必要性，但丹麦数字部长Caroline Stage Olsen指出，法规需要更简便的执行方式。前意大利总理德拉吉也曾警告，复杂的法规阻碍了欧洲经济追赶美国和中国。此次修改可能涉及简化数据处理记录和数据保护影响声明等要求。然而，修改GDPR可能引发大型科技公司与隐私保护倡导者之间的激烈游说战，有人担心这可能削弱该法律的效力。

评论摘要

The “S” in MCP Stands for Security

文章摘要

文章讨论了MCP（Model Context Protocol）这一新标准在促进大型语言模型与工具和数据集成方面的优势和潜在安全风险。MCP允许AI代理连接工具、维持会话并共享上下文，但其默认设置并不安全，可能导致命令注入、工具中毒、静默重定义和跨服务器工具劫持等安全问题。文章详细描述了这些风险，并指出MCP目前缺乏认证标准、上下文加密和工具完整性验证机制。为应对这些问题，文章建议开发者进行输入验证、固定服务器和工具版本、清理工具描述，平台构建者应展示完整工具元数据并强制执行会话安全，用户则应避免连接到随机服务器并监控会话行为。文章最后提出建立像ScanMCP.com这样的工具来审计和标记MCP工具的风险。
