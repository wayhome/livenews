Bttf is a command line datetime Swiss army knife

作者: burntsushi | 评分: 136 | 评论数: 13 | 发布时间: 2026-05-28 02:58
文章摘要

Biff是一个命令行工具，用于处理日期时间的算术运算、解析、格式化等操作。主要功能包括：打印当前时间、在不同时区间转换、添加或减去时间段、计算时间跨度、格式化时间戳、生成日期序列（如每月第二个星期二）、从日志文件中提取和转换时间戳等。支持多种时间格式（RFC3339、RFC9557等）、时区处理、时间舍入、相对时间表达式（如"next sat"、"1 week ago"）。该工具采用MIT或UNLICENSE双重许可，提供详细的用户指南和命令行帮助文档。

评论摘要
主要讨论点：关于 Bttf/Jiff 时间处理工具的实用性和技术特点 不同观点： • **支持派**：认为工具设计优秀，特别赞赏其将"民用时间"和"绝对时刻"作为不同类型处理的设计理念，这是 GNU date 和多数标准库 API 的缺陷。指出 Jiff 借鉴了 TC39 的 Temporal 标准，这是 JS 首次在时间处理领域引领创新。有用户表示该工具可替代约 40 行 bash 脚本，用于处理"节假日后第二个周二"等复杂日期逻辑 • **AI 替代论**：认为此类工具已被 LLM（包括本地模型）完全淘汰，直接询问 ChatGPT 等 AI 更高效，尤其是处理日志时间戳转换等一次性任务 • **其他工具用户**：提到 dateutils 等替代工具，表示会对比测试哪个更符合人体工程学 补充讨论： - 有人混淆了工具名称，将 "bttf"（Back to the Future）误认为 "biff"（Unix 邮件通知工具） - 发现了格式化输出的小 bug（"M05" 而非 "May"） - 作者展示的核心用例是通过并行化 git log 查询，按最近修改时间排序仓库文件，并支持自定义时间格式和时区转换

Tuning LLVM's SLP Vectorizer Cost Model

作者: matt_d | 评分: 6 | 评论数: 0 | 发布时间: 2026-05-28 16:44
文章摘要

这篇文章讨论了LLVM编译器SLP向量化器的性能回归问题。作者发现一个LLVM补丁将标量浮点加法链替换为有序向量归约指令后，在RISC-V目标上导致性能下降89%。 问题根源在于：新代码虽然使用了向量归约指令（vfredosum.vs），但每次迭代都需要先将标量值存储到栈上（fsd指令），再加载到向量寄存器，这个构建向量的开销未被正确计入成本模型。结果导致指令数增加26%，执行周期增加48%。 作者通过分析汇编代码和LLVM IR，定位了引入这些低效指令的位置，为修复这个成本模型缺陷提供了基础。

文章摘要

评论摘要
主要讨论点：航空旅行的演变及其对度假模式的影响 不同观点： • **地理认知的局限性**（ilamont）：波士顿居民对近距离目的地存在认知偏差，蒙特利尔等地虽然更近却被视为"遥远"，而华盛顿特区虽远却更受欢迎。过去依赖本地海滩（科德角等），冬季只去百慕大和佛罗里达。 • **航空旅行的民主化**（raddan）：90年代飞行还是精英特权，朋友中只有一人坐过飞机。2000年代后情况剧变，2009年JetBlue推出500美元三个月无限飞行套餐，使频繁跨国往返成为可能。航空从奢侈品变为大众消费。 • **百慕大旅游的现状**（lo_zamoyski）：文章缺乏深度分析，但指出百慕大因进口依赖导致物价高昂（早餐30美元），这可能影响其作为度假目的地的吸引力。 补充讨论：有评论者分享了为百慕大航空公司开发自动化系统的经历，以及关于百慕大地理的视频推荐。整体讨论反映了航空业变革如何重塑人们的旅行习惯和地理认知。

Seeing Around Corners Using Smartphone-Grade Lidar

作者: marc__1 | 评分: 61 | 评论数: 5 | 发布时间: 2026-05-25 11:32
文章摘要

这篇文章报道了使用智能手机级别的激光雷达(Lidar)实现"看穿角落"的技术突破。研究人员开发出低成本系统,虽然无法捕捉清晰图像,但能揭示隐藏物体的大致形状。这项技术可能改善机器人和自动驾驶车辆的性能。文章发表于2026年5月20日的IEEE Spectrum,作者Charles Q. Choi,来自MIT媒体实验室的研究成果。

评论摘要
主要讨论点：WiFi信号可通过生物特征识别技术"透视"墙壁和角落，识别人体行走模式 不同观点： • **隐私担忧派**：研究者警告该技术将每个路由器变成潜在监控工具，普通人经过咖啡馆WiFi网络时可能在不知情下被识别和追踪，呼吁IEEE在802.11bf标准中加入更强隐私保护措施 • **技术演进派**：认为消费级硬件已能实现过去研究级和工业级的技术能力，这可能是多个技术领域的转型信号，期待该领域有更多发现 • **技术细节质疑派**：对实现条件提出疑问，如是否需要角落对面有墙壁才能工作 • **替代方案派**：提出简单的物理解决方案——在角落放置45度镜子即可看到拐角处，无需激光雷达且效果更好 补充讨论：有评论将此技术与智能手机级激光雷达（如FaceID）进行类比，暗示类似的生物识别技术可能在多个消费级设备中存在。研究基于近200名参与者的WiFi信号记录，使用BFI方法和传统CSI方法从四个角度采集数据。
