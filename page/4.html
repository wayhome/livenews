Google to embrace MCP

文章摘要

Google DeepMind宣布将支持Anthropic的模型上下文协议（MCP），该协议允许AI模型从业务工具、软件、内容库和应用开发环境等数据源获取数据，建立双向连接。MCP已成为开放标准，获得多家公司采用。Google计划将MCP集成到其Gemini模型和SDK中，但未给出具体时间表。这一举措旨在促进行业合作，共同推动AI技术发展。

DolphinGemma: How Google AI is helping decode dolphin communication

作者: alphabetting | 评分: 243 | 评论数: 23 | 发布时间: 2025-04-14 13:12
文章摘要

Google开发的AI模型DolphinGemma正协助科学家研究海豚的交流方式，旨在破解其“语言”含义。该项目由Google与乔治亚理工学院及野生海豚项目（WDP）合作推进。WDP自1985年起研究巴哈马野生大西洋斑点海豚，积累了数十年的水下音视频数据。通过分析海豚的哨声、脉冲等声音与行为的关联，研究人员试图理解其交流结构和潜在意义。DolphinGemma模型利用WDP的数据进行训练，使用Google的音频技术分析海豚声音，识别模式并预测声音序列，帮助研究人员发现隐藏的结构和意义。最终目标是通过技术与海豚建立互动交流，甚至形成共享词汇。

文章摘要

Google将开始将其国家代码顶级域名（ccTLD）如google.fr、google.ng等重定向到google.com。这是因为Google搜索在提供本地化体验方面有了改进，所有用户无论使用哪个域名都能获得相同的本地搜索结果。此次变更将逐步在未来几个月内推行，大部分用户不会感受到明显变化，但可能需要重新登录或调整搜索设置。此举不会影响搜索功能或谷歌在各国法律下的义务，但可能会对引流和登录体验产生轻微影响。

JEP 506: Scoped Values final for Java 25

作者: ludovicianul | 评分: 5 | 评论数: 0 | 发布时间: 2025-04-15 11:17
文章摘要

JEP 506 提出引入 "scoped values" 机制，允许方法在线程内及其子线程中共享不可变数据。相比线程局部变量（ThreadLocal），scoped values 更易于理解和推理，具有更低的空间和时间成本，尤其在与虚拟线程（JEP 444）和结构化并发（JEP 505）结合使用时。该机制经历了多个预览和改进阶段（JEP 429, JEP 446, JEP 464, JEP 481, JEP 487），并计划在 JDK 25 中正式引入。其目标包括易用性、可理解性、健壮性和高效性，但不旨在改变 Java 语言或废弃 ThreadLocal API。Scoped values 解决了在方法间传递共享数据时的繁琐问题，尤其在大型程序中不同组件间传递上下文时非常实用。
