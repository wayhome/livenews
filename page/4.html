Klong: A Simple Array Language

作者: tosh | 评分: 96 | 评论数: 11 | 发布时间: 2025-06-20 12:44
文章摘要

Klong是一种简单的数组语言，类似于K语言，但更明确清晰。它主要用于操作列表和多维数组，适合熟悉K或APL的用户。Klong更像是一种数学符号，而非传统编程语言，使用时需注意。官方提供了详细的参考手册、快速参考和入门书籍，帮助学习和使用Klong。程序示例包括判断一个数是否为素数。Klong可编译安装于多种系统，并提供下载和安装指南。若Klong速度不够快，还有KlongPy版本可供选择。

Minimal auto-differentiation engine in Rust

文章摘要

**nanograd** 是一个用Rust编写的最小自动微分引擎。它通过定义`Scalar`结构体来存储值、可选的梯度以及生成它的操作描述。利用操作符重载（如`+`、`*`、`-`等）和辅助函数，构建出一个有向无环图（DAG），并在每个边缓存局部导数。通过调用`backward()`方法，可以从输出节点开始递归传播梯度，最终累积到初始节点。此外，它还支持通过`plot::dump_graph`将计算图可视化为一个包含D3.js的HTML文件。该项目包含一个训练小型多层感知机（MLP）学习XOR功能的演示范例。

评论摘要
主要讨论点：关于自动微分中全局/共享状态的可行性及设计选择 不同观点： • [amelius] 认为在当前设计中，使用全局或共享状态进行自动微分可能存在风险。他举例说明，如果有两个函数分别计算不同的结果（如 z = x * y + 3 和 w = x + 2 * y），并且它们同时进行反向传播（可能在不同线程中），那么收集反向传播结果（偏导数）在共享变量 x 和 y 中可能会导致问题。amelius 建议一个更好的设计是使用 z.get_grad(x) 和 z.get_grad(y) 这样的方式来获取偏导数，而不是通过共享变量直接访问。 • [tnlogy] 对 Rust 和机器学习（ML）的学习过程进行了分享，提到自己曾经做了一个小型的 telegrad 项目，并计划将计算图存储在堆中以便后续发送到 GPU，但后来因为懒惰而放弃了该计划。tnlogy 表示通过这种项目总是能学到一些东西。 • [kragen] 提出一个简短的建议，认为应该在标题中加入 "backward-mode"（反向模式）以更好地描述内容。 补充讨论： • amelius 提出的设计争议焦点在于共享状态在多线程或多函数同时进行反向传播时的潜在问题，这可能导致结果不准确或不安全。amelius 强调了通过函数接口明确获取偏导数的设计优势。 • tnlogy 的评论更多是个人项目经验的分享，与主要讨论点无直接争议，但展示了在类似项目中可能遇到的技术选择和挑战。 • kragen 的评论主要是关于标题的优化建议，并未直接参与到设计讨论中。

Hurl: Run and test HTTP requests with plain text

作者: flykespice | 评分: 164 | 评论数: 21 | 发布时间: 2025-06-20 03:55
文章摘要

Hurl是一个开源命令行工具，用于通过简单的文本格式运行和测试HTTP请求。它可以发送链式请求、捕获响应值、评估头信息和主体内容的查询。Hurl适用于处理HTML、REST、SOAP、GraphQL等API，支持多种断言方式如XPath、JSONPath，并可测试状态码、头信息及响应时间。它基于libcurl，具有快速、高效、支持IPv6和HTTP/3的特点，且易于集成到CI/CD流程中，提供多种报告格式。Hurl轻量易用，适合开发人员和运维人员。
