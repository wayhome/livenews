文章摘要

Claude Code IDE for Emacs通过Model Context Protocol (MCP)实现与Claude Code CLI的原生集成，不仅是一个简单的终端包装器，还能让Claude利用Emacs的强大功能，如LSP、项目管理等。其功能包括自动项目检测、会话管理、终端集成、MCP协议实现、工具支持、诊断集成、差异视图等。通过MCP工具集成，Claude可以访问Emacs的各种功能，如代码导航、语法树分析、项目操作和自定义Elisp函数，提供更智能的协助。安装需Emacs 28.1及以上版本、Claude Code CLI和vterm或eat包，使用`use-package`进行配置。基本操作通过交互菜单实现，如`M-x claude-code-ide-menu`打开菜单。

Leonardo Chiariglione: “I closed MPEG on 2 June 2020”

作者: eggspurt | 评分: 189 | 评论数: 14 | 发布时间: 2025-08-07 10:09
文章摘要

Leonardo Chiariglione，一位拥有跨文化技术背景和基督教天主教教育背景的工程师，致力于开发可互操作的数字媒体技术。1987年，他创立了**MPEG（动态图像专家组）**，该组织在随后几年制定了多项重要标准，如MPEG-1、MPEG-2和MPEG-4，推动了数字媒体时代的到来。然而，由于一些不明势力的干预，MPEG逐渐失去活力，技术发展停滞，知识产权授权模式过时，导致行业和消费者无法受益于新技术。2020年6月，Chiariglione离开MPEG，随后于2020年7月提出成立**MPAI（人工智能编码的动态图像、音频和数据）**，旨在开发基于强大技术的新标准，打破僵局。MPAI已经制定了五项标准，并有多个项目正在进行中，涵盖AI应用、音频增强、多模态对话等领域。Chiariglione通过其著作和博客记录了MPEG的兴衰及MPAI的成长。
