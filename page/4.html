**textsnap** 是一个轻量级的 OCR 工具，可将图片、截图或网页转换为纯文本。主要特点： 1. **纯 CPU 运行**：使用量化的 0.9B PaddleOCR-VL-1.5 模型，无需 GPU 或云服务 2. **离线工作**：首次运行下载约 890MB 模型后完全离线 3. **多种输入源**：支持本地图片、剪贴板、图片 URL 和网页 URL 4. **剪贴板集成**：无参数运行时自动读取剪贴板图片并将识别结果写回 5. **便携模式**：将模型文件放在脚本旁边即可在任何机器上独立运行 6. **输出格式**：默认 Markdown，可选纯文本 安装简单（`pip install textsnap`），使用方便（`textsnap screenshot.png`），整个工具仅一个 Python 文件，依赖自动安装。
