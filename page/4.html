Landrun: Sandbox any Linux process using Landlock, no root or containers

作者: Zoup | 评分: 411 | 评论数: 20 | 发布时间: 2025-03-22 13:56
文章摘要

**landrun** 是一个轻量级、安全的 Linux 进程沙箱工具，利用 Linux 内核的 Landlock LSM 实现内核级安全控制。相比于 firejail，landrun 更轻量、用户友好且内核集成度高。其主要功能包括： - 基于 Landlock LSM 的内核级安全 - 轻量快速执行 - 目录级的细粒度访问控制 - 支持读写路径设置 - 可选的执行权限 - TCP 网络访问控制（需内核 6.8 及以上） **安装**： - 快速安装：`go install github.com/zouuup/landrun/cmd/landrun@latest` - 源码安装需克隆仓库并使用 Go 构建。 **使用**： - 基本语法：`landrun [选项] <命令> [参数...]` - 选项包括设置只读、读写路径，执行权限，TCP 端口绑定和连接等。 **示例**： - 运行命令并设置目录只读权限、TCP 端口绑定等。 **安全性**： - 通过 Landlock LSM 实现文件系统和网络访问控制，增强进程隔离和安全性。 **要求**： - 需要 Linux 内核 5.13 及以上（网络限制需 6.8 及以上），Go 1.24.1 及以上。 该工具适用于需要细粒度访问控制和安全隔离的场景。

The Software Engineering Identity Crisis

作者: napolux | 评分: 65 | 评论数: 16 | 发布时间: 2025-03-23 18:37
文章摘要

文章讨论了软件工程师在人工智能（AI）时代面临的身份危机。传统上，软件工程师以亲手编写代码、解决技术问题为核心身份，但随着AI编码助手的出现，工程师的角色正从“建造者”转变为“协调者”或“管理者”。AI不仅改变了编码方式，还可能剥夺工程师在解决问题和优化算法过程中获得的成就感。 尽管有人乐观认为工程师将更多关注高层次架构和系统思维，但这种转变引发了对工程师核心身份的质疑。现实中，如Google和Y Combinator的案例显示，越来越多的代码由AI生成，传统编码技能或将被“提示工程”（prompt engineering）取代，工程师需要提升沟通能力以更好地指导AI。 像Andrej Karpathy提出的“氛围编码”（vibe coding）概念，反映了从关注代码细节到依赖AI生成内容的转变，这让人质疑：如果忘记代码，我们还是工程师吗？Gene Kim和Steve Yegge展示了如何利用AI在短时间内重构代码，进一步表明这一身份转变已是现实。

文章摘要

All Placebos are not created equal (2021)

作者: sebg | 评分: 67 | 评论数: 9 | 发布时间: 2025-03-21 11:28
文章摘要

文章讨论了安慰剂效应的不同效果，指出并非所有安慰剂都相同。18世纪的Perkins Tractors就是一个早期例子，人们使用它们缓解疼痛，尽管它们并无生理作用。John Haygarth医生的实验首次展示了安慰剂效应。现代研究发现，不同类型的安慰剂（如口服、外用、关节注射）产生的效果不同，其中关节注射安慰剂效果最强。此外，医生的特质和患者的期望也会影响安慰剂的效果。例如，温暖且表现出能力的医生能增强安慰剂的作用。孩子的安慰剂反应比成人更强，这可能影响药物试验结果。文章最后指出，美国的安慰剂效应正变得更强，可能影响新药的批准。

评论摘要
主要讨论点： placebo效应的本质及其相关误解 不同观点： • [BugsJustFindMe] 认为，相信某事物改善与实际改善之间存在区别，感觉症状改善与症状实际改善是两回事。他还指出，自我评估的不确定性可能会让人在无意识中倾向于乐观评价，从而感觉更好，但实际上症状并未改善。这种现象与安慰剂效应不同，可能只是对痛苦的感知或承认发生了变化，而非痛苦本身减少。 • [galaxyLogic] 提出一种理论，认为安慰剂效应可能与“自私的基因”有关。当潜意识认为身体即将死亡时，可能会停止为生存而战；但如果相信药物治疗有效，潜意识则会继续为生存而战。这种效应并非单纯的个人心理作用，而是基因层面上对群体有利的选择。 • [somenameforme] 强调安慰剂效应的真实性和客观性，引用维基百科上的研究表明安慰剂效应可以影响非主观的身体功能，如帕金森病患者的运动功能、免疫和内分泌参数等。还提到与安慰剂相对的“nocebo”效应，即负面的预期可以导致实际的负面结果，如因预期死亡而迅速死亡的现象。 • [linasj] 反驳关于安慰剂效应增强的说法，认为这是由于我们更好地控制了其他因素，如回归均值、自我报告偏差和观察效应等。安慰剂效应并不是“心胜于物”，而是治疗过程中人们行为、偏差和生活经历的综合结果。 • [danilor] 对一项研究结果提出疑问，指出虽然统计结果显示显著，但临床意义是否显著值得怀疑，特别是当差异仅为1毫米时，是否足以用于改善治疗结果。 • [tasty_freeze] 对标题的语法提出意见，认为“All doctors are not men”与“Not all doctors are men”在表达上有所不同，前者更具冲击力。 • [tracerbulletx] 重申安慰剂效应是一种统计效应，而非物理效应。它并不意味着相信干预有效会对身体产生影响，而是在试验中影响数据结果。 补充讨论： - 不同评论者对安慰剂效应的理解存在明显分歧，有些人强调其客观性和真实影响，另一些人则认为只是统计和心理作用。 - 讨论中涉及了安慰剂效应的多种表现形式及其可能的机制，如基因层面的解释和nocebo效应的负面影响。 - 争议的焦点在于安慰剂效应是否具有临床显著性以及其本质是心理作用还是物理效应。
