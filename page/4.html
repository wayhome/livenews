CosAE: Learnable Fourier Series for Image Restoration

作者: E-Reverance | 评分: 48 | 评论数: 7 | 发布时间: 2025-04-26 20:43
文章摘要

本文介绍了一种名为CosAE（Cosine Autoencoder）的新型自动编码器，它结合了经典的傅里叶级数和前馈神经网络。CosAE通过将输入图像表示为一系列二维余弦时间序列，利用可学习的频率和傅里叶系数进行编码，在保持细节的同时实现了高度的空间压缩。其瓶颈层编码频率系数，使得即使在64倍下采样的情况下仍能保持图像细节。实验表明，CosAE在灵活分辨率超分辨率和盲图像修复任务中超越了现有方法，展现了其对复杂甚至未知图像退化的强大泛化能力。

Tilt: dev environment as code

作者: saikatsg | 评分: 86 | 评论数: 17 | 发布时间: 2025-04-26 19:14
文章摘要

Tilt 是一个开源工具，用于简化在 Kubernetes 上开发微服务应用的过程。它允许开发者通过代码定义开发环境，并自动化从代码更改到环境更新的所有步骤，包括文件监控、容器镜像构建等。Tilt 类似于运行 `docker build && kubectl apply` 或 `docker-compose up`。其主要功能包括一键安装、多语言支持（如 NodeJS、Python、Go 等）、详细的 API 参考以及社区贡献指南。Tilt 遵循 Apache-2.0 许可证，并重视安全问题报告。通过 Tilt，开发者可以更高效地管理和开发基于 Kubernetes 的微服务应用。

Tipping: How Gratuity Replaced Fair Wages in U.S. Restaurants

作者: madpen | 评分: 70 | 评论数: 13 | 发布时间: 2025-04-27 05:20
文章摘要

这篇文章探讨了美国餐厅小费文化的复杂历史与现状。小费在北美是预期行为，但在世界其他地区并不普遍，甚至被视为不礼貌。小费习俗起源于欧洲中世纪的主仆关系，美国人在19世纪50、60年代引入这种做法，以显示贵族气质。然而，初期美国社会对小费存在抵制，认为其“不美国”且带有阶级歧视色彩。 随着废奴运动后，南方服务业成为解放奴隶的早期就业选择，小费成为这些工人的重要收入来源。尽管有多个州尝试废除小费，但最终未能成功。1938年，《公平劳动标准法》确立了联邦最低工资，但未包括小费工人的最低工资。1966年，国会引入“小费抵税”制度，允许餐馆支付低于最低工资的薪酬，依赖小费补足。 至今，小费制度仍在演变，一些餐馆尝试取消小费，但效果不一。文章指出，小费问题仍在美国社会和餐饮业中引发讨论。
