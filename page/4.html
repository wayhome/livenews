OpenChamber 是一个开源的代理开发环境,帮助开发者通过 AI 代理完成开发任务。 **核心功能包括:** - 会话目标设置,让代理持续工作直到完成任务 - 多模型并行运行,可选择最佳结果或融合优势 - 从 GitHub issue 直接创建 PR,处理失败检查并合并 - 定时任务执行和预览功能 - 变更演示功能,以步骤形式展示大型代码改动 **多平台支持:**支持 macOS/Windows/Linux 桌面应用、浏览器/PWA/移动端访问,以及 VS Code 编辑器集成,可在不同设备间无缝切换工作。 **隐私保护:**所有代码和会话内容保持本地存储,不会被收集。远程访问可通过 UI 密码保护,支持端到端加密的私有中继连接。 该工具基于 OpenCode SDK 构建,完全免费且开源。

文章摘要

这篇文章介绍了一本15世纪末的琐罗亚斯德教占卜书籍《Marnameh》（蛇之书）。1892年，英国外科医生George Waters向孟买人类学学会介绍了这部作品。该书列出琐罗亚斯德教历法中30天内看到蛇的各种征兆预示。 最引人注目的是，琐罗亚斯德教传统上视蛇为邪恶生物，鼓励信徒杀蛇，但《Marnameh》中却包含大量吉祥预兆，如"找到失散的朋友"或"愿望得以满足"等。这与正统教义形成矛盾。 Waters认为此书可能受埃及思想影响，学者则推测可能反映了前琐罗亚斯德教时期伊朗对蛇的正面看法。尽管文学价值有限，但这部神秘的占卜文本为研究古代宗教观念演变提供了独特视角。

评论摘要
主要讨论点：这些评论涉及三个独立的话题，分别关于波斯文化术语、互联网档案馆以及游戏文化 不同观点： • **语言文化趣味**（shervinafshar）：波斯语维基百科社区曾将软件bug戏称为"khrafstar"（祆教中的邪恶生物）。这个玩笑源于khrafstar（蛇等）在传统中与厄运相关，却被用来指代现代技术问题，形成有趣的文化挪用 • **知识共享倡议**（georgefrowny）：赞扬互联网档案馆的巨大公共价值，建议将其元数据众包化，可能通过与维基数据合作来实现。强调开放知识平台的重要性和改进空间 • **文化代表性诉求**（Razengan）：希望游戏行业创作更多基于波斯传说的作品，类比D&D中已有的阿拉伯主题设定Al-Qadim。反映了对多元文化在娱乐媒体中呈现的期待 补充讨论：三条评论虽然主题各异，但都隐含着对波斯/中东文化在现代数字文化中表达方式的关注——从社区内部的语言创新，到知识保存，再到大众娱乐的文化多样性。

Meta宣布开放Muse Glimmer模型权重，这是一个可本地运行的30B参数密集模型。公司还将发布最新基础模型Muse Spark 1.2的权重。Mark Zuckerberg在推文中表示Meta坚定支持开源，并感谢alexandr_wang和MSL团队的工作。这一举措获得AI社区的积极响应，Yann LeCun、Unsloth AI和Hugging Face等纷纷点赞支持，认为这是对开源社区的重要贡献。
