文章摘要

TokenDagger 是一个高性能的 OpenAI TikToken 实现，专为大规模文本处理设计，提供更快的处理速度。相比原版，TokenDagger 在代码样本分词上速度提升4倍，整体吞吐量提升2倍。它使用优化的 PCRE2 正则引擎进行快速分词匹配，并简化了BPE算法以减少大词汇量对性能的影响。TokenDagger 与 TikToken 完全兼容，可作为直接替代品。安装可通过 PyPI 使用 `pip install tokendagger` 完成，并提供多种测试脚本以验证性能。项目主要使用 C++ 开发，并包含少量 Python 和 Makefile 代码。

Introduction to Linux Netkit interfaces – with a grain of eBPF

作者: jtlebigot | 评分: 10 | 评论数: 1 | 发布时间: 2025-07-01 21:27
文章摘要

本文介绍了Linux中的**netkit接口**，它类似于**veth接口**，但更加注重性能优化。netkit接口默认工作在L3（IP层），跳过L2（以太网层）的OSI模型开销，且可以通过eBPF程序扩展功能。其设计理念是由Isovalent公司在2023年提出，旨在保持传输路径中的代码最少化，从而提高性能。通过使用iproute2命令可以创建netkit接口对，并通过eBPF程序控制其行为，例如创建“黑洞”接口对，默认丢弃所有数据包，除非特别允许。文章还简要提及了如何使用Cilium的eBPF库进行编程。总体而言，netkit接口通过简化功能和依赖eBPF扩展，实现了高效的网络传输和控制。
