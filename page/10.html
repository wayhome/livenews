Migrating from GNU Stow to Chezmoi

作者: speckx | 评分: 136 | 评论数: 29 | 发布时间: 2026-06-18 17:09
文章摘要

作者从 GNU Stow 迁移到 chezmoi 来管理 dotfiles。Stow 使用符号链接，导致多设备间同步混乱，且新机器初始化繁琐。chezmoi 采用源目录模式，将配置文件复制到 `~/.local/share/chezmoi`，通过 `chezmoi apply` 同步到实际位置。这避免了符号链接的自动写入问题，使变更更可控。作者用它管理 3 台 Mac 的 shell、git、编辑器配置，以及 AI agent 技能文件。chezmoi 支持模板、权限控制和脚本自动化，统一了 Homebrew 和系统设置的管理流程。

评论摘要
主要讨论点：dotfiles（配置文件）管理方案的选择与权衡 不同观点： • **支持 GNU Stow + 符号链接派**：认为符号链接的"双向性"是优势而非缺点，文件修改后 git 能直接显示变更状态，无需额外步骤。通过合理组织文件结构（如将特定机器配置分离到独立文件）可以避免冲突 • **Chezmoi 用户派**：认为 Chezmoi 是社区宠儿，结合 mise 工具可以用 2-3 个命令快速配置新机器。虽然模板和文件命名约定需要适应，但功能完整 • **Nix + Home Manager 派**：认为既然已经用到 Chezmoi 这个复杂度，不如直接上 Nix 和 Home Manager，"为什么爬到山顶前就停下" • **自研工具派**：认为现有工具过于复杂，自己编写简单脚本（如 200 行 shell、双向同步工具、Ansible 方案）更可控且易理解 • **原始方案派**：直接将 home 目录放入 Git 仓库（默认忽略所有文件），或用 rsync 同步整个 home 目录到多台机器 补充讨论：Stow 的符号链接问题是核心争议点——支持者视为特性，反对者因此转向其他方案。Syncthing + Stow 组合、yadm 等工具也获得推荐。

Hospitals and universities repurposing drugs at lower cost

作者: giuliomagnifico | 评分: 324 | 评论数: 14 | 发布时间: 2026-06-18 10:33
文章摘要

大学和医院正在以比制药企业低90%的成本重新利用现有药物进行后期试验。这个在专利体系外运作的"隐藏"研究系统具有巨大潜力，能为社会提供可负担的治疗方案。伦敦国王学院的研究显示，医院和大学进行大量后期临床试验的资金成本不到制药公司报告成本的10%。这是因为重新利用仿制药的专业门槛、风险和资本需求都较低，而临床医生和科学家的动机是帮助患者康复和推进职业发展，而非专利激励。各国政府已开始制定计划正式认可这一研究体系，确保患者获得廉价药物。

评论摘要
主要讨论点：药物再利用的机遇与美国医疗体系的结构性问题 不同观点： • **支持药物再利用但强调安全风险**（atourgates）：以Avastin治疗黄斑变性为例，虽然成本仅为Lucentis的1/30（50美元 vs 1500美元），但重新包装过程存在污染风险。眼科医生需权衡省钱与感染风险，曾有医生检测出细菌污染批次，该事件后多位医生停用。结论：药物定价疯狂，但问题复杂。 • **积极支持药物再利用用于罕见病**（jawns）：通过Cures Within Reach等非营利组织，为亨廷顿舞蹈症等罕见病寻找已有药物的新用途，因大型药企不会为小众市场开发新药，再利用是患者唯一希望。 • **批判专利驱动的非理性定价**（dabinat）：亲身经历Spravato（esketamine）治疗，保险公司月付1.7万美元，而更有效的氯胺酮因无专利而未获FDA批准，极其便宜却无法使用。保险公司缺乏动力联合资助研究以长期省钱。 • **系统性改革主张**（photochemsyn）：应废除Bayh-Dole法案，将纳税人资助的药物研发成果开源，由政府主导透明的临床试验，私营企业竞争生产以降低价格。 补充讨论： - 监管障碍：即使研究证明有效，未经制造商同意无法正式扩展药物适应症（oezi） - 美国医疗体系被指为卡特尔垄断而非自由市场竞争（shevy-java） - 某些疾病（如长新冠）药物再利用无效，仍需新药研发但美国科研投资被削减（ck2）

主要讨论点：SpaceX以600亿美元收购Cursor的合理性及AI编程工具的实际价值 不同观点： • **质疑收购价值派**：认为600亿美元过高，Cursor本质只是VS Code扩展+提示词包装，技术门槛低可被轻易复制；对比Minecraft仅25亿收购价，认为估值荒谬 • **已转向其他工具派**：多位用户表示已不再使用Cursor，转向Claude Code、Codex或Copilot；主要原因包括成本过高（月费500-1000美元）、使用限制、以及Cursor对模型响应质量的影响 • **仍认可Cursor价值派**：肯定其自动补全、Plan模式和Agent模式的实用性，认为它降低了普通开发者使用AI的门槛，是最完整的AI编程工具 • **战略收购合理派**：认为这是xAI/SpaceX快速获取成熟产品、用户基础和企业客户的捷径，弥补自身产品短板 补充讨论： 数据隐私担忧明显——用户代码、设计决策被用于训练Grok模型；政治因素影响——部分用户因Musk个人原因表示将停用；市场泡沫警告——有人质疑这种估值是否可持续，类比特斯拉和比特币的投机属性。争议焦点集中在：技术壁垒的真实性、AI工具的长期价值、以及SpaceX收购动机的合理性。
