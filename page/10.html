RISC-V Router

主要讨论点：StartWRT 这款基于 OpenWrt 的 RISC-V 路由器是否值得众筹，核心争议集中在“开放性是否真有优势”、价格/配置是否合理，以及是否满足真实路由需求。 不同观点： • 质疑者认为，小型初创做“深度定制软件栈”风险很高，历史上不少众筹硬件最后因维护困难失败；更希望看到路由吞吐、VPN 吞吐等实测，而不是只看更快网口。 • 有人指出“最开放路由器”的宣传夸大了：OpenWrt One、Turris 也有开源启动链、内核和公开硬件资料，甚至 Turris 的文档标准更高；真正争议是 OpenWrt 反复被分叉维护。 • 价格党认为 250k 众筹和 300 美元定价偏高，尤其 4GB RAM/16GB eMMC 对路由器显得过剩；同芯片的 Banana Pi 板子更便宜。 • 支持者则看好 RISC-V 在嵌入式、低功耗场景的潜力，希望更多系统采用。 • 实用派吐槽接口太少：只有 1 WAN+1 LAN，不适合家庭自建服务、备份 WAN，甚至希望至少有 SFP+、USB-C。 补充讨论：也有人担心外国产处理器/无线模块会受美国 FCC 相关限制；争议焦点主要是“开放性宣传、性价比、以及作为路由器的实际可用性”。

评论摘要
主要讨论点：Linux/Proton/Wine/NTSync 是否正在让“Windows 才适合游戏”的旧格局瓦解，以及仍存在哪些技术和生态障碍。 不同观点： • 乐观派认为 Linux 游戏已明显成熟：Bazzite、Steam Deck、Proton 让大量游戏“点运行即可”，老笔记本也能流畅跑旧游戏；部分用户表示多年未遇到不能玩的游戏，甚至可睡眠恢复、无需折腾 Proton 版本。 • Proton 路线被认为优于原生移植：不仅能跑游戏，还能保留 Windows Mod、插件和辅助工具生态；有人举 ESO 价格插件、Rust 交叉编译后直接在 Proton 运行的例子。 • 产业推动因素：云游戏厂商不愿支付 Windows 授权费，倾向 Linux+Proton+Vulkan+AMD；Steam Deck 也降低了主流用户接触 Linux 的门槛。 • 主要阻碍集中在反作弊：BattlEye、Vanguard、Battlefield、Warzone、League 等竞技/多人游戏若不支持 Linux，会限制大众迁移。 • 怀疑派要求数据：不仅看 FPS，还要看帧时间、延迟、Nvidia 支持等；认为旧对比中 Linux 仍落后 Windows 5–30%，希望有充分理由再切换。 • 技术讨论认为 NTSync/Wine 进展重要：实现 Win32 事件、信号量、互斥和 WaitForMultipleObjects，改善锁竞争；也有人设想未来接近“Linux Subsystem for Windows”。 • 兼容性反讽：有人称 Linux 反而是最佳 WinAPI/旧 Windows 游戏平台，而原生 Linux 旧程序因依赖废弃更难运行。 补充讨论：还有人提到 Windows 11 促使用户离开、微软是否会阻挠；也有人表达对开源开发者的感激。
