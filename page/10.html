文章摘要

文章介绍了使用聚焦超声波刺激（FUS）技术调节神经系统以治疗炎症和糖尿病等疾病的新方法。传统上，超声波多用于产前检查和诊断成像，而FUS通过低强度超声波振动与神经元膜相互作用，打开离子通道，改变细胞电压，从而触发神经元活动。这种非侵入性技术有望精准、安全地治疗多种急性和慢性疾病，包括炎症、糖尿病和肥胖等。研究团队正在探索通过刺激特定外周神经来干预炎症和代谢过程，以解决疾病的根本原因，而非仅缓解症状。FUS有可能成为家庭可用的可穿戴设备，为现代医学面临的重大健康挑战提供新治疗手段。

Building a Tiny CNC Router for Making Circuit Boards

作者: eldog_ | 评分: 10 | 评论数: 0 | 发布时间: 2025-06-10 08:44
文章摘要

Tom Nixon在2025年5月8日撰文介绍了他自制的一台小型CNC路由器，主要用于制作电路板。该设备工作体积为106 x 104 x 20毫米，整体尺寸为300 x 250 x 200毫米，能处理0.5毫米间距的FR4电路板，并可切割铝材。Nixon的动机源于看到Scanlime使用Bantam Tools桌面铣床制作电路板，虽然CNC铣削并非制作电路板的最优方法，且其他方法如蚀刻或PCB打样服务更便宜便捷，但他看重CNC的多功能性和自制体验。 设计目标包括：至少100x100毫米的工作面积，约15毫米的作业高度，能使用标准刀具，并具备足够的刚性和精度以处理FR4材料和铝材。市面上的机器要么太大、太贵，要么不符合需求，因此Nixon自行设计。 该CNC采用龙门结构，由2020铝型材构成，X和Z轴使用单根MGN12H导轨，Y轴使用两根，均由NEMA17步进电机驱动。尽管看似单薄，但短小的尺寸和紧凑的设计使其刚性足够。Nixon还考虑了升级方案，如将X轴导轨替换为更坚固的型材和导轨组合。

Using `make` to compile C programs

作者: mfrw | 评分: 4 | 评论数: 2 | 发布时间: 2025-06-11 03:24
文章摘要

文章主要介绍了如何在不同系统上编译C/C++程序，特别是针对Mac系统遇到的问题。作者分享了编译过程的四个步骤： 1. **安装C编译器**：在Ubuntu上通过`sudo apt-get install build-essential`安装，而在Mac上则需要安装Xcode命令行工具。 2. **安装程序依赖**：C语言没有依赖管理器，需手动安装。例如，通过`sudo apt install -y libqpdf-dev libpaper-dev`安装依赖。在Mac上则使用`brew`。 3. **运行`./configure`**：有些程序需要运行此脚本生成Makefile。 4. **运行`make`**：使用`make`命令编译程序，可能需要处理编译器和链接器的错误，特别是依赖问题。 文章还提到编译过程分为编译和链接两步，可能需要手动指定包含路径和库路径，例如通过`-I`和`-L`选项。

评论摘要
主要讨论点：[Makefile中不同编译选项的含义和使用] 不同观点： • **CPPFLAGS 和 CXXFLAGS 的区别**：kazinator 认为 CPPFLAGS 是指 C 预处理器的选项，适用于任何语言，而 CXXFLAGS 则是专门用于 C++ 语言的选项。他还特别指出，CXXFLAGS 中的 "XX" 是 "++" 旋转45度而来，与文件后缀 ".cpp" 无关，纠正了一些可能因文件后缀引发的误解。 • **LDLIBS 和 LDFLAGS 的区别**：kazinator 进一步解释 LDFLAGS 和 LDLIBS 的区别。LDFLAGS 是指链接器命令行选项，通常放在目标文件之前；而 LDLIBS 是用于指定库的选项（如 -lssl, -ldl, -lcrypto），这些库选项通常放在目标文件之后。 补充讨论： • **Makefile 编写中的注意事项**：kazinator 提醒，如果自己在编写 Makefile 并自定义链接配方，务必正确地插入 LDFLAGS 和 LDLIBS 到合适的位置，以确保编译和链接过程的正确性。 争议焦点： • 该评论主要是解释性内容，没有直接的争议，但潜在的争议可能在于开发者对 CPPFLAGS 和 CXXFLAGS 的误用，或者在 Makefile 中错误地放置 LDFLAGS 和 LDLIBS 位置，从而导致编译错误。
