作者: PaulHoule | 评分: 50 | 评论数: 0 | 发布时间: 2025-04-10 17:03
文章摘要

本文报道了维尔茨堡大学研究团队的一项突破性研究，他们将小干扰RNA（siRNA）与两性霉素B（AmB）共同包装入阴离子脂质体，成功靶向并抑制危险霉菌烟曲霉（Aspergillus fumigatus）的生长。烟曲霉感染导致的死亡率高达85%，且抗药性不断增加。通过结合RNA干扰（RNAi）技术和纳米医学的优化递送技术，研究人员实现了对霉菌关键基因的抑制，显著减少了感染模型中的霉菌生长。该方法首次成功将siRNA疗法应用于人类病原真菌，展示了其对抗真菌感染的潜力，并为减少哺乳动物实验提供了新的感染模型。研究成果发表于《Nanoscale》期刊，并被选为封底推荐。

Information Converted to Energy (2010)

作者: teleforce | 评分: 6 | 评论数: 0 | 发布时间: 2025-04-14 14:23
文章摘要

日本物理学家通过实验证明，粒子只需接收信息而非能量即可做功。该实验利用反馈系统控制微小聚苯乙烯珠的电势，不违反热力学第二定律，并可能推动新型微观设备的发展。实验由东京中央大学的Shoichi Toyabe及其团队完成，实质上实现了1871年詹姆斯·克拉克·麦克斯韦提出的思想实验，即“麦克斯韦妖”通过信息控制分子运动。实验显示，信息可以转换为能量，具体转换率为每比特信息转换为0.28 kT ln2的能量，验证了信息到能量的转换。不过，这一成果仅在微观尺度上有效，宏观设备消耗的能量远大于此。

Whenever: Typed and DST-safe datetimes for Python

作者: pkkm | 评分: 266 | 评论数: 20 | 发布时间: 2025-04-13 09:12
文章摘要

"Whenever" 是一个现代的 Python 日期时间库，旨在解决标准库 `datetime` 以及其他第三方库（如 Arrow 和 Pendulum）的不足。它支持 DST 安全的时间计算，并通过类型安全的 API 防止常见的错误。与标准库和其他库相比，Whenever 提供了更高的性能，并且能够明确区分简单和时区感知的时间类型，避免意外混用。此外，Whenever 还支持纳秒精度和多种时间运算，并提供了基于 Rust 的高性能实现，同时也有纯 Python 版本可供选择。该库文档完善、测试充分，且即将发布 1.0 版本。
