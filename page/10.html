Rust CUDA Project

作者: sksxihve | 评分: 139 | 评论数: 6 | 发布时间: 2025-04-11 15:22
文章摘要

Rust-CUDA 是一个致力于让 Rust 成为高性能 GPU 计算一级语言的生态系统，通过 CUDA 工具包实现高效的 GPU 代码编写和执行。该项目提供编译工具和库，将 Rust 代码编译为高性能的 PTX 代码，并支持使用现有的 CUDA 库。尽管 GPU 计算常使用 CUDA 工具包（主要支持 Fortran/C/C++），但 Rust-CUDA 项目旨在解决 Rust 在 CUDA 环境中的兼容性问题，提供如 rustc_codegen_nvvm、cuda_std、cudnn、cust、gpu_rand 和 optix 等多个库，涵盖从 GPU 内核函数、内存管理到深度学习加速等功能。项目仍在早期开发阶段，欢迎社区贡献以推动 Rust 在 GPU 计算领域的发展。

评论摘要
主要讨论点：Rust中使用CUDA的相关库的实用性、维护状态及未来发展 不同观点： • [the__alchemist] 认为rust-CUDA库多年来处于未维护状态，需要特定旧版本的Rust和CUDA才能运行。虽然最近该项目重启了，但尚未发布可用版本。相比之下，Cudarc库更活跃且实用，支持多种CUDA版本，但不能在主机和设备间共享数据结构。他指出，推广最多的项目往往并非最实用或管理最好的。 • [jjallen] 支持Cudarc库，表示自己专业使用该库，并且不需要使用特别旧的Rust版本。 • [porphyra] 对rust-CUDA项目重启表示乐观，认为如果能获得足够的社区支持，可能会成功发展。虽然理论上Rust和CUDA的结合可行，但实际操作中工作量巨大。 • [ein0p] 认为rust-CUDA需要Nvidia的支持才能在功能上与C++并驾齐驱，否则只会是一个小众工具。他表达了自己多年来希望摆脱C++的愿望，但目前仍无法实现。 • [nuc1e0n] 对项目命名提出幽默建议，认为应该叫RUDA（Rust + CUDA）。 • [shmerl] 对项目持怀疑态度，认为不应局限于CUDA，Rust应该有更通用的GPU编程方式，不依赖于Nvidia。 补充讨论： • 关于rust-CUDA库的实用性和维护状态存在争议，部分用户认为其未得到良好维护，而其他用户则认为Cudarc库更为实用。 • 关于Rust与CUDA结合的实际可行性和工作量，部分用户认为理论可行但实际操作困难。 • 对Nvidia官方支持的期望，部分用户认为这是rust-CUDA能否广泛应用的关键因素。 • 对Rust用于GPU编程的更广泛应用场景的讨论，部分用户希望Rust有更通用的GPU编程解决方案，而不依赖于特定硬件厂商。
