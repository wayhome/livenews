Connomore64: Cycle exact emulation of the C64 using parallel microcontrollers

作者: codewiz | 评分: 193 | 评论数: 10 | 发布时间: 2025-05-03 03:04
文章摘要

Connomore64 是一个使用多个微控制器并行运行的Commodore 64（C64）计算机的实时循环精确仿真项目。该项目旨在通过廉价的RP2040/RP2350微控制器（每芯片不到1欧元）重建C64，通过8位多路复用总线以约8 MHz的有效速度互连，使用DVI/HDMI输出视频和音频，并精确模拟原始硬件信号时序。它可以与C1541软驱和一些扩展硬件接口，支持快速加载器。此外，它也是一个示例，展示了如何在廉价低功耗的互连微控制器上运行计算密集型软件，并作为调试和测试多个RP2040/RP2350并行项目的仿真框架。该项目起源于2022年圣诞节的业余项目，目标是探索RP2040微控制器的潜力，特别是其PIO（GPIO处理协处理器）。与现有简化版的C64仿真器不同，Connomore64追求精确的循环和时序仿真，同时兼容物理 retro 硬件。硬件方面，使用了自定义PCB（Breadbox v0原型），支持C64的常用端口和HDMI、音频输出。

Show HN: Pipask – safer pip without compromising convenience

作者: Feynmanix | 评分: 48 | 评论数: 7 | 发布时间: 2025-05-03 13:43
文章摘要

Pipask 是一个增强安全性的 Python 包安装工具，作为 pip 的替代品，在安装前进行安全检查并征求用户同意。与 pip 直接下载并执行代码不同，Pipask 尽可能通过 PyPI 获取元数据，并在必须执行第三方代码时请求用户确认。它进行多项安全检查，包括仓库流行度、包年龄、已知漏洞、下载量和元数据验证。所有检查针对直接依赖执行，仅对严重漏洞检查传递依赖。Pipask 使用 PyPI 的 JSON API 获取信息，并在用户同意后使用 pip 完成实际安装。安装方式可通过 pipx 或 pip，并支持 dry-run 模式预览检查结果。
