文章摘要

**s3mini** 是一个超轻量级的 TypeScript S3 客户端，大小约 14 KB，性能比同类库高约 15%。它无依赖，支持 AWS SigV4 签名，适用于 Node.js、Bun 和 Cloudflare Workers 等边缘计算平台，但不支持浏览器环境。该库支持基本的 S3 操作，如创建、列出、获取、删除对象及多部分上传，已在 Cloudflare R2、Backblaze B2、DigitalOcean Spaces 和 MinIO 上测试。用户可以通过 npm、yarn 或 pnpm 安装，并在 Node.js 或 Cloudflare Workers 环境中使用，需配置相应的访问凭证和端点信息。

文章摘要

美国海军和陆军正在推动“维修权”，以解决因合同限制导致军方无法自行修理设备的问题。海军部长约翰·费伦在参议院作证时提到，价值130亿美元的USS Gerald R. Ford航母因合同限制无法修理故障的六个烤箱，导致无法为4500名船员提供充足的餐食。此外，航母的武器升降机也因类似问题延迟四年才完全运作。陆军同样面临类似困扰，国防部长指示将“维修权”条款纳入合同。参议员伊丽莎白·沃伦提出的《军人维修权法案》正在国会审议。军方强调，士兵有能力修理自己的设备，不应依赖第三方承包商。这一行动也可能推动联邦层面的“维修权”立法。

It's the end of observability as we know it (and I feel fine)

文章摘要

文章《It’s The End Of Observability As We Know It (And I Feel Fine)》讨论了大型语言模型（LLMs）在可观察性工具领域的颠覆性影响。作者Austin Parker指出，LLMs作为通用函数逼近器，能够有效分析和解决系统中的问题，例如通过自动化工具调查性能异常。文章描述了作者使用LLM代理结合Honeycomb的Model Context Protocol（MCP）服务器，在80秒内以低成本分析出前端服务延迟峰值的根本原因。这一示例表明，LLMs可以自动化并取代传统的可观察性分析工作，从而改变系统设计和运维方式。作者强调，随着LLMs分析成本的下降和OpenTelemetry的普及，传统的可观察性工具面临巨大挑战，行业需要重新思考其价值主张。
