LPython: Novel, Fast, Retargetable Python Compiler (2023)

作者: luismedel | 评分: 50 | 评论数: 5 | 发布时间: 2025-05-13 09:01
文章摘要

LPython是一个能够将带类型注解的Python代码编译为优化机器码的编译器。它支持多种后端，如LLVM、C、C++、WASM等，具有快速编译和高效运行时性能。LPython提供AOT和JIT编译，并与CPython无缝兼容。其核心目标是实现极快的编译和生成高速代码。 LPython的编译过程包括将代码转换为抽象语法树（AST），再转为抽象语义表示（ASR）。ASR经过多轮优化后，生成后端代码。它支持多种机器无关的优化，如循环展开、死代码移除等，可通过`--fast`参数启用所有优化，或通过命令行选择特定优化。 LPython目前发布的是alpha版本，可能存在bug，用户可以通过Conda安装或从源码构建。文章还展示了LPython与Numba、C++的性能对比基准测试。

The first year of free-threaded Python

作者: rbanffy | 评分: 219 | 评论数: 20 | 发布时间: 2025-05-16 09:42
文章摘要

本文总结了Python社区在支持无全局解释器锁（GIL）的多线程版本方面所取得的进展。CPython 3.14.0b1的发布和PyCon 2025的召开标志着这一努力的重要里程碑。无GIL的Python能够更好地利用现代多核CPU和GPU的计算能力，但需要对许多依赖C扩展的包进行审核和修改以确保线程安全。 Quansight团队在多个方面做出了贡献，包括打包工具、绑定生成器、PyData生态系统的基础包及热门依赖包的支持。CPython核心开发者也进行了多项改进，如使warnings模块在无GIL构建中默认线程安全，修复asyncio和ctypes模块中的线程安全问题，以及提升垃圾回收器的性能。 一年前，Python包生态系统在无GIL构建中几乎完全无法运行，但现在情况已显著改善。本文还提到正在努力支持的其他流行包，并提供了一份详细指南以帮助其他开发者更新他们的包以支持无GIL的Python。

作者: Keats | 评分: 71 | 评论数: 11 | 发布时间: 2025-05-16 15:37
文章摘要

`rv` 是一个用于管理和安装 R 包的工具，以可重现、快速和声明式的方式进行。它仍在开发中，提供两个主要命令：`rv plan` 用于预览同步操作的结果，`rv sync` 用于同步库、配置文件和锁文件。通过配置文件指定项目所需的 R 版本、代码库和依赖项，`rv` 可以自动安装指定包及其依赖。配置文件示例如下： ```toml [project] name = "my first rv project" r_version = "4.4" repositories = [ { alias = "PPM", url = "https://packagemanager.posit.co/cran/latest" } ] dependencies = [ "dplyr", { name = "ggplot2", install_suggestions = true } ] ``` 安装和使用说明可参考文档，贡献者需安装 Rust 和可选的 Just 工具。项目文件和示例可在代码库中找到。

SSRIs induce cardiac toxicity through dysfunction of mitochondria and sarcomeres

作者: XzetaU8 | 评分: 13 | 评论数: 3 | 发布时间: 2025-05-17 12:55
文章摘要

本研究探讨了选择性5-羟色胺再摄取抑制剂（SSRIs）对心脏系统的毒性作用及其机制。利用人类多能干细胞（hPSCs）建立了2D单层心肌细胞和3D心脏类器官模型，评估了氟西汀、帕罗西汀和舍曲林三种SSRIs对心肌细胞发育的影响。结果显示，SSRIs暴露抑制了ATP生成和线粒体呼吸，扰乱了分化中心肌细胞的线粒体稳态和肌节结构，增加了心肌细胞功能异常的风险。此外，心脏类器官模型进一步分析表明，SSRIs不仅减少线粒体呼吸和ATP生成，还可能影响心脏发育和血管生成。总体而言，研究揭示了SSRIs通过引发线粒体功能障碍和肌节紊乱，对心脏系统构成潜在风险。

评论摘要
主要讨论点：SSRI（选择性5-羟色胺再摄取抑制剂）的有效性和安全性，以及制药公司的商业行为是否误导了公众。 不同观点： • [devwastaken的观点] 认为SSRI在现代社会中之所以合法，仅仅是因为其高盈利性。现代社会将人类与自然环境隔离，导致心理健康问题增多，而SSRI药物实际上可能是在应对这种人为造成的问题。 • [valec的观点] 没有详细展开，但暗示了SSRI对胎儿可能有影响，可能在讨论药物对不同人群的潜在危害。 • [reify的观点] 作为有25年经验的退休心理治疗师，认为SSRI是“一个大骗局”。他指出药物公司通过“化学失衡”理论（该理论已被证明是虚构的）来推广SSRI，实际上这些药物可能加剧抑郁症状，甚至引发自杀念头。他还提到，药物公司隐瞒了SSRI导致的性功能障碍等副作用，直到多年后才被正式承认。 补充讨论： • [reify提供的论据] 提供了具体的学术论文和新闻报道作为证据，如2018年的论文和《卫报》的文章，来支持其关于SSRI可能导致反效果和性功能障碍的观点。 • [争议焦点] SSRI是否通过“化学失衡”理论误导了公众，以及药物公司是否故意隐瞒了药物的负面副作用。Reify认为药物不仅没有帮助，反而会加剧问题，而devwastaken则更关注药物在现代社会中的广泛使用及其背后的经济利益。 • [具体案例] SSRI导致的性功能障碍最终被DSM-5收录为PSSD（持续性SSRI性功能障碍），以及未公开的试验中超过50%的健康志愿者出现严重性问题，进一步加剧了对药物安全性的质疑。

Working on complex systems: What I learned working at Google

作者: 0xKelsey | 评分: 285 | 评论数: 19 | 发布时间: 2025-05-13 09:35
文章摘要

本文讨论了复杂系统（complex systems）的概念，并区分了复杂问题与繁杂问题（complicated problems）的不同处理方法。繁杂问题虽然棘手但可预测，可以通过结构化方案解决；而复杂问题则需要适应性和创新的解决方案。作者以在Uber竞争对手公司优化司机-乘客匹配为例，说明该问题虽具挑战但并非复杂，而Google的大规模机器学习基础设施则被视为真正的复杂系统，需要全新的范式和调度方法。文章进一步阐述了复杂系统的五大特征：涌现行为（emergent behavior）、延迟后果（delayed consequences）、局部与全局优化（local vs. global optimization）、滞后效应（hysteresis）等，强调在复杂系统中，局部优化不一定改善整体性能，且后果可能延迟显现，这使得调试和管理更加困难。理解这些特征有助于有效应对复杂系统中的挑战。

评论摘要
主要讨论点：复杂系统和复杂性在不同领域中的应用与理解 不同观点： • **[braza]的观点**：认为许多文章在讨论复杂性时没有区分可控复杂性（boundaried/arbitrary complexity）和环境复杂性（domain/accidental/environmental complexity）。他指出，像Google这样的大公司虽然解决了很多高难度问题，但在某些领域（如海运物流、制造业等）面临的复杂性可能更高且更难解决。 • **[dmoy]和[neilv]的观点**：dmoy引用了一个例子，说明在Google，难题常常被简化为硬题，而简单任务却被提升为难题。neilv进一步反思这种“我们能做到”的自信文化，并担心这种自信可能演变为傲慢和例外主义，从而忽视谦逊和真实。 • **[gilbetron]的观点**：通过面试Google员工的经验指出，Google的系统虽然庞大复杂，但其开发工具也非常先进。实际工作中，很多员工只是在大系统中进行相对简单的修改，真正构建重要系统的人少之又少。 • **[ggm]的观点**：提出两个迷思，一是复杂系统不一定是坏的，例如军队的后勤支持系统；二是简单系统不总是更好，有些美丽的复杂事物是由简单元素构建而成，例如DNA。 • **[destring]的观点**：从数学背景出发，认为软件工程师应具备系统建模的词汇，推荐《Thinking in Systems》一书以提升理解。 • **[kossTKR]的观点**：认为复杂系统的不可预测性在许多中小型网络项目中同样存在，例如由于异步性质导致的调试困难。 • **[tunesmith]的观点**：复杂和复杂的定义常常与系统是否为封闭系统混淆，许多被定义为“复杂”的系统实际上只是模型没有包含外部因素。 补充讨论： • **技术问题与工具**：[RenThraysk]和[Pavilion2095]提到网站的技术问题，如cookie策略弹窗错误，反映了实际技术实现中的小故障。 • **历史与科学背景**：[quantum_state]指出复杂系统的特性在物理和生物学中已被研究多年，大型组织或代码库只是其中一个例子。 • **术语使用**：[polotics]指出在使用“hysteresis”一词时，实际上可能更广泛地指路径依赖。 • **人文因素**：[carom]对文章中的错别字表示高兴，认为这表明文章不是由LLM生成的，反映了对人工智能生成内容的某种不信任。 争议焦点： • **Google等大公司是否真正解决复杂问题**：[braza]和[gilbetron]质疑Google等大公司在某些实际领域中的复杂性处理能力，认为其面对的复杂性可能被夸大。 • **复杂性定义的模糊性**：[tunesmith]和[gilleain]等对复杂系统的定义和是否为封闭系统展开讨论，反映了复杂性在不同背景下的多样性。 通过这些观点，可以看出复杂性在不同领域和技术背景下的多样理解和应用，以及对实际工作中复杂系统处理能力的反思。

Lawful kinematics link eye movements to the limits of high-speed perception

作者: bookofjoe | 评分: 23 | 评论数: 3 | 发布时间: 2025-05-13 12:27
文章摘要

本文探讨了人类视知觉与快速眼动（ saccades ）之间的关联，特别是眼动引起的视网膜图像高速运动为何通常不被感知。研究通过高速度投影刺激模拟眼动期间的视网膜运动，并要求观察者识别这些运动轨迹。结果显示，刺激的可见性与眼动的运动学特性密切相关，包括速度、持续时间和幅度，且这种关系在个体间存在差异。计算模型进一步表明，早期视觉处理中的时空整合能够预测这种在生物学合理参数范围内的关联。这表明视觉系统在忽略眼动引起的附带感官影响时，保留了对高速物体运动的敏感性。研究揭示了眼动运动学如何限制高速度感知，强调了行动与感知之间的紧密联系。

评论摘要
