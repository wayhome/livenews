Ancient Roman Glass Reveals a Hidden "Language"

文章摘要

考古学家兼玻璃工匠Hallie Meredith在观察古罗马玻璃笼杯时，意外翻转杯体发现了长期被忽视的符号图案。通过系统研究4-6世纪的同类玻璃器，她发现这些十字、树叶和菱形等符号并非单纯装饰，而可能是古代工匠团体使用的视觉语言，类似"品牌标识"。未完成残片上的工具痕迹表明，这些需数年完成的精美作品由学徒、抛光师和雕刻师协作完成。这一发现颠覆了对古代工匠群体的传统认知，揭示了更多关于手工业组织的细节。相关研究成果已发表在《玻璃研究杂志》和《世界考古学》期刊上。

文章摘要

GitHut 是一个可视化分析 GitHub 上编程语言使用情况的平台。它通过 GitHub Archive 的数据，展示了不同语言的活跃度（按仓库活动量而非创建量统计），帮助开发者了解语言流行趋势。平台采用季度更新，数据来源于 GitHub API 和 Google BigQuery。由于很多仓库未标注语言类型，GitHut 选择以代码提交活动量作为主要评估指标。项目还参考了维基百科的编程语言年表，所有方法论和数据都在 GitHub 开源，采用知识共享许可协议。
