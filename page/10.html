How to Generate an API Key

作者: spy888 | 评分: 5 | 评论数: 0 | 发布时间: 2026-07-08 19:37
文章摘要

这篇文章讲述如何安全生成和管理API密钥。随着AI时代来临，2025年GitHub上暴露了2860万个密钥，同比增长34%。 **安全API密钥的核心要素：** 1. 使用加密安全随机数生成器产生128位随机数 2. 添加可识别前缀（如Stripe的`sk_live_`格式，包含类型和环境信息） 3. 仅存储SHA-256哈希值，密钥只显示一次 4. 区分可公开密钥（pk_，前端安全）和机密密钥（sk_，服务器端全权限） 文章以Stripe为蓝本，提供Node.js、Python和Go的实现代码，强调使用平台的CSPRNG而非`Math.random()`或UUID。16字节可产生128位熵值，提供3.4×10³⁸种可能组合，在常规计算条件下几乎无法暴力破解。
