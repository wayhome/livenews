Show HN: Keybench – Scriptable, extensible performance tool for key value stores

作者: alexpadula | 评分: 8 | 评论数: 0 | 发布时间: 2026-06-06 23:06
文章摘要

keybench 是一个可脚本化、可扩展的键值存储性能测试工具。用户用 Lua 编写工作负载，keybench 在一个或多个存储引擎上运行并测量每个操作的时间，报告吞吐量和延迟分布。它测量两个速率：工作负载单元数/秒（wu/s）和原始操作数/秒（ops/s），以及各操作类型的延迟分布（p50、p99、p99.9、最大值）。工具由五部分组成：引擎（负责并发）、工作负载（Lua 脚本）、存储接口（统一的8个操作）、后端插件（支持内存 skiplist、RocksDB、TidesDB 等）和报告器（控制台、TSV、时间线等输出格式）。默认构建仅需 C 编译器和 pthreads，可通过 make 参数添加持久化引擎支持。

First Commodore PET sold, June 5, 1977

文章摘要

这篇文章讲述了Commodore PET 2001个人电脑的历史。1977年6月5日，Commodore在消费电子展上接到首个经销商订单，成为"1977三巨头"（PET、Apple II、TRS-80）中最早销售的预装电脑之一。PET由6502处理器设计师Chuck Peddle主导开发，售价495美元，配备内置显示器、磁带录音机和4KB内存。值得注意的是，Commodore仅支付25,000美元就获得了微软BASIC的永久授权，这让微软后来非常后悔，因为该授权延续到了后来极为畅销的C-64和VIC-20。PET首年仅生产500台，供不应求。

评论摘要
主要讨论点：80年代个人计算机的怀旧回忆和存储设备的演进 不同观点： • fipar的经历：使用过TK-90X和TK-95（改进版Spectrum克隆机），在80年代编程课程中短暂接触过某款计算机。最近在山景城计算机历史博物馆重见这些设备时情绪激动，推荐参观该博物馆，特别提到了馆内运行中的IBM 1401和打孔卡体验 • mjcohen的经历：作为PET计算机早期用户，声称获得了西海岸第一台外置磁带驱动器，但使用次数很少。真正的技术飞跃是获得软盘驱动器后，认为"可以做任何事了" 补充讨论：两位评论者都在分享个人的计算机历史体验，但关注点不同——fipar侧重于怀旧情感和博物馆体验，mjcohen则强调存储技术升级带来的能力提升。两者没有直接争议，而是在各自讲述平行的回忆。

Fine-tuning an LLM to write docs like it's 1995

作者: taubek | 评分: 189 | 评论数: 25 | 发布时间: 2026-06-05 05:46
文章摘要

这篇文章讲述了作者尝试微调（fine-tuning）一个本地LLM，使其模仿90年代技术文档的写作风格。作者从Bitsavers网站下载了1977-2005年间的微软技术手册（超3700万字），经过清洗和分类后，生成了19万多个训练样例。由于缺乏从零训练模型的资金，作者选择了更经济的微调方法，使用Runpod租用GPU，采用QLoRA技术进行训练。微调通过在模型上添加"适配器"来改变其行为，而非直接修改模型权重。作者认为，相比RAG（检索增强生成）更适合事实检索，微调更擅长学习特定的写作风格。

评论摘要
主要讨论点：如何通过AI微调技术重现1990年代优质技术文档风格 不同观点： • **文档质量取决于深度而非AI技巧**（v1ne）：认为好文档需要深入理解和上下文知识，LLM无法替代。以佳能相机手册为例，现代文档充斥空洞内容和糟糕翻译，不如旧版本 • **旧文档优秀有历史原因**（kjellsbells）：发布速度慢给文档打磨留足时间；简洁性约束（如72x24屏幕限制）；作者、开发者、读者文化背景一致，沟通效率高。怀疑AI时代能否改善文档质量 • **LLM擅长遵循样式无需微调**（badsectoracula）：通过实例演示，给定1990年代MSDN风格示例后，普通LLM（如Devstral Small 2）即可生成高质量仿古文档，甚至处理自定义格式 • **LLM不适合长篇文档**（fga_qwrh）：LLM缺乏信息优先级和精简能力，只适合半页目标问答，长文本如"在糖浆中游泳" • **本地运行模型的硬件门槛**（mock-possum）：质疑作者提到的8B模型能在MacBook Air舒适运行，认为功能性本地模型需要强大硬件，成本是主要障碍 补充讨论：多位读者感谢作者介绍Bitsavers资源库；有开发者受启发制作Windows 98风格设计刊物；也有人寻求微调/RAG技术的入门教程
