Working with AI: Measuring the Occupational Implications of Generative AI

作者: nialse | 评分: 4 | 评论数: 1 | 发布时间: 2025-07-30 17:17
文章摘要

这篇文章分析了生成式AI对各类职业的潜在影响，重点研究了人们在与AI协作时所进行的工作活动、这些活动的成功程度和广泛性，以及它们在不同职业中的分布。研究使用了微软Bing Copilot的20万条匿名对话数据，发现人们最常寻求AI帮助的活动包括信息收集和写作，而AI最常执行的任务是提供信息、协助、写作、教学和建议。通过结合任务成功率和影响范围，研究计算了每个职业的AI适用性分数，发现知识型工作（如计算机和数学领域）以及涉及信息传递的职业（如销售）具有最高的AI适用性。文章还探讨了工作活动的成功性、工资与教育水平对AI适用性的影响，以及实际使用情况与职业AI影响预测的比较。

评论摘要
主要讨论点：人工智能对不同职业的影响 不同观点： • 第一种观点：人工智能将对某些职业产生重大影响，尤其是那些依赖语言处理和重复性任务的职业。支持这一观点的例子包括口译员、笔译员、作家和销售代表等职业，这些职业容易受到自动化技术的影响，因为它们的部分工作可以通过人工智能高效完成。 • 第二种观点：某些职业相对不容易受到人工智能的冲击，尤其是那些需要实际操作和面对面人际互动的职业。例子包括护理助理、采血员、危险材料处理工和油漆工助手等。这些职业需要手工技能或情感劳动，人工智能难以替代。 补充讨论： • 人工智能对职业的影响存在显著差异，具体取决于工作的性质和所需的技能。 • 争议的焦点在于哪些职业确实会受到影响，以及如何为可能被淘汰的职业工作者提供再培训和职业转型机会。 • 有人可能认为，即使某些职业的部分任务可以自动化，人类的创造力、判断力和情感共鸣仍然是不可替代的，因此完全替代的可能性较低。

文章摘要

这篇文章探讨了病毒感染与精神疾病（如精神分裂症（SCZ）和双相情感障碍（BPD））之间的关联，特别是通过研究脉络丛（CP）中的病毒RNA。研究使用来自Stanley Medical Research Institute的脑组织样本，对84例SCZ、73例BPD、23例重度抑郁症（MDD）和76例对照组进行了RNA测序。结果发现，SCZ和BPD患者的CP中更可能含有病毒序列，尤其是丙型肝炎病毒（HCV）。进一步分析显示，SCZ和BPD人群中的慢性HCV患病率显著高于MDD和对照组。尽管HCV未在 hippocampus 中发现，但其在CP中的存在与宿主转录变化相关，可能涉及先天免疫反应。这表明HCV感染可能与精神疾病的病理有关，而不仅是由静脉注射等行为引起。

评论摘要
主要讨论点：HCV（丙型肝炎病毒）与精神疾病（如精神分裂症和双相情感障碍）之间的关联及其因果关系 不同观点： • [_alternator_] 认为该研究揭示了HCV与精神疾病（如精神分裂症和双相情感障碍）之间的关联是真实的，但质疑HCV是否是这些疾病的因果因素。虽然HCV在脑部（脉络丛）中出现并可能引发局部免疫反应，但要得出“HCV导致精神分裂症和双相情感障碍”的结论仍存在较大跳跃。 • [hungmung] 提到治疗HCV的新药物可能引发躁狂发作，但目前尚不确定这种现象的具体原因。可能是药物本身导致，也可能是生活突然改变引发的反应，或者是由于身体不再需要对抗慢性感染而导致能量过剩，使人无法适应。 补充讨论： • [_alternator_] 强调了研究中的机制性证据有限，目前仅知道HCV会出现在脑部并引发免疫反应，但这不足以证明HCV是精神疾病的原因。 • [hungmung] 提出了治疗HCV的药物可能带来的精神健康副作用，这表明在治疗HCV时需要考虑其对精神健康的潜在影响。 争议焦点：HCV是否是精神分裂症和双相情感障碍的因果因素，以及治疗HCV的药物对精神健康的影响机制。这两个问题目前都缺乏足够的证据支持明确的结论。

**PR Quiz** 是一个 GitHub Action，利用 AI 根据 pull request 生成测验，帮助开发者检验对代码的理解。它要求用户拥有 OpenAI API Key 和 ngrok 认证 token，并在 GitHub 仓库中设置为 secrets。当 pull request 通过审核后，系统会触发测验生成，并在临时 web 服务器上通过 ngrok 提供访问。测验有时间限制和尝试次数限制，还可以排除特定文件。该工具确保代码不会发送给第三方，仅与 OpenAI 模型交互，也可修改为支持自托管模型。
