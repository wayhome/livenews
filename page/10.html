How to have the browser pick a contrasting color in CSS

作者: Kerrick | 评分: 253 | 评论数: 21 | 发布时间: 2025-05-17 16:26
文章摘要

文章介绍了CSS中一种新的功能`contrast-color()`，它可以让浏览器根据背景颜色自动选择黑色或白色作为对比鲜明的文本颜色。这种方法简化了在不同背景颜色下管理文本颜色的复杂性，特别适用于按钮等元素的设计。通过定义一个背景颜色变量，浏览器会自动选择合适的对比色，无需手动设置文本颜色。 不过，文章也提醒读者，虽然`contrast-color()`有助于自动选择对比色，但不保证完全符合无障碍标准。WCAG 2的对比度算法可能会选择数学上对比度高的颜色，而未必是视觉上最优的选择。因此，设计师和开发者仍需注意确保颜色组合的无障碍性。文章最后展示了在Safari技术预览版中的演示，并讨论了实际应用中的潜在问题。

评论摘要
主要讨论点：如何为不同背景色选择合适的对比前景色以满足无障碍设计标准（WCAG/ACPA），以及工具和算法在颜色选择中的应用。 不同观点： • seanwilson：介绍了一个工具（Inclusive Colors），可以自动生成具有WCAG/ACPA对比度的颜色对，并指出APCA算法在深色主题中更为严格，不建议使用WCAG。还提到手动设计调色板时需要考虑饱和度和色调的非线性变化。 • qfr：提出使用lch颜色空间来处理对比度问题，并提供了一个参考链接，展示如何在黑色和白色之间切换。 • jjcm：认为对于简单网站，自动对比色选择是可行的，但对于需要WCAG合规的大型项目，建议使用语义标记层，以加速开发并确保对比度。还分享了在Figma和Atlassian的实施经验。 • politelemon：质疑将对比色选择交给浏览器厂商是否合适，认为这不够可预测，更适合作为设计阶段的辅助工具。 • mediumsmart：指出在大型项目中管理颜色细节的难度，建议在项目早期进行检查和制定规则，并提到感知对比度和数学对比度的区别。 • econ：分享了过去使用系统颜色和计算对比度的经验，提到使用getComputedStyle和文本阴影的解决方案。 • jbritton：希望有针对伪类（如active, focus, hover, link, visited）的颜色组合建议，尤其是对于Material UI的额外状态。 • atum47：介绍了一个简单的视频教程，使用灰度转换来选择对比色，但承认其方法较为简化。 • rendaw：质疑此类工具的必要性，认为选择背景色和对比色应是基本能力，工具仅在团队 dysfunctional 时有用，且现有工具算法不够理想。 • andix：询问是否有在构建时使用的替代方案，如基于SASS或Tailwind的工具，并对未来各平台的实现一致性表示担忧。 • ZYbCRq22HbJ2y7：提供了一个未来可能解决此问题的规范草案链接。 • akkartik：分享了一个自制的小型浏览器项目，其中包含自动对比色选择工具，并在颜色空间上有所学习。 • naggie：手动使用Python和终端颜色实现类似功能，并提供博客链接。 • lancekey：提到过去使用YIQ值处理颜色对比的经验，并提供参考链接。 • Hyperlisk：分享了一个动态文本对比度的实现方法链接。 补充讨论： • 不同颜色空间（如lch、YIQ）在处理对比度问题上的应用。 • 对于自动对比色选择工具的实用性和必要性存在争议，部分用户认为手动选择和团队沟通更为重要。 • 提及未来可能的规范和标准，可能为当前问题提供更全面的解决方案。

研究人员发现了一段人类特有的基因片段（HARE5），当将其植入小鼠体内时，小鼠的大脑体积增加了约6.5%。这一基因片段能增强特定基因的表达，促进神经细胞的生成，从而扩大大脑外层。这项研究发表在《Nature》上，进一步揭示了人类大脑相比灵长类动物为何更大更复杂的部分原因。此前研究曾指出人类加速区域（HARs）可能与大脑发育有关，而HARE5正是其中之一，它在人类版本下能更有效地促进小鼠神经干细胞分裂和神经元生成。不过，目前尚不清楚大脑变大的小鼠是否在认知或记忆上有所提升。这项研究为理解人类大脑演化提供了新视角。

Popcorn: Run Elixir in WASM

作者: clessg | 评分: 138 | 评论数: 8 | 发布时间: 2025-05-15 17:14
文章摘要

Popcorn 是一个允许在浏览器中运行 Elixir 代码的库，通过客户端 AtomVM 运行时执行编译后的 Elixir 代码。它提供了 Elixir 与 JavaScript 互操作的 API，处理序列化、通信，并确保浏览器响应能力。本文介绍了三个使用 Popcorn 的示例：Elixir REPL、Elixir 文档交互片段和生命游戏模拟。 要使用 Popcorn，需将其作为依赖添加到 `mix.exs` 文件中，并运行 `mix deps.get`。接着，通过命令生成包含 Popcorn 库和 WASM 文件的目录，并在 HTML 中引入相关脚本。 Popcorn 通过消息传递实现 JS 和 Elixir 代码的交互。Elixir 端需要定义一个包含 `start/0` 函数的入口模块，并配置在 `config.ex` 文件中。完成 Elixir 初始化后，通过 `Wasm.send_elixir_ready/1` 通知 JS 端。 Popcorn API 提供了 `Popcorn.init(options)` 方法来初始化实例，并支持通过 `call` 和 `cast` 方法与 Elixir 进程通信。Elixir 端则使用 `Popcorn.Wasm` 模块处理与 JS 的通信。注意，该库仍在开发中，API 不稳定，部分功能未实现。
