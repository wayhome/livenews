Are OpenAI and Anthropic losing money on inference?

作者: martinald | 评分: 496 | 评论数: 62 | 发布时间: 2025-08-28 10:15
文章摘要

这篇文章通过粗略计算分析了大规模AI推理的成本结构。作者基于72块H100显卡（每小时144美元）的配置，以DeepSeek R1模型（670亿参数，370亿活跃参数）为基准，区分了输入处理和输出生成两个阶段的成本差异。 核心发现： 1. 输入处理成本极低（约0.001美元/百万token），因可并行处理 2. 输出生成成本较高（约3美元/百万token），需逐个token生成 3. 超长上下文（12.8万token以上）会因注意力计算使成本增加2-10倍 这解释了为何AI服务商会对长上下文窗口额外收费，以及Claude Code限制上下文长度的商业考量。

评论摘要
主要讨论点：[大型语言模型（LLM）推理成本的计算和商业模式是否可行] 不同观点： • 文章的计算有根本性错误：用户 chillee 指出文章中的数学计算错误，例如预填充（prefill）并非带宽限制，且假设的并发请求数和 GPU 配置不合理。此外，用户 qrios 提到内存传输速率是真正的瓶颈，而非计算本身。 • 推理成本的可盈利性：用户 _sword 和 simonw 提到推理可以带来高毛利率（50%+），但模型训练成本是否计入是关键。用户 pityJuke 和 simonw 引用 Sam Altman 的话，称如果不考虑训练成本，OpenAI 在推理上是盈利的。 • 现实中的低价 API 缺失：用户 noodletheworld 质疑，如果推理成本如此低，为何市场上没有更多低价 API 提供商？他认为现实情况与文章的计算不符。 • 模型的效率差异：用户 sc68cal 指出文章基于 DeepSeek R1 的假设不准确，因为 DeepSeek 在推理上非常高效，而 OpenAI 和 Anthropic 的模型可能不同。 • 商业模式类比：用户 JCM9 将 LLM 商业模式类比为房地产，指出忽略模型训练成本（类似建筑成本）是不合理的，认为当前模式不可持续。 补充讨论： • 用户 a333999 为文章辩护，认为文章标题已明确仅讨论推理成本，训练成本不在范围内，并批评其他评论过于苛刻。 • 用户 jonathan-adly 将 LLM 商业模式比作现代制造业，认为其毛利率可能介于特斯拉和纯软件公司之间，但仍具吸引力。 • 用户 moduspol 质疑文章是否考虑了硬件闲置成本，认为实际运营中的峰值和低谷会影响成本计算。 • 用户 KallDrexx 建议通过实际测试 DeepSeek R1 的推理能力来验证文章的计算，而非仅依赖理论假设。 争议焦点： • 是否应该将模型训练成本纳入推理成本的盈利计算中。 • 文章中的数学假设（如带宽、并发请求、GPU 配置）是否合理。 • 现实市场中低价 API 的缺失是否反驳了文章的低成本推理结论。

My startup banking story (2023)

作者: dvrp | 评分: 156 | 评论数: 25 | 发布时间: 2025-08-28 19:38
文章摘要

本文作者Mitchell Hashimoto分享了自己作为初创公司创始人选择银行的故事。22岁时他随意选择了大通银行开设公司账户，随后在获得多轮融资时都收到当初开户的银行职员Alex的电话问候，但他一直没在意。直到公司融资达3500万美元时，新任财务副总裁建议转投更懂初创企业的硅谷银行（SVB）。当Mitchell将全部资金转出后，Alex再次来电表示不满，但Mitchell坚持更换银行的决定。故事揭示了银行关系管理的重要性，以及创业者初期常会忽视的银行选择问题。

评论摘要
主要讨论点：[银行服务体验、银行系统缺陷、客户与银行的互动关系] 不同观点： • **作者mitchellh的观点**： - 使用Chase作为个人零售银行，因其便利性（ATM、Zelle等）。 - 大额资金流动触发Chase自动化系统的频繁电话，但银行人员无法理解其需求。 - 认为问题不在于Chase本身，而是银行系统的普遍行为。 • **批评Chase的观点**（heyflyguy、bdcravens等）： - Chase的服务和系统过于落后，导致客户体验极差。 - 例如：无故扣款且不解释（bdcravens的经历）。 - 认为Chase的“控制措施”繁琐且不人性化。 • **对银行系统普遍不满的观点**（josh2600、supportengineer等）： - 银行流程繁琐且不透明（如意大利银行关闭账户的困难经历）。 - 银行未能明确提供价值主张（如支持工程师的吐槽）。 • **对作者行为的质疑**（recursive、ungreased0675等）： - 作者未解释其行为的“错误”之处，导致读者困惑。 - 质疑为何初创公司将融资资金存入普通银行账户而非更专业的金融机构。 补充讨论： - **争议焦点**： - Chase的服务是否真的“问题不大”（作者观点）还是普遍存在缺陷（批评者观点）。 - 银行系统是否普遍缺乏灵活性和人性化（如jancsika提到的“社会纽带”缺失）。 - **其他讨论点**： - 初创公司在融资后应如何选择银行服务（holman、awl130的经验分享）。 - 银行对大额账户的管理是否合理（如作者与Alex的互动）。
