Show HN: Safe-NPM – only install packages that are +90 days old

作者: kevinslin | 评分: 74 | 评论数: 20 | 发布时间: 2025-11-23 22:14
文章摘要

这篇文章介绍了一个名为 `safe-npm` 的安全工具，旨在防止因 npm 包被恶意篡改而引发的供应链攻击。其主要功能包括： 1. **安全安装**：只安装发布超过设定天数（默认为90天）的 npm 包版本，降低使用近期被篡改包的风险。 2. **工作原理**：通过检查包的发布时间，筛选符合版本要求和安全时间要求的版本进行安装。 3. **使用方式**：支持全局安装或从源码构建，提供多种配置选项如最小天数、忽略特定包、严格模式等。 4. **应用场景**：适用于需要高安全性的生产环境或希望减少供应链攻击风险的开发场景。 该工具适合对安全性要求较高的开发者或团队使用。

评论摘要
主要讨论点：[关于限制安装新发布的NPM包以提高安全性的讨论] 不同观点： • **支持限制安装新包的观点**：如[zelphirkalt]认为，90天的冷却期可以减少安全风险，因为新包可能未被充分测试或存在漏洞。他建议结合版本固定和校验和来进一步提高安全性。 • **反对限制安装新包的观点**：如[ttoinou]指出，如果所有人都限制安装新包，可能会延迟发现和修复问题的时间。[asdkkthrowaway]也质疑这种做法是否会导致用户错过重要的安全补丁。 • **其他解决方案的讨论**：如[moritzwarhier]和[tkzed49]提到，pnpm已经内置了类似功能，并且建议固定依赖和禁用后安装脚本是更有效的解决方案。[spullara]则分享了自己的alias方法，限制安装一周内的新包。 补充讨论： • **争议焦点**：是否限制安装新包真的能提高安全性，还是仅仅延迟了问题的发现和修复。 • **其他讨论点**：如[PunchyHamster]提到，应该关注CVE修复的版本，而不是简单地限制安装新包。[codezero]则提出是否有统计数据支持新包更容易被攻击的观点。

How Does Microwaving Grapes Create Plumes of Plasma? (2019)

作者: wredcoll | 评分: 59 | 评论数: 8 | 发布时间: 2025-11-24 04:16
文章摘要

加拿大研究人员发现，将两颗葡萄或其他类似大小的水果放入微波炉加热会产生等离子体。这种现象是由于微波能量在两颗接触的葡萄之间的小空间内高度集中，形成强电场，从而电离原子释放电子。研究证实，葡萄不必切开，只要两颗接触就能产生等离子体，且最适合产生等离子体的物体大小与葡萄相近。这一发现揭示了日常现象背后的物理原理，但研究人员警告不要在家尝试，以免引发火灾。
