Different Clocks

作者: pppone | 评分: 215 | 评论数: 14 | 发布时间: 2025-07-28 19:05
文章摘要

Ianto Cannon创建的时钟图形使用JavaScript生成可缩放矢量图形（SVG），源代码可自由使用和修改。每个时钟显示当前的协调世界时（UTC），包括以下几种样式： 1. **Binary**：方块显示Unix时间，即自1970年以来的秒数，以32位整数表示。 2. **Polygons**：多边形显示时间，格式为yy:M:w:d:h:mm:ss，其中M是月份，w是当月第几周，d是星期几。 3. **Blobs**：左起第一个blob显示每千年波峰移动一次，后续blob分别显示每年的波峰、每天的波峰、每小时的波峰、每分钟的波峰和每秒的波峰，最后一个blob综合了所有六种波。 4. **Peaks**：最高峰每千年从右向左移动一次，依次递减至每分钟移动一次。 5. **Waves**：与Peaks类似，但使用贝塞尔曲线而非锐边。 © Ianto Cannon 2025年7月28日

文章摘要

"Wush Action" 是一个 GitHub Actions 工具，允许用户通过 SSH 进入 GitHub Actions 运行环境，像在本地机器上一样调试工作流。它通过 WireGuard 隧道在本地机器和 GitHub Actions runner 之间建立端到端加密连接，使用 x25519 密钥进行身份验证，无需依赖第三方认证或中继服务器。支持 Linux、Windows 和 macOS 平台。使用方法是在工作流中添加 `coder/wush-action@v1.0.0`，并在本地安装 Wush。若要无论任务成功与否都运行 Wush，建议使用 `${{ !cancelled() }}` 而非 `${{ always() }}`。
